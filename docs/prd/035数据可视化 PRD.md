**数据可视化 PRD**

**1. 产品定位**

数据可视化模块用于让用户在不编写 SQL 的情况下，基于已创建的数据集或临时上传的本地文件，通过拖拽字段、配置图表、设置筛选、排序、Top N、合计、百分比、同环比、表计算等能力，生成可交互的数据图表，并支持查询历史、数据下载、查询配置、字段计算、标注、提示信息、自定义配色等完整分析闭环。

模块核心目标不是单纯“画图”，而是形成一套完整的自助式分析工作台：

1. 选择数据来源；
2. 选择维度、指标、日期、筛选条件；
3. 选择图表类型；
4. 配置字段、图表样式和分析规则；
5. 执行查询并渲染图表；
6. 支持下钻、联动、排序、Top N、同环比、表计算等分析行为；
7. 支持下载、查询历史、缓存、抽样、公告、标注、提示信息和配色管理。

**4. 数据源选择**

**4.1 查询数据集数据**

**4.1.1 入口**

用户进入可视化查询页面时，如果 URL 携带 datasetId，系统直接加载该数据集；否则展示数据集选择弹窗。

入口包括：

1. 数据集列表页点击“可视化查询”；
2. 可视化查询页面左侧字段列表顶部点击当前数据集名称；
3. 新建分析时选择数据集；
4. 查询历史恢复时自动加载历史数据集。

**4.1.2 数据集选择弹窗**

字段：

type DatasetOption = {

id: string;

name: string;

description?: string;

ownerName: string;

lastVisitedAt?: string;

updatedAt: string;

accessMode: "extract" | "direct";

fieldCount: number;

rowCount?: number;

permission: "view" | "edit" | "none";

};

交互逻辑：

1. 默认按最近访问排序；
2. 支持搜索数据集名称；
3. 仅展示当前用户有查看权限的数据集；
4. 点击数据集行后，右侧展示数据集详情；
5. 点击“确定”后切换当前数据集；
6. 如果当前页面已有字段配置，切换数据集时弹出确认框：
   * “切换后将清空当前字段配置、筛选、图表配置和分析设置，是否继续？”
7. 用户确认后：
   * 清空当前 fieldSlots；
   * 清空 filters；
   * 清空 analysis；
   * 重置图表为默认表格；
   * 加载新数据集字段；
   * 记录最近访问。

**4.1.3 空状态**

无数据集权限时：

暂无可查询的数据集，请联系管理员授权或先创建数据集。

数据集加载失败时：

数据集加载失败，请稍后重试。

**4.2 查询本地文件数据**

**4.2.1 入口**

图表预览区空状态展示：

拖拽 CSV / Excel 文件到此处，或点击上传本地文件进行临时分析

**4.2.2 文件限制**

支持格式：

.csv

.xlsx

.xls

限制：

单文件最大 500MB

校验规则：

function validateLocalFile(file: File) {

if (!["csv", "xlsx", "xls"].includes(ext)) throw "仅支持 CSV / Excel 文件";

if (file.size > 500 \* 1024 \* 1024) throw "文件大小不能超过 500MB";

}

**4.2.3 上传流程**

1. 用户点击上传或拖拽文件；
2. 前端校验格式和大小；
3. 上传文件；
4. 后端解析字段名、字段类型、前 100 行预览；
5. 生成临时数据集；
6. 返回 tempDatasetId；
7. 前端将数据源切换为 local\_file；
8. 字段列表展示解析后的字段；
9. 默认生成表格预览。

**4.2.4 本地文件字段识别**

字段类型识别规则：

if all sample values can parse as number => number

else if all sample values can parse as date/datetime => date/datetime

else string

当字段类型识别不准确时，用户可在字段配置中手动转换维度 / 指标或修改日期类型。

**4.2.5 临时数据生命周期**

type TempDataset = {

};

function canDrop(field, targetSlot, chartType) {

4. 如果槽位达到上限，提示：

当前图表该区域已达到字段数量上限

**6.3 表达式编辑器**

表达式编辑器需要支持：

1. 字段插入；
2. 函数搜索；
3. 函数说明；
4. 语法高亮；
5. 括号匹配；
6. 表达式校验；
7. 预览计算结果。

字段引用格式建议：

[字段展示名]

后端转换为真实字段名。

**6.3.1 表达式校验**

校验维度：

type ExpressionValidationResult = {

valid: boolean;

dataType?: FieldDataType;

errorMessage?: string;

position?: {

line: number;

column: number;

};

};

校验规则：

1. 字段必须存在；
2. 函数必须存在；
3. 聚合函数不能嵌套非法聚合；
4. 指标字段表达式如果包含聚合函数，则后续不允许再修改聚合方式；
5. 日期函数返回日期类型；
6. LOD 表达式必须符合 LOD 语法；
7. 表计算函数只能作为指标使用。

**6.3.2 常用函数分类**

函数面板按以下分类：

聚合函数：count、count distinct、sum、avg、max、min

数值函数：abs、round、ceil、floor

文本函数：concat、substring、replace、length、extractAll

日期函数：toDate、toStartOfMonth、dateDiff、now

条件函数：if、multiIf、case when

数组函数：arrayJoin、length

LOD 函数：fixed、include、exclude

表计算函数：TOTAL、RUNNING\_SUM、RANK、LOOKUP

函数插入逻辑：

insertFunction("sum") => "sum([字段])"

insertFunction("if") => "if(条件, 真值, 假值)"

**7. 字段值别名**

**7.1 功能说明**

字段值别名用于将维度字段中的实际值映射为更易理解的展示值。

示例：

010 -> 北京

020 -> 广州

CN -> China

US -> United States

**7.2 入口**

维度字段右侧 More 菜单：

字段值别名

**7.3 权限**

1. 数据集字段设置别名，需要数据集编辑权限；
2. 个人字段设置别名，仅本人可操作；
3. 指标字段不支持字段值别名；
4. 参数字段不支持字段值别名。

**7.4 别名配置方式**

支持两种方式：

type AliasConfig =

| {

mode: "manual";

mappings: {

rawValue: string;

aliasValue: string;

}[];

}

| {

mode: "bind\_field";

sourceFieldId: string;

aliasFieldId: string;

};

**7.5 手动设置别名**

交互流程：

1. 点击“字段值别名”；
2. 弹窗展示当前字段值列表；
3. 每一行包含：
   * 原始值；
   * 别名输入框；
4. 用户输入别名；
5. 点击保存；
6. 保存后图表展示使用别名，但查询计算仍使用原始值。

校验：

1. 原始值不能为空；
2. 别名可以为空，空时展示原始值；
3. 同一原始值只能配置一个别名；
4. 允许多个原始值映射到同一个别名。

**7.6 绑定字段设置别名**

适用场景：

城市编码字段 city\_code 绑定城市名称字段 city\_name

交互：

1. 选择“绑定其他字段”；
2. 选择当前字段作为原始值字段；
3. 选择另一个维度字段作为别名字段；
4. 保存。

后端查询时需要构造映射关系：

SELECT DISTINCT city\_code, city\_name FROM dataset

如果一个原始值对应多个别名：

默认取出现频次最高的别名；如果频次相同，取字典序最小值。

**8. 维度创建层级**

**8.1 功能说明**

层级用于表达有上下级关系的维度，例如：

国家 - 省份 - 城市 - 区县

公司 - 部门 - 小组 - 员工

层级用于图表上钻、下钻和多层级展示。

**8.2 创建层级**

入口：

维度字段右侧 More 菜单：

创建层级

字段结构：

type HierarchyConfig = {

id: string;

name: string;

datasetId: string;

fields: {

fieldId: string;

level: number;

}[];

};

交互流程：

1. 用户点击某个维度字段的“创建层级”；
2. 弹窗打开；
3. 默认将当前字段作为第一级；
4. 用户输入层级名称；
5. 用户从字段列表中添加其他维度；
6. 支持拖拽调整层级顺序；
7. 点击确定；
8. 字段列表中新增层级结构节点；
9. 层级节点展开后显示内部字段。

校验：

1. 层级名称必填；
2. 至少包含 2 个维度字段；
3. 不允许加入指标字段；
4. 同一层级中同一个字段不能重复；
5. 层级字段必须属于同一数据集。

**8.3 图表下钻逻辑**

当图表使用层级字段时：

type DrillState = {

hierarchyId: string;

currentLevel: number;

path: {

fieldId: string;

value: string;

}[];

};

下钻：

1. 用户点击图表中某个维度项；
2. 如果当前层级还有下一层，系统追加筛选条件；
3. 当前展示维度切换为下一层字段；
4. 面包屑展示路径。

上钻：

1. 用户点击面包屑上一级；
2. 移除后续路径筛选；
3. 展示对应层级字段。

**9. 维度 / 指标创建组**

**9.1 功能说明**

创建组用于将字段值重新分组，生成新的字段。

常见场景：

国家 -> 洲

售价 -> 价格区间

年龄 -> 年龄段

**9.2 文本维度分组**

结构：

type TextGroupConfig = {

mode: "text\_group";

sourceFieldId: string;

newFieldName: string;

groups: {

groupName: string;

values: string[];

}[];

unmatchedStrategy: "keep\_original" | "set\_null" | "set\_other";

otherGroupName?: string;

};

交互：

1. 用户选择维度字段；
2. 点击“创建组”；
3. 输入新字段名称；
4. 选择分组方式为“手动分组”；
5. 左侧展示所有字段值；
6. 用户新建组；
7. 将字段值拖入组；
8. 未分组字段按策略处理；
9. 保存后生成新的维度字段。

校验：

1. 新字段名称必填；
2. 至少创建一个组；
3. 同一字段值只能属于一个组；
4. 组名不能为空；
5. 组名不能重复。

查询转换：

CASE

WHEN country IN ('中国', '日本', '韩国') THEN '亚洲'

WHEN country IN ('法国', '德国') THEN '欧洲'

ELSE '其他'

END

**9.3 数值指标分箱**

结构：

type NumericBinConfig = {

mode: "numeric\_bin";

sourceFieldId: string;

newFieldName: string;

bins: {

name: string;

min?: number;

max?: number;

includeMin: boolean;

includeMax: boolean;

}[];

unmatchedStrategy: "set\_null" | "set\_other";

};

交互：

1. 用户选择数值字段；
2. 点击“创建组”；
3. 选择“数值区间”；
4. 添加区间；
5. 保存后生成新的维度字段。

校验：

1. 区间不能重叠；
2. min 必须小于 max；

**16.3 查询校验**

function validateBeforeQuery(state) {

validateChartSlots(state.chart.type, state.fieldSlots);

validateFilters(state.filters);

validateAnalysis(state.analysis);

}

校验失败时不请求后端，直接显示错误。

**16.4 SQL 编译逻辑**

伪代码：

function compileQuery(state: VisualQueryState) {

const selectDims = buildDimensions(state.fieldSlots);

const selectMeasures = buildMeasures(state.fieldSlots);

const where = buildWhereFilters(state.filters);

const groupBy = selectDims;

const having = buildMetricResultFilters(state.filters);

const orderBy = buildSort(state.analysis.sort);

const limit = state.queryConfig.limit;

return {

select: [...selectDims, ...selectMeasures],

from: state.source.datasetId,

where,

groupBy,

having,

orderBy,

limit

};

}

鼠标悬停图表数据区域时展示 tooltip。默认展示维度和指标信息，用户可自定义内容，也可插入相关图表。

**22.2 配置**

type TooltipConfig = {

enabled: boolean;

trigger: "dimension" | "item" | "measure";

displayFields: string[];

customText?: string;

linkedChartIds?: string[];

};

**22.3 触发方式**

以柱状图为例：

1. 维度触发：鼠标移动到某一维度区域时显示；
2. 指标触发：鼠标移动到某个柱体时显示；
3. 项触发：鼠标移动到具体数据项时显示。

**22.4 内容配置**

支持：

1. 默认字段；
2. 自定义字段；
3. 自定义文本；
4. 插入关联图表。

插入图表逻辑：

1. tooltip 展示时获取当前数据点上下文；
2. 将上下文作为筛选条件传给关联图表；
3. 关联图表执行轻量查询；
4. 在 tooltip 内展示小图表。

**23. 自定义配色方案**

**23.1 功能说明**

用户可创建团队或业务统一配色方案，并应用于图表。

**23.2 数据结构**

type PaletteConfig = {

id: string;

name: string;

colors: string[];

scope: "personal" | "workspace";

createdBy: string;

updatedAt: string;

};

**23.3 创建配色方案**

流程：

1. 进入配色方案管理；
2. 点击新增；
3. 输入方案名称；
4. 添加颜色；
5. 保存。

校验：

1. 名称不能为空；
2. 至少包含 1 个颜色；
3. 颜色必须是合法 HEX；
4. 同一作用域下名称不能重复。

**23.4 应用配色**

图表颜色配置中选择配色方案。

应用逻辑：

seriesColor = palette.colors[index % palette.colors.length]

**24. LOD 表达式**

**24.1 功能说明**

LOD 用于在一个可视化视图中处理不同聚合粒度的问题。

适用场景：

当前图表按城市展示，但需要计算省份总额

当前图表按商品展示，但需要计算全局平均值

**24.2 表达式结构**

建议支持：

{ FIXED [维度] : 聚合表达式 }

{ INCLUDE [维度] : 聚合表达式 }

{ EXCLUDE [维度] : 聚合表达式 }

**24.3 语义**

**FIXED**

固定在指定维度粒度计算，不受当前视图维度影响。

**INCLUDE**

在当前视图维度基础上增加指定维度后计算。

**EXCLUDE**

从当前视图维度中排除指定维度后计算。

**24.4 校验**

1. LOD 内必须包含聚合表达式；
2. LOD 维度必须存在；
3. LOD 表达式只能生成指标；
4. 不允许非法嵌套 LOD。

**28. 验收标准**

**28.1 数据源**

1. 用户可以选择已有数据集进行可视化查询；
2. 用户可以切换数据集，切换后清空旧配置；
3. 用户可以上传 CSV / Excel 临时查询；
4. 超过 500MB 或格式不支持时阻止上传。

**28.2 字段**

1. 字段可以拖入维度、指标、筛选等槽位；
2. 不兼容字段不能拖入对应槽位；
3. 可以添加计算字段；
4. 表达式错误时必须明确提示；
5. 可以配置字段别名、分组、层级、地理角色。

**28.3 筛选**

1. 维度筛选支持精确、条件、手动输入、子查询；
2. 指标筛选支持结果筛选和明细筛选；
3. 日期筛选支持动态日期和固定日期；
4. 组合筛选支持多层 AND / OR；
5. 级联筛选不能形成循环依赖。

**28.4 图表**

1. 所有图表类型可以在图表面板选择；
2. 图表切换时自动校验字段槽位；
3. 字段不足时显示明确空状态；
4. 查询成功后正确渲染；
5. 查询失败后显示错误信息。

**28.5 分析能力**

1. 排序支持升序、降序、手动排序；
2. Top N 可正确截取前 / 后 N；
3. 合计可按全量数据或当前展示数据计算；
4. 百分比可生成衍生指标；
5. 同环比公式正确；
6. 表计算按区域和寻址方向正确计算；
7. 参考线不影响原始查询结果。

**28.6 查询辅助**

1. 查询历史可查看、恢复；
2. 数据可下载为 CSV、XLSX、图片；
3. 缓存开启时相同查询命中缓存；
4. 抽样开启时图表显示抽样提示；
5. 公告可配置、展示、关闭。

**28.7 图表增强**

1. 用户可添加数据点标注和时间段标注；
2. 标注卡片可拖动、编辑、删除；
3. tooltip 可开关、切换触发方式、配置展示字段；
4. 自定义配色方案可创建、保存、应用。

**29. Codex 开发落地原则**

开发时必须遵守以下原则：

1. 所有图表必须走 chartRegistry，不能为每个图表写散落的硬编码逻辑；
2. 所有查询状态必须收敛到 VisualQueryState；
3. 字段槽位校验必须由图表定义驱动；
4. 筛选必须统一编译为结构化查询条件，再由后端转换 SQL；
5. 表计算、百分比、参考线等分析能力不得污染原始查询结果；
6. 下载、查询历史、公告、配色、标注必须以独立配置实体保存；
7. 图表渲染失败不能导致页面崩溃，必须进入错误态；
8. 所有字段配置变更后必须重新校验当前图表；
9. 本地文件数据必须视为临时数据源，不可默认持久化；
10. 权限不足时必须在入口层禁用操作，而不是等提交时报错。
