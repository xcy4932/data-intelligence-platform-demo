**数据集管理 PRD**

**1. 产品定位**

**1.1 功能目标**

数据集管理模块用于在数据集创建完成后，对数据集进行查看、预览、维护、权限控制、血缘追踪、影响分析、跨项目复用和运维管理。

本模块不是数据集创建编辑器，而是数据集创建后的统一管理中心。用户进入某个数据集详情页后，可以完成以下操作：

1. 查看数据集基本信息。
2. 查看明细数据抽样预览。
3. 查看和维护表结构字段。
4. 查看同步状态、同步日志、同步任务历史。
5. 对同步实例进行单实例重跑或批量同步。
6. 查看模型信息，包括模型构成、筛选条件、性能配置。
7. 查看血缘视图，识别上游来源和下游影响资源。
8. 删除数据集或修改字段前进行影响分析。
9. 通过 Excel 批量修改字段配置。
10. 配置跨项目镜像数据集。
11. 配置数据行权限和列权限。
12. 转移数据集所有者。
13. 转移数据集告警人。
14. 为直连数据集配置数据就绪信息，支撑监控订阅场景。
15. 跳转到可视化查询，基于当前数据集直接分析。

**5. 数据预览**

**5.1 功能目标**

数据预览用于让用户快速了解数据集的数据格式和样例内容。预览结果是抽样数据，不作为精确查询结果。如果用户需要精确结果，应进入可视化查询或明细查询能力。

数据预览包含两个视图：

明细数据

表结构

dataset.permission.canPreviewData === true

**6. 表结构管理**

**6.1 功能目标**

表结构用于查看和维护数据集字段信息，包括字段名称、显示名称、字段类型、维度指标、字段表达式、备注、可见性、排序等。

表结构可以通过两种方式修改：

1. 页面上直接点击 修改字段。
2. 通过 Excel 批量修改字段。

**6.2 表结构展示**

表结构字段列表展示：

| **字段** | **说明** |
| --- | --- |
| 字段名称 | 系统内部字段名 |
| 显示名称 | 可视化查询中展示的名称 |
| 字段类型 | string、number、date 等 |
| 字段角色 | 维度、指标、时间、ID |

| 来源 | 原始字段、计算字段、镜像复制字段 |
| 操作 | 编辑、删除、影响分析 |

**6.3 搜索字段**

用户可在表结构页输入关键词搜索字段。

搜索范围：

1. 字段名称
2. 显示名称
3. 字段备注
4. 表达式

搜索规则：

输入关键词

→ debounce 300ms

→ 前端本地过滤当前字段列表

→ 如果字段数量超过 500，调用后端搜索接口

**6.4 修改字段入口**

点击 修改字段 后进入字段编辑态。

字段编辑态包含：

编辑态规则：

**6.5.2 保存校验**

| **校验项** | **规则** |
| --- | --- |
| 字段显示名 | 必填，长度 1 到 64 |
| 字段名称 | 不允许重复 |
| 表达式 | 计算字段必须合法 |
| 字段类型 | 表达式返回类型必须与字段类型兼容 |
| 引用关系 | 被下游图表使用的字段修改前触发影响分析 |
| 敏感列 | 敏感列修改需要重新计算列权限影响 |
| 镜像字段 | 镜像数据集不允许修改来源字段结构 |

**6.6 删除字段**

用户点击字段行的 删除。

流程：

点击删除字段

→ 判断字段类型

→ 判断字段是否被计算字段引用

→ 判断字段是否被行列权限规则引用

→ 判断字段是否被下游图表、仪表盘引用

→ 执行影响分析

→ 展示影响分析弹窗

→ 用户确认

→ 删除字段

→ 保存字段配置

禁止删除场景：

| **场景** | **处理** |
| --- | --- |
| 字段被 Join 条件引用 | 禁止删除 |
| 字段被行权限规则引用 | 禁止删除，需先删除权限规则 |
| 字段被列权限规则引用 | 禁止删除，需先删除列权限规则 |
| 字段被其他计算字段引用 | 禁止删除，需先删除依赖字段 |
| 主题数据集字段 | 禁止删除 |
| 镜像数据集原始字段 | 禁止删除 |

**7.5 Excel 修改规则**

**7.5.1 修改已有字段**

如果 field\_id 存在：

1. 系统识别为修改已有字段。
2. 可修改 display\_name、semantic\_type、description、visible、aggregation\_default、sort\_order。
3. 原始字段不允许修改 expression。
4. 计算字段允许修改 expression，但必须重新解析。
5. 字段名称原则上不建议修改；若允许修改，需要触发影响分析。

**7.5.2 新增字段**

如果 field\_id 为空且 operation=create：

1. 识别为新增计算字段。
2. field\_name、display\_name、field\_type、semantic\_type、expression 必填。
3. expression 必须合法。
4. 新增字段追加到字段列表末尾。
5. sort\_order 为空时自动生成最大 sort\_order + 1。

**7.5.3 删除字段**

如果 operation=delete：

1. 字段必须存在。
2. 原始字段默认不允许通过 Excel 删除，除非系统配置允许。
3. 计算字段可以删除。
4. 删除前必须执行影响分析。
5. 如果字段被权限规则、计算字段、图表引用，则上传校验阶段展示阻断错误或风险提示。

**7.6 上传后确认页**

上传校验通过后，展示字段变更对比表：

| **字段** | **原值** | **新值** | **变更类型** |
| --- | --- | --- | --- |
| 显示名称 | old | new | 修改 |
| 字段角色 | old | new | 修改 |
| 表达式 | old | new | 修改 |
| 新增字段 | -- | new | 新增 |
| 删除字段 | old | -- | 删除 |

用户点击 确认保存 后：

→ 后端再次校验版本号

→ 执行影响分析

**12.5 行权限：固定值**

**12.5.1 适用场景**

例如：

**12.5.2 配置结构**

type RowPermissionConfig = {

};

type RowPermissionCondition = {

fieldId: string;

fieldName: string;

operator:

| "="

| "!="

| "in"

| "not\_in"

| "contains"

| "not\_contains"

| "is\_null"

| "is\_not\_null";

fixedValue?: any;

fixedValueList?: any[];

userAttributeId?: string;

};

**12.5.3 固定值规则**

1. 用户选择数据集字段。
2. 用户选择操作符。
3. 用户输入固定值。
4. 系统将该条件追加到查询 SQL 的 WHERE 条件中。
5. 多个条件之间使用 AND。
6. 不支持 OR，避免权限规则过度复杂。
7. 字段被删除前必须检查是否被行权限引用。

**12.6 行权限：动态值**

**12.6.1 适用场景**

适用于用户数量多、权限范围与用户属性绑定的场景。

例如：

用户属性 region = 上海

则用户只能查看 dataset.region = 上海 的数据

**12.6.2 配置逻辑**

选择数据集字段

→ 选择匹配用户属性

→ 系统运行时读取当前登录用户属性值

→ 将字段值限制为用户属性值

动态值配置：

type DynamicRowPermissionCondition = {

datasetFieldId: string;

userAttributeId: string;

operator: "=" | "in";

};

**12.6.3 运行时逻辑**

查询执行前：

获取当前用户

→ 获取该用户属性

→ 查找命中的行权限规则

→ 将用户属性值转为 SQL 条件

→ 拼接到查询条件

→ 执行查询

如果用户属性为空：

| **生效范围配置** | **处理** |
| --- | --- |
| 未命中用户不可查看任何数据 | 返回空结果 |
| 未命中用户不受行权限控制 | 不追加该规则 |

适用成员：管理者

结果：

- 管理者可见收入字段

- 其他人不可见收入字段

**模式二：适用成员不可见，适用成员以外可见**

选择字段：内部成本

适用成员：外包人员

结果：

- 外包人员不可见内部成本

- 其他人可见内部成本

**12.7.4 派生字段影响**

如果敏感列被用于计算字段：

敏感字段：作业提交率

计算字段：是否达成提交率目标 = 作业提交率 >= 0.8

计算字段：平均提交率 = AVG(作业提交率)

则默认规则：

1. 基于敏感列创建的计算字段也受列权限影响。
2. 无权限用户看不到敏感列及其派生字段。
3. 如果不希望派生字段被隐藏，需要将具体数据集字段而不是模型字段设置为敏感列，并明确配置派生字段权限。

**12.8 多个行列权限规则的生效逻辑**

**12.8.1 多个行权限规则**

如果用户命中多个行权限规则：

推荐采用 OR 合并规则，即用户可查看任一规则授权的数据范围。

规则 A：province = 上海

规则 B：province = 北京

用户同时命中 A 和 B

最终可见：province in (上海, 北京)

如果同一个规则内有多个条件，则规则内使用 AND：

规则 A：

province = 上海

department = 销售

最终条件：

province = 上海 AND department = 销售

最终行权限表达式：

(rule\_1\_condition\_1 AND rule\_1\_condition\_2)

OR

(rule\_2\_condition\_1 AND rule\_2\_condition\_2)

**12.8.2 多个列权限规则**

列权限合并时，需要以更严格的可见性为准。

推荐规则：

1. 如果任何规则明确禁止用户查看某字段，则该字段不可见。
2. 如果规则是白名单模式，用户必须命中可见成员才能查看字段。
3. 如果字段没有被任何列权限规则控制，则默认可见。
4. 数据集管理员和项目全局查看权限用户可按系统管理策略豁免。

**12.9 未命中规则用户的生效范围**

系统提供开关：

type DataPermissionScopeConfig = {

rowPermissionUnmatchedUserPolicy:

| "deny\_all\_rows"

| "allow\_all\_rows";

columnPermissionUnmatchedUserPolicy:

| "deny\_sensitive\_columns"

| "allow\_all\_columns";

};

默认建议：

rowPermissionUnmatchedUserPolicy = "deny\_all\_rows";

即未被行权限规则命中的用户无法查看任何数据。

页面提示：

当前设置下，未被行权限规则命中的用户将无法查看任何行数据。请确认该规则符合业务预期。

**12.10.1 功能目标**

**13. 镜像数据集与跨项目配置**

**13.1 功能目标**

原项目：被引用数据集所在项目

被引用数据集：真实数据集，负责建模、同步、运维

新项目：被授权使用该数据集的项目

镜像数据集：在新项目中展示的镜像对象

→ 系统执行影响分析

→ 检查目标项目中镜像数据集下游图表/仪表盘

→ 展示影响分析弹窗

→ 用户确认

→ 关闭镜像连接

→ 目标项目数据集列表不再展示该镜像数据集

如果目标项目已有基于镜像数据集创建的图表或仪表盘：

1. 影响分析必须展示这些资源。
2. 关闭后相关图表可能不可用。
3. 高风险时需要二次确认。

**13.7 镜像数据集使用权限**

新项目成员使用镜像数据集前，需要被原项目被引用数据集管理员授权。

权限规则：

1. 镜像数据集在新项目可搜索、可查看。
2. 用户是否能查询镜像数据，取决于原始数据集授权。
3. 目标项目管理员不能直接修改镜像数据集权限的底层数据范围。
4. 目标项目内图表和仪表盘使用镜像数据集时，仍按原始数据集授权规则执行。

**13.8 镜像数据集管理限制**

镜像数据集在新项目内不支持：

1. 编辑数据模型。
2. 修改同步配置。
3. 数据运维。
4. 血缘管理。
5. 删除原始数据。
6. 转移所有者。
7. 修改跨项目配置。

镜像数据集在新项目内支持：

1. 查看数据集。
2. 使用数据集创建图表。
3. 使用数据集创建仪表盘。
4. 查看表结构。
5. 在允许范围内添加字段或批量修改字段。
6. 查看镜像来源信息。

如果用户点击不支持的操作：

该数据集为镜像数据集，请前往原项目的被引用数据集进行管理。

**16. 直连数据集数据就绪配置**

**16.1 功能目标**

直连数据集没有同步任务，但下游监控订阅需要知道数据何时已经准备好。数据就绪配置用于告诉系统：某个直连数据集依赖的上游库表在哪个业务日期已经完成产出。

这样，基于直连数据集创建的图表和仪表盘在监控订阅中，可以选择 数据完成同步时触发，避免数据尚未就绪就发送订阅通知。

**16.2 入口**

直连数据集详情页

→ 更多

→ 数据就绪配置

显示条件：

dataset.sourceMode === "direct"

&& dataset.permission.canEditDataset === true

**16.3 配置前提**

用户需要先准备一个用于记录数据就绪状态的数据集。

该数据集至少包含：

| **字段** | **说明** |
| --- | --- |
| database\_name | 上游数据库名称 |
| table\_name | 上游数据表名称 |
| ready\_date | 数据就绪业务日期 |
| ready\_status | 是否就绪 |
| ready\_time | 实际就绪时间 |

字段名称不强制固定，用户可以在配置中映射。

**16.4 配置弹窗**

数据就绪配置

├── 当前直连数据集上游库表信息

├── 选择数据就绪信息数据集

├── 字段映射

│ ├── 数据库名称字段

│ ├── 数据表名称字段

│ ├── 数据就绪日期字段

│ ├── 就绪状态字段

│ └── 就绪时间字段

├── 校验

└── 保存

**16.6 校验逻辑**

点击保存前：

1. 必须选择数据就绪信息数据集。
2. 必须映射数据库名称字段。
3. 必须映射数据表名称字段。
4. 必须映射数据就绪日期字段。
5. 如果选择状态字段，则必须配置 readyStatusRule。
6. ready\_date 字段必须是 date、datetime 或 string 可解析日期。
7. 当前直连数据集的上游库表必须至少有一项能在就绪信息数据集中匹配。
8. 如果没有匹配样例，提示用户确认是否仍保存。

**16.7 监控订阅触发逻辑**

当基于该直连数据集的图表配置监控订阅，并选择 数据完成同步时触发：

到达订阅检测时间

→ 判断图表依赖的数据集是否为直连数据集

→ 判断直连数据集是否配置数据就绪信息

→ 查询就绪信息数据集

→ 判断当前业务日期依赖表是否全部就绪

→ 全部就绪

→ 执行图表查询

→ 发送订阅通知

→ 未就绪

→ 等待下一次检测

→ 超过最大等待时间

→ 按订阅配置处理，发送失败提醒或跳过

**20. 验收标准**

**20.1 数据集详情**

1. 用户点击数据集后可以进入详情页。
2. 详情页展示所有者、最近同步时间、数据集大小、访问热度。
3. 不同权限用户看到的操作按钮不同。
4. 主题数据集、镜像数据集、普通数据集的操作差异正确。
5. 无权限用户无法查看数据预览或敏感字段。

**20.2 数据预览**

1. 明细数据可以正常抽样展示。
2. 表结构可以正常展示字段。
3. 支持字段搜索。
4. 支持指定筛选条件预览目标数据。
5. 行列权限对预览结果生效。
6. 同步失败无数据时展示合理空状态。
7. 直连数据集预览实时查询。

**20.3 表结构与 Excel 批量修改**

1. 用户可以进入字段编辑态。
2. 用户可以修改字段显示名、维度指标、备注、可见性。
3. 用户可以下载字段 Excel 模板。
4. 用户可以上传修改后的 Excel。
5. 系统能识别新增、修改、删除字段。
6. Excel 校验错误能定位到行和列。
7. 删除或高风险修改字段前触发影响分析。
8. 保存成功后可视化查询字段列表同步更新。

**20.4 同步状态**

1. 抽取数据集展示同步状态 Tab。
2. 直连数据集不展示同步任务列表。
3. 用户可以按业务日期、状态、数据结果为 0 筛选任务。
4. 用户可以查看同步日志。
5. 用户可以单实例重新同步。
6. 用户可以批量同步数据。
7. 运行中任务不能重复提交。
8. 无权限用户不能触发同步。

**20.5 模型信息**

1. 用户可以查看模型构成。
2. 用户可以查看 Join、Union、筛选条件。
3. 用户点击模型节点可以查看字段信息。
4. 模型信息页为只读。
5. 字段异常、权限异常能正确标识。

**20.6 血缘视图**

1. 用户可以查看上游和下游资源。
2. 下游支持仪表盘、图表、数据集、可视化建模、大屏。
3. 用户可以查看近 30 天引用和访问情况。
4. 用户可以点击访问统计跳转详情。
5. 用户可以下载血缘信息。
6. 无权限资源需要脱敏或提示无权限。

**20.7 影响分析**

1. 删除数据集前必须触发影响分析。
2. 删除或修改字段前必须触发影响分析。
3. 影响分析展示下游图表、仪表盘、大屏、保存分析等资源。
4. 影响分析展示近 30 天访问总数。
5. 支持查看血缘详情。
6. 高风险操作需要二次确认。

**20.8 数据行列权限**

1. 数据集管理员可以添加行权限规则。
2. 行权限支持固定值。
3. 行权限支持动态用户属性。
4. 数据集管理员可以添加列权限规则。
5. 列权限对敏感列生效。
6. 基于敏感列创建的派生字段默认受影响。
7. 多个行权限规则能正确合并。
8. 未命中规则用户按默认策略无法查看任何数据。
9. 权限模拟验证可以模拟指定用户的数据可见范围。
10. 行列权限在预览、可视化查询、图表、仪表盘和筛选器中均生效。

**20.9 镜像数据集**

1. 原项目管理员可以配置跨项目镜像。
2. 目标项目可以看到镜像数据集。
3. 镜像数据集不复制物理数据。
4. 镜像数据集不复制原数据集权限配置。
5. 镜像数据集不允许在目标项目内编辑和运维。
6. 目标项目成员使用镜像数据集需要原始数据集授权。
7. 关闭镜像连接前触发影响分析。
8. 开启使用通知后，目标项目成员创建图表或仪表盘时通知管理员。

**20.10 转移所有者与告警人**

1. 用户可以转移数据集所有者。
2. 新所有者必须是有效项目成员。
3. 转移所有者时，相关告警所有者同步转移。
4. 用户可以单独转移告警人。
5. 转移操作写入操作日志。
6. 转移后页面基础信息刷新。

**20.11 直连数据集数据就绪配置**

1. 直连数据集支持数据就绪配置入口。
2. 用户可以选择数据就绪信息数据集。
3. 用户可以映射数据库名称、数据表名称、就绪日期等字段。
4. 保存前进行字段和样例匹配校验。
5. 监控订阅可以基于直连数据集数据就绪状态触发。
6. 未配置就绪信息时，不允许选择或无法正常使用 数据完成同步时触发。
