版本：v3.0

**1. 模块定位**

**1.1 产品定位**

事件分析模块是平台中的**用户行为分析工作台**。

它的核心不是展示固定报表，而是让用户通过配置事件、指标、筛选、分组和图表，完成一次完整的行为分析过程。

本模块需要回答：

某个用户行为发生了多少？

哪些用户发生了？

不同维度下有什么差异？

指标为什么波动？

异常主要由哪些维度贡献？

能否进一步查看受影响用户？

能否把分析结果沉淀到看板、用户分群或后续运营动作？

**1.2 本 Demo 的业务主线**

本 Demo 不做泛泛的“万能分析器”，而是围绕一个具体场景做深：

广告观看次数为什么下降？

完整业务链路：

进入事件分析

↓

加载广告观看下降分析模板

↓

查看默认事件指标

↓

调整指标、筛选、分组、对照组

↓

点击开始分析

↓

查看指标卡、趋势图、贡献度图、明细表

↓

点击趋势图异常点

↓

进入异常诊断

↓

查看贡献维度

↓

点击明细数据查看受影响用户

↓

保留保存分群 / 创建运营任务 / 创建 A/B 实验按钮入口

**1.3 设计原则**

| **原则** | **说明** |
| --- | --- |
| 真实分析产品逻辑优先 | 不做静态卡片，而是做“配置 → 查询 → 结果 → 诊断 → 下钻”的流程 |
| 默认模板驱动 | 进入页面默认加载“广告观看下降分析模板”，避免空白页面 |
| 火山能力完整吸收 | 事件指标、自定义指标、公式指标、细分筛选、属性分组、异常诊断、保存看板均要体现 |
| 神策交互能力补充 | 指标复制、重命名、拖拽排序、用户详情、分组值筛选等能力要吸收 |
| Demo 可分期实现 | 产品逻辑完整设计，但工程可按阶段开发 |
| 下游动作先做入口 | 保存分群、运营任务、A/B 测试本阶段只做按钮和提示，不展开完整流程 |

**6. 功能点 3：自定义指标与完整公式编辑器**

**6.1 功能目标**

支持用户基于已有事件指标、计算条件、常数和运算符，构建复合指标。

典型指标：

广告完成率 = 广告观看完成次数 / 广告开始播放次数

广告点击率 = 广告点击次数 / 广告入口曝光次数

广告收益效率 = 广告收益 / 广告观看人数

各广告位广告观看人数占比 = 分组广告观看人数 / 全部广告观看人数

火山文档中自定义指标支持基于常规指标做四则运算，支持 +、-、\*、/、括号，括号仅支持一层；并支持选择精度和单位，以及是否同时展示原子指标。公式指标相比自定义指标更灵活，还支持设置各计算条件是否参与分组。

**6.2 入口位置**

左侧指标配置卡片：

+ 自定义指标

+ 公式指标

**6.3 自定义指标与公式指标区别**

| **类型** | **作用** | **是否参与分组控制** | **示例** |
| --- | --- | --- | --- |
| 自定义指标 | 已有指标之间四则运算 | 否 | 广告完成率 |
| 公式指标 | 每个计算条件可设置是否参与分组 | 是 | 各广告位访问用户占比 |

Demo 中两者使用同一个公式编辑器，但公式指标额外展示“是否参与分组”。

**1. 模块定位**

**1.1 产品定位**

事件分析模块是平台中的**用户行为分析工作台**。

它的核心不是展示固定报表，而是让用户通过配置事件、指标、筛选、分组和图表，完成一次完整的行为分析过程。

本模块需要回答：

某个用户行为发生了多少？

哪些用户发生了？

不同维度下有什么差异？

指标为什么波动？

异常主要由哪些维度贡献？

能否进一步查看受影响用户？

能否把分析结果沉淀到看板、用户分群或后续运营动作？

**1.2 本 Demo 的业务主线**

本 Demo 不做泛泛的“万能分析器”，而是围绕一个具体场景做深：

广告观看次数为什么下降？

**5.8 指标算子**

**通用算子**

| **算子** | **名称** | **说明** |
| --- | --- | --- |
| PV | 总次数 | 事件发生次数 |
| UV | 触发用户数 | 触发事件的去重用户数 |
| PV\_UV | 人均次数 | 事件次数 / 触发用户数 |
| UV\_AU | 渗透率 | 触发用户数 / 活跃用户数 |

**数值属性算子**

| **算子** | **名称** | **说明** |
| --- | --- | --- |
| SUM | 求和 | 数值属性求和 |
| AVG | 平均值 | 数值属性平均值 |
| MAX | 最大值 | 数值属性最大值 |
| MIN | 最小值 | 数值属性最小值 |
| PER\_USER\_AVG | 人均值 | 数值属性总和 / 触发用户数 |
| PERCENTILE\_25 | 下四分位数 | P25 |
| PERCENTILE\_50 | 中位数 | P50 |
| PERCENTILE\_75 | 上四分位数 | P75 |
| PERCENTILE\_90 | P90 | P90 |

**去重算子**

| **算子** | **名称** | **说明** |
| --- | --- | --- |
| DISTINCT\_COUNT | 属性去重数 | 属性出现的去重个数 |
| DISTINCT\_USER\_PROPERTY | 属性与用户去重 | 用户维度下的属性去重 |

神策文档中对所有事件支持总次数、触发用户数、人均次数，并对数值型属性支持总和、均值、最大值、最小值、分位数等；火山文档也列出了 PV、UV、PV/UV、UV/AU、SUM、MAX、MIN、平均值、人均值、分位数、去重数等算子。

**5.9 算子联动规则**

| **用户选择** | **页面行为** |
| --- | --- |
| PV / UV / PV\_UV | 不显示属性选择器 |
| SUM / AVG / MAX / MIN / P90 | 必须显示数值属性选择器 |
| DISTINCT\_COUNT | 显示全部可去重属性 |
| UV\_AU | 提示分母为活跃用户数 |
| PER\_USER\_AVG | 必须选择数值属性 |

如果事件没有数值属性，则数值算子置灰。

Tooltip：

当前事件无数值型属性，无法使用该算子。

**6. 功能点 3：自定义指标与完整公式编辑器**

**6.1 功能目标**

支持用户基于已有事件指标、计算条件、常数和运算符，构建复合指标。

典型指标：

广告收益效率 = 广告收益 / 广告观看人数

各广告位广告观看人数占比 = 分组广告观看人数 / 全部广告观看人数

火山文档中自定义指标支持基于常规指标做四则运算，支持 +、-、\*、/、括号，括号仅支持一层；并支持选择精度和单位，以及是否同时展示原子指标。公式指标相比自定义指标更灵活，还支持设置各计算条件是否参与分组。

**功能点：图表类型切换与图表配置**

**1. 功能目标**

图表类型切换用于让用户根据不同分析目的，选择最适合的数据展示方式。

趋势变化 → 折线图

组成变化 → 堆叠图 / 累积图 / 百分比图

分组对比 → 柱形图

多指标不同量纲 → 双轴图

占比结构 → 环形图 / 饼图

核心指标概览 → 指标卡

明细校验 → 表格

累积图

表格

**7. 柱形图 / 柱状图**

火山文档中明确说明柱形图中 PV、UV、PV/UV、SUM、AVG、人均值、去重数、分位数等指标在时间区间内的计算方式。 神策文档中也说明所有查询场景均支持柱状图预览，且柱状图支持数值类型和百分比类型展示，多指标场景下支持设置横纵坐标轴。

**7.4 指标计算口径**

| **指标类型** | **柱形图计算规则** |

| PER\_USER\_AVG | 时间区间内属性总和 / 用户数 |

| PERCENTILE | 时间区间内按属性值计算分位数 |
| 自定义指标 | 按公式中的原子指标汇总后再计算 |
| 公式指标 | 按计算条件参与分组规则计算 |
