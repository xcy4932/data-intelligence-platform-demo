**数字大屏图表组件PRD**

**1. 文档定位**

本文定义数字大屏中的图表组件体系，覆盖图表组件的创建、数据绑定、字段映射、样式配置、动画配置、交互事件、渲染规则、异常处理、保存结构和验收标准。

本文不是“图表清单”，而是面向前端开发、后端接口、图表渲染器、Codex 代码生成的“产品功能逻辑级 PRD”。每个图表组件都需要按照统一组件协议接入数字大屏编辑器，同时保留各自图表类型的字段配置、样式配置和交互逻辑差异。

**2. 图表组件范围**

**2.1 本文覆盖图表组件**

| **一级分类** | **图表组件** |
| --- | --- |
| 指标展示类 | 指标卡、翻牌器、排行榜 |
| 表格类 | 表格 |
| 柱状图类 | 并列柱状图、堆叠柱状图、百分比柱状图 |
| 条形图类 | 并列条形图、堆叠条形图、百分比条形图、双向条形图 |
| 趋势类 | 折线图、面积图、百分比面积图 |
| 组合图类 | 双轴图 |
| 占比类 | 饼图、环形图、单值环形图、玫瑰图 |
| 分布关系类 | 散点图、圆视图、词云 |
| 流程转化类 | 漏斗图、桑基图 |
| 多维评估类 | 雷达图 |
| 进度状态类 | 仪表图、水波图 |

**2.2 本文暂不展开的图表组件**

中国地图、世界地图、GIS 地图归入“数字大屏地图/场景组件”子模块，不在本文展开。

**3. 图表组件产品定位**

图表组件用于把数据源中的维度、指标、日期字段映射为可视化图形，并在数字大屏中承担核心数据展示任务。

图表组件与默认组件不同：

| **对比项** | **默认组件** | **图表组件** |
| --- | --- | --- |
| 核心作用 | 展示文本、形状、媒体、容器、控件 | 展示数据分析结果 |
| 是否必须绑定数据 | 多数不需要 | 通常需要 |
| 是否有字段槽位 | 少量控件有 | 必须有 |
| 是否支持数据刷新 | 部分支持 | 全部支持 |
| 是否支持图元级交互 | 少量支持 | 大多数支持 |
| 是否内置静态数据 | 不一定 | 默认内置静态数据，方便拖入后立即可见 |

4. 右侧面板展示该图表的样式配置。
5. 底部查询栏展示该图表的数据配置。
6. 图表使用内置静态数据渲染默认效果。

8. 创建操作写入撤销栈。

**6.4 字段胶囊配置**

用户将字段拖入字段槽位后，字段以胶囊形式展示。点击字段胶囊左侧小三角，打开字段配置面板。

字段胶囊配置项：

| **配置项** | **说明** |
| --- | --- |
| 展示名称 | 控制图表中展示的字段名称 |
| 聚合方式 | 指标字段支持 sum、avg、count、distinct\_count、max、min |
| 数据格式 | 控制数值、百分比、千分符、小数位、有效位 |
| 排序 | 当前字段参与排序时可设置升序、降序、自定义排序 |
| 删除字段 | 从当前字段槽位中移除 |

字段胶囊行为：

1. 字段拖入槽位后立即更新图表预览。
2. 字段删除后，图表重新校验字段完整性。
3. 字段类型不满足槽位要求时，不允许拖入。
4. 字段配置修改后，图表重新查询或重新渲染。
5. 字段展示名称为空时，使用原字段名。

**7.2 查询触发时机**

| **触发场景** | **是否重新查询** |
| --- | --- |
| 首次加载图表 | 是 |
| 切换数据源 | 是 |
| 字段映射变化 | 是 |
| 筛选条件变化 | 是 |
| 排序变化 | 是 |
| TopN 变化 | 是 |

| 自动刷新到达间隔 | 是 |
| 被交互事件触发刷新 | 是 |

**7.3 自动更新规则**

type ChartUpdateMode = "auto" | "once" | "manual";

| **更新方式** | **运行逻辑** |
| --- | --- |
| auto | 组件加载后立即请求数据，之后按刷新间隔重复请求 |
| once | 组件加载后只请求一次 |
| manual | 组件加载后不主动请求，等待用户手动刷新或交互事件触发 |

自动更新规则：

1. auto 模式必须配置 refreshIntervalSeconds。
2. 刷新间隔必须大于等于系统最小值，建议默认 30 秒。
3. 页面不可见时暂停自动刷新。
4. 页面重新可见时，如果距离上次刷新已超过刷新间隔，则立即刷新一次。
5. 自动刷新失败时，保留上一次成功数据，并在编辑态展示错误提示。
6. 发布态单个图表刷新失败不能影响其他图表。

2. 图例项来自字段映射后的系列名称、分拆字段值或图例字段值。
3. 图例超出一行时默认出现翻页按钮。

**11.2 数轴范围**

数值轴支持 3 种模式：

| **模式** | **说明** |
| --- | --- |
| auto | 自动计算范围，包含 0 |
| auto-without-zero | 自动计算范围，不强制包含 0 |
| fixed | 用户手动输入最小值和最大值 |

固定范围校验：

1. 最小值不能为空。
2. 最大值不能为空。
3. 最大值必须大于最小值。
4. 如果数据超出固定范围，超出部分按图表库裁剪，但编辑态需要提示“部分数据超出数轴范围”。

**11.3 数据格式**

| --- | --- |

| 小数位数 | 保留几位小数 |
| 有效位数 | 使用有效数字格式化 |
| 百分比 | 是否按百分比展示 |
| 前缀 | 例如 ¥、$ |
| 后缀 | 例如 %、人、次、万元 |

**14. 指标卡 PRD**

**14.1 使用场景**

指标卡用于展示核心指标值，例如 GMV、销售额、订单数、利润、用户数等。它适合在大屏顶部或核心区域展示关键业务结果。

**14.2 字段配置**

interface MetricCardDataBinding extends ChartDataBinding {

fields: {

values: ChartFieldMapping[];

filters: ChartFieldMapping[];

};

}

规则：

1. 指标卡接受多个值字段。
2. 第一个值字段为主指标。
3. 第二个及之后的值字段为次指标。
4. 值字段必须为指标字段。
5. 如果未配置值字段，显示“请配置指标值”。
6. 字段展示名称作为指标名称。
7. 聚合结果作为指标数值。

主指标配置：

1. 可配置主指标名称字体、字号、字重、颜色。
2. 可配置主指标数值字体、字号、字重、颜色。
3. 主指标数值使用字段格式化规则。

3. 次指标数量过多时，按容器空间自动换行或裁剪。
4. 可配置次指标名称和数值样式。

图标逻辑：

1. 图标可选三角形、线、箭头。
2. 数值大于 0 使用上升颜色。
3. 数值小于 0 使用下降颜色。
4. 数值等于 0 使用持平颜色。
5. 开启“主次指标与图标同色”后，指标数值颜色跟随图标状态颜色。
6. 图标在前时，图标渲染在数值前；否则渲染在数值后。

**14.4 渲染逻辑**

↓

计算聚合结果

↓

第一个结果渲染为主指标

↓

其余结果渲染为次指标

↓

根据数值正负渲染图标

**14.5 验收标准**

1. 配置一个指标时，只展示主指标。
2. 配置多个指标时，第一个为主指标，其余为次指标。
3. 修改字段展示名称后，指标名称同步变化。
4. 图标颜色随数值正负变化。
5. 主次指标与图标同色配置生效。

**15.4 前缀图标逻辑**

如果 compareMode = previous-value：

当前值 > 上一次值：展示上升状态

当前值 < 上一次值：展示下降状态

当前值 = 上一次值：展示持平状态

如果 compareMode = zero：

当前值 > 0：展示上升状态

当前值 < 0：展示下降状态

当前值 = 0：展示持平状态

**15.5 数字展示逻辑**

1. integerLength 用于控制整数最小展示位数。
2. 实际整数位数小于 integerLength 时，前侧补 0。
3. 实际整数位数大于 integerLength 时，按真实位数展示，不截断。
4. decimalPlaces 控制小数位。
5. 开启千分符后，对整数部分增加千分位分隔符。
6. 前缀文本和后缀文本直接拼接在数字前后。

**15.6 动画逻辑**

1. 仅当数值发生变化时执行动画。
2. 数字翻牌适用于数值变化展示。
3. 数字上升适用于从旧值递增到新值。
4. 新值不是数值时，不执行数字上升动画。
5. 首次加载是否执行动画由 playOnFirstLoad 控制。
6. 动画执行期间如果新数据到达，停止当前动画并以当前展示值作为起点执行新动画。

规则：

**18. 条形图类 PRD**

条形图类包括：

1. 并列条形图
2. 堆叠条形图
3. 百分比条形图
4. 双向条形图
5. 排行榜

条形图为横向图表，Y 轴为类别轴，X 轴为数值轴。

**18.1 并列条形图**

字段规则与并列柱状图一致，但坐标方向不同：

Y 轴：类别字段

X 轴：指标值

渲染规则：

1. 同一 Y 轴类目下多个指标横向并列。
2. 条形长度代表数值大小。
3. 动画默认使用“向右伸展”。

**18.2 堆叠条形图**

渲染规则：

1. 同一 Y 轴类目下不同系列横向堆叠。
2. 每条总长度表示总量。
3. 每个堆叠段表示该系列贡献值。
4. 支持指标堆叠开关。

**18.3 百分比条形图**

字段规则与百分比柱状图一致。

渲染规则：

1. 每个 Y 轴类目的条形总长度固定为 100%。
2. 每个堆叠段长度表示该部分占比。
3. tooltip 中同时保留原始值和百分比。
4. 总值为 0 时，占比全部置为 0。

**18.4 双向条形图**

**18.4.1 使用场景**

用于左右对比两个指标或两组数据，例如男性/女性、收入/支出、流入/流出、正向/负向反馈。

规则：

3. 左侧值渲染在中轴左侧。
4. 右侧值渲染在中轴右侧。

**23. 词云 PRD**

**23.1 使用场景**

词云用于展示大量文本标签及其重要性，常用于关键词、热词、用户反馈、舆情词频等场景。

**23.2 字段配置**

interface WordCloudDataBinding extends ChartDataBinding {

fields: {

label: ChartFieldMapping[];

size?: ChartFieldMapping[];

filters: ChartFieldMapping[];

};

}

规则：

1. label 必须配置 1 个维度字段。
2. size 可配置 1 个指标字段。
3. 未配置 size 时，所有词按默认字号展示。
4. 配置 size 时，字号根据指标值映射。
5. 指标值越大，词越大、优先布局在中心区域。
6. label 为空的数据行不参与渲染。

**23.3 字号映射**

fontSize = minFontSize + (value - minValue) / (maxValue - minValue) \* (maxFontSize - minFontSize)

规则：

1. 最大值等于最小值时，所有词使用平均字号。
2. 可配置最小字号和最大字号。
3. 布局冲突时，优先展示权重高的词。
4. 无法放入画布的词自动隐藏。

**25. 圆视图 PRD**

**25.1 使用场景**

圆视图用于以圆形大小展示分类数据的相对比例关系，适合表现构成、分布、规模差异。

**25.2 字段配置**

interface CircleViewDataBinding extends ChartDataBinding {

fields: {

category: ChartFieldMapping[];

value: ChartFieldMapping[];

color?: ChartFieldMapping[];

filters: ChartFieldMapping[];

};

}

规则：

1. category 必须配置 1 个维度字段。
2. value 必须配置 1 个指标字段。
3. 每个 category 生成一个圆。
4. 圆面积与 value 成比例。

**26.1 使用场景**

**26.2 字段配置**

**33. 图表组件验收标准**

**33.1 通用验收**

1. 所有图表可以从左侧组件区双击添加到画布。
2. 所有图表可以拖拽添加到画布指定位置。
3. 所有图表创建后默认使用静态数据渲染。
4. 所有图表支持拖动、缩放、复制、删除、锁定、隐藏。
5. 所有图表支持保存后刷新页面恢复配置。
6. 所有图表支持数据来源切换。
7. 所有图表支持字段拖拽配置。
8. 所有图表支持筛选、排序、TopN。
9. 所有图表支持清除缓存并刷新数据。
10. 所有图表数据查询失败时，不影响其他组件。
11. 所有图表支持出入场动画。
12. 所有图表支持组件级交互事件。
13. 支持图元级交互的图表能正确抛出 RowData。

**33.2 分类型验收**

**指标类**

1. 指标卡第一个指标为主指标，其余为次指标。
2. 翻牌器只接受一个指标。
3. 翻牌器仅在数值变化时播放动画。
4. 排行榜按指标排序后展示排名。

**表格类**

1. 表格可展示多个维度和指标列。
2. 表头、序号列、奇偶行背景、行分割线配置生效。
3. 双击表格可调整列宽。
4. 表格滚动行数和滚动间隔配置生效。
5. 行单击、双击事件可获得当前行数据。

**柱状图 / 条形图**

1. 并列图按系列并列展示。
2. 堆叠图按系列堆叠展示。
3. 百分比图每个类目总和为 100%。
4. 条形图方向为横向，柱状图方向为纵向。
5. 图例、值标签、坐标轴配置生效。

**趋势图**

1. 折线图展示趋势线。
2. 面积图展示趋势线和面积填充。
3. 百分比面积图每个 X 点总和为 100%。
4. 节点单击、双击事件可获得当前节点数据。

**占比图**

1. 饼图、环形图、玫瑰图按维度生成扇区。
2. 扇区百分比计算正确。
3. 单值环形图只展示一个 0-100 的占比。
4. 扇区点击事件可获得当前扇区数据。

**分布关系图**

1. 词云按标签生成词，按指标控制大小。
2. 散点图按 X/Y 指标生成坐标点。
3. 散点图尺寸和颜色通道映射生效。
4. 圆视图按数值控制圆面积。

**流程转化图**

1. 漏斗图按阶段和数值生成漏斗。
2. 漏斗图转化率计算正确。
3. 桑基图按 source、target、value 生成节点和连线。
4. 桑基图相同 source-target 自动聚合。

**进度状态图**

1. 仪表图根据 min、max、value 计算指针位置。
2. 仪表图目标值线和区间配置生效。
3. 水波图根据 value 计算水位高度。
4. 超出 0-100 的水波值按边界渲染并提示。
