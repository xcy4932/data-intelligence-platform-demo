**组织与身份中心 PRD**

**1. 模块定位**

**1.1 模块名称**

组织与身份中心，英文名称为 Organization & Identity Center。

**1.2 产品定位**

组织与身份中心是统一数据平台左侧导航的基础模块，负责管理平台内所有“人”和“组织关系”。

本模块不直接管理具体业务资源权限，例如仪表盘权限、数据集权限、实验权限、标签权限等；这些权限由“权限与策略中心”负责。本模块负责为权限系统提供稳定、统一、可追溯的身份基础数据。

**1.3 解决的问题**

组织与身份中心需要解决以下问题：

1. 企业/集团是谁。
2. 平台中有哪些内部用户。
3. 用户属于哪些部门、用户组、角色、项目。
4. 用户是否可以登录平台。
5. 用户是否占用 License。
6. 用户是否绑定了企业微信、飞书、钉钉、邮箱、SSO 等外部身份。
7. 用户离职、转岗、禁用、删除时，平台如何处理其登录状态、组织关系、角色关系和资产交接。
8. 管理员如何批量创建、导入、导出、禁用、删除用户。
9. 企业如何维护部门、用户组、身份关系，为后续权限、审批、通知、审计提供基础数据。

**1.4 设计原则**

1. **身份统一**
   同一个自然人在平台内只能对应一个主用户账号。即使绑定多个第三方账号，也必须归并到同一个平台用户 ID 下。
2. **组织关系与资源权限解耦**
   组织与身份中心只维护用户、部门、用户组、角色成员关系，不维护具体资源授权规则。资源授权由权限中心负责。
3. **禁用优先于删除**
   用户离职、异常、冻结等场景优先使用“禁用”。删除是高危操作，必须要求资产交接和二次确认。
4. **所有关系可追溯**
   用户创建、编辑、禁用、删除、移除用户组、绑定第三方账号、License 分配等操作必须记录操作日志。
5. **本地管理与外部同步兼容**
   支持本地创建用户、部门、用户组，也支持从 LDAP、AD、飞书、企业微信、钉钉等外部组织系统同步。外部同步对象原则上不可在本地直接修改关键字段。
6. **可面向私有化部署**
   企业可以选择自动占用 License，也可以选择由管理员手动分配 License。

**2. 功能范围**

**2.1 本期包含**

组织与身份中心包含以下功能：

1. 企业/集团信息管理。
2. 用户管理。
3. 部门与组织架构管理。
4. 用户组管理。
5. 角色成员关系管理。
6. 第三方账号绑定管理。
7. License 管理。
8. 个人资料。
9. 身份相关操作日志记录。
10. 用户离职/删除时的资产交接触发逻辑。

**2.2 本期不包含**

以下能力不在组织与身份中心中直接实现：

1. 资源级权限配置，例如给用户授权某个仪表盘、数据集、实验、标签。
2. 行列权限配置。
3. 数据脱敏规则配置。
4. 审批流程配置。
5. 办公平台 App ID、App Secret 等系统级集成配置。
6. 任务运维、队列、存储配额配置。
7. 资产详情治理与资源健康度分析。

以上能力分别由权限与策略中心、申请审批中心、系统配置中心、数据运维中心、资源与资产中心实现。

**3. 用户角色与操作权限**

**3.1 角色定义**

**3.1.1 系统管理员**

系统管理员拥有组织与身份中心全部管理权限。

可操作内容：

1. 查看和编辑企业/集团信息。
2. 新增、编辑、禁用、启用、删除用户。
3. 批量导入、批量禁用、批量删除用户。
4. 管理所有部门。
5. 管理所有用户组。
6. 管理所有用户的角色成员关系。
7. 管理 License 分配策略。
8. 查看所有用户第三方账号绑定状态。
9. 解绑异常第三方账号。
10. 导出用户、部门、用户组数据。

**3.1.2 组织管理员**

组织管理员只能管理其被授权管理范围内的部门、用户和用户组。

可操作内容：

1. 查看其管理范围内的用户。
2. 编辑其管理范围内用户的姓名、手机号、邮箱、职位、部门。
3. 禁用其管理范围内的普通用户。
4. 不可删除用户。
5. 不可修改系统管理员、其他组织管理员。
6. 可创建和维护其管理范围内的项目级用户组。
7. 不可修改 License 策略。
8. 不可管理企业/集团信息。

**3.1.3 用户管理员**

用户管理员是偏操作型角色，负责用户创建和维护，但不负责组织架构和 License 策略。

可操作内容：

1. 新增用户。
2. 批量导入用户。
3. 编辑用户基础信息。
4. 禁用、启用普通用户。
5. 重置本地账号密码。
6. 不可删除用户。
7. 不可编辑部门树结构。
8. 不可调整 License 策略。
9. 不可编辑系统管理员账号。

**3.1.4 普通用户**

普通用户只能访问个人资料。

可操作内容：

1. 查看自己的姓名、邮箱、手机号、部门、职位、角色、用户组。
2. 修改允许自助修改的个人信息。
3. 修改密码。
4. 绑定或解绑允许自助操作的第三方账号。
5. 查看自己当前登录设备。
6. 退出登录。

| --- | --- | --- | --- | --- |

**4.2.2 状态流转规则**

1. pending 可以变为 active。
2. active 可以变为 disabled。
3. disabled 可以变为 active。
4. active 和 disabled 可以变为 deleted。
5. deleted 不可恢复为 active。若业务需要恢复，必须新建用户或由系统管理员执行后台恢复流程。
6. deleted 用户的 username、email、mobile、employee\_no 默认进入保留状态，不允许被新用户立即复用。保留期默认 180 天，可由系统参数配置。

**5. 信息架构**

组织与身份中心在左侧导航左侧菜单中展示。

一级菜单：组织与身份中心。

二级菜单如下：

1. 概览。
2. 企业/集团信息。
3. 用户管理。
4. 部门与组织架构。
5. 用户组管理。
6. 角色成员关系。
7. 第三方账号绑定。
8. License 管理。
9. 个人资料。

其中：

1. 普通用户只能看到“个人资料”。
2. 用户管理员可看到“概览、用户管理、第三方账号绑定、个人资料”。
3. 组织管理员可看到“概览、用户管理、部门与组织架构、用户组管理、角色成员关系、个人资料”。
4. 系统管理员可看到全部菜单。

6. 如果企业未配置任何第三方身份源，则“第三方账号绑定”菜单仍展示，但页面显示空状态和接入提示。

**6. 通用页面规则**

**6.1 列表页通用规则**

所有列表页统一支持：

1. 搜索。
2. 筛选。
3. 分页。
4. 刷新。
5. 导出。
6. 空状态。
7. 加载状态。
8. 错误状态。

**6.1.1 搜索规则**

1. 搜索框默认占位文案为“请输入关键词搜索”。
2. 用户输入关键词后，点击搜索按钮或按 Enter 触发搜索。
3. 搜索不自动实时触发，避免大规模用户列表频繁请求。
4. 点击清空图标后，仅清空输入框，不自动搜索。
5. 点击“重置”按钮后，清空所有搜索和筛选条件，并重新加载第一页。

**6.1.2 分页规则**

1. 默认每页 20 条。
2. 支持切换为 20、50、100 条。
3. 页码变化后保留当前筛选条件。
4. 筛选条件变化后回到第 1 页。
5. 删除当前页最后一条数据后，如果当前页已无数据，则自动跳转到上一页。

**6.1.3 导出规则**

1. 导出按钮导出当前筛选条件下的全部数据，不仅是当前页。
2. 导出前弹窗确认。
3. 导出文件格式为 XLSX。
4. 文件名格式为：模块名称\_导出时间.xlsx。
5. 若导出数据超过系统配置上限，则提示“导出数据量超过上限，请缩小筛选范围后重试”。
6. 导出操作必须写入操作日志。

**6.1.4 空状态规则**

1. 无数据时展示空状态插画。
2. 若无任何筛选条件，文案为“暂无数据”。
3. 若存在筛选条件，文案为“未找到符合条件的数据，请调整筛选条件后重试”。
4. 有创建权限的用户在空状态下展示主按钮，例如“添加用户”“新建用户组”。
5. 无创建权限的用户不展示主按钮。

**6.1.5 错误状态规则**

1. 网络失败展示“加载失败，请重试”。
2. 页面中提供“重新加载”按钮。
3. 点击重新加载后使用当前筛选条件重新请求。
4. 后端返回权限不足时，展示 403 页面，不展示空列表。
5. 后端返回资源不存在时，展示 404 页面。

**6.2 弹窗通用规则**

1. 弹窗右上角显示关闭按钮。
2. 点击关闭按钮，如果表单无变更，直接关闭。
3. 如果表单有变更，弹出二次确认：“当前内容尚未保存，关闭后将丢失已填写内容，是否确认关闭？”
4. 表单提交中，确认按钮进入 loading 状态，禁止重复点击。
5. 提交成功后关闭弹窗，并刷新列表。
6. 提交失败后不关闭弹窗，在顶部展示错误提示，同时保留用户已填写内容。

**6.3 删除类操作通用规则**

1. 删除必须二次确认。
2. 删除确认弹窗必须展示删除对象名称。
3. 删除多个对象时必须展示数量。
4. 若删除对象有关联关系，必须展示影响范围。
5. 高危删除需要用户输入对象名称或“确认删除”。
6. 删除成功后展示成功提示。
7. 删除失败时展示失败原因。

**7. 页面一：组织与身份概览**

**7.1 页面入口**

入口路径：

左侧导航 > 组织与身份中心 > 概览。

**7.2 页面目标**

概览页面用于让管理员快速了解当前企业内用户、部门、用户组、License、第三方账号绑定的整体情况，并快速进入常用管理操作。

**7.3 页面结构**

页面由以下区域组成：

1. 顶部统计卡片。
2. 待处理事项。
3. 用户增长趋势。
4. 第三方账号绑定概览。
5. 快捷入口。
6. 最近操作记录。

**7.4 顶部统计卡片**

**7.4.1 卡片字段**

显示以下卡片：

1. 用户总数。
2. 已启用用户数。
3. 已禁用用户数。
4. 未激活用户数。
5. 部门数量。
6. 用户组数量。
7. 已占用 License 数。
8. License 剩余数。

**7.4.2 卡片点击逻辑**

1. 点击“用户总数”跳转至用户管理页面，筛选条件为空。
2. 点击“已启用用户数”跳转至用户管理页面，并自动筛选状态为 active。
3. 点击“已禁用用户数”跳转至用户管理页面，并自动筛选状态为 disabled。
4. 点击“未激活用户数”跳转至用户管理页面，并自动筛选状态为 pending。
5. 点击“部门数量”跳转至部门与组织架构页面。
6. 点击“用户组数量”跳转至用户组管理页面。
7. 点击“已占用 License 数”跳转至 License 管理页面，筛选状态为 occupied。
8. 点击“License 剩余数”跳转至 License 管理页面。

如果当前用户没有目标页面访问权限，则卡片不可点击，鼠标悬停提示“暂无权限访问该页面”。

**7.5 待处理事项**

**7.5.1 待处理类型**

展示以下待处理事项：

1. 未激活用户。
2. 第三方账号绑定冲突。
3. License 待分配用户。
4. 外部组织同步失败。
5. 即将删除的已删除用户保留记录。
6. 删除用户待资产交接。

**7.5.2 交互逻辑**

每条待处理事项展示：

1. 类型。
2. 数量。
3. 最近发生时间。
4. 操作按钮。

操作按钮规则：

1. 未激活用户：按钮为“去处理”，跳转用户管理并筛选 pending。
2. 第三方账号绑定冲突：按钮为“查看冲突”，跳转第三方账号绑定并筛选 conflict。
3. License 待分配用户：按钮为“去分配”，跳转 License 管理并筛选 pending。
4. 外部组织同步失败：按钮为“查看日志”，跳转部门与组织架构的同步日志抽屉。

**9.8.3 字段规则**

**姓名**

**邮箱**

1. 系统生成 12 位随机密码。
2. 密码必须包含大小写字母、数字、特殊字符。
3. 添加成功后弹窗展示账号、密码、登录地址。
4. 管理员可点击复制。

当选择手动输入：

1. 展示密码输入框。
2. 密码需满足安全策略。
3. 提交时仅传输加密后的密码。
4. 前端不保存明文密码。

当选择用户首次登录自设密码：

1. 用户状态为 pending。
2. 系统生成激活链接。
3. 必须填写邮箱。
4. 用户通过激活链接设置密码后状态变为 active。

1. 可多选。
2. 仅展示 active 用户组。
3. 若当前管理员只有组织范围权限，则只展示其可管理范围内的用户组。

4. 组织管理员只能分配其管理范围内可分配角色。
5. 不允许通过此处给其他用户分配系统管理员，系统管理员需在企业/集团信息页面添加。

**License 分配方式**

可选：

3. 暂不占用 License。

按钮：

1. 取消。
2. 确认禁用。

**9.11.3 禁用逻辑**

点击确认禁用：

1. 修改用户状态为 disabled。
2. 释放 License。
3. 失效该用户所有登录会话。
4. 保留部门、用户组、角色关系。
5. 保留资源 owner。
6. 写入操作日志。

**9.12 启用用户**

**9.12.1 入口**

disabled 用户操作列点击“启用”。

**9.12.2 启用逻辑**

点击启用后弹窗确认。

启用时：

1. 修改用户状态为 active。
2. 如果租户为自动 License 策略，用户首次登录时占用 License。
3. 如果租户为手动 License 策略，启用后不自动占用 License。
4. 不恢复历史登录会话。
5. 写入操作日志。

**9.13 删除用户**

**9.13.1 删除定义**

删除用户是高危操作。删除后：

1. 用户无法登录。
2. 用户不占用 License。
3. 用户从默认用户列表中隐藏。
4. 用户作为用户组成员、角色成员、部门成员的关系被解除。
5. 用户创建的资源必须先完成资产交接。
6. 历史操作日志中仍保留该用户标识。

**9.13.2 删除前校验**

点击删除后，系统检查：

1. 用户是否为唯一系统管理员。
2. 用户是否拥有未转交资产。
3. 用户是否为审批流程唯一流程管理员。
4. 用户是否为某用户组唯一负责人。
5. 用户是否为某部门负责人。
6. 用户是否有运行中的任务。

如果存在阻断项，则不可删除，并展示阻断原因。

阻断项包括：

1. 唯一系统管理员。
2. 未转交资产。
3. 审批流程唯一管理员。
4. 运行中的关键任务负责人。

非阻断项包括：

1. 部门负责人。
2. 用户组负责人。

非阻断项允许继续删除，但需选择替代负责人。

**9.13.3 删除弹窗**

第一步：影响检查。

展示：

1. 用户基本信息。
2. 未转交资产数量。
3. 所属部门。
4. 所属用户组数量。
5. 角色数量。
6. 是否占用 License。
7. 是否为负责人。

第二步：资产交接。

如果存在资产：

1. 必须选择资产接收人。
2. 接收人必须为 active 用户。
3. 接收人必须属于当前租户。
4. 接收人不能是待删除用户本人。
5. 如果资产跨项目，接收人必须至少拥有对应项目的查看权限；若没有，系统提示“接收人缺少部分项目权限，是否同时授予项目查看权限？”
6. 管理员可勾选“自动授予接收人必要项目查看权限”。

第三步：确认删除。

用户必须输入“确认删除”。

按钮：

1. 上一步。
2. 取消。
3. 确认删除。

**9.13.4 删除执行逻辑**

点击确认删除后：

1. 执行资产交接。
2. 删除用户与用户组关系。
3. 删除用户与角色关系。
4. 释放 License。
5. 失效所有登录会话。
6. 修改用户状态为 deleted。
7. 记录删除原因、交接人、操作人。
8. 写入操作日志。
9. 刷新用户列表。

**9.13.5 批量删除**

批量删除入口：

1. 勾选多个用户。
2. 底部操作条点击“批量删除”。

批量删除规则：

1. 不能包含系统管理员。
2. 不能包含当前登录用户本人。
3. 所有用户都需要完成资产检查。
4. 可选择同一个资产接收人。
5. 如果不同用户资产需要不同接收人，则需要下载交接模板批量填写。
6. 存在阻断项时，整批不允许提交。
7. 删除完成后展示批量结果。

**12.3.4 自定义用户组**

2. 子组成员变更后，父组成员计算结果自动更新。
3. 权限中心授权给父组时，子组成员可继承对应授权。
4. 若权限中心启用“屏蔽组授权”，用户可在特定资源上不继承来自用户组的权限。

**12.9.3 移除子组**

1. 来源为 local。
2. 用户组未被审批流程引用。
3. 用户组未被系统配置引用。
4. 若被资源权限引用，允许删除，但必须提示影响。

**12.10.2 删除确认**

用户需输入用户组名称确认。

**17. 关键业务流程**

**17.1 新员工入职流程**

流程：

1. 管理员进入用户管理。
2. 点击添加用户或批量导入。
3. 填写用户基础信息。
4. 选择部门。
5. 关联用户组。
6. 关联角色。

10. 用户状态变为 active。

1. 管理员进入用户管理。
2. 搜索离职用户。

6. 系统检查未交接资产。
7. 管理员选择资产接收人。
8. 系统完成资产转移。
9. 系统删除用户组织关系和角色关系。
10. 用户状态变为 deleted。
11. 操作日志保留用户历史记录。

**17.3 外部组织同步流程**

1. 系统管理员完成外部组织源配置。
2. 管理员进入部门与组织架构。

5. 按 external\_user\_id 匹配已有用户。
6. 匹配成功则更新外部同步字段。

8. 匹配冲突进入冲突列表。
9. 同步完成后生成同步报告。

**19. 异常与边界规则**

**19.1 当前用户不能删除自己**

如果当前登录用户在用户列表点击自己的删除按钮：

1. 删除按钮不展示。
2. 若通过接口调用，后端返回错误。
3. 错误文案：“不可删除当前登录用户”。

**19.2 当前用户不能禁用自己**

规则同删除自己。

**19.3 唯一系统管理员不可被禁用或删除**

如果租户内只有一个系统管理员：

1. 该用户禁用按钮禁用。
2. 删除按钮禁用。
3. 移除系统管理员按钮禁用。
4. 提示：“至少需要保留一名系统管理员”。

**19.4 外部同步用户字段不可本地覆盖**

外部同步用户的姓名、邮箱、手机号、部门、工号默认只读。

如需修改：

1. 到外部组织系统修改。
2. 再执行同步。
3. 本地编辑页面显示提示。

**19.5 用户组不允许循环嵌套**

例如：

1. A 包含 B。
2. B 包含 C。
3. C 不允许再包含 A。

系统在添加子组时必须校验所有祖先链路。

**19.6 License 已满**

当 License 已满：

1. 自动策略下，新用户访问业务产品失败。
2. 手动策略下，管理员无法继续分配。
3. 页面提示：“License 已用完，请释放无效用户或联系系统管理员扩容”。

**19.7 第三方账号冲突**

当一个外部账号可能匹配多个平台用户：

1. 不自动绑定。
2. 状态置为 conflict。
3. 管理员必须手动选择绑定对象。
4. 冲突未处理前，该外部账号不可登录平台。

**21. 验收标准**

**21.1 用户管理验收**

1. 系统管理员可以成功创建本地用户。
2. 用户名重复时创建失败，并提示重复原因。
3. 批量导入时，错误行不可提交。
4. 禁用用户后，该用户无法登录。
5. 禁用用户后 License 自动释放。
6. 启用用户后，用户可重新登录。
7. 删除用户前必须完成资产交接。
8. 唯一系统管理员不可被删除或禁用。
9. 当前用户不可删除或禁用自己。
10. 用户编辑后，列表和详情页数据一致。

**21.2 部门管理验收**

1. 可创建一级部门和子部门。
2. 同级部门名称不可重复。
3. 不允许将部门移动到自己的子部门下。
4. 有用户或子部门的部门不可删除。
5. 外部同步部门不可本地编辑关键字段。
6. 部门成员添加和移除后，用户详情同步变化。

**21.3 用户组管理验收**

1. 可创建系统级用户组和项目级用户组。
2. 用户组名称不可重复。
3. 可添加和移除用户。
4. 可添加和移除子组。
5. 不允许循环嵌套。
6. 删除用户组时，系统提示权限影响。
7. 删除用户组后，该组从授权关系中移除。

**21.4 第三方账号绑定验收**

1. 可查看用户第三方账号绑定状态。
2. 可手动绑定未绑定账号。
3. 唯一登录方式不可解绑。
4. 冲突账号不可自动绑定。
5. 冲突处理后，绑定状态正确更新。

**21.5 License 管理验收**

1. 可查看 License 总数、已用数、剩余数。
2. 可手动分配 License。
3. License 已满时不可继续分配。
4. 禁用用户自动释放 License。
5. 删除用户自动释放 License。
6. 修改 License 策略后，新用户按新策略执行。

**21.6 个人资料验收**

1. 普通用户可查看个人资料。
2. 普通用户不可修改用户名、部门、角色、用户组。
3. 密码用户可修改密码。
4. 纯 SSO 用户不展示修改密码按钮。
5. 用户可绑定第三方账号。
6. 唯一登录方式不可解绑。

**21.7 日志验收**

1. 用户新增、编辑、禁用、删除均记录日志。
2. 部门新增、编辑、删除均记录日志。
3. 用户组成员变更记录日志。
4. License 分配和释放记录日志。
5. 第三方账号绑定和解绑记录日志。
6. 日志中包含操作人、操作时间、对象、原值、新值、结果。
