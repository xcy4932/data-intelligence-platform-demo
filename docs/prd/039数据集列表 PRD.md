**数据集列表 PRD**

**1. 模块定位**

**1.1 功能目标**

数据集列表是数据准备模块中用于统一展示、检索、分类、组织和操作数据集资源的页面。用户进入数据集模块后，需要通过数据集列表快速找到目标数据集，并完成基础管理动作，例如查看基础信息、移动文件夹、复制数据集、删除数据集、设置标签、创建使用说明、配置可视化查询行为、授权、进入详情页等。

数据集列表不负责深度建模编辑，也不负责数据预览和同步状态详情展示。它主要解决三个问题：

1. 数据集资源很多时，用户如何快速找到目标数据集。
2. 数据集分散在不同目录、分类、标签、状态下时，用户如何统一管理。
3. 用户在不进入完整详情页的情况下，如何完成常用轻量操作。

**3. 用户角色与权限**

**3.1 角色定义**

| **角色** | **说明** | **数据集列表能力** |
| --- | --- | --- |
| 项目管理员 | 管理整个项目资源 | 可查看全部数据集，可管理标签、类目、权限、删除、恢复 |
| 数据集所有者 | 创建或被转移为所有者的人 | 可管理自己拥有的数据集 |
| 数据生产者 | 负责数据准备与建模 | 可创建、编辑、移动、复制有权限的数据集 |
| 分析用户 | 使用数据集做分析的人 | 可查看有权限的数据集、进入可视化查询 |
| 普通只读用户 | 只查看分析结果 | 只能查看授权范围内的数据集基础信息 |
| 个人数据集用户 | 无项目编辑权限但可创建个人数据集的人 | 可创建和管理自己的个人数据集 |

**3.2 权限层级**

数据集列表中每个数据集都需要根据当前用户权限返回可用操作。

type DatasetListPermission = {

权限计算规则：

→ 每条数据集返回 permission 对象

→ 前端根据 permission 控制按钮展示、置灰和菜单项可见性

**6. 概览页**

**6.1 功能定位**

概览页是数据集列表的默认入口，用于承载数据集搜索、筛选、全局管理入口和数据集列表展示。

用户进入数据集模块后，默认选中左侧 概览，右侧展示所有有权限的数据集。

**6.2 顶部工具栏**

**6.2.1 新建按钮**

点击 新建 后展开：

新建数据集

新建关联数据集

新建文件夹

显示规则：

| **菜单项** | **显示条件** |
| --- | --- |
| 新建数据集 | 用户有创建普通数据集权限，或支持个人数据集创建 |
| 新建关联数据集 | 用户至少有两个可查看数据集 |
| 新建文件夹 | 用户有项目编辑权限或个人空间管理权限 |

个人数据集规则：

1. 用户即使没有项目编辑权限，也可以创建个人数据集。
2. 个人数据集默认只对创建者可见。
3. 个人数据集可用于自己的可视化查询。
4. 如果要共享给其他人，需要走授权或转为公共/共享数据集。

**6.2.2 标签管理按钮**

显示条件：

currentUser.isProjectAdmin === true

点击后打开标签管理弹窗。

如果普通用户点击或通过 URL 访问标签管理接口：

当前账号暂无标签管理权限，请联系项目管理员。

**6.2.3 参数管理按钮**

显示条件：

currentUser.canViewDatasetList === true

参数管理允许查看项目内公共参数和当前用户个人参数。

创建公共参数需要项目管理员或数据管理员权限；创建个人参数只需要当前用户有数据集使用权限。

**6.2.4 类目管理按钮**

显示条件：

currentUser.isProjectAdmin === true

类目管理用于创建项目级字段类目，并控制是否允许用户在数据集中创建自定义类目。

**7. 数据集搜索**

**7.1 搜索范围**

搜索框支持按以下信息查询：

1. 数据集名称。
2. 数据源名称。
3. 底表名称。
4. 所有者姓名。
5. 权限类型。
6. 数据集描述。
7. 标签名称。

**7.2 搜索交互**

用户输入关键词

→ 前端 debounce 300ms

→ 更新查询条件 keyword

→ 调用列表查询接口

→ 返回结果后刷新表格

→ 命中字段高亮

搜索框规则：

| **规则** | **说明** |
| --- | --- |
| 空关键词 | 查询当前筛选条件下的全部数据集 |
| 前后空格 | 自动 trim |
| 大小写 | 英文大小写不敏感 |
| 中文 | 支持模糊匹配 |
| 特殊字符 | 作为普通字符处理，不允许注入查询语句 |

**7.3 搜索结果高亮**

命中高亮范围：

数据集名称

数据源名称

底表名称

所有者

标签名称

高亮逻辑：

function highlight(text: string, keyword: string): HighlightSegment[] {

if (!keyword.trim()) return [{ text, matched: false }];

// 前端只负责展示高亮，不负责搜索判断

}

**7.4 空结果**

当搜索无结果时，展示：

未找到符合条件的数据集

你可以尝试：

1. 更换关键词；

2. 清空部分筛选条件；

3. 检查是否拥有对应数据集权限。

如果当前用户无任何数据集权限：

暂无可访问的数据集

→ 作为筛选下拉选项

告警人支持搜索用户。

交互逻辑：

→ 查询项目成员

→ 选择一个或多个告警人

→ 刷新列表

如果选择多个告警人，查询逻辑为 OR：

**8.2.7 运行频率筛选**

选项：

全部

分钟级

小时级

天级

周级

月级

手动

其他

规则：

1. 抽取数据集按同步配置映射运行频率。
2. 直连数据集 runFrequency = none。
3. 手动同步数据集归为 手动。
4. 复杂 Cron 表达式无法归类时归为 其他。

**8.2.8 标签筛选**

标签选项来自项目标签列表。

规则：

1. 支持多选。
2. 多个标签默认 AND 或 OR 需要明确配置，建议默认 OR。
3. 可提供切换项：满足任一标签 / 满足全部标签。
4. 标签被删除后，列表筛选项立即消失。
5. 已打在数据集上的删除标签需要从数据集标签关系中移除。

| **设置** | **可视化查询行为** |
| --- | --- |
| 允许 | 用户拖入字段或修改配置后自动查询 |
| 不允许 | 进入可视化查询后默认关闭自动查询，需要用户手动点击查询 |

不允许自动查询时：

1. 字段拖拽不自动触发后端查询。
2. 筛选条件变化不自动触发查询。
3. 页面展示提示：当前数据集已关闭自动查询，请点击查询按钮获取数据。
4. 不影响仪表盘展示。

**16.5.2 筛选搜索优化**

字段：

allowFilterSearchOptimization: boolean;

默认值：

allowFilterSearchOptimization = true;

行为：

| **设置** | **筛选器搜索行为** |
| --- | --- |
| 允许 | 筛选器精确搜索优先走前端缓存，提升搜索效率 |
| 不允许 | 筛选器搜索全量查询最近 30 天后端数据，保证完整性 |

适用范围：

1. 图表筛选器。
2. 公共筛选器。

多数据集规则：

如果一个筛选器涉及多个数据集，

只要其中任意一个数据集设置为“不允许筛选搜索优化”，

则该筛选器整体按“不允许”逻辑处理。

**16.5.3 查询天数限制**

字段：

maxQueryDaysEnabled: boolean;

maxQueryDays?: number;

行为：

1. 开启后，用户只能查询最近 N 天内的数据。
2. 可视化查询中的时间筛选器必须被限制在 N 天范围内。
3. 公共筛选器也需要同步生效。
4. 如果用户选择超过范围，系统自动截断或提示用户修改。

推荐交互：

用户设置最大查询天数 = 30

→ 用户在可视化查询中选择最近 90 天

→ 系统提示：当前数据集最大仅支持查询最近 30 天

→ 查询按钮置灰，或自动改为最近 30 天

与抽样数据展示规则：

如果最大查询天数 <= 仅展示最近 N 天抽样数据，

则以最大查询天数为准。

**16.5.4 明细字段**

字段：

detailFieldIds: string[];

功能：

支持将数据集中的某些字段设置为明细字段。当查询中未添加指标时，这些字段只能进行明细查询。

规则：

1. 明细字段通常是订单号、用户 ID、设备 ID、流水号等高基数字段。
2. 明细字段不建议直接参与聚合分析。
3. 当用户仅拖入明细字段时，系统引导切换到明细表。
4. 当用户拖入指标时，明细字段是否可作为维度由系统配置决定，默认限制。

**16.6.2 允许舍弃超时节点**

功能：

规则：

1. 默认关闭。
2. 开启后需要配置允许精度损失阈值。
3. 查询结果必须展示近似结果提示。
4. 对财务、对账、审计类数据集建议不允许开启。
5. 如果数据集涉敏或高精度标签，可强制禁止开启。

提示文案：

**26. 异常场景**

**26.1 列表加载失败**

数据集列表加载失败，请稍后重试。

提供 重试 按钮。

**26.2 权限变化**

如果用户打开列表后权限被移除：

1. 列表刷新后该数据集消失。
2. 如果用户正在操作该数据集，保存时返回 403。
3. 页面提示：当前账号已失去该数据集操作权限。

**26.3 数据集被他人删除**

如果用户点击操作时数据集已被删除：

该数据集已被删除，无法继续操作。

列表刷新。

**26.4 标签被删除**

如果用户正在设置标签时，某标签被管理员删除：

1. 保存时返回标签不存在。
2. 前端刷新标签列表。
3. 提示：部分标签已被删除，请重新选择。

**26.5 默认可视化查询失效**

如果配置的默认查询链接已删除：

1. 点击可视化查询时提示失效。
2. 自动进入空白查询。
3. 在配置弹窗中标记该链接异常。

**27. 验收标准**

**27.1 搜索筛选**

1. 支持按数据集名称、数据源名称、底表、所有者、权限搜索。
2. 支持来源、类型、状态基础筛选。
3. 支持分类、涉敏定级、存储类型、告警人、优先级、队列、运行频率、标签高级筛选。
4. 搜索和筛选组合生效。
5. 清空筛选后列表恢复。
6. 搜索无结果时展示空状态。

**27.2 列表展示**

1. 数据集列表展示名称、标签、来源、类型、状态、所有者、告警人、最近同步时间、更新时间。
2. 数据集名称可点击进入详情。
3. 标签按颜色展示。
4. 状态点击后可跳转对应详情。
5. 镜像、主题、个人数据集有明确标识。
6. 不同权限用户看到的操作菜单不同。

**27.3 基础信息**

1. 用户可修改有权限数据集的名称和描述。
2. 名称必填且唯一。
3. 主题数据集和镜像数据集不允许在当前项目修改基础信息。
4. 保存后列表立即刷新。

**27.4 移动**

1. 用户可将数据集移动到其他文件夹。
2. 目标路径必须有权限。
3. 同名冲突时不可移动。
4. 移动后不影响图表和仪表盘引用。
5. 操作写入日志。

**27.5 复制**

1. 用户可复制普通数据集。
2. 复制后生成新数据集。
3. 复制抽取型数据集时复制同步配置但不复制物理数据。
4. 不复制权限配置。
5. 不复制字段层级和类目。
6. 权限或数据连接缺失时，复制后的模型页面能标记异常。

**27.6 删除与回收站**

1. 删除前触发影响分析。
2. 删除确认弹窗展示下游图表、仪表盘和访问量。
3. 高风险删除需要二次确认。
4. 删除后进入回收站。
5. 15 天内可恢复。
6. 超过 15 天后可查询模型信息进行重建。
7. 主题数据集不允许删除。

**27.7 使用说明**

1. 用户可为数据集配置使用说明 URL。
2. URL 必须合法。
3. 配置后可视化查询中展示使用说明入口。
4. 点击后打开说明文档。
5. 无权限用户不可编辑使用说明。

**27.8 可视化查询配置**

1. 用户可配置是否允许订阅。
2. 用户可配置是否允许新建监控。
3. 用户可配置是否允许自动查询。
4. 用户可配置筛选搜索优化。
5. 用户可配置最大查询天数。
6. 用户可配置明细字段。
7. 用户可配置默认可视化查询链接。
8. 用户可配置是否允许舍弃超时节点。
9. 配置保存后对后续查询立即生效。

**27.9 标签管理**

1. 项目管理员可创建、编辑、删除标签。
2. 标签支持 7 种颜色。
3. 标签可配置是否继承到图表标题。
4. 数据集支持多标签。
5. 标签可用于列表筛选。
6. 镜像数据集标签与原数据集一致。

**27.10 参数管理**

1. 用户可查看公共参数和个人参数。
2. 有权限用户可创建公共参数。
3. 普通用户可创建个人参数。
4. 参数可应用到指定数据集。
5. 参数可在计算字段表达式中使用。
6. 参数类型和初始值必须匹配。

**27.11 类目管理**

1. 项目管理员可管理项目级类目。
2. 可控制是否允许用户创建数据集类目。
3. 删除被字段使用的类目前需要阻断或迁移。
4. 字段配置中可选择项目级类目。

**27.12 授权**

1. 有权限用户可进入授权弹窗。
2. 支持用户、用户组、角色授权。
3. 支持查看、编辑、管理权限。
4. 资源权限和行列权限分离。
5. 镜像和主题数据集按各自权限来源处理。
