**数字化大屏概要 PRD**

**1. 文档定位**

本文是数字化大屏模块的总框架 PRD，用于定义数字大屏的产品边界、核心概念、页面结构、编辑器框架、组件体系、画布操作、数据绑定入口、动画入口、预览发布流程、版本模板能力、快捷键能力和基础数据结构。

后续子模块 PRD 可以继续拆分为：大屏列表、模板管理、默认组件、图表组件、地图场景组件、自定义组件、数据来源配置、字段配置、事件交互、动画编排、发布权限、智能助手等。

本文不只描述“有哪些功能”，而是将数字大屏作为一个可开发的产品框架来定义，要求前端、后端、Codex 可以基于本文搭建出可运行的数字大屏基础系统。

**2. 产品目标与定位**

**2.1 产品定位**

数字化大屏是智能数据洞察平台中的“数据展示与数据故事表达”模块，核心目标不是复杂探索式分析，而是将已经整理好的业务指标、图表、地图、装饰元素、动态效果、交互事件组合成可展示、可讲述、可发布的大屏页面。

数字化大屏需要同时支持两类使用方式：

| **使用方式** | **说明** |
| --- | --- |
| 讲述式大屏 | 面向展厅、会议、领导汇报、业务宣讲场景，由讲解人按照页面或动效流程讲述业务进展、区域情况、经营成果、风险预警。 |
| 自由浏览式大屏 | 面向监控中心、办公室电视、网页展示、定期总结场景，用户不依赖讲解人也能快速看到当前发生了什么。 |

数字化大屏与普通仪表盘的区别在于：

| **对比项** | **数字化大屏** | **仪表盘** |
| --- | --- | --- |
| 核心目标 | 展示、表达、视觉冲击、数据故事 | 分析、筛选、查询、解释 |
| 数据层级 | 更偏汇总数据、关键指标、宏观趋势 | 可覆盖明细数据、汇总数据、OLAP 分析 |
| 目标受众 | 领导层、公众、展厅访客、全体员工 | 业务人员、分析师、运营、管理者 |
| 交互重点 | 页面切换、动画、地图联动、场景演示、讲述节奏 | 图表联动、筛选器、钻取、明细查看 |
| 视觉侧重 | 设计感、动效、空间布局、炫酷展示 | 信息密度、分析效率、数据解释 |

**4.1 用户角色**

| **角色** | **主要目标** | **权限要求** |
| --- | --- | --- |
| 大屏设计者 | 搭建大屏页面、调整样式、配置动画、发布大屏 | 创建、编辑、保存、预览、发布、下线、版本管理 |
| 数据分析人员 | 配置图表数据、字段、查询逻辑 | 编辑组件数据配置、查看数据、刷新缓存 |

**4.2 权限控制原则**

系统需要至少支持以下权限点：

type BigScreenPermission =

| "bigscreen:create"

| "bigscreen:view"

| "bigscreen:edit"

| "bigscreen:delete"

| "bigscreen:preview"

| "bigscreen:publish"

| "bigscreen:offline"

| "bigscreen:version:create"

| "bigscreen:version:restore"

| "bigscreen:template:create"

| "bigscreen:customComponent:manage";

权限校验规则：

1. 用户进入大屏编辑页时，必须校验 bigscreen:edit。
2. 用户点击发布时，必须校验 bigscreen:publish。
3. 用户点击一键下线时，必须校验 bigscreen:offline。
4. 用户访问发布 URL 时，不进入编辑权限校验，只校验大屏是否处于已发布状态，以及发布访问权限是否允许当前用户访问。
5. 私有化环境中，如果客户要求所有访问都需要登录，则发布 URL 也必须经过登录态校验。

**5. 核心业务对象**

**5.1 大屏项目 Screen**

大屏项目是数字化大屏的最高级对象，一个大屏项目包含多个页面、多个组件、发布记录、版本记录和全局配置。

interface BigScreen {

id: string;

name: string;

description?: string;

status: "draft" | "published" | "offline";

deviceMode: "pc" | "mobile";

homePageId: string;

pages: BigScreenPage[];

globalVariables: BigScreenVariable[];

assets: BigScreenAsset[];

draftSnapshot: BigScreenSnapshot;

publishedSnapshot?: BigScreenSnapshot;

versionCount: number;

latestVersionId?: string;

createdBy: string;

updatedBy: string;

createdAt: string;

updatedAt: string;

publishedAt?: string;

}

状态说明：

| **状态** | **说明** |
| --- | --- |
| draft | 只存在草稿或已保存但未发布。 |
| published | 已发布，可通过 URL 访问。 |
| offline | 曾发布过，但当前已下线，访问 URL 不再展示正式内容。 |

**5.2 页面 Page**

一个大屏项目可以包含多个页面，页面用于承载组件、背景、交互和页面级配置。

interface BigScreenPage {

id: string;

screenId: string;

name: string;

width: number;

height: number;

background: {

type: "color" | "image" | "color-image";

color?: string;

imageUrl?: string;

imageFit?: "cover" | "contain" | "stretch" | "repeat";

opacity?: number;

};

componentIds: string[];

interactionEvents: InteractionEvent[];

sortIndex: number;

isHomePage: boolean;

}

页面基本规则：

1. 每个大屏至少保留一个页面。
2. 删除当前访问首页时，系统必须要求用户先设置其他页面为首页，或者自动将排序第一的页面设置为首页。
3. 页面宽高默认为 PC 大屏尺寸，可配置。
4. 移动端模式需要独立存储布局，不直接覆盖 PC 布局。

**5.4 组件布局 Layout**

interface ComponentLayout {

x: number;

y: number;

width: number;

height: number;

rotate?: number;

lockAspectRatio: boolean;

opacity: number;

overflowHidden: boolean;

}

规则：

1. x、y 表示组件左上角相对当前页面画布左上角的位置。
2. width、height 表示组件当前尺寸。
3. lockAspectRatio = true 时，拖拽宽或高必须按原始宽高比例同步缩放。
4. opacity 取值范围为 0 - 100。
5. overflowHidden = true 时，组件实际渲染区域必须裁剪到组件矩形框内。

**5.5 组 Group**

组是一种特殊图层对象，用于管理多个组件。

interface ComponentGroup {

id: string;

pageId: string;

name: string;

componentIds: string[];

layout: ComponentLayout;

visible: boolean;

locked: boolean;

zIndex: number;

}

组规则：

1. 至少选择 2 个组件才允许编组。
2. 编组后，组内组件保持相对位置不变。
3. 拖动组时，组内所有组件一起移动。
4. 锁定组时，组内组件不可通过画布拖拽移动。
5. 隐藏组时，组内组件全部不显示。
6. 解组后，组件恢复为普通独立组件，原 zIndex 按组内顺序重新写回。

**7.2 编辑状态流转**

type EditorDirtyState = "clean" | "dirty" | "saving" | "saved" | "save\_failed";

状态规则：

| **状态** | **触发条件** | **页面表现** |
| --- | --- | --- |
| clean | 初次加载，内容与服务端一致 | 保存按钮置灰或显示“已保存” |
| dirty | 用户进行了未保存修改 | 保存按钮高亮，离开页面时二次确认 |
| saving | 点击保存后请求进行中 | 保存按钮 loading，不允许重复点击 |
| saved | 保存成功 | 提示保存成功，状态回到 clean |
| save\_failed | 保存失败 | 提示失败原因，允许重试 |

离开规则：

1. 当前状态为 dirty 或 save\_failed 时，点击返回必须弹出确认框。
2. 确认离开则丢弃未保存修改。
3. 取消离开则回到编辑器。
4. 当前状态为 saving 时，不允许直接离开，或提示“正在保存，请稍后”。

**8. 顶部导航区 PRD**

**8.1 返回与命名**

**8.1.1 返回**

入口：顶部左侧返回按钮。

交互逻辑：

1. 用户点击返回。
2. 系统检查当前编辑器是否存在未保存修改。
3. 若无未保存修改，直接返回大屏列表。
4. 若存在未保存修改，弹出确认框：

标题：存在未保存修改

内容：当前大屏存在未保存内容，离开后修改将丢失。

按钮：取消、放弃修改并离开、保存并离开

按钮逻辑：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗，停留编辑器。 |
| 放弃修改并离开 | 不保存当前草稿，返回列表。 |
| 保存并离开 | 调用保存接口，保存成功后返回列表，保存失败则停留并提示错误。 |

**8.1.2 重命名**

入口：顶部大屏名称区域。

交互逻辑：

1. 用户点击或双击名称。
2. 名称进入输入状态。
3. 用户输入新名称。
4. 按 Enter 或输入框失焦时提交。
5. 按 Esc 取消修改。

校验规则：

| **校验项** | **规则** |
| --- | --- |
| 必填 | 名称不能为空。 |
| 长度 | 建议 1-50 个字符。 |
| 空格 | 前后空格自动 trim。 |
| 重名 | 同一项目空间下是否允许重名由平台配置决定；如不允许，保存时提示。 |

数据更新：

updateScreenName(screenId: string, name: string): Promise<BigScreen>

**8.2.1 编组**

入口：顶部“编组”按钮或快捷键 Ctrl + G / ⌘ + G。

启用条件：

1. 当前选中对象数量大于等于 2。
2. 选中对象均属于同一个页面。
3. 选中对象不包含已锁定对象。
4. 选中对象不能同时包含父组和其子组件。

执行逻辑：

1. 根据选中组件计算最小外接矩形。
2. 创建 ComponentGroup。
3. 将选中组件的 parentGroupId 设置为新组 ID。
4. 组的 layout 使用最小外接矩形。
5. 组内组件保存相对坐标关系。
6. 图层面板显示为组节点，组下展示子组件。
7. 画布选中新组。

异常逻辑：

| **场景** | **处理** |
| --- | --- |
| 只选中 1 个组件 | 编组按钮置灰。 |
| 包含锁定组件 | 不允许编组，并提示“锁定组件不可编组”。 |
| 跨页面组件 | 不允许发生，因为画布只允许选择当前页面组件。 |

**8.2.2 解组**

入口：顶部“解组”按钮或快捷键 Ctrl + Shift + G / ⌘ + ⇧ + G。

启用条件：

1. 当前选中对象中至少包含一个组。
2. 组未锁定。

执行逻辑：

1. 删除组对象。
2. 将组内组件的 parentGroupId 清空。
3. 组件维持当前画布绝对位置不变。
4. 图层面板中组件恢复到原组所在层级位置。
5. 画布选中解组后的所有组件。

**8.2.3 层级调整**

支持操作：

| **操作** | **说明** |
| --- | --- |
| 置顶 | 将选中组件或组移动到当前页面最上层。 |
| 前置 | 将选中组件或组向上移动一层。 |
| 后置 | 将选中组件或组向下移动一层。 |
| 置底 | 将选中组件或组移动到当前页面最底层。 |

层级字段：

zIndex: number;

执行规则：

1. zIndex 越大，越靠上显示。
2. 同一页面内 zIndex 必须唯一或按数组顺序稳定排序。
3. 对组调整层级时，应整体调整组及其子组件。
4. 锁定状态不影响层级调整，除非产品配置为“锁定后禁止任何编辑”。建议本期锁定后禁止层级调整。

**8.2.4 撤销与重做**

操作栈结构：

interface EditorHistory {

past: BigScreenSnapshot[];

present: BigScreenSnapshot;

future: BigScreenSnapshot[];

maxLength: number;

}

默认规则：

1. 用户每完成一次原子操作，写入历史栈。
2. 原子操作包括：新增组件、删除组件、移动组件、调整尺寸、修改样式、修改数据配置、编组、解组、图层变化、页面设置变化。
3. 连续拖拽过程中不应每个鼠标移动事件都写历史栈，而应在 dragEnd 时写入一次。
4. 历史栈建议最多保存 50 步。
5. 保存不清空历史栈。
6. 切换大屏项目时清空历史栈。

快捷键：

| **操作** | **Windows** | **macOS** |
| --- | --- | --- |
| 撤销 | Ctrl + Z | ⌘ + Z |
| 重做 | Ctrl + Y 或 Ctrl + Shift + Z | ⌘ + Shift + Z |

**8.2.5 缩放**

缩放对象是画布视口，不改变页面真实宽高，也不改变组件真实坐标。

interface CanvasViewport {

zoom: number;

offsetX: number;

offsetY: number;

}

规则：

1. 默认缩放为 100%。
2. 最小缩放建议 20%。
3. 最大缩放建议 400%。
4. 点击放大按钮，每次增加 10%。
5. 点击缩小按钮，每次减少 10%。
6. 缩放后，组件实际坐标不变，只改变视觉显示比例。
7. 保存时不保存 zoom，除非需要恢复用户编辑器视图偏好。

**9. 页面与图层 PRD**

**9.1 页面管理**

页面区域展示当前大屏所有页面。

页面结构：

interface PageListItem {

**9.1.1 新增页面**

入口：页面区域的 “+” 按钮。

逻辑：

1. 用户点击 “+”。
2. 系统创建新页面。
3. 新页面名称默认为：

页面{n}

其中 n = 当前页面数量 + 1。如果名称重复，则继续递增。

1. 新页面默认尺寸继承当前大屏默认尺寸。
2. 新页面默认背景继承系统默认背景，不继承当前页面背景，除非用户选择“复制当前页面”。
3. 新页面插入页面列表末尾。
4. 创建后自动切换到新页面。

**9.1.2 删除页面**

入口：页面右侧删除按钮。

规则：

1. 大屏至少保留一个页面。
2. 当只剩一个页面时，删除按钮置灰。
3. 删除首页时，需要处理首页重置。

删除首页逻辑：

点击删除首页

↓

弹出确认

↓

确认删除

↓

删除页面

↓

将剩余页面中 sortIndex 最小的页面设为首页

确认文案：

确认删除该页面？

页面删除后，该页面内所有组件和配置都会被删除，无法直接恢复。

删除后：

1. 若删除的是当前页面，自动切换到剩余页面中的第一个页面。
2. 删除操作写入撤销栈。
3. 删除后编辑器状态变为 dirty。

**9.1.3 重命名页面**

入口：双击页面名称。

规则：

1. 页面名称不能为空。
2. 页面名称长度建议 1-30 个字符。
3. 同一大屏内页面名称允许重复，但不建议重复。为了降低用户混淆，建议重复时提示“存在同名页面”，但不强制阻止。
4. Enter 提交，Esc 取消。

**9.1.4 设置访问首页**

入口：页面设置区的“设为访问大屏首页”。

逻辑：

1. 用户选中某页面。
2. 点击“设为访问大屏首页”。
3. 系统将当前页面 isHomePage 设置为 true。
4. 其他页面 isHomePage 设置为 false。
5. 大屏 homePageId 更新为当前页面 ID。
6. 保存后，发布访问默认从该页面开始。

**9.2 图层管理**

图层区以树形列表展示当前页面的组件和组。

interface LayerNode {

id: string;

type: "component" | "group";

name: string;

visible: boolean;

locked: boolean;

selected: boolean;

children?: LayerNode[];

}

排序规则：

1. 图层列表从上到下对应画布从上层到下层。
2. zIndex 越大，显示越靠上。
3. 组内子组件按组内 zIndex 排序。

**9.2.1 图层选择**

逻辑：

1. 点击图层项，画布中选中对应组件或组。
2. 点击画布组件，图层区同步选中对应图层。
3. 按住 Ctrl / ⌘ 点击支持多选。
4. 按住 Shift 点击支持范围选择。
5. 选中组时，默认选中整个组。
6. 深度选择时，可直接选择组内子组件。

**9.2.2 显示 / 隐藏**

入口：图层名称右侧显隐图标。

逻辑：

1. 点击显示图标，切换 visible。
2. visible = false 时，组件在画布和预览中均不显示。
3. 隐藏组件仍保留在图层列表中。
4. 隐藏组件不能在画布上直接选中，但可以在图层列表中选中。
5. 隐藏组时，组内所有组件视觉上隐藏，但子组件自身 visible 状态不被覆盖。组恢复显示后，子组件按自身 visible 状态显示。

**9.2.3 锁定 / 解锁**

入口：图层名称右侧锁定图标。

逻辑：

1. 点击锁定图标，切换 locked。
2. 锁定后，组件不可在画布上移动、缩放、删除、调整层级。
3. 锁定组件仍可被选中查看属性，但属性输入框应置灰。
4. 锁定组时，组内组件整体不可移动和编辑。
5. 解锁后恢复正常编辑。

**9.2.4 图层重命名**

入口：双击图层名称。

规则：

1. 名称不能为空。
2. 默认组件名称按类型生成，例如“文本 1”“柱状图 1”“3D地图 1”。
3. 重命名只影响编辑管理，不影响组件渲染。

**9.2.5 图层拖拽排序**

建议本期支持图层拖拽排序。

逻辑：

1. 用户拖拽图层项。
2. 拖拽过程中显示插入位置。
3. 放下后重新计算 zIndex。
4. 如果拖拽组，组整体移动。
5. 如果拖拽组内组件到组外，需要弹出确认或禁止。建议本期禁止跨组拖拽，避免结构混乱。

**10. 可视化组件区 PRD**

**10.1 组件分类**

组件资源中心需要支持以下一级分类：

| **分类** | **说明** | **是否可绑定数据** |
| --- | --- | --- |
| 默认组件 | 文本、矩形、图片、视频、基础图形等 | 通常不可绑定数据，特殊文本可支持变量绑定 |

| 图表组件 | 柱状图、折线图、饼图、表格等 | 必须支持数据绑定 |

| 装饰素材 | 标题框、背景框、装饰线、图标等 | 默认不可绑定数据 |

**10.5 变量管理**

变量用于大屏内跨组件复用动态值，例如当前区域、当前日期、选中业务线等。

interface BigScreenVariable {

}

变量规则：

1. 变量 key 必须唯一。
2. 变量 key 只能包含字母、数字、下划线，且不能以数字开头。
3. 变量可被控件组件、图表查询参数、交互事件引用。

5. 如果变量被引用，删除时提示影响范围。

5. 多选对象包含锁定组件时，整体拖拽禁止，或仅移动未锁定组件。建议本期整体禁止，并提示“选中对象包含锁定组件”。

**11.2.3 深度选择**

用于组内组件选择。

操作：

| **操作** | **Windows** | **macOS** |
| --- | --- | --- |
| 深度选择 | Ctrl + 点选 | ⌘ + 点选 |
| 忽略组多选 | Ctrl + Shift + 点选 | ⌘ + ⇧ + 点选 |

规则：

1. 普通点击组内组件时，选中整个组。
2. 深度选择时，选中组内具体组件。
3. 深度选择后的组件仍保留在组内，不改变结构。
4. 修改组内组件属性时，只影响该组件。

**11.3 拖拽移动**

逻辑：

1. 用户按下鼠标并移动。
2. 如果组件未锁定，组件跟随鼠标移动。
3. 拖动过程中实时更新视觉位置，但不立即写入历史栈。
4. 拖动结束后，将最终 x、y 写入组件 layout。
5. 拖动结束后写入一次历史栈。

辅助线：

1. 拖动时，若组件边缘或中心线接近其他组件边缘或中心线，显示对齐线。
2. 接近阈值建议为 5px。
3. 吸附功能可作为开关，默认开启。

**11.4 缩放尺寸**

逻辑：

1. 选中组件后显示 8 个缩放控制点。
2. 用户拖拽控制点调整 width、height。
3. 如果 lockAspectRatio = true，按原比例缩放。
4. 按住 Shift 拖拽时，临时锁定宽高比例。
5. 尺寸不能小于组件最小尺寸。

最小尺寸建议：

| **组件** | **最小宽度** | **最小高度** |
| --- | --- | --- |
| 文本 | 20 | 20 |
| 图表 | 100 | 80 |
| 地图 | 200 | 150 |
| 控件 | 80 | 28 |
| 装饰 | 10 | 10 |

**11.5 画布滚动与拖拽**

快捷操作：

| **操作** | **Windows** | **macOS** |

| 向下滚动画布 | 鼠标下滚 | 鼠标下滚 |

| 向右滚动画布 | Shift + 鼠标下滚 | ⇧ + 鼠标下滚 |

规则：

1. 画布拖拽只改变视口 offset，不改变组件坐标。
2. 当用户按住空格时，鼠标样式变为抓手。
3. 松开空格后恢复默认选择模式。

**11.6 复制、粘贴、剪切、全选**

快捷键：

| **操作** | **Windows** | **macOS** |
| --- | --- | --- |
| 剪切 | Ctrl + X | ⌘ + X |
| 复制 | Ctrl + C | ⌘ + C |
| 粘贴 | Ctrl + V | ⌘ + V |
| 全选 | Ctrl + A | ⌘ + A |
| 保存 | Ctrl + S | ⌘ + S |

复制规则：

1. 复制组件时，需要复制组件布局、样式、数据配置、动画配置。
2. 粘贴后生成新的组件 ID。
3. 粘贴组件名称可追加“副本”或自动编号。
4. 粘贴位置相对原组件偏移，例如 x + 20、y + 20。
5. 跨页面粘贴时，组件粘贴到当前页面。
6. 跨大屏粘贴时，若数据源、变量、素材引用不存在，需要进入降级处理。

**12. 页面设置区 PRD**

页面设置区在用户点击画布空白区域时展示。

**12.1 页面布局**

字段：

| **字段** | **说明** |
| --- | --- |
| W | 页面宽度 |
| H | 页面高度 |

交互规则：

1. 修改 W/H 后，画布页面尺寸实时变化。
2. 已有组件坐标和尺寸不自动缩放。
3. 如果页面尺寸缩小导致组件超出画布，组件仍保留原坐标，但画布中可能显示在边界外。
4. 发布预览时，页面按配置尺寸渲染。

建议提供常用尺寸：

| **名称** | **尺寸** |
| --- | --- |
| 16:9 Full HD | 1920 x 1080 |
| 2K | 2560 x 1440 |
| 4K | 3840 x 2160 |
| 移动端竖屏 | 375 x 812 |
| 自定义 | 用户输入 |

**12.2 背景设置**

支持两种背景：

| **类型** | **说明** |
| --- | --- |
| 背景色 | 通过颜色选择器设置。 |
| 背景图 | 上传图片作为页面背景。 |

组合规则：

1. 背景色和背景图可以同时存在。
2. 当背景图不透明时，背景图覆盖背景色。
3. 当背景图带透明区域时，透明区域显示背景色。
4. 删除背景图后，背景色仍保留。
5. 背景图支持 fit 配置：cover、contain、stretch、repeat。

上传规则：

1. 支持 png、jpg、jpeg、webp。
2. 文件大小限制建议由系统配置，默认可设为 10MB。
3. 上传成功后返回 imageUrl。
4. 上传失败需要提示失败原因。

**12.3 设为访问大屏首页**

逻辑见 9.1.4。

页面设置区展示规则：

1. 当前页面是首页时，按钮显示“当前为访问首页”，置灰或显示已选中状态。
2. 当前页面不是首页时，按钮显示“设为访问大屏首页”。
3. 点击后立即更新本地状态，并标记 dirty。
4. 保存后生效到草稿。
5. 发布后生效到访问 URL。

**13. 组件通用样式 PRD**

组件通用样式区在用户选中具体组件时展示。

**13.1 位置与宽高**

字段：

| **字段** | **说明** |
| --- | --- |
| X | 组件相对画布左上角的横坐标 |
| Y | 组件相对画布左上角的纵坐标 |
| W | 组件宽度 |
| H | 组件高度 |
| 锁定比例 | 是否保持宽高比例 |

交互规则：

1. 用户可直接输入 X/Y/W/H。
2. 输入后组件实时更新。
3. X/Y 支持负数，允许组件部分位于画布外。
4. W/H 必须大于 0。
5. W/H 输入非法值时，输入框提示错误，不写入组件状态。
6. 锁定比例开启后，修改 W 自动计算 H，修改 H 自动计算 W。

**13.2 不透明度**

字段：

opacity: number; // 0 - 100

交互：

1. 拖动滑块调整不透明度。
2. 支持手动输入百分比。
3. 0 表示完全透明。
4. 100 表示完全不透明。
5. 透明组件仍可在编辑态被选中；预览态按透明度渲染。

**13.3 标记 Marker**

每个组件创建后默认生成一个标记。

marker: string;

用途：

1. 用于跨页面中同一业务对象的识别。
2. 用于页面切换时的补间动画匹配。
3. 用于事件交互中定位目标组件。

规则：

1. marker 默认自动生成，例如 marker\_xxxxx。
2. 用户可手动修改。
3. 同一页面内 marker 不强制唯一。
4. 如果用于跨页面补间动画，建议不同页面中相同对象使用相同 marker。
5. 删除组件后 marker 不回收。

**13.4 超出区块部分不显示**

字段：

overflowHidden: boolean;

规则：

1. 开启时，组件内容超出组件矩形区域的部分被裁剪。
2. 关闭时，组件内容可超出组件矩形区域显示。
3. 文本、图片、图表、自定义组件均应遵循该规则。
4. 对部分第三方 iframe 或自定义组件，如果无法裁剪，需要外层容器强制 overflow: hidden。

**13.5 氛围效果**

氛围效果用于增强图表视觉表现。

结构：

interface AtmosphereEffect {

enabled: boolean;

type?: "glow" | "shadow" | "halo";

intensity?: number;

color?: string;

}

规则：

1. 默认关闭。
2. 仅图表类组件显示该配置。
3. 开启后在预览和发布态生效。
4. 强度范围建议 0-100。
5. 如果组件类型不支持氛围效果，不显示该配置项。

**13.6 颜色配置**

图表组件支持根据字段或条件配置颜色。

interface ColorEncoding {

mode: "fixed" | "field" | "condition";

fixedColor?: string;

fieldKey?: string;

palette?: string[];

conditions?: ColorCondition[];

}

interface ColorCondition {

operator: ">" | ">=" | "<" | "<=" | "=" | "!=" | "between";

value: any;

valueEnd?: any;

color: string;

}

规则：

1. 默认使用系统色板。
2. 固定颜色模式下，所有图元使用同一颜色或组件默认颜色组。
3. 字段模式下，按字段值进行颜色分组。
4. 条件模式下，按阈值设置颜色，可用于告警。
5. 如果字段被删除或清空，颜色配置自动降级为默认色板。

**14. 数据可视化面板 PRD**

数据可视化面板主要服务于图表组件、地图组件和支持数据绑定的自定义组件。

**14.1 数据绑定结构**

interface DataBindingConfig {

dataSourceId?: string;

filters?: QueryFilter[];

parameters?: QueryParameter[];

updateMode: "auto" | "once" | "manual";

}

字段映射：

interface FieldMapping {

slotName: string;

fieldKey: string;

fieldName: string;

aggregation?: "sum" | "avg" | "count" | "max" | "min" | "distinct\_count";

}

**14.2 查看数据**

入口：数据面板中的“查看数据”。

逻辑：

1. 用户点击查看数据。
2. 系统根据当前组件的数据绑定配置发起数据预览请求。
3. 返回前若配置不完整，提示缺失项。
4. 返回后展示表格弹窗或底部数据预览区域。
5. 数据预览只用于编辑态，不影响发布内容。

请求结构：

interface PreviewDataRequest {

screenId: string;

pageId: string;

componentId: string;

dataBinding: DataBindingConfig;

limit: number;

}

默认规则：

1. 默认预览前 100 行。
2. 如果数据量较大，只展示分页结果。
3. 查询失败时显示失败原因。
4. 无数据时显示空状态。

**14.3 一键清空字段**

入口：字段面板中的“一键清空”。

逻辑：

1. 用户点击一键清空。
2. 弹出确认：

确认清空当前组件已选择字段？

清空后图表将无法正常展示数据。

1. 确认后清空 fieldMappings。
2. 组件进入无数据配置状态。
3. 画布中图表显示占位状态。

占位文案：

请配置数据字段

**14.4 清除缓存并刷新数据**

入口：数据面板中的刷新按钮。

逻辑：

1. 用户点击“清除缓存并刷新数据”。
2. 系统调用刷新接口，携带组件当前查询配置。
3. 后端清除该组件对应查询缓存。
4. 重新请求数据。
5. 刷新成功后更新画布展示。
6. 刷新失败时保留旧数据，并提示失败原因。

**14.5 数据更新方式**

支持三种更新方式：

| **更新方式** | **说明** |
| --- | --- |
| 自动更新 | 按指定间隔自动请求数据。 |
| 只请求一次 | 页面加载时请求一次，之后不自动刷新。 |
| 不自动请求 | 页面加载不主动请求，需要交互或手动触发。 |

字段：

updateMode: "auto" | "once" | "manual";

refreshIntervalSeconds?: number;

规则：

1. 选择自动更新时，必须设置刷新间隔。
2. 刷新间隔必须大于等于系统最小值，建议最小 5 秒或 10 秒。
3. 选择只请求一次时，发布页加载后请求一次。
4. 选择不自动请求时，发布页不主动请求数据，除非事件交互触发刷新。
5. 编辑态和发布态均应遵守更新方式。
6. 页面不可见时应暂停自动刷新，避免资源浪费。
7. 页面重新可见时，如果超过刷新间隔，则立即刷新一次。

**15. 查询与动画区 PRD**

**15.1 查询区域**

查询区域用于管理组件数据来源、字段、过滤条件和数据预览。

展示规则：

1. 未选中组件时，查询区域为空或提示“请选择组件”。
2. 选中不可绑定数据组件时，提示“当前组件不支持数据配置”。
3. 选中可绑定数据组件时，展示数据来源、字段、查看数据、刷新、更新方式等配置。

**15.2 字段区域**

字段区域用于将数据字段拖入组件需要的字段槽位。

示例：

interface ChartFieldSlots {

dimensions: FieldMapping[];

measures: FieldMapping[];

color?: FieldMapping;

tooltip?: FieldMapping[];

}

规则：

1. 不同组件拥有不同字段槽位。
2. 字段拖入槽位时，需要校验字段类型。
3. 维度槽位一般接受 string、date、number 类型。
4. 指标槽位一般接受 number 类型。
5. 如果字段类型不匹配，禁止放入并提示。
6. 删除字段后，图表实时重新渲染。

**18. 预览与发布页渲染 PRD**

**18.1 预览页**

预览页职责：

1. 渲染编辑器中的当前大屏快照。
2. 支持从当前页或首页开始。
3. 支持动画播放。
4. 支持交互事件。
5. 支持数据请求。
6. 不影响正式发布内容。

预览 URL 建议：

/big-screen/preview/:previewSessionId

预览 session：

interface PreviewSession {

id: string;

screenId: string;

startPageId: string;

snapshot: BigScreenSnapshot;

createdBy: string;

createdAt: string;

expiredAt: string;

}

预览 session 应有过期时间，避免长期占用存储。

**18.2 发布页**

发布页职责：

1. 读取 publishedSnapshot。
2. 按访问首页展示。
3. 执行动画和交互。
4. 按数据更新方式请求数据。
5. 适配 PC、移动端、触摸屏、LED 联屏等展示环境。

发布 URL 建议：

/big-screen/view/:screenId

访问规则：

| **状态** | **访问表现** |
| --- | --- |
| published | 正常展示 publishedSnapshot。 |
| draft | 提示“大屏尚未发布”。 |
| offline | 提示“大屏已下线”。 |
| deleted | 提示“大屏不存在或已删除”。 |

**19. 快速复制与外部分析引用 PRD**

**19.1 组件复制**

支持范围：

| **来源** | **目标** | **是否支持** |
| --- | --- | --- |
| 同一页面 | 同一页面 | 支持 |
| 页面之间 | 其他页面 | 支持 |
| 大屏之间 | 其他大屏 | 支持 |
| 重复器、标签页、轮播器页面之间 | 对应容器页面 | 支持，具体容器规则后续展开 |

限制：

1. 大部分组件支持复制。
2. 少部分带复杂事件交互的组件可能不支持复制。
3. 不支持复制时，应提示具体原因，而不是静默失败。

**19.2 快速引用可视化查询图表**

用于处理大屏原生图表组件暂时无法满足的复杂分析场景。

流程：

在可视化查询中完成分析图表

↓

点击或复制图表 URL

↓

回到大屏编辑画布

↓

粘贴 URL

↓

系统创建引用型图表组件

引用规则：

1. 系统将图表当时的请求快照存储到大屏内。
2. 后续原分析条件变化后，大屏中的分析配置不自动更新。
3. 但数据请求仍可按快照配置保持实时更新。

**23. 异常与边界场景**

**23.1 未保存修改**

场景：

1. 用户返回列表。
2. 用户关闭浏览器。
3. 用户刷新页面。
4. 用户切换大屏。
5. 用户恢复版本。

处理：

1. 存在 dirty 状态时弹出确认。
2. 浏览器刷新使用 beforeunload 提示。
3. 恢复版本必须二次确认。

**23.2 数据源异常**

场景：

1. 数据源被删除。
2. 字段被删除。
3. 查询权限失效。
4. 查询超时。
5. 自动刷新失败。

处理：

1. 编辑态组件显示异常标记。
2. 数据面板展示具体失败原因。
3. 发布态组件可显示空状态或保留上次成功数据。
4. 自动刷新失败时不应导致整个大屏崩溃。

**23.3 组件渲染异常**

处理：

1. 单个组件渲染失败时，只显示该组件错误占位。
2. 不影响其他组件渲染。
3. 错误占位在编辑态展示详细错误，在发布态展示简化提示或隐藏。
4. 自定义组件异常必须捕获，避免拖垮整个页面。

**23.4 发布内容为空**

允许发布空白大屏，但需要提示：

当前大屏内容较少或没有配置数据，确认发布？

如果没有页面，则不允许发布。

**23.5 版本超过上限**

当版本数量达到 20：

版本数量已达到上限 20 个，请删除不需要的版本后再创建。

**24. 验收标准**

**24.1 大屏基础流程**

1. 用户可以创建一个新数字大屏。
2. 用户可以进入编辑器。
3. 用户可以修改大屏名称。
4. 用户可以新增页面、删除页面、重命名页面。
5. 用户可以设置访问首页。
6. 用户可以保存大屏。
7. 用户可以从当前页预览。
8. 用户可以从首页预览。
9. 用户可以发布大屏。
10. 发布后可以获得访问 URL。
11. 已发布大屏可以一键下线。
12. 下线后原 URL 不再展示正式大屏内容。

**24.2 画布编辑**

1. 用户可以从组件区添加组件到画布。
2. 用户可以拖动组件位置。
3. 用户可以调整组件尺寸。
4. 用户可以多选组件。
5. 用户可以编组和解组。
6. 用户可以调整组件层级。
7. 用户可以复制、粘贴、剪切组件。
8. 用户可以通过快捷键保存。
9. 用户可以缩放和拖动画布。
10. 画布缩放不改变组件真实坐标。

**24.3 页面与图层**

1. 图层区能展示当前页面所有组件。
2. 点击图层能同步选中画布组件。
3. 点击画布组件能同步选中图层。
4. 图层支持显示和隐藏。
5. 图层支持锁定和解锁。
6. 锁定组件不能被拖动和修改。
7. 图层支持重命名。
8. 组在图层中以树形结构展示。

**24.4 样式与数据**

1. 选中页面空白区域时，右侧展示页面设置。
2. 选中组件时，右侧展示组件样式。
3. 用户可以修改 X、Y、W、H。
4. 用户可以锁定宽高比例。
5. 用户可以调整不透明度。
6. 用户可以设置超出区块隐藏。
7. 图表组件可以进入数据配置。
8. 用户可以查看数据。
9. 用户可以清空字段。
10. 用户可以清除缓存并刷新数据。
11. 用户可以设置自动更新、只请求一次、不自动请求。

**24.5 动画与交互入口**

1. 组件可以配置入场动画。
2. 组件可以配置出场动画。
3. 动画类型包含无动画、淡入、抽屉、缩放、卷轴、飞入、浮动。
4. 动画支持持续时间、开始时间、缓动方式配置。
5. 开始时间不合法时不允许保存。
6. 组件和页面存在交互配置入口。
7. 禁用的交互事件不在预览和发布态执行。

**24.6 版本、模板与扩展能力**

1. 用户可以创建版本。
2. 单个大屏最多 20 个版本。
3. 用户可以恢复版本。
4. 用户可以将当前大屏共享为模板。
5. 私有化环境支持自定义组件管理入口。
6. 智能助手入口受功能开关控制。
