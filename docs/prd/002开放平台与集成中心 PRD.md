**开放平台与集成中心 PRD**

**1. 产品定位**

**1.1 模块定位**

开放平台与集成中心是数据平台对内、对外提供系统集成、能力开放、API 管理、应用接入、Webhook 事件订阅、第三方系统连接、开发者调试、调用监控和开放治理的统一入口。

该中心解决的问题是：

1. 数据平台内部能力如何标准化开放给其他业务系统；
2. 外部系统如何安全接入数据平台；
3. API、Webhook、SDK、连接器如何统一管理；
4. 应用接入、密钥、权限、配额、调用日志如何可控；
5. 集成失败、调用异常、流量突增如何监控和治理；
6. 平台能力如何通过文档、沙箱和调试工具被开发者快速使用。

**1.2 模块边界**

**1.2.1 与权限与策略中心的边界**

开放平台与集成中心负责应用级接入、API 订阅、密钥、Token、调用权限和开放范围管理。

权限与策略中心负责平台内部用户、角色、资源权限和策略决策。

当外部应用申请调用某个数据 API 时，开放平台负责应用接入和调用凭证，权限与策略中心负责判断该 API 背后的数据资源是否允许被该应用访问。

**1.2.2 与申请审批与流程中心的边界**

开放平台不直接实现复杂审批流，只负责发起审批动作并展示审批状态。

以下动作需要走申请审批与流程中心：

1. 应用上线；
2. API 发布；
3. API 订阅；
4. 高敏数据 API 调用申请；
5. 密钥重置；
6. 配额提升；
7. Webhook 生产环境启用；
8. 第三方连接器上线。

**1.2.3 与数据安全与合规中心的边界**

开放平台负责展示 API 的安全等级、敏感标记、脱敏状态和风险提示。

数据安全与合规中心负责敏感字段识别、脱敏策略、合规规则、访问风险判定。

当 API 涉及敏感数据时，开放平台必须调用安全中心的策略结果，决定是否允许发布、是否允许订阅、是否需要脱敏、是否需要审批。

**1.2.4 与审计与可观测中心的边界**

开放平台负责展示 API 调用监控、Webhook 投递日志、应用调用统计和集成运行状态。

审计与可观测中心负责全局操作日志、系统链路日志、异常追踪和底层可观测能力。

开放平台内的调用日志可以跳转到审计与可观测中心查看完整链路。

**1.2.5 与数据目录与治理中心的边界**

数据目录与治理中心负责数据资产的发现、治理状态、质量评分和生命周期。

开放平台负责将可开放的数据资产封装为 API、Webhook 事件、SDK 能力或外部集成能力。

只有满足开放条件的数据资产，才能被开放平台发布为开放能力。

**2. 用户角色与权限**

**2.1 平台管理员**

平台管理员拥有开放平台与集成中心的全部权限。

可执行操作：

1. 查看全部应用；
2. 创建和管理应用；
3. 创建和发布 API；
4. 管理全部密钥；
5. 审核 API 上线；
6. 审核应用上线；
7. 配置全局限流策略；
8. 配置开放域名白名单；
9. 配置 IP 白名单；
10. 配置 Webhook 全局策略；
11. 查看全部调用日志；
12. 强制下线异常应用；
13. 强制停用异常 API；
14. 管理连接器市场；
15. 管理开发者文档。

**2.2 开放平台管理员**

开放平台管理员负责 API、应用、Webhook、连接器等开放能力的日常管理。

可执行操作：

1. 创建应用；
2. 创建 API；
3. 编辑 API 文档；
4. 发布 API；
5. 配置 API 鉴权；
6. 配置调用配额；
7. 配置 Webhook；
8. 查看调用监控；
9. 处理集成异常；
10. 维护 SDK 文档；
11. 管理连接器实例。

不可执行操作：

1. 修改全局安全策略；
2. 跳过审批发布敏感 API；
3. 修改用户身份体系；
4. 删除审计日志。

**2.3 API 负责人**

API 负责人是某个 API 的业务或技术责任人。

可执行操作：

1. 编辑自己负责的 API；
2. 修改 API 文档；
3. 配置请求参数和响应参数；
4. 发起 API 发布；
5. 查看 API 调用日志；
6. 处理 API 异常；
7. 审核低风险 API 订阅申请；
8. 配置 API 下线计划。

**2.4 应用负责人**

应用负责人负责某个接入应用。

可执行操作：

1. 查看自己负责的应用；
2. 编辑应用基础信息；
3. 申请 API 订阅；
4. 查看应用密钥；
5. 重置密钥申请；
6. 配置回调地址；
7. 配置 IP 白名单；
8. 查看应用调用统计；
9. 查看应用错误日志；
10. 发起配额提升申请。

**2.5 开发者**

开发者使用开放平台进行 API 查询、文档阅读、沙箱调试和集成测试。

可执行操作：

1. 查看已开放 API；
2. 阅读 API 文档；
3. 使用调试控制台；
4. 申请创建应用；
5. 申请订阅 API；
6. 查看自己有权限的密钥；
7. 查看自己应用的调用日志；
8. 下载 SDK；
9. 查看接入示例。

不可执行操作：

1. 发布 API；
2. 修改全局配置；
3. 查看其他应用密钥；
4. 查看其他应用调用日志；
5. 删除 API。

1. 开发环境；
2. 测试环境；
3. 预发环境；

1. 当前页面重新加载；
2. 列表数据切换为目标环境；
3. 当前筛选条件保留；
4. 当前分页回到第一页；

**6. 开放总览页面**

**6.1 页面用途**

开放总览用于展示开放平台整体运行状态，包括应用数量、API 数量、调用量、错误率、慢请求、Webhook 投递成功率、连接器运行状态和待处理事项。

**6.2 页面布局**

页面从上到下分为：

1. 时间范围筛选区；
2. 核心指标卡片区；
3. 调用趋势区；
4. API 健康度区；
5. 应用调用排行区；
6. Webhook 投递区；
7. 连接器运行区；
8. 待处理事项区；
9. 风险提示区。

**6.3 时间范围筛选区**

字段包括：

1. 环境；
2. 时间范围；
3. API 类型；
4. 应用类型；
5. 刷新按钮；
6. 导出报告按钮。

**6.3.1 时间范围**

可选项：

1. 最近 1 小时；
2. 今日；
3. 昨日；
4. 近 7 天；
5. 近 30 天；
6. 自定义。

选择后页面自动刷新。

自定义时间规则：

1. 开始时间不可晚于结束时间；
2. 最大查询跨度 90 天；
3. 查询跨度超过 7 天时，调用趋势按天聚合；
4. 查询跨度小于等于 7 天时，调用趋势按小时聚合。

**6.3.2 导出报告按钮**

点击后打开导出弹窗。

字段：

| **字段** | **类型** | **必填** | **默认值** |

1. 取消：关闭弹窗；

导出规则：

1. 不包含明细日志时直接导出汇总；
2. 包含明细日志且日志超过 5000 条时创建异步任务；
3. 导出完成后进入下载中心；
4. 导出操作写入审计日志。

**6.6 风险提示区**

展示系统自动识别的开放风险。

风险类型包括：

1. 应用长期未调用；
2. 应用调用错误率过高；
3. API 慢请求过多；
4. API 即将下线但仍有调用；
5. 密钥长期未轮换；
6. Webhook 连续投递失败；
7. 连接器认证失效；
8. 应用配额即将耗尽；
9. 敏感 API 存在未审批订阅；
10. IP 白名单为空但生产环境启用。

每条风险展示：

1. 风险等级；
2. 风险对象；
3. 风险说明；
4. 发现时间；
5. 处理按钮。

处理按钮点击规则：

1. 应用风险跳转应用详情；
2. API 风险跳转 API 详情；
3. Webhook 风险跳转 Webhook 订阅详情；
4. 连接器风险跳转连接器实例详情；
5. 配额风险跳转配额配置页。

1. 数据源；

3. 参数绑定；
4. 最大返回行数；
5. 查询超时时间；
6. 是否启用缓存。

规则：

1. SQL 只允许 SELECT；

**22. 验收标准**

**22.1 应用管理验收**

1. 用户可以创建应用；
2. 应用编码唯一且创建后不可修改；
3. 生产应用必须配置安全策略；
4. 应用可保存草稿、提交审核、启用、停用和删除；
5. 应用停用后所有调用失败；
6. 密钥只能授权用户查看；
7. 查看密钥必须写入审计日志；
8. 重置密钥后旧密钥按配置失效；
9. 应用列表筛选、搜索、分页正常；
10. 批量启用和停用能正确处理部分失败。

**22.2 API 管理验收**

1. 用户可以创建 API；
2. API 路径在同环境下唯一；
3. 请求参数、响应参数可配置；
4. API 可配置 HTTP、SQL、数据集等后端；
5. API 发布前必须通过发布检查；
6. 敏感 API 发布必须审批；
7. 已发布 API 编辑时生成新版本；
8. API 下线后调用返回固定错误码；
9. API 文档可预览和导出；
10. API 调试能展示请求和响应详情。

**22.3 API 市场验收**

1. 用户可以搜索已发布 API；
2. 用户可以查看 API 文档；
3. 用户可以选择应用申请订阅 API；
4. 重复订阅会被拦截；
5. 敏感 API 订阅进入审批；
6. 审批通过后应用可调用 API；
7. 用户可以查看自己的订阅；
8. 用户可以申请配额扩容；
9. 取消订阅后调用失败；
10. API 废弃后不允许新订阅。

**22.4 Webhook 验收**

1. 管理员可以创建事件；
2. 事件发布后才允许订阅；
3. 应用可以创建 Webhook 订阅；
4. 启用前必须测试投递成功；
5. 投递日志可以查看请求和响应；
6. 投递失败可以自动重试；
7. 用户可以手动重试失败投递；
8. 连续失败后订阅进入失败状态；
9. 停用订阅后不再投递；
10. 敏感字段必须脱敏展示。

**22.5 连接器验收**

1. 用户可以查看连接器市场；
2. 用户可以创建连接器实例；
3. 认证配置必须加密保存；
4. 测试连接成功后才能启用；
5. 连接器任务可以手动运行；
6. 同步失败可以查看日志；
7. 失败数据可以重跑；
8. 连接器认证失效会产生告警；
9. 生产环境启用连接器需要审批；
10. 停用实例后调度停止。

**22.6 配额与限流验收**

1. 可以配置全局限流；
2. 可以配置 API 限流；
3. 可以配置应用配额；
4. 超限后返回统一错误码；
5. 配额使用量可以统计；
6. 配额即将耗尽可以告警；
7. 配额提升超过阈值需要审批；
8. 限流命中日志可查询。

**22.7 调用监控验收**

1. 可以查看调用趋势；
2. 可以查看错误分析；
3. 可以查看慢请求分析；
4. 可以查看调用日志详情；
5. 请求和响应敏感字段脱敏；
6. 调用日志支持按应用、API、状态码筛选；
7. 调用日志可以导出；
8. 错误率超过阈值可以创建告警；
9. 慢请求可以定位 API 和应用；
10. 调用日志能关联请求 ID。

**23. 非功能要求**

**23.1 性能要求**

1. 应用列表加载时间不超过 2 秒；
2. API 列表加载时间不超过 2 秒；
3. API 市场搜索响应时间不超过 3 秒；
4. API 调试响应时间取决于后端，但网关开销不超过 200ms；
5. 调用日志查询 7 天内数据响应不超过 5 秒；
6. 调用趋势图加载时间不超过 5 秒；
7. 大规模日志导出必须异步处理；
8. Webhook 投递日志写入延迟不超过 5 秒。

**23.2 安全要求**

1. AppSecret 不允许明文持久化；
2. Secret 明文只允许展示一次或限时展示；
3. Token、Secret、Password 在日志中必须脱敏；
4. 生产环境回调地址必须 HTTPS；
5. 生产环境应用必须配置 IP 白名单；
6. 敏感 API 必须认证；
7. 高敏数据 API 必须审批；
8. 所有密钥查看、重置、吊销操作必须审计；
9. API 请求必须支持防重放；
10. Webhook 必须支持签名校验。

**23.3 可用性要求**

1. API 网关应支持水平扩展；
2. 单个应用异常流量不得影响全局服务；
3. 单个 Webhook 回调失败不得阻塞事件生成；
4. 连接器任务失败不得影响其他连接器；
5. 限流策略应优先保护平台稳定性；
6. 监控和日志应支持问题定位。

**23.4 审计要求**

以下操作必须写入审计日志：

1. 创建应用；
2. 编辑应用；
3. 停用应用；
4. 删除应用；
5. 查看密钥；
6. 重置密钥；
7. 创建 API；
8. 编辑 API；
9. 发布 API；
10. 下线 API；
11. 订阅 API；
12. 取消订阅；
13. 创建 Webhook；
14. 启用 Webhook；
15. 修改连接器认证；
16. 启用连接器；
17. 修改限流配置；
18. 修改配额；
19. 导出调用日志；
20. 查看敏感请求明细。
