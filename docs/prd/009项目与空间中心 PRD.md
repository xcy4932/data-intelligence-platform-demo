**项目与空间中心 PRD**

**1. 模块定位**

**1.1 模块名称**

项目与空间中心，英文名称为 Project & Workspace Center。

**1.2 产品定位**

项目与空间中心是统一数据平台左侧导航的空间治理模块，负责管理平台内所有项目、空间、应用、业务线、项目成员、项目设置、项目资源配额、项目访问边界和项目级管控策略。

本模块不直接实现数据分析、A/B 实验、营销触达、标签生产、数据建模等业务功能，而是为这些业务功能提供统一的空间容器和管理边界。

在统一数据平台中，项目是数据隔离、权限隔离、资源归属、业务归属和运维治理的核心单位。所有资源都必须归属于某个项目或某个项目下的空间，不能存在无项目归属的业务资源。

**1.3 模块目标**

项目与空间中心需要解决以下问题：

1. 企业内可以创建哪些项目。
2. 项目之间如何进行数据、权限、资源隔离。
3. 项目是否为保密项目。
4. 项目是否允许普通用户搜索和申请加入。
5. 项目内资源的创建、授权、管理归属如何受项目管控程度影响。
6. 一个项目下可以接入哪些应用。
7. 一个项目是否支持多应用、多端、多主体。
8. 项目内成员如何管理。
9. 项目默认的下载、复制、嵌出、多语言、数据集和仪表盘展示规则如何配置。
10. 项目存储、任务、查询、数据回溯等资源配额如何限制。
11. 业务线如何承载项目内官方资源、数据集、报表、指标等资产目录治理。
12. 项目删除、归档、冻结时，项目内资源如何处理。
13. 用户在多个项目之间如何切换。
14. 各业务产品如何接入统一项目空间。

**1.4 设计原则**

1. **项目是平台资源的第一隔离边界**
   所有仪表盘、数据集、图表、数据连接、A/B 实验、Feature、标签、分群、营销任务、数据任务等资源都必须归属于一个项目。
2. **项目空间与组织身份解耦**
   项目成员来自组织与身份中心，但项目成员管理不修改用户的基础身份信息，只维护用户和项目之间的关系。
3. **项目权限与资源权限分层**
   项目权限决定用户能否进入项目、能否创建项目级资源、能否管理项目；资源权限决定用户对具体数据集、仪表盘、实验等资源能做什么。
4. **项目设置影响新增资源，不强制回刷历史资源**
   例如项目管控程度从常规切换到严格后，只影响切换后新建的资源；历史资源的所有者和管理权限保持原状，除非管理员显式发起批量治理。
5. **保密项目默认最小可见**
   保密项目只有已有项目权限的用户可见、可搜索。无项目权限用户无法在项目列表、项目切换器、搜索框中发现该项目。
6. **业务产品只注册资源类型和入口，不重复建设项目体系**
   BI、增长分析、A/B 测试、CDP、营销平台等业务产品统一挂载到项目下，不允许各产品各自维护独立项目空间。
7. **所有项目级变更必须可审计**
   项目创建、编辑、成员变更、管控策略变更、应用接入、业务线调整、配额修改、删除归档等操作必须记录操作日志。

**2. 功能范围**

**2.1 本期包含**

项目与空间中心包含以下功能：

1. 项目概览。
2. 项目列表。
3. 新建项目。
4. 编辑项目。
5. 项目详情。
6. 项目信息管理。
7. 项目类型管理。
8. 项目管控程度设置。
9. 项目成员管理。
10. 项目应用管理。
11. 多应用绑定。
12. 应用切换。
13. 业务线管理。
14. 项目资源配额管理。
15. 项目级下载/复制规则。
16. 项目级显示规则。
17. 项目级嵌出规则。
18. 项目归档。
19. 项目删除。
20. 项目切换器。
21. 项目访问申请入口。
22. 项目操作日志记录。

**2.2 本期不包含**

以下能力不在本模块中直接实现：

1. 用户、部门、用户组的基础身份创建，由组织与身份中心负责。
2. 资源级权限配置，由权限与策略中心负责。
3. 数据集、仪表盘、图表等资源本身的创建和编辑，由对应业务模块负责。
4. 具体数据连接表单，由数据接入与运维中心负责。
5. 数据安全脱敏、行列权限，由数据安全与合规中心负责。
6. 审批流配置，由申请审批与流程中心负责。
7. 查询任务队列和执行引擎，由数据运维中心负责。
8. 资产健康评分和血缘分析，由数据目录与治理中心负责。

**3. 用户角色与项目操作权限**

**3.1 系统管理员**

系统管理员拥有所有项目的最高管理权限。

可操作：

1. 查看全部项目，包括保密项目。
2. 新建项目。
3. 编辑任意项目基础信息。
4. 删除或归档任意项目。
5. 添加、移除任意项目成员。
6. 设置任意项目管理员。
7. 修改任意项目管控程度。
8. 修改任意项目资源配额。
9. 接入、编辑、删除任意项目下的应用。
10. 查看所有项目操作日志。
11. 设置项目是否为保密项目。
12. 设置项目是否允许申请加入。
13. 跨项目迁移资源。
14. 强制解除项目冻结状态。

**3.2 项目管理员**

项目管理员是项目内最高业务管理角色。

可操作：

1. 查看自己管理的项目。
2. 编辑项目名称、描述、LOGO。
3. 管理项目成员。
4. 为项目成员分配项目权限。
5. 修改项目显示规则。
6. 修改项目下载/复制规则，但不可超过系统全局限制。
7. 接入、编辑、删除项目内应用。
8. 新建、编辑、删除项目业务线。
9. 查看项目资源概览。
10. 查看项目访问统计。
11. 查看项目操作日志。
12. 在权限中心为项目内资源授权。
13. 管理项目内资源所有者转移。
14. 申请调整项目配额。

不可操作：

1. 删除项目，除非系统配置允许项目管理员删除项目。
2. 修改项目所属企业/集团。
3. 修改系统级项目创建策略。
4. 修改全局 License 策略。
5. 修改系统全局下载/复制开关。
6. 访问其他无权限项目。

**3.3 项目编辑者**

项目编辑者用于项目内日常资源生产。

可操作：

1. 进入项目。
2. 查看项目内自己有权限的资源。
3. 在允许位置创建资源。
4. 创建个人仪表盘、个人文件夹。
5. 在有编辑权限的公共文件夹下创建资源。
6. 在项目规则允许的情况下创建数据集、图表、分析任务。
7. 查看项目基础信息。
8. 查看自己相关的成员身份。

不可操作：

1. 编辑项目信息。
2. 管理项目成员。
3. 修改项目设置。
4. 删除项目。
5. 接入应用。
6. 修改项目配额。
7. 查看项目内所有资源。

**3.4 项目查看者**

项目查看者用于项目内普通消费数据。

可操作：

1. 进入项目。
2. 查看自己有权限的资源。
3. 新建个人仪表盘或个人文件夹，前提是项目管控程度允许。
4. 收藏资源。
5. 发起权限申请。

不可操作：

1. 在公共目录根目录创建公共资源。
2. 新建数据集。
3. 新建公共仪表盘。
4. 管理成员。
5. 修改项目设置。
6. 接入应用。

**3.5 项目全局查看者**

项目全局查看者适合业务负责人、审计人员或数据负责人。

可操作：

1. 进入项目。
2. 查看项目内全部公共仪表盘、公共文件夹、数据集等公共资源。
3. 查看全部数据，但仍受系统级脱敏、行列权限、安全策略限制。
4. 通过资源链接访问项目内个人资源。
5. 查看项目内资源访问统计摘要。

不可操作：

1. 修改资源，除非同时拥有资源编辑权限。
2. 管理项目成员。
3. 修改项目设置。
4. 删除项目。
5. 接入应用。

**3.6 普通成员**

普通成员指仅通过某个资源授权自动获得项目访问能力的用户。

可操作：

1. 进入项目。
2. 访问被授权资源。
3. 查看项目基础信息中的只读内容。
4. 发起权限申请。

不可操作：

1. 创建公共资源。
2. 管理项目。
3. 管理成员。
4. 修改项目设置。

**4.2.1 project\_role 权限顺序**

项目权限等级从低到高：

viewer < editor < global\_viewer < admin

用户同时通过多个来源获得项目权限时，最终项目权限取最高等级。

例如：

1. 用户通过资源授权获得 viewer。
2. 用户通过用户组获得 editor。
3. 用户最终项目权限为 editor。

**5. 信息架构**

**5.1 菜单结构**

一级菜单：项目与空间中心。

二级菜单：

1. 概览。
2. 项目列表。
3. 项目详情。
4. 项目成员。
5. 应用管理。
6. 业务线管理。
7. 项目设置。
8. 资源配额。
9. 项目操作日志。

**5.1.1 菜单展示规则**

1. 系统管理员可见全部菜单。
2. 项目管理员可见其有管理权限项目的全部项目内菜单。
3. 项目编辑者可见“项目详情”只读页，不可见项目设置、资源配额、应用管理。
4. 项目查看者可见“项目详情”只读页。
5. 无项目权限用户不可进入项目详情页。
6. 若用户没有任何项目权限，则进入项目与空间中心时展示空状态和“申请加入项目”入口。
7. 若系统配置关闭“项目申请”，则无项目用户仅展示“暂无可访问项目，请联系管理员”。

**5.2 项目内顶部上下文**

所有项目内页面顶部必须展示当前项目上下文：

1. 当前项目名称。
2. 项目类型标签。
3. 项目状态标签。
4. 项目切换器。
5. 当前用户在该项目下的项目权限。
6. 项目更多操作按钮。

项目切换器位于顶部导航左侧或项目名称旁。

**6. 通用交互规则**

**6.1 列表页通用规则**

所有列表页统一支持：

1. 搜索。
2. 筛选。
3. 分页。
4. 刷新。
5. 导出。
6. 空状态。
7. 加载状态。
8. 错误状态。

**6.1.1 搜索触发**

1. 用户输入关键词后，点击搜索按钮或按 Enter 触发搜索。
2. 不使用输入实时搜索。
3. 点击清空图标只清空输入框，不自动搜索。
4. 点击重置按钮清空搜索和筛选条件，并加载第一页。

**6.1.2 分页**

1. 默认每页 20 条。
2. 支持 20、50、100 条切换。
3. 切换页码保留筛选条件。
4. 筛选条件变更后回到第一页。
5. 删除当前页最后一条数据后，如果当前页无数据，自动跳转上一页。

**6.2 弹窗通用规则**

1. 弹窗右上角展示关闭按钮。
2. 表单无改动时点击关闭直接关闭。
3. 表单已改动时点击关闭，弹出二次确认。
4. 提交中确认按钮 loading，禁止重复提交。
5. 提交失败时不关闭弹窗。
6. 提交失败需在对应字段或弹窗顶部展示失败原因。

**6.3 删除类操作规则**

1. 删除必须二次确认。
2. 项目删除、应用删除、业务线删除属于高危操作。
3. 高危删除必须要求输入对象名称。
4. 存在资源依赖时不可直接删除。
5. 删除成功后写入操作日志。

**6.4 只读态规则**

当项目状态为 archived 或 frozen 时：

1. 项目详情可查看。
2. 项目成员可查看。
3. 项目资源可查看。
4. 不允许新建资源。
5. 不允许新增应用。
6. 不允许新增业务线。
7. 不允许修改项目设置。
8. archived 状态下系统管理员和项目管理员可恢复项目。
9. frozen 状态下只有系统管理员可解除冻结。

**9.4 第一步：基本信息**

**9.4.1 字段**

字段：

1. 项目名称。
2. 项目编码。
3. 项目 LOGO。
4. 项目描述。
5. 项目负责人。
6. 默认语言。
7. 默认时区。

**9.4.2 校验规则**

项目名称：

1. 必填。
2. 长度 2 到 60 个字符。
3. 租户内唯一。
4. 不允许全为空格。
5. 不允许包含特殊控制字符。

项目编码：

1. 必填。
2. 租户内唯一。
3. 只能包含小写字母、数字、下划线、短横线。
4. 长度 3 到 64 个字符。
5. 创建后不可修改。
6. 输入项目名称后，系统自动生成项目编码候选值，用户可修改。

项目 LOGO：

1. 非必填。
2. 支持 PNG、JPG、JPEG。
3. 文件大小不超过 2MB。
4. 未上传时使用默认项目图标。

项目负责人：

1. 必填。
2. 必须为 active 用户。
3. 默认当前创建人为项目负责人。

默认语言：

1. 默认继承企业默认语言。
2. 可选中文、英文。

默认时区：

1. 默认继承企业默认时区。
2. 可从系统时区列表选择。

**9.5 第二步：空间策略**

字段：

1. 项目类型。
2. 管控程度。
3. 是否允许申请加入。
4. 是否允许无权限用户搜索。
5. 默认仪表盘显示规则。
6. 默认数据集显示规则。

**9.5.1 项目类型**

可选：

1. 普通项目。
2. 保密项目。

选择普通项目：

1. allow\_search 默认 true。
2. allow\_apply\_join 默认 true。

选择保密项目：

1. allow\_search 强制 false。
2. allow\_apply\_join 默认 false。
3. 页面提示：“保密项目仅已有权限用户可见，无权限用户无法搜索到该项目。”

**9.5.2 管控程度**

可选：

1. 常规。
2. 中等。
3. 严格。

默认选择常规。

页面需要展示说明：

1. 常规：创建者默认获得其创建资源的管理权限。
2. 中等：公共资源默认由项目管理员管理，创建者获得编辑权限。
3. 严格：普通成员不可新建个人仪表盘，公共资源默认由项目管理员管理。

**9.5.3 允许申请加入**

开关字段。

开启后：

1. 无权限用户搜索到项目后，可发起加入申请。
2. 申请提交至项目管理员或指定审批流。

关闭后：

1. 无权限用户无法申请加入。
2. 无权限提示页展示“请联系项目管理员”。

保密项目默认关闭。

**9.5.4 允许无权限用户搜索**

开关字段。

普通项目可手动开启或关闭。

保密项目强制关闭，不可编辑。

**9.5.5 仪表盘显示规则**

可选：

1. 展示全部公共仪表盘。
2. 仅展示有权限仪表盘。

默认：

1. 常规模式：展示全部公共仪表盘。
2. 中等模式：仅展示有权限仪表盘。
3. 严格模式：仅展示有权限仪表盘。

**9.5.6 数据集显示规则**

规则同仪表盘显示规则。

**14.2 应用切换器**

1. 当前项目。

1. 项目名称分组。
2. 应用名称。
3. 应用类型。
4. 状态。
5. 是否当前选中。

**14.4 切换规则**

1. 项目管理员看到“当前项目尚未接入应用”。
2. 展示按钮“新增应用”。

**16.6.2 管控程度影响**

**常规**

1. 个人仪表盘允许创建。
2. 创建者默认获得个人仪表盘管理权限。
3. 公共仪表盘创建者默认获得管理权限。
4. 项目管理员不自动成为新增公共资源管理员，除非资源授权规则另有配置。

**中等**

1. 个人仪表盘允许创建。
2. 个人仪表盘创建者默认管理。
3. 公共资源由项目管理员默认管理。
4. 公共资源创建者默认获得编辑权限。
5. 普通用户不可把个人仪表盘授权给他人。

**严格**

1. 普通成员不可创建个人仪表盘。
2. 个人仪表盘入口对普通成员隐藏。
3. 公共资源由项目管理员默认管理。
4. 公共资源创建者默认获得编辑权限。
5. 普通用户不可为他人授权个人资源。

**16.7 资源显示规则**

2. 无权限资源点击后展示无权限页。
3. 如项目允许权限申请，则展示申请权限按钮。

仅展示有权限仪表盘：

1. 用户只看到自己有权限的仪表盘。
2. 无权限仪表盘完全不出现在列表中。
3. 搜索也无法搜到无权限仪表盘。

**16.7.2 数据集显示规则**

规则同仪表盘显示规则。

**16.8 下载与复制规则**

字段：

1. 全部资源均可下载/复制。
2. 全部资源均不可下载/复制。
3. 仅部分资源可以下载/复制。
4. 仅部分资源不可下载/复制。

**16.8.1 全部资源均可**

1. 项目内资源按资源权限判断是否可下载/复制。

**16.8.2 全部资源均不可**

1. 项目内所有数据下载、复制入口隐藏或禁用。
2. 用户点击相关按钮时提示“当前项目不允许下载或复制数据”。

**16.8.3 仅部分资源可以**

1. 需要点击“资源列表”配置允许下载/复制的资源。
2. 未在白名单中的资源不可下载/复制。

**16.8.4 仅部分资源不可**

1. 需要点击“资源列表”配置禁止下载/复制的资源。
2. 未在黑名单中的资源按资源权限正常下载/复制。

**16.8.5 资源列表按钮**

点击后打开资源选择弹窗。

弹窗支持：

1. 按资源名称搜索。
2. 按资源类型筛选。
3. 多选资源。
4. 已选择资源列表。
5. 确定。
6. 取消。

**16.9 嵌出设置**

字段：

**18. 项目归档、冻结与删除**

**18.1 项目归档**

**18.1.2 归档入口**

1. 项目列表更多菜单。

弹窗展示影响：

2. 不允许新建资源。
3. 不允许新增成员。

**18.1.4 归档逻辑**

点击确认：

1. 项目状态变为 archived。
2. 根据选择处理周期任务。
3. 写入操作日志。

archived 项目可恢复。

点击恢复：

**18.3 项目冻结**

**18.3.1 使用场景**

系统管理员发现项目存在安全风险、违规使用、资源异常消耗时，可冻结项目。

**18.3.2 冻结后影响**

1. 项目可查看。
2. 不允许新建、编辑、删除资源。
3. 不允许下载数据。
4. 不允许复制数据。
5. 不允许生成嵌出链接。
6. 所有周期任务暂停。
7. 项目管理员不可解除冻结。

**18.3.3 冻结确认**

弹窗字段：

1. 冻结原因。
2. 是否通知项目管理员。
3. 是否暂停所有任务。

冻结原因必填，长度 5 到 300 字。

**18.4 项目删除**

**18.4.1 删除条件**

项目可删除条件：

1. 当前用户为系统管理员，或系统配置允许项目管理员删除且当前用户为项目管理员。
2. 项目无运行中任务。
3. 项目内资源已清空或已完成迁移。
4. 项目未被外部系统引用。
5. 项目下应用已删除或停用。
6. 项目无待审批工单。

不满足条件时不可删除。

**18.4.2 删除前检查**

点击删除后进入删除检查页。

检查项：

1. 仪表盘数量。
2. 数据集数量。
3. 图表数量。
4. 数据连接数量。
5. 应用数量。
6. 任务数量。
7. A/B 实验数量。
8. 标签数量。
9. 分群数量。
10. 营销任务数量。
11. 待审批工单数量。
12. 外部引用数量。

**18.4.3 删除处理方式**

如果存在资源，管理员可选择：

1. 取消删除。
2. 先归档项目。
3. 迁移项目资源。
4. 强制删除，需系统配置允许。

强制删除默认不开放。

**18.4.4 删除确认**

若满足删除条件：

1. 用户输入项目名称。
2. 勾选“我确认该项目删除后不可恢复”。
3. 点击确认删除。

删除后：

1. 项目状态变为 deleted。
2. 项目不再出现在默认列表中。
3. 项目内成员关系标记 removed。
4. 项目内资源按删除策略处理。
5. 写入日志。

**20. 项目访问申请**

**20.1 触发入口**

入口：

1. 项目切换器中点击“申请加入”。
2. 无权限项目页点击“申请加入项目”。

**20.2 申请弹窗字段**

字段：

1. 项目名称，只读。
2. 申请人，只读。
3. 申请权限。
4. 申请理由。
5. 使用场景。
6. 预计使用期限。

申请权限：

1. 查看者。
2. 编辑者。

项目管理员权限不可由普通申请入口申请。

申请理由：

1. 必填。
2. 10 到 500 字。

预计使用期限：

1. 7 天。
2. 30 天。
3. 90 天。
4. 长期。

**20.3 提交逻辑**

点击提交：

1. 校验必填字段。
2. 检查是否已有相同项目的待审批申请。
3. 如果存在，提示“你已有该项目的待审批申请，请勿重复提交”。
4. 创建审批工单。
5. 通知项目管理员。
6. 弹窗关闭。
7. 展示提交成功提示。

**20.4 审批通过后**

审批通过：

1. 创建项目成员关系。
2. 按审批结果授予项目权限。
3. 通知申请人。

**22. 权限判定与状态逻辑**

**22.1 用户是否可进入项目**

判断顺序：

1. 用户状态必须为 active。
2. 项目状态不能为 deleted。
3. 系统管理员可进入全部项目。
4. 用户是项目成员，则可进入。
5. 用户通过资源授权自动获得项目查看权限，则可进入。
6. 用户通过用户组或角色获得项目权限，则可进入。
7. 以上都不满足，则不可进入。

**22.2 用户是否可搜索到项目**

判断顺序：

1. 系统管理员可搜索全部项目。
2. 用户已有项目权限，可搜索到。
3. 项目为 confidential，不可被无权限用户搜索。
4. 项目 allow\_search=false，不可被无权限用户搜索。
5. 项目 allow\_search=true，可被搜索到。

**22.3 用户是否可申请加入项目**

判断顺序：

1. 项目必须为 active。
2. 项目 allow\_apply\_join=true。
3. 用户状态必须 active。
4. 用户当前没有项目权限。
5. 不存在相同项目的待审批申请。
6. 满足后展示申请按钮。

**22.4 项目设置是否可编辑**

判断顺序：

1. 项目状态必须 active。
2. 当前用户是系统管理员或项目管理员。
3. 若项目 frozen，则只有系统管理员可编辑解除冻结相关配置。
4. 若项目 archived，则只允许恢复，不允许编辑普通配置。

**24. 异常与边界规则**

**24.1 项目不能没有管理员**

以下操作必须校验项目管理员数量：

1. 移除项目管理员。
2. 降级项目管理员。
3. 删除项目管理员用户。
4. 禁用项目管理员用户。
5. 批量移除成员。

如果操作后项目无管理员，则阻止并提示：

“项目至少需要保留一名项目管理员。”

**24.2 当前用户不能移除自己的项目管理员权限**

如果当前项目只有当前用户一个项目管理员：

1. 当前用户不能移除自己。
2. 当前用户不能将自己降级。
3. 需先添加其他项目管理员。

**24.3 保密项目不可被无权限用户发现**

以下入口均不能暴露保密项目：

1. 项目列表。
2. 项目切换器。
3. 搜索框。
4. 权限申请资源搜索。
5. 最近访问推荐。
6. 数据资产目录推荐。

**24.4 项目归档后不允许新增资源**

所有业务模块在创建资源前必须校验项目状态。

若项目为 archived：

提示：

“当前项目已归档，不允许新增或编辑资源。”

**24.5 项目冻结后不允许数据导出**

若项目为 frozen：

1. 隐藏下载按钮。
2. 隐藏复制按钮。
3. 禁止生成嵌出链接。
4. 接口层也必须拦截。

**24.6 应用删除不删除历史数据**

应用删除仅标记 deleted，不物理删除历史上报数据。历史报表是否可继续查询由业务产品的数据保留策略决定。

**24.7 业务线删除不能影响资产本身**

删除业务线不删除资产。若业务线下有资产，则必须先移动资产。

**27. 验收标准**

**27.1 项目列表验收**

1. 系统管理员可查看全部项目。
2. 普通用户只能查看有权限项目和允许搜索的普通项目。
3. 保密项目不会被无权限用户搜索到。
4. 项目筛选和分页逻辑正确。
5. 项目导出字段完整。
6. 项目状态标签展示正确。
7. 归档、冻结、删除项目的操作按钮按权限展示。

**27.2 新建项目验收**

1. 项目名称必填且租户内唯一。
2. 项目编码必填且创建后不可修改。
3. 保密项目自动关闭允许搜索和申请加入。
4. 新建项目至少有一名项目管理员。
5. 可选择暂不接入应用。
6. 可在创建项目时同时创建应用。
7. 创建成功后进入项目详情页。
8. 创建失败时保留表单内容。

**27.3 项目详情验收**

1. 项目基础信息展示正确。
2. 资源概览数量准确。
3. 应用概览展示正确。
4. 成员概览展示正确。
5. 当前用户项目权限展示正确。
6. 无权限用户不可进入保密项目详情页。

**27.4 项目成员验收**

1. 可添加 active 用户为项目成员。
2. 不可添加 disabled 或 deleted 用户。
3. 用户项目权限可修改。
4. 项目至少保留一名项目管理员。
5. 移除有资产用户时必须完成资产交接。
6. 批量移除不能导致项目无管理员。
7. 成员变更写入操作日志。

**27.5 应用管理验收**

1. 可新增不同类型应用。
2. 不同应用类型展示不同字段。
3. 应用名称项目内唯一。
4. 创建应用后自动生成 app\_id、app\_key、app\_secret。
5. app\_secret 创建后只明文展示一次。
6. 停用应用不删除历史数据。
7. 删除应用前必须完成依赖检查。
8. 应用变更写入日志。

**27.6 业务线管理验收**

1. 可创建一级业务线和子业务线。
2. 同级业务线名称不可重复。
3. 业务线最多支持 5 级。
4. 业务线下存在资产时不可删除。
5. 删除业务线不删除资产。
6. 移动资产到业务线后资产归属更新。

**27.7 项目设置验收**

1. 项目类型可在普通和保密之间切换。
2. 保密项目强制关闭无权限搜索。
3. 管控程度切换只影响新增资源。
4. 仪表盘显示规则生效。
5. 数据集显示规则生效。
6. 下载/复制规则生效。
7. 系统全局下载关闭时，项目下载设置不可突破。
8. 加密嵌出依赖系统全局开关。

**27.8 资源配额验收**

1. 可查看项目存储、任务、数据集等使用量。
2. 可编辑项目配额。
3. 配额超限时状态变为 exceeded。
4. 超限后按配置阻止新增资源或任务。
5. 配额修改写入日志。

**27.9 项目归档、冻结、删除验收**

1. 归档项目不可新增资源。
2. 归档项目可恢复。
3. 冻结项目不可下载、复制、编辑、新建。
4. 冻结项目只有系统管理员可解除冻结。
5. 删除项目前必须完成资源和任务检查。
6. 删除项目后默认列表不再展示。
7. 删除操作写入日志。

**27.10 项目切换器验收**

1. 用户可切换已有权限项目。
2. 保密项目不对无权限用户展示。
3. 非保密且允许搜索项目可被搜索到。
4. 无权限但可申请项目展示申请加入按钮。
5. 最近访问项目正确记录。
6. 收藏项目仅对当前用户生效。
