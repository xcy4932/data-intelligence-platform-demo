**系统配置中心 PRD**

**1. 模块定位**

**1.1 模块目标**

系统配置中心是数据平台的底座配置模块，用于集中管理平台级参数、租户基础信息、功能开关、菜单导航、系统字典、编码规则、消息通道、文件存储、任务调度、开放集成、系统公告、版本信息和操作日志。

系统配置中心不直接承载数据分析、权限审批、资源治理等业务流程，但它决定这些业务模块的运行边界、默认规则、展示方式和系统行为。

该模块的目标是：

1. 让平台管理员可以在不改代码的情况下配置平台基础行为。
2. 让不同租户、项目、环境拥有独立配置空间。
3. 让所有关键配置支持版本、变更记录、灰度、回滚和审计。
4. 让配置变更具备明确的校验、发布、生效、回滚机制。
5. 避免配置散落在各模块中，形成统一的配置管理入口。
6. 为 Codex 或前端开发提供可以直接落地的数据结构、页面逻辑、按钮逻辑和异常规则。

**1.2 模块边界**

系统配置中心负责“平台如何运行”的配置，不负责具体业务数据管理。

包含：

1. 租户基础信息配置。
2. 平台品牌与界面配置。
3. 菜单与导航配置。
4. 功能开关配置。
5. 系统参数配置。
6. 字典管理。
7. 编码规则管理。
8. 消息通道配置。
9. 文件与存储配置。
10. 任务调度配置。
11. 开放集成配置。
12. 系统公告配置。
13. 系统版本与环境信息。
14. 系统操作日志。
15. 配置变更发布与回滚。

不包含：

1. 用户、部门、角色、组织架构配置，归属组织与身份中心。
2. 权限策略、资源授权、访问控制策略，归属权限与策略中心。
3. 数据脱敏、敏感等级、合规规则，归属数据安全与合规中心。
4. 资源目录、资产元数据、血缘，归属资源与资产中心。
5. 申请审批流程配置，归属申请审批与流程中心。
6. 具体分析模型、看板、报表配置，归属各数据应用模块。

**1.3 使用角色**

| **角色** | **权限说明** |
| --- | --- |
| 平台超级管理员 | 可查看和修改所有系统配置，可发布、回滚、停用配置 |
| 租户管理员 | 可管理当前租户范围内的基础配置、功能开关、字典、公告、消息通道 |
| 项目管理员 | 可查看部分项目级默认配置，只能修改明确开放给项目的配置项 |
| 运维管理员 | 可查看环境信息、任务调度、存储配置、集成配置，可执行连接测试和任务重试 |
| 安全管理员 | 可查看消息通道、开放集成、配置变更日志，对高风险配置有审批或复核权限 |
| 审计员 | 只读查看配置内容、配置版本和操作日志 |
| 普通用户 | 无系统配置中心访问权限，但受系统配置结果影响 |

**2. 全局设计原则**

**2.1 配置分层**

系统配置必须支持四层：

平台级配置

租户级配置

项目级配置

用户级偏好配置

配置优先级从高到低为：

用户级偏好 > 项目级配置 > 租户级配置 > 平台级默认配置

规则：

1. 平台级配置由平台超级管理员维护。
2. 租户级配置只能影响当前租户。
3. 项目级配置只能影响当前项目空间。
4. 用户级偏好只影响当前用户本人。
5. 若某配置项被上级锁定，下级不能覆盖。
6. 前端展示配置值时，必须同时支持查看“当前生效值”和“来源层级”。

**2.2 配置状态**

所有可发布配置统一使用以下状态：

| **状态编码** | **状态名称** | **说明** |
| --- | --- | --- |
| DRAFT | 草稿 | 已编辑但未发布 |
| PUBLISHED | 已发布 | 当前正式生效版本 |
| DISABLED | 已停用 | 不再生效，但保留历史 |
| ARCHIVED | 已归档 | 只读保留，不允许恢复为生效 |
| PENDING\_APPROVAL | 待审批 | 配置变更需要审批后发布 |
| REJECTED | 已驳回 | 发布审批被驳回 |
| ROLLED\_BACK | 已回滚 | 曾经发布过，后被回滚替换 |

**2.3 配置生效方式**

配置项必须支持以下生效方式：

| **生效方式** | **说明** | **示例** |
| --- | --- | --- |
| 保存即生效 | 保存后立即影响系统行为 | 用户界面主题、公告展示 |
| 发布后生效 | 草稿保存后需点击发布 | 功能开关、菜单配置、字典 |
| 审批后生效 | 发布前必须走审批流程 | 开放集成、存储配置、消息通道密钥 |
| 定时生效 | 到指定时间自动生效 | 系统公告、功能灰度 |
| 重启后生效 | 修改后需服务重启 | 底层存储连接、队列配置 |

页面必须在每个配置项旁边展示生效方式，不允许用户误认为所有配置保存后立即生效。

**2.4 配置版本规则**

支持版本的配置对象包括：

1. 菜单配置。
2. 功能开关。
3. 系统参数。
4. 字典。
5. 编码规则。
6. 消息通道。
7. 存储配置。
8. 任务调度配置。
9. 开放集成配置。
10. 公告配置。

版本规则：

1. 每次发布生成一个新版本。
2. 版本号格式为 v1、v2、v3。
3. 草稿可以多次保存，不增加版本号。
4. 发布成功后才增加版本号。
5. 回滚本质上是基于历史版本生成一个新发布版本，不直接修改历史版本。
6. 历史版本只读，不允许编辑。
7. 配置详情页必须展示当前版本、最近发布人、发布时间、变更说明。

**2.5 高风险配置变更规则**

以下配置属于高风险配置：

1. 关闭登录安全校验。
2. 修改消息通道密钥。
3. 修改文件存储连接。
4. 修改任务调度执行频率。
5. 开启外部 API 访问。
6. 修改开放集成白名单。
7. 修改功能开关并影响全租户。
8. 修改系统参数导致权限、审批、安全、导出行为变化。
9. 删除字典值且该字典值已被业务数据引用。
10. 修改编码规则且该规则已生成过历史编号。

高风险配置点击“发布”时，不允许直接生效，必须进入申请审批与流程中心，生成配置变更申请。

**4. 配置总览页面**

**4.1 页面目标**

配置总览页面用于让管理员快速了解当前系统配置健康状态、待处理配置、最近变更、高风险配置、配置异常和系统运行状态。

**4.3 顶部统计卡片区**

展示以下卡片：

| **卡片** | **统计口径** | **点击行为** |
| --- | --- | --- |
| 已发布配置数 | 当前租户状态为 PUBLISHED 的配置数量 | 跳转系统参数，筛选已发布 |

**5. 租户基础配置页面**

**5.1 页面目标**

租户基础配置页面用于配置当前租户的基础信息、默认语言、时区、日期格式、数据保留策略、默认项目策略等。

**5.2 页面结构**

页面分为 Tabs：

基本信息

租户状态

页面顶部按钮：

默认进入只读状态，点击“编辑”后表单可编辑。

**5.3 基本信息 Tab**

字段：

| **字段** | **类型** | **必填** | **规则** |
| --- | --- | --- | --- |
| 租户名称 | 输入框 | 是 | 2-80 字 |
| 租户编码 | 输入框 | 是 | 创建后不可修改 |
| 租户简称 | 输入框 | 否 | 最多 20 字 |
| 管理员邮箱 | 输入框 | 是 | 必须为合法邮箱 |
| 联系电话 | 输入框 | 否 | 支持国际区号 |
| 租户说明 | 多行文本 | 否 | 最多 500 字 |
| 租户 Logo | 图片上传 | 否 | png/jpg/svg，最大 2MB |

**5.3.1 编辑按钮逻辑**

点击“编辑”：

1. 页面进入编辑状态。
2. 可编辑字段解除禁用。
3. “编辑”按钮隐藏。
4. 显示“保存”“取消”按钮。
5. 租户编码保持只读。

**5.3.2 保存按钮逻辑**

点击“保存”：

1. 前端校验必填字段。
2. 校验租户名称长度。
3. 校验管理员邮箱格式。
4. 若上传 Logo，则校验文件类型和大小。
5. 后端保存配置。
6. 保存成功后页面回到只读状态。
7. 操作写入日志。
8. 提示“租户基础信息已保存”。

若保存失败：

1. 保留当前编辑内容。
2. 字段级错误展示在对应输入框下方。
3. 全局错误展示在页面顶部。

**5.3.3 取消按钮逻辑**

点击“取消”：

1. 若内容未修改，直接退出编辑状态。
2. 若内容已修改，弹窗提示“当前修改未保存，确认放弃吗？”
3. 点击确认后恢复进入编辑前的数据。
4. 点击取消则关闭弹窗，继续编辑。

**5.4 区域与格式 Tab**

字段：

| **字段** | **类型** | **必填** | **默认值** |
| --- | --- | --- | --- |
| 默认语言 | 下拉选择 | 是 | zh-CN |
| 默认时区 | 下拉选择 | 是 | Asia/Shanghai |
| 日期格式 | 下拉选择 | 是 | yyyy-MM-dd |
| 时间格式 | 下拉选择 | 是 | HH:mm:ss |
| 日期时间格式 | 下拉选择 | 是 | yyyy-MM-dd HH:mm:ss |
| 数字千分位 | 开关 | 是 | 开启 |
| 小数位默认精度 | 数字输入 | 是 | 2 |
| 货币单位 | 下拉选择 | 否 | CNY |

规则：

1. 修改默认语言只影响未设置个人偏好的用户。
2. 修改时区影响平台时间展示，不修改数据库存储时间。
3. 日期格式保存后，列表、详情、日志中的时间展示必须按新格式渲染。
4. 小数位默认精度影响指标展示默认值，但不改变原始数据。

**5.5 默认项目规则 Tab**

字段：

| **字段** | **类型** | **说明** |
| --- | --- | --- |
| 新用户是否自动加入默认项目 | 开关 | 开启后新用户创建时自动加入 |
| 默认项目 | 项目选择器 | 开关开启时必填 |
| 默认项目角色 | 下拉选择 | 开关开启时必填 |
| 是否允许用户自行创建项目 | 开关 | 控制普通用户是否可创建项目 |
| 创建项目是否需要审批 | 开关 | 开启后走申请审批流程 |
| 项目归档保留天数 | 数字输入 | 项目归档后保留多少天可恢复 |

校验规则：

1. 自动加入默认项目开启时，必须选择默认项目和默认角色。
2. 默认项目必须处于启用状态。
3. 默认角色不能是项目管理员，除非平台超级管理员配置。
4. 项目归档保留天数必须大于等于 1。

**19. 配置发布与回滚机制**

**19.1 发布流程**

所有“发布后生效”的配置统一使用以下流程：

编辑草稿 -> 保存草稿 -> 校验配置 -> 提交发布 -> 风险判断 -> 直接发布或审批发布 -> 生效 -> 记录版本

**19.2 发布按钮统一逻辑**

点击“发布”：

1. 前端检查是否存在未保存内容。
2. 若存在未保存内容，提示“请先保存草稿后再发布”。
3. 后端执行配置完整性校验。
4. 后端执行风险等级判断。
5. 若低风险，直接发布。
6. 若中风险，根据租户策略决定是否审批。
7. 若高风险，必须创建审批申请。
8. 发布成功后生成新版本。
9. 配置状态变为 PUBLISHED。
10. 旧版本变为历史版本。
11. 写入操作日志。

**19.3 回滚流程**

点击“回滚”：

1. 打开版本列表。
2. 用户选择目标历史版本。
3. 系统展示当前版本和目标版本 diff。
4. 用户填写回滚原因。
5. 系统执行回滚风险判断。
6. 若高风险，创建配置变更审批。
7. 审批通过后，以历史版本内容生成新版本。
8. 新版本发布成功后成为当前生效版本。
9. 原当前版本保留为历史版本。
10. 回滚动作写入日志。

**19.4 配置 Diff 展示规则**

Diff 必须支持：

1. 新增字段标绿。
2. 删除字段标红。
3. 修改字段展示修改前和修改后。
4. 敏感字段只展示“已变更”，不展示明文。
5. JSON 配置按字段层级展开。
6. 列表型配置按新增项、删除项、修改项展示。

**22. 异常处理规则**

**22.1 配置发布失败**

发布失败时：

1. 配置状态保持 DRAFT。
2. 页面展示失败原因。
3. 如果失败发生在审批通过后的生效阶段，状态变为 EFFECT\_FAILED。
4. 管理员可点击“重试发布”。
5. 失败记录写入操作日志。

**22.2 配置冲突**

当新配置与已有配置冲突时：

1. 后端返回冲突对象。
2. 前端展示冲突配置名称、类型、当前值。
3. 用户不能强制发布，除非该配置类型允许覆盖。
4. 允许覆盖的场景必须二次确认。
5. 覆盖行为写入日志。

**22.3 下级配置覆盖失败**

若某配置项被上级锁定：

1. 下级页面仍可看到配置项。
2. 输入组件置灰。
3. 展示提示“该配置已被上级锁定，不允许覆盖”。
4. 不允许提交修改。

**22.4 敏感配置读取失败**

若用户无敏感配置查看权限：

1. 字段展示为 \*\*\*\*\*\*。
2. 不展示“查看明文”按钮。
3. API 不返回明文值。
4. 非法请求明文接口返回权限错误。
5. 权限错误写入安全日志。

**22.5 外部连接测试失败**

连接测试失败时：

1. 展示失败环节。
2. 展示错误原因。
3. 保留当前配置内容。
4. 不允许启用该配置。
5. 允许保存草稿。
6. 测试失败记录写入日志。

**23. 验收标准**

**23.1 配置总览验收**

1. 管理员进入配置总览后能看到配置数量、草稿数量、待审批数量、高风险数量、异常数量。
2. 点击统计卡片可以跳转到对应页面并自动带入筛选条件。
3. 健康检测失败时能展示具体失败原因。
4. 重新检测按钮能触发检测并刷新结果。

**23.2 租户基础配置验收**

1. 租户管理员可以编辑当前租户基础信息。
2. 租户编码创建后不可修改。
3. 保存失败时字段错误能准确定位。
4. 修改时区、日期格式后，平台展示格式按配置变化。
5. 停用租户后普通用户不能继续访问系统。

**23.3 菜单与导航验收**

1. 管理员可以新增、编辑、删除、排序菜单。
2. 页面菜单必须填写路由。
3. 外链菜单必须填写合法 URL。
4. 权限标识必须唯一。
5. 发布前能校验异常菜单。
6. 发布后新菜单对用户生效。
7. 历史版本可以查看和回滚。

**23.4 功能开关验收**

1. 管理员可以新建、启用、停用功能开关。
2. 功能开关支持按用户、角色、项目、比例灰度。
3. 灰度命中规则优先级正确。
4. 高风险开关变更必须走审批。
5. 前后端都能通过接口读取开关值。
6. 停用开关后相关功能不可访问或隐藏。

**23.5 系统参数验收**

1. 参数支持字符串、数字、布尔、JSON、枚举。
2. JSON 参数必须校验合法性。
3. 敏感参数默认脱敏。
4. 查看敏感参数明文需要权限并写入审计。
5. 发布后生效参数必须经过发布流程。
6. 重启后生效参数必须展示“待重启生效”。

**23.6 字典管理验收**

1. 管理员可以新增字典和字典项。
2. 字典项值在同一字典下唯一。
3. 已被引用的字典项不能删除。
4. 停用字典项后历史数据仍可展示。
5. 字典导入能校验错误行。
6. 发布后业务页面使用新字典值。

**23.7 编码规则验收**

1. 管理员可以配置编码组成。
2. 测试生成不占用真实流水号。
3. 同一适用对象只能启用一个编码规则。
4. 已生成历史编号的规则不能修改核心结构。
5. 新规则启用后只影响后续编号。

**23.8 消息通道验收**

1. 管理员可以配置邮件、Webhook 等通道。
2. 启用前必须测试连接成功。
3. 密钥不明文展示。
4. 修改密钥需要审批。
5. 停用默认通道前必须指定替代通道。
6. 通道测试记录写入日志。

**23.9 文件与存储验收**

1. 管理员可以配置不同用途的存储。
2. 测试连接必须完成写入、读取、删除三步。
3. 默认存储必须处于启用且测试成功状态。
4. 停用默认存储前必须设置替代存储。
5. 历史文件不因默认存储切换而迁移。
6. 存储密钥加密保存。

**23.10 任务调度验收**

1. 管理员可以新增、暂停、恢复、立即执行任务。
2. Cron 表达式必须合法。
3. 任务执行记录包含开始时间、结束时间、状态、失败原因。
4. 失败任务可按规则重试。
5. 并发策略能正确控制重复执行。
6. 暂停任务后不再自动触发。

**23.11 开放集成验收**

1. 管理员可以创建集成应用。
2. app\_secret 只展示一次。
3. 重置密钥支持立即失效和宽限期失效。
4. IP 白名单校验合法性。
5. API 权限范围扩大需要审批。
6. 调用日志可查询。

**23.12 系统公告验收**

1. 管理员可以创建、发布、下线公告。
2. 定时公告按发布时间自动发布。
3. 公告支持指定用户、角色、项目展示。
4. 需要确认的公告必须用户点击“我已知晓”。
5. 管理员可以查看阅读情况。
6. 公告下线后前端不再展示。

**23.13 操作日志验收**

1. 所有配置新增、修改、发布、停用、删除、回滚都写入日志。
2. 日志包含操作人、时间、IP、操作前后状态。
3. 敏感配置明文查看写入审计日志。
4. 日志支持筛选和导出。
5. 普通管理员只能查看自己权限范围内日志。
6. 审计员可以只读查看全量日志。

**24. 前端开发注意事项**

1. 所有配置编辑页面默认只读，点击编辑后进入编辑状态。
2. “保存草稿”和“发布”必须分离，不能保存后直接线上生效，除非配置项明确为保存即生效。
3. 所有高风险操作必须有二次确认。
4. 所有敏感字段必须脱敏展示。
5. 所有配置列表都必须支持搜索、筛选、分页。
6. 所有配置详情页都必须展示当前状态、当前版本、更新时间、修改人。
7. 所有发布动作都必须展示变更 diff。
8. 所有测试连接按钮必须有 loading 状态，防止重复点击。
9. 所有导入功能必须先校验，再确认导入。
10. 所有删除操作必须先检查引用关系。
11. 所有配置项都应由后端返回按钮权限，不允许前端写死角色判断。
12. 页面刷新后不能丢失已保存草稿。
13. 未保存离开页面必须弹出确认。
14. 复制配置时必须生成新编码或要求用户输入新编码。
15. 对于需要重启后生效的配置，页面必须展示醒目标识。

**25. 与其他中心的关系**

**25.1 与组织与身份中心**

系统配置中心使用组织与身份中心提供的用户、角色、部门、用户组，用于配置负责人、通知对象、灰度用户、公告目标用户。

**25.2 与权限与策略中心**

系统配置中心的菜单权限标识、功能开关访问范围、开放 API 授权范围，需要与权限与策略中心联动。

**25.3 与申请审批与流程中心**

高风险配置发布、密钥重置、存储连接修改、开放集成启用等操作必须进入申请审批与流程中心。

**25.4 与数据安全与合规中心**

敏感配置查看、密钥管理、外部访问、日志导出等行为需要符合安全与合规中心的策略。

**25.5 与资源与资产中心**

资源类型字典、编码规则、菜单入口、资源相关功能开关会影响资源与资产中心的展示和行为。

**25.6 与数据应用模块**

系统参数、字典、功能开关、主题配置会影响事件分析、留存分析、仪表盘、SQL 查询、数字大屏等数据应用模块。
