**数字大屏 3D 图表组件 PRD**

**1. 产品定位**

数字大屏 3D 图表组件用于在大屏编辑器中展示具有空间属性的数据，主要包括两类组件：

| **组件类型** | **产品定位** | **适用场景** |
| --- | --- | --- |
| 3D 地图 | 基于中国地图、世界地图、自定义行政边界或高德底图展示空间数据 | 全国业务分布、省市区下钻、区域热力、城市迁徙、交通流、门店覆盖、园区可达性 |
| 3D 地球 | 基于球体展示全球宏观数据 | 国际业务分布、全球流向、跨国贸易、航线、全球节点热力 |

3D 图表不是单一图表，而是一个“地图容器 + 多个子图层”的组合型场景组件。容器负责地图主体、视角、底图、交互、钻取和坐标系统；子图层负责具体业务数据表达，例如气泡、柱状、飞线、轨迹线、热力、信息标签、等时圈等。

**2. 功能范围**

**2.1 本期必须实现**

| **模块** | **是否必须** | **说明** |

**2.2 3D 地球的范围限制**

3D 地球本期只实现：

1. 地球容器；
2. 地球气泡层；
3. 地球飞线层。

其他子图层暂不在 3D 地球内开放。编辑器中如果用户在 3D 地球子图层面板中尝试添加未支持图层，系统不展示入口，而不是展示后报错。

**3. 整体页面与用户流程**

**3.1 编辑器入口**

在数字大屏编辑器左侧组件区中增加“场景”分类，分类下展示：

| **组件名称** | **图标** | **双击行为** | **拖拽行为** |
| --- | --- | --- | --- |
| 3D 地图 | map3d | 在画布中心创建默认 3D 中国地图 | 在鼠标释放位置创建组件 |
| 3D 地球 | earth3d | 在画布中心创建默认 3D 地球 | 在鼠标释放位置创建组件 |

创建后，画布中出现组件实例，左侧场景树增加节点：

3D地图 / 3D地球

├─ 地图容器

├─ 子图层1

├─ 子图层2

└─ ...

**3.2 组件编辑主流程**

用户使用流程必须固定为：

选择组件入口

→ 创建 3D 地图/3D 地球

→ 配置地图容器

→ 双击组件进入子图层编辑模式

→ 添加子图层

→ 为子图层绑定数据

→ 配置样式

→ 配置交互

→ 返回 Page 层

→ 保存大屏

→ 预览/发布

**3.3 子图层编辑模式**

用户双击 3D 地图或 3D 地球组件，进入子图层编辑模式。进入后页面状态变化如下：

| **区域** | **状态变化** |
| --- | --- |
| 画布 | 只聚焦当前 3D 组件，不允许选中其他普通组件 |
| 左侧组件区 | 只展示当前容器支持的子图层 |
| 左侧场景树 | 展示当前 3D 组件内部结构 |
| 右侧配置面板 | 选中地图容器时展示容器配置；选中子图层时展示子图层配置 |
| 底部数据面板 | 展示当前选中图层的数据可视化字段槽位 |
| 顶部返回按钮 | 显示“Page”，点击返回大屏页面级编辑 |

退出子图层编辑模式时，需要将当前视角、子图层列表、子图层配置、数据绑定、交互配置写回大屏组件状态。

**4. 核心数据模型**

**4.1 组件基础模型**

type ThreeDComponentType = 'map3d' | 'earth3d';

interface ThreeDComponent {

id: string;

type: ThreeDComponentType;

name: string;

x: number;

y: number;

width: number;

height: number;

opacity: number;

containerConfig: Map3DContainerConfig | Earth3DContainerConfig;

layers: ThreeDLayer[];

interactions: InteractionConfig[];

createdAt: string;

updatedAt: string;

}

保存逻辑：

1. x、y、width、height、opacity 属于大屏画布层级配置；
2. containerConfig 属于地图容器配置；
3. layers 只保存子图层配置，不允许直接修改容器配置；
4. 子图层顺序按照数组顺序渲染，数组后面的图层视觉层级更高；
5. 所有配置保存时必须进行 schema 校验，不合法时阻止保存并定位到错误字段。

**4.2 子图层通用模型**

type ThreeDLayerType =

| 'bubble'

| 'iconScatter'

| 'bar3d'

| 'infoLabel'

| 'flyLine'

| 'trajectoryLine'

| 'adminHeat'

| 'classicHeat'

| 'hexHeat'

| 'gridHeat'

| 'surfaceDecoration'

| 'risingChar'

| 'particle'

| 'isochrone';

interface ThreeDLayer {

id: string;

parentComponentId: string;

type: ThreeDLayerType;

name: string;

visible: boolean;

locked: boolean;

zIndex: number;

minZoom?: number;

maxZoom?: number;

dataBinding?: LayerDataBinding;

styleConfig: Record<string, any>;

animationConfig?: Record<string, any>;

interactions?: InteractionConfig[];

}

通用规则：

1. visible=false 时图层不参与渲染、不参与拾取、不触发交互；
2. locked=true 时图层不能被拖拽、删除、改名，但仍可通过配置面板修改参数；
3. minZoom/maxZoom 只在预览和查看态生效，编辑态始终可见，但需要在图层标题处显示“当前缩放下预览不可见”；
4. zIndex 只控制同类 overlay 的渲染顺序，不改变地图容器主体；
5. 删除子图层时必须二次确认，确认文案为：“删除后该图层的样式、数据绑定和交互配置将不可恢复”。

**5.2 基础配置逻辑**

基础配置包含组件位置、尺寸、不透明度：

| **字段** | **类型** | **校验** | **生效逻辑** |
| --- | --- | --- | --- |
| X | number | 可为负数 | 控制组件左上角在画布中的横坐标 |
| Y | number | 可为负数 | 控制组件左上角在画布中的纵坐标 |
| W | number | 最小 100 | 控制 WebGL canvas 宽度 |
| H | number | 最小 100 | 控制 WebGL canvas 高度 |
| 不透明度 | number | 0-1 | 作用于整个组件容器，不单独改变图层透明度 |

尺寸变更时：

1. 前端需要调用 renderer.resize(width, height)；
2. 地图相机保持中心点不变；
3. 南海附图、信息标签、tooltip 等屏幕坐标元素需要重新计算位置；
4. 若 width 或 height 小于最小值，输入框显示错误，组件不更新。

**5.3 背景填充**

配置项：

| **字段** | **类型** | **默认** | **说明** |
| --- | --- | --- | --- |
| enabled | boolean | false | 是否启用非透明背景 |
| color | color | #000000 | 背景色 |

渲染逻辑：

1. enabled=false 时，WebGL canvas 背景透明，透出大屏底色；
2. enabled=true 时，在地图主体后方渲染纯色背景层；
3. 背景层不参与鼠标事件；
4. 背景色透明度只由颜色 alpha 决定，不受地图行政区域透明度影响。

**5.4 手势交互**

配置项：

| **字段** | **默认** | **操作行为** |
| --- | --- | --- |
| enabled | true | 总开关 |
| zoomable | true | 鼠标滚轮缩放 |
| pannable | true | 右键拖拽平移 |
| pitchable | true | 左键上下拖拽调整倾斜角 |
| rotateable | true | 左键左右拖拽旋转 |

生效范围：

1. 编辑态中的“默认视角调整”不受手势开关影响；
2. 预览态和发布态必须严格受手势开关控制；
3. enabled=false 时，子开关全部不可操作，UI disabled；
4. enabled=false 时仍允许区域点击事件，但不允许用户拖拽地图。

**5.5 地图边界数据**

支持两类边界来源：

| **来源** | **说明** |
| --- | --- |
| 系统默认 | 中国、世界、中国省市区等内置边界 |
| 自定义 | 用户上传 GeoJSON 边界数据 |

**5.5.1 系统默认边界**

字段：

boundary.sourceType = 'system';

boundary.systemRegion = 'china' | 'world' | regionCode;

逻辑：

1. 中国地图初始化展示全国；
2. 用户钻取到省、市后，根据 regionCode 加载下一级边界；
3. 若 regionCode 无下级边界，地图保持当前层级，不再继续钻取；
4. 回退钻取时，从 drill.history 中取上一级区域。

**5.5.2 自定义 GeoJSON 边界**

上传校验：

1. 文件格式必须是 .json 或 .geojson；
2. 根节点必须是 FeatureCollection；
3. 每个 feature 必须包含 geometry；
4. geometry.type 必须是 Polygon 或 MultiPolygon；
5. 每个 feature 必须存在唯一名称字段，默认读取 properties.name；
6. 如果缺少 name，上传时提示用户选择一个属性字段作为区域名称；
7. 上传成功后生成 assetId，容器配置只保存 assetId，不保存完整 GeoJSON。

失败提示：

| **错误** | **提示** |
| --- | --- |
| 非 GeoJSON | 文件不是有效的 GeoJSON 格式 |
| 无 geometry | 边界数据缺少 geometry |
| 无名称字段 | 请指定区域名称字段 |
| 坐标异常 | 边界坐标无法解析，请确认坐标为经纬度 |

**5.6 行政地图**

行政地图负责 3D 地图主体区域渲染。

配置分组：

| **分组** | **字段** |
| --- | --- |
| 总开关 | enabled |
| 外描边 | width、color、opacity |
| 内描边 | width、color、opacity |
| 外描边发光 | enabled、color、intensity、radius |
| 外描边流光 | enabled、color、width、speed、length |
| 地图厚度 | extrusionHeight |
| 填充样式 | color、opacity、texture、metalness、roughness |
| 标注文本 | visible、fontSize、color、fontWeight、offset、formatter |

渲染逻辑：

1. enabled=false 时不渲染行政区块，但仍保留坐标系统，子图层继续显示；
2. extrusionHeight=0 时渲染为平面地图；
3. extrusionHeight>0 时区域拉伸为 3D 区块；
4. 外描边跟随当前地图边界的最外轮廓；
5. 内描边跟随行政区块之间的边界；
6. 流光动画必须使用独立动画时钟，不阻塞数据更新；
7. 标注文本基于区域中心点显示，若区域配置了自定义大区标注点，则优先使用自定义标注点。

**5.7 南海附图**

仅中国地图相关场景展示。

字段：

southChinaSeaInset = {

enabled: true,

position: 'left-top' | 'left-bottom' | 'right-top' | 'right-bottom',

scale: number,

marginX: number,

marginY: number,

seaColor: string,

landColor: string,

borderStyle: LineStyle,

frameStyle: LineStyle,

labelStyle: TextStyle

}

逻辑：

1. 只有当前地图为中国或中国省级地图时显示；
2. 当前钻取到海南时，南海附图需要自动适配视域，只展示主岛部分；
3. 南海附图不参与区域钻取；
4. 南海附图必须随组件尺寸变化重新定位；
5. 关闭行政地图时，南海附图也默认隐藏，但用户可强制开启，此时只显示南海小地图，不显示主体行政地图。

**5.8 高德底图**

高德底图用于在线地图底图展示。

配置项：

| **字段** | **类型** | **必填逻辑** |
| --- | --- | --- |
| enabled | boolean | 开启后必须校验公网访问能力 |
| styleType | preset/custom | 必填 |
| presetStyle | enum | styleType=preset 时必填 |
| customStyleId | string | styleType=custom 时必填 |
| key | string | 开启高德底图时必填 |
| securityJsCode | string | 开启高德底图时必填 |
| contentControl | object | 非必填 |
| filter | object | 非必填 |

标准模板：

'presetStyle' =

| 'phantom-black'

| 'indigo-blue'

| 'polar-night-blue'

| 'gray'

| 'moonlight-silver';

逻辑：

1. 开启高德底图后，允许关闭行政地图，只保留高德底图 + 子图层；
2. 若高德 key 为空，右侧面板显示错误：“请配置高德 Key”；
3. 若安全密钥为空，显示错误：“请配置高德安全密钥”；
4. 若自定义模式下样式 ID 为空，显示错误：“请配置高德自定义样式 ID”；
5. 高德底图 Logo 不提供隐藏配置；
6. 风格滤镜在底图 canvas 上执行，不影响子图层颜色；
7. 私有化环境断网时，开启高德底图需要显示“当前环境无法访问高德服务”。

**5.9 默认视角调整**

操作流程：

双击 3D 地图

→ 在子图层编辑模式中通过鼠标调整视角

→ 点击 Page 返回

→ 点击保存

→ 将当前 camera 写入 containerConfig.camera

保存字段：

camera = {

规则：

1. 只有点击保存后才持久化；

3. 点击取消则恢复进入编辑模式前的 camera；
4. 预览态以保存后的 camera 初始化。

**6.2 视图配置**

字段：

| **字段** | **说明** |
| --- | --- |
| longitude | 当前正对地球视点经度 |
| latitude | 当前正对地球视点纬度 |
| zoom | 球体整体缩放比例 |
| minZoom | 缩放下限 |
| maxZoom | 缩放上限 |

规则：

1. 经度范围为 [-180, 180]；
2. 纬度范围为 [-90, 90]；
3. minZoom <= zoom <= maxZoom；
4. 若用户修改 minZoom 导致当前 zoom 小于 minZoom，则自动将 zoom 修正为 minZoom；
5. 若用户修改 maxZoom 导致当前 zoom 大于 maxZoom，则自动将 zoom 修正为 maxZoom。

**6.3 地球材质**

字段：

| **字段** | **类型** | **校验** |
| --- | --- | --- |
| metalness | number | 0-1 |
| roughness | number | 0-1 |
| diffuseTextureAssetId | string/null | 图片资源 |
| normalTextureAssetId | string/null | 图片资源 |
| normalScale | number | 0-10 |

逻辑：

1. 填充贴图为空时使用默认地球纹理；
2. 法线贴图为空时不启用地形凹凸；
3. normalScale=0 时等价于关闭法线效果；
4. 上传贴图只允许 png、jpg、jpeg、webp；
5. 图片上传后先进入资源库，再由组件引用 assetId。

**6.4 自转**

字段：

| **字段** | **默认** | **说明** |
| --- | --- | --- |
| enabled | true | 是否开启自转 |
| speed | 1 | 正数逆时针，负数顺时针 |
| pauseOnHover | true | 鼠标悬停时暂停 |

逻辑：

1. 自转只在预览态和发布态生效；
2. 编辑态不自动旋转，避免影响配置；
3. 鼠标进入组件区域时，如果 pauseOnHover=true，暂停自转；
4. 鼠标离开后恢复自转；
5. 用户手动拖拽旋转地球后，自转从新的角度继续。

**6.5 辉光、云层、光照**

辉光：

1. 开启后在球体外层渲染半透明 glow mesh；
2. range 控制辉光半径相对球体半径的倍率；
3. intensity 控制颜色强度；
4. color 控制辉光颜色。

云层：

1. 开启后在地球外层渲染云层球壳；
2. scale 必须大于 1，否则自动修正为 1.01；
3. opacity 范围为 0-1；
4. speed 控制云层相对于地球的自转速度。

光照：

1. 环境光影响整体明暗；
2. 平行光影响球体明暗方向；
3. 地球自转时，平行光位置保持世界坐标不变，用于形成晨昏线效果；
4. 如果用户将环境光和平行光强度都设为 0，需要提示：“当前光照强度为 0，地球可能不可见”。

**6.6 地球交互限制**

2. 加载完成；

4. 子图层点击/双击，取决于子图层是否支持。

**7.3 位置解析通用逻辑**

位置字段支持多种类型。

**7.3.1 省市区解析**

适用图层：

1. 气泡层；
2. 图标散点层；
3. 柱状层；
4. 信息标签层；
5. 飞线层；
6. 轨迹线层；
7. 经典热力层；
8. 蜂窝热力层；
9. 网格热力层。

解析规则：

1. 支持省、市、区县简称和全称；
2. 例如“山东”和“山东省”解析为同一区域；
3. 例如“青岛”和“青岛市”解析为同一区域；
4. 如果同名城市存在歧义，优先使用当前地图层级范围内的区域；
5. 如果仍然无法唯一匹配，标记为 invalidLocation；
6. invalidLocation 不渲染，但需要在数据诊断中展示失败行数。

**7.3.2 经纬度解析**

格式要求：

lng,lat

规则：

1. 必须使用英文逗号；
2. 经度范围 [-180, 180]；
3. 纬度范围 [-90, 90]；
4. 允许字符串前后有空格；
5. 不允许中文逗号；
6. 不允许经纬度颠倒自动猜测；
7. 解析失败的数据不渲染。

**7.3.3 国家与 ISO3 解析**

适用于 3D 地球。

规则：

1. 国家名称支持部分简称和全称；
2. ISO3 支持 CHN、JPN、KOR 等三位国家代码；
3. 如果国家名称与 ISO3 同时存在，优先使用 ISO3；
4. 国家解析后取国家质心作为默认点位；
5. 若业务字段提供经纬度，则优先使用经纬度。

**7.3.4 文字地址解析**

适用于等时圈层。

规则：

1. 一个位置字段中只能存在一种地址类型；
2. 不允许同一字段既包含经纬度，又包含文字地址；
3. 文字地址应尽量完整；
4. 地址解析结果需要缓存；
5. 缓存 key 为 projectId + datasetId + fieldId + rawAddress；
6. 地址解析失败时，该行不参与等时圈计算。

**7.4 数值映射通用逻辑**

多个图层需要将数值映射为颜色、半径、高度、宽度等视觉属性。

基础算法：

function normalize(value: number, min: number, max: number) {

if (max === min) return 1;

return Math.max(0, Math.min(1, (value - min) / (max - min)));

}

线性映射：

visualValue = minVisual + normalize(value, dataMin, dataMax) \* (maxVisual - minVisual)

颜色映射：

color = interpolateColor(minColor, maxColor, normalize(value, dataMin, dataMax))

规则：

1. 只统计合法数值计算 dataMin/dataMax；
2. null、undefined、空字符串、NaN 均为非法值；
3. 非法值使用“无值底色”；
4. 如果数值字段未绑定，使用默认视觉值；
5. 如果所有数值都非法，图层展示空状态：“当前图层无有效数值”。

**8. 气泡层 PRD**

**8.1 适用容器**

| **容器** | **是否支持** |
| --- | --- |
| 3D 地图 | 是 |
| 3D 地球 | 是 |

**8.2 功能定位**

气泡层用于以圆形或多边形气泡展示空间点位分布。气泡大小和颜色可与数值指标绑定，适合表达城市销售额、门店规模、用户数、风险点、业务覆盖点等。

**8.3 数据绑定**

字段槽位：

| **槽位** | **必填** | **类型** | **说明** |
| --- | --- | --- | --- |
| 位置 | 是 | 地理字段 | 地图支持省市区/经纬度；地球支持国家/ISO3/经纬度 |
| 值 | 否 | 数值指标 | 用于映射气泡大小、颜色 |
| 主要标注 | 否 | 维度/指标 | 气泡主文本 |
| 次要标注 | 否 | 维度/指标 | 气泡副文本 |

规则：

1. 未绑定位置时，图层不渲染，并提示“请绑定位置字段”；
2. 绑定值字段后，气泡大小与值正相关；
3. 3D 地图中位置可解析到省、市、区县或经纬度；
4. 3D 地球中位置可解析到国家、ISO3 或经纬度；
5. 同一位置多行数据默认不聚合，每行渲染一个气泡；如需聚合，应由数据集层先完成。

| **分组** | **字段** | **默认** | **逻辑** |

| 气泡样式 | maxColor | #FF5A5F | 数值最大时颜色 |
| 气泡样式 | emptyColor | #999999 | 无效值颜色 |
| 气泡大小 | minRadius | 6 | 最小半径 |
| 气泡大小 | maxRadius | 30 | 最大半径 |
| 呼吸动画 | enabled | true | 半径周期变化 |

5. 上传贴图必须为图片资源。

**8.5 渲染逻辑**

每条数据转为：

interface BubbleRenderItem {

流程：

读取数据

→ 解析位置

→ 过滤无效位置

→ 计算数值 min/max

→ 计算 radius/color

→ 生成 mesh 或 sprite

→ 绑定拾取 id

→ 渲染

3D 地图气泡层支持每项气泡单击/双击。

事件 payload：

5. 变更轮播状态；

柱状层通过三维柱体表达空间点位上的数值大小，适合展示城市销售额、区域用户量、门店交易额、站点吞吐量等。

**10.2 数据绑定**

| **槽位** | **必填** | **类型** | **说明** |
| --- | --- | --- | --- |
| 位置 | 是 | 省市区/经纬度 | 柱体所在位置 |
| 值 | 是 | 数值 | 控制柱体高度和颜色 |

**10.3 配置项**

| **分组** | **字段** | **默认** | **逻辑** |
| --- | --- | --- | --- |
| 通用配置 | minZoom/maxZoom | 空 | 缩放可见性 |

| 柱子形状 | edgeCount | 3 | useCylinder=false 时生效 |
| 柱子形状 | topRadius | 8 | 顶面半径 |
| 柱子形状 | bottomRadius | 8 | 底面半径 |

**10.4 渲染逻辑**

绑定位置和值

→ 解析位置

→ 过滤无效位置

→ 计算数值 min/max

→ 按值计算高度

→ 按值计算颜色

规则：

2. 值越大，颜色越接近最大值颜色；
3. null 值不参与 min/max 计算；
4. 无值底色只对位置合法但值非法的数据生效；
5. 如果位置非法，不渲染柱体。

**11. 信息标签层 PRD**

信息标签层用于在地图点位上展示自定义信息卡片。标签内容可以由文字、图片、视频、网页等组件组合而成，适合展示城市卡片、门店详情、实时告警、重点项目、区域 KPI 等。

| 飞线样式 | emitInterval | 1 | 发射间隔 |
| 底线 | color | #1E90FF | 起终点底线颜色 |
| 落地冲击环 | color | #00FFFF | 冲击环颜色 |
| 落地冲击环 | radius | 20 | 晕开半径 |
| 落地冲击环 | speed | 1 | 晕开速度 |

**12.6 渲染逻辑**

1. 起点和终点必须均解析成功；
2. 地图飞线使用地图坐标空间中的弧线；
3. 地球飞线使用球面大圆路径；
4. 动画粒子沿路径从起点飞向终点；
5. speed 控制单位时间内路径进度；
6. emitInterval 控制同一路径连续飞线之间的时间差；
7. 终点颜色如果绑定字段，则按照连续映射或离散映射计算；
8. 数据更新时需要销毁旧路径并重建，但相机状态不变。

**13. 轨迹线层 PRD**

**13.1 功能定位**

轨迹线层用于表达多个连续位置之间的运动轨迹，例如物流路线、车辆行驶路线、巡检路线、用户迁移路径等。

**13.2 数据绑定**

读取每行轨迹

行政区域热力层存在两种模式：

**普通行政区模式**

数据行政字段

→ 匹配当前地图行政区

→ 每个区域取对应热力值

→ 按 min/max 映射颜色

如果同一区域出现多行数据：

1. 默认聚合方式为 sum；

**18. 等时圈层 PRD**

**18.1 功能定位**

等时圈层用于展示某个点在指定交通方式和时间范围内可到达的空间范围，适合园区服务半径、门店覆盖范围、金融网点可达性、汽车服务圈、政务服务覆盖等场景。

**18.2 数据绑定**

| **槽位** | **必填** | **类型** | **说明** |
| --- | --- | --- | --- |
| 位置 | 是 | 具体地址/经纬度 | 中心点 |
| 排序/筛选 | 否 | 任意字段 | 数据筛选 |
| TOP N | 否 | number | 限制展示前 N 条 |

位置字段规则：

1. 一个字段中只能有一种位置类型；
2. 不能同时混用经纬度和文字地址；
3. 经纬度必须使用英文逗号；
4. 文字地址尽量完整；

**18.4 计算逻辑**

读取位置字段

→ 解析中心点坐标

→ 校验 Mapbox Token

→ 根据交通方式和时长请求等时圈服务

→ 获取 polygon

→ 渲染 polygon

→ 渲染中心点图标

请求参数：

interface IsochroneRequest {

token: string;

center: [number, number];

mode: 'walking' | 'cycling' | 'driving';

durationMinutes: number;

}

缓存规则：

cacheKey = lng + lat + mode + duration

1. 同一中心点、交通方式、时长命中缓存时不重复请求；
2. 用户点击“清除缓存并刷新”后清空当前图层缓存；
3. Token 为空时不发起请求；
4. duration > 60 时输入框报错；
5. 服务请求失败时，该点展示错误状态，但不影响其他点。

**18.5 数据更新方式**

支持：

| **方式** | **逻辑** |
| --- | --- |
| 自动更新 | 按配置时间间隔重新请求数据 |
| 只请求一次 | 首次加载请求，后续不自动刷新 |
| 不自动请求 | 仅配置改变或手动刷新时请求 |

3. 图标散点层只展示当前区域范围内点；
4. 行政区域热力层按当前层级展示；
5. 信息标签层根据当前区域更新候选标签；
6. 飞线层如果起点或终点在当前区域内，则展示；否则隐藏；
7. 轨迹线层只要轨迹经过当前区域即可展示。

**24. 异常诊断与性能 PRD**

**24.1 WebGL2 检测**

组件加载前执行：

function checkWebGL2Support() {

const canvas = document.createElement('canvas');

const gl = canvas.getContext('webgl2');

return !!gl;

}

如果不支持：

1. 组件区域显示错误态；
2. 文案：“当前浏览器或显卡不支持 WebGL2，3D 地图无法渲染”；
3. 提供“查看诊断详情”按钮；
4. 不初始化 3D renderer。

**24.2 硬件加速检测**

前端无法直接判断 Chrome 是否开启硬件加速，但可以结合 renderer 信息提示。

诊断项：

1. WebGL2 是否可用；
2. renderer 是否为 SwiftShader；
3. 是否可能为软件渲染；
4. 是否处于虚拟机/远程桌面环境。

如果检测到 SwiftShader：

当前浏览器可能正在使用软件渲染，3D 地图性能会明显下降。请检查浏览器硬件加速或显卡驱动。

**24.3 黑屏/闪烁处理**

如果 renderer context lost：

1. 监听 webglcontextlost；
2. 阻止默认行为；
3. 显示“WebGL 上下文丢失，正在尝试恢复”；
4. 监听 webglcontextrestored；
5. 恢复后重新初始化图层；
6. 如果 3 次恢复失败，显示错误态。

**24.4 性能阈值**

建议阈值：

| **图层** | **警告阈值** | **处理** |
| --- | --- | --- |
| 气泡层 | 5000 点 | 提示开启数据筛选 |
| 图标散点层 | 3000 点 | 自动关闭部分标注 |
| 柱状层 | 3000 柱 | 提示降低数据量 |
| 飞线层 | 2000 条 | 降低动画精度 |
| 轨迹线层 | 1000 条轨迹 | 提示简化轨迹点 |
| 经典热力层 | 50000 点 | 使用聚合纹理 |
| 蜂窝/网格热力 | 50000 点 | 后台预聚合 |
| 粒子系统 | 10000 粒子 | 提示降低粒子数量 |

**27. 验收标准**

**27.1 3D 地图容器**

1. 用户可从组件区创建 3D 地图；
2. 创建后默认显示中国 3D 地图；
3. 可配置 X/Y/W/H/不透明度；
4. 可开启/关闭背景填充；
5. 可开启/关闭缩放、平移、倾斜、旋转；
6. 可切换系统边界和自定义 GeoJSON；
7. 可开启/关闭行政地图；
8. 可配置南海附图；
9. 可开启高德底图；
10. 可保存默认视角；
11. 可通过区域点击钻取；
12. 可通过按钮钻取指定区域；
13. 可通过 -1 返回上一级；
14. 可通过“全国”返回全国；
15. 可通过 Region:大区名 钻取自定义大区。

**27.2 3D 地球容器**

1. 用户可创建 3D 地球；
2. 地球支持经度、纬度、缩放配置；
3. 支持自转；
4. 支持悬浮暂停；
5. 支持辉光；
6. 支持云层；
7. 支持光照；
8. 支持填充贴图和法线贴图；
9. 支持气泡层；
10. 支持飞线层；
11. 不支持行政区域钻取。

**27.3 子图层**

1. 用户可进入子图层编辑模式；
2. 用户可新增支持的子图层；
3. 用户可删除、复制、重命名、显隐、排序子图层；
4. 图层可绑定数据；
5. 位置字段解析失败时不渲染错误数据；
6. 数值字段非法时使用无值逻辑；
7. 缩放超出可见区间时图层隐藏；
8. 数据刷新后图层重新渲染；
9. 保存大屏后重新打开配置不丢失。

**27.4 异常与性能**

1. 不支持 WebGL2 时不初始化地图；
2. 软件渲染时展示性能风险提示；
3. WebGL context lost 时尝试恢复；
4. 虚拟机环境下展示性能风险提示；
5. 数据量超过阈值时展示性能提示；
6. 图层异常不应导致整个大屏崩溃；
7. 单个图层数据失败时，只显示该图层错误，不影响其他图层。

**27.5 保存与发布**

1. 编辑态配置修改后可保存；
2. 保存后预览态展示一致；
3. 发布态与预览态展示一致；
4. 数据刷新策略在发布态生效；
5. 交互事件在发布态生效；
6. 未保存退出时提示用户保存。
