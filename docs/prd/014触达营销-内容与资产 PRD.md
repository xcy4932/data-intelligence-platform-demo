**触达营销-内容与资产 PRD**

**1. 产品定位与范围**

**1.1 产品目标**

「内容与资产」是触达营销平台中用于统一管理营销素材、触达内容、活动资产、权益资源、落地页、短链和通道模板的基础模块。它的目标不是直接完成用户触达，而是为「消息触达」「流程画布」「资源位」「弹窗」「Webhook」「短信模板」等执行型营销模块提供可复用的内容资产。

本模块需要解决以下问题：

1. 运营人员可以统一创建、查看、编辑、复用营销活动；
2. 运营人员可以统一上传和管理图片、视频、音频、文案等素材；
3. 运营人员可以创建和管理 H5 落地页，并在触达任务中插入落地页链接；
4. 运营人员可以创建短链、小程序短链，并追踪 PV、UV；
5. 运营人员可以管理短信签名与短信模板；
6. 运营人员可以查看 Webhook 模板字段；
7. 运营人员可以创建和管理 WhatsApp 模板；
8. 运营人员可以导入、发放、查看权益；
9. 运营人员可以在短信、Webhook、魔方落地页等触达场景中插入权益；
10. 内容资产可以被消息触达、流程画布、资源位、公众号消息、Webhook 等模块引用。

**1.2 功能范围**

本 PRD 覆盖以下模块：

| **一级模块** | **二级功能** |
| --- | --- |
| 活动管理 | 活动列表、创建活动、编辑活动、删除活动、活动关联、活动筛选 |
| 素材管理 | 素材列表、分组管理、素材上传、素材查看、素材下载、素材引用 |
| 落地页模板 | 模板列表、模板预览、基于模板创建落地页 |
| 落地页管理 | 落地页列表、新建落地页、编辑器、预览、发布、版本切换、数据分析 |
| 魔方落地页 | 外部魔方落地页入口、魔方落地页链接插入 |
| 短信签名与模板 | 通道切换、签名列表、模板列表、三方签名导入、三方模板导入 |
| Webhook 模板 | 模板列表、模板字段查看、模板通道区分 |
| WhatsApp 模板 | 模板列表、新增模板、编辑模板、删除模板、内容配置 |
| 链接工具 | 通用短链、带参长链转短链、小程序短链、短链列表、数据趋势、明细下载 |
| 权益管理 | 权益导入、权益列表、权益下发、权益发放明细、明细导出 |

**1.3 不在本 PRD 展开的功能**

以下能力仅作为依赖存在，不在本 PRD 中展开：

1. 短信通道、Webhook 通道、WhatsApp 通道、微信小程序通道的底层接入配置；
2. 魔方活动落地页系统内部编辑器；
3. 消息触达任务和流程画布的完整创建流程；
4. 资源位管理完整流程；
5. 企业权限管理后台；
6. 审批流后台；
7. 三方权益系统接口对接技术细节。

**3. 全局数据状态与引用关系**

**3.1 内容资产状态**

不同资产的状态不同，统一抽象如下：

| **状态** | **适用模块** | **含义** |
| --- | --- | --- |
| 草稿 | 落地页、模板类 | 已保存但未发布或未生效 |
| 已上线 | 落地页 | 当前线上可访问版本 |
| 已下线 | 落地页 | 不再线上访问 |
| 审核中 | 短信模板、WhatsApp 模板 | 等待通道或平台审核 |
| 审核通过 | 短信模板、WhatsApp 模板 | 可被触达任务使用 |
| 审核驳回 | 短信模板、WhatsApp 模板 | 不可使用 |
| 有效 | 短链、权益、素材 | 可正常引用 |
| 已失效 | 短链、权益 | 不可继续使用或访问 |
| 库存不足 | 权益 | 权益剩余数量不足 |

**3.2 内容资产引用关系**

内容资产可能被以下业务引用：

| **资产** | **可被引用位置** |
| --- | --- |
| 活动 | 消息触达、流程画布、资源位素材 |
| 素材 | 落地页、资源位、Webhook、公众号群发、公众号活跃、弹窗、消息触达图片上传控件、流程画布图片上传控件 |
| 落地页 | Webhook、消息触达、流程画布、资源位、触达模板 |
| 短链 | 短信、Webhook、流程画布、消息触达 |
| 短信签名 | 短信触达任务 |
| 短信模板 | 短信触达任务 |
| Webhook 模板 | Webhook 触达任务 |
| WhatsApp 模板 | WhatsApp 触达任务 |
| 权益 | Webhook、短信、魔方落地页 |

删除资产前必须判断是否被引用。

通用删除规则：

若资产未被任何任务、页面、模板、活动引用，允许删除。

若资产已被引用，禁止删除，并展示引用位置。

引用提示文案：

该资产已被以下内容引用，暂不可删除。

**4. 活动管理**

**4.1 功能定位**

活动管理用于统一管理营销活动。活动是多个营销任务的集合，可以将消息触达、流程画布、资源位素材关联到同一个活动下，便于后续按活动维度进行聚合分析。

示例：

1. 618 活动；
2. 双十一活动；
3. 长期拉新活动；
4. 新用户召回活动；
5. 会员促活活动。

**4.2 页面入口**

内容与资产 / 活动管理

进入页面时：

1. 校验活动管理查看权限；
2. 加载当前项目下活动分组和活动列表；
3. 默认展示全部活动；
4. 按创建时间倒序展示。

**4.5 新建活动**

**4.5.1 入口**

点击「新建活动」按钮。

**4.5.2 弹窗字段**

| **字段** | **控件** | **必填** | **规则** |
| --- | --- | --- | --- |
| 活动名称 | Input | 是 | 不可为空，同项目下不可重名 |
| 活动分组 | Select | 是 | 从已有分组中选择 |

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 确定 | 校验字段，通过后创建活动 |

**4.5.3 活动名称规则**

1. 必填；
2. 前后空格 trim；
3. 最大长度建议 50 个字符；
4. 同一项目下不可重名；
5. 不允许仅输入空格。

校验失败文案：

| **场景** | **文案** |
| --- | --- |
| 未填写 | 请输入活动名称 |
| 重名 | 活动名称已存在，请修改 |
| 超长 | 活动名称不能超过 50 个字符 |

**4.5.4 创建成功**

成功后：

1. 关闭弹窗；
2. 刷新活动列表；
3. 新活动显示在列表第一行；
4. 提示：活动创建成功。

**4.6 编辑活动**

**4.6.1 入口**

活动列表点击「编辑」。

**4.6.2 可编辑字段**

1. 活动名称；
2. 活动分组。

不可编辑字段：

1. 活动 ID；
2. 创建人；
3. 创建时间；
4. 关联任务数量。

**4.6.3 保存逻辑**

点击「确定」：

1. 校验活动名称；
2. 校验活动分组；
3. 若活动名称未变化，不做重名校验；
4. 若活动名称变化，需要做重名校验；
5. 保存成功后刷新列表。

**4.7 删除活动**

**4.7.1 删除条件**

仅当活动没有绑定以下内容时允许删除：

1. 消息触达任务；
2. 流程画布；
3. 资源位素材。

判断逻辑：

canDelete =

relatedTouchTaskCount === 0 &&

relatedFlowCanvasCount === 0 &&

relatedResourceCount === 0;

**4.7.2 删除交互**

点击「删除」：

若可删除，弹出确认框：

确认删除该活动吗？删除后不可恢复。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗 |
| 确认删除 | 删除活动 |

若不可删除，弹窗展示：

该活动已绑定触达任务、流程画布或资源位素材，暂不可删除。

并展示绑定数量。

**4.8 活动关联逻辑**

在消息触达、流程画布、资源位素材创建时，展示「关联活动」字段。

活动选择结构：

活动分组

├── 活动 A

├── 活动 B

└── 活动 C

规则：

1. 一个触达任务只能关联一个活动；
2. 一个流程画布只能关联一个活动；
3. 一个资源位素材只能关联一个活动；
4. 关联活动为选填；
5. 不关联活动时，该任务不进入活动聚合分析。

**5. 素材管理**

**5.1 功能定位**

素材管理是营销内容的统一素材库，支持图片、视频、音频、文案等素材的上传、分组、查看、下载和引用。

素材可用于：

1. 落地页编辑；
2. 资源位编辑；
3. Webhook 内容；
4. 公众号群发消息；
5. 公众号活跃消息；
6. 弹窗；
7. 个性化资源位；
8. 消息触达图片上传控件；
9. 流程画布图片上传控件。

**5.2 页面入口**

内容与资产 / 素材管理

1. 校验素材查看权限；
2. 加载素材分组；
3. 加载素材列表；
4. 默认展示全部类型素材；
5. 默认按上传时间倒序排列。

| --- | --- |

**12.6 带参长链转短链**

**12.6.1 字段**

| **字段** | **必填** | **说明** |

| 有效期 | 是 | 到期失效 / 永久有效 |
| 到期时间 | 条件必填 | 到期失效时填写 |
| 统计点击 UV | 是 | 通常需要开启 |

5. 示例：

https://example.com/page?user\_id={{user\_id}}&level={{user\_level}}

执行时：

1. 每个用户生成带不同参数的链接；
2. 再转换为短链；
3. 用户点击后进入带自己参数的原始页面。

3. 点击后生成原始长链；

校验规则：

6. 数量必须为正整数。

**13.8 权益下发**

**13.8.1 使用场景**

在 Webhook、短信、魔方落地页内点击「插入权益」。

**13.8.2 插入流程**

1. 进入 Webhook 或短信通道配置页面；
2. 点击「插入权益」；
3. 打开权益选择弹窗；
4. 选择权益；
5. 确认后回填权益名称或权益占位符；
6. 任务提交审批或保存后完成权益插入。

**13.8.3 权益选择弹窗**

字段：

| **字段** | **说明** |
| --- | --- |
| 权益名称 | 权益名称 |
| 权益类型 | 兑换码、实物、积分 |
| 可用数量 | 当前库存 |
| 状态 | 是否可用 |
| 操作 | 选择 |

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 查询 | 按筛选条件查询权益 |
| 重置 | 清空筛选 |
| 确定 | 插入已选权益 |
| 取消 | 关闭弹窗 |

选择规则：

1. 仅可选择有效权益；
2. 库存为 0 的权益不可选择；
3. 同一内容中可插入多个权益，但需要校验库存；
4. 权益被插入后，显示权益名称；
5. 具体发放在触达执行时完成。

**13.9 权益发放逻辑**

触达执行时：

1. 系统判断目标用户是否需要发放权益；
2. 判断权益库存；
3. 若库存充足，锁定并发放权益；
4. 若库存不足，权益发放失败；
5. 对兑换码权益，分配一个未使用码值；
6. 对实物和积分，扣减对应数量；
7. 发放结果进入权益发放明细。

**13.10 权益发放明细**

**13.10.1 入口**

权益列表操作栏点击「查看明细」。

**13.10.2 明细字段**

| 发放数量 | 发放数量 |
| 兑换码 | 兑换码类型展示 |
| 发放通道 | 短信、Webhook、魔方落地页等 |
| 发放任务 | 触达任务或流程画布 |
| 发放人 | 发放人或任务创建人 |
| 发放时间 | 发放时间 |
| 发放状态 | 成功、失败 |
| 失败原因 | 失败时展示 |

**13.10.3 筛选**

支持：

1. 发放时间；
2. 权益类型；
3. 发放通道；
4. 发放状态；
5. 用户 ID；
6. 任务 ID。

**13.10.4 导出明细**

点击「下载」或「导出」：

1. 校验导出权限；
2. 按当前筛选条件导出；
3. 生成 Excel；
4. 若数据量过大，进入异步导出；
5. 导出完成后提示下载。

**14. 跨模块引用规则**

**14.1 在消息触达中引用内容资产**

可引用资产：

1. 短信签名；
2. 短信模板；
3. 短链；
4. 活动落地页；
5. 权益；
6. 素材；
7. Webhook 模板；
8. WhatsApp 模板；
9. 活动。

引用时：

1. 只能选择有效状态资产；
2. 已失效资产不展示；
3. 历史任务中引用的失效资产可查看但不可重新提交；
4. 若复制任务引用失效资产，编辑页必须提示重新选择。

**14.2 在流程画布中引用内容资产**

触达节点可引用：

1. 短信模板；
2. 短信签名；
3. Webhook 模板；
4. WhatsApp 模板；
5. 素材；
6. 短链；
7. 权益；
8. 落地页；
9. 活动。

节点保存时校验：

1. 模板是否有效；
2. 素材是否存在；
3. 短链是否有效；
4. 权益是否有库存；
5. 落地页是否已上线；
6. 活动是否存在。

**14.3 在落地页中引用素材**

落地页编辑器调用素材库时：

1. 图片组件只能选择图片；
2. 视频组件只能选择视频；
3. 音频组件只能选择音频；
4. 图文模块可选择图片和文案；
5. 素材被删除后，落地页编辑器打开时展示失效提示；
6. 已发布页面中的素材 URL 应保持可访问，除非物理文件被删除。

**14.4 在活动中关联任务**

关联规则：

1. 消息触达任务、流程画布、资源位素材创建时可选择活动；
2. 活动字段为选填；
3. 选择活动时按“活动分组 - 活动”两级树展示；
4. 一个任务只能关联一个活动；
5. 关联后支持在列表中按活动筛选。

**16. 验收标准**

**16.1 活动管理验收**

1. 用户可创建活动，活动名称和分组必填；
2. 活动名称同项目下不可重复；
3. 活动可编辑名称和分组；
4. 已绑定触达任务、流程画布、资源位素材的活动不可删除；
5. 创建触达任务、流程画布、资源位素材时可选择活动；
6. 列表支持按活动筛选相关任务数据。

**16.2 素材管理验收**

1. 支持图片、视频、音频、文案素材；
2. 支持单个上传和批量上传；
3. 文件格式和大小校验准确；
4. 支持分组筛选和素材名称搜索；
5. 支持查看素材详情；
6. 支持下载素材原文件；
7. 支持在落地页、资源位、Webhook、公众号消息、弹窗、消息触达、流程画布中引用素材；
8. 被引用素材不可删除。

**16.3 落地页验收**

1. 支持基于空白页面或模板创建落地页；
2. 编辑器包含组件区、编辑区、设置区；
3. 支持文本、图片、视频、音频、轮播图、按钮、音乐、倒计时、图文等组件；
4. 支持保存草稿、预览、发布；
5. 发布新版本后 URL 保持不变；
6. 每次线上仅有一个版本；
7. 支持查看 PV、UV 数据；
8. 支持按时间和版本查看数据。

**16.4 魔方落地页验收**

1. 已购买魔方落地页的项目可从 GMP 跳转魔方落地页；
2. 魔方落地页创建后可在 GMP 插入链接；
3. Webhook 触达配置中可插入魔方落地页链接；
4. 未开通时展示开通提示。

**16.5 短信签名与模板验收**

1. 支持按短信通道查看签名和模板；
2. 火山引擎通道签名与模板自动同步；
3. 三方通道支持导入签名和模板；
4. 签名列表展示签名 ID、内容、类型、申请日期、状态；
5. 模板列表展示模板 ID、名称、类型、内容、状态；
6. 审核通过模板可被短信触达任务选择；
7. 审核未通过模板不可用于触达任务。

**16.6 Webhook 模板验收**

1. 支持查看已对接 Webhook 模板；
2. 不同 Webhook 通道展示不同模板；
3. 模板详情展示模板字段；
4. Webhook 触达任务选择模板后，自动生成参数表单；
5. GMP 内不允许直接编辑对接模板字段。

**16.7 WhatsApp 模板验收**

1. 支持切换 WhatsApp 通道；
2. 支持新建 WhatsApp 模板；
3. 支持配置 WABA ID、模板名称、类型、语言、正文、标题、页脚、按钮；
4. 正文必填，支持变量；
5. 标题支持文本、图片、视频、文件、地点；
6. 页脚仅支持无变量单行文本；
7. 行动呼吁按钮支持 1-2 个；
8. 快速回复支持 1-3 个；
9. 模板可在 WhatsApp 推送触达任务中使用。

**16.8 链接工具验收**

1. 支持通用短链；
2. 支持带参长链转短链；
3. 支持小程序短链；
4. 到期失效时间不能超过 1 年；
5. 小程序短链有效期最多 3 个月；
6. 支持统计 PV、UV；
7. 未开启 UV 统计时 UV 展示无统计；
8. 支持查看短链数据趋势；
9. 支持下载点击明细。

**16.9 权益管理验收**

1. 支持接口导入权益；
2. 支持手动上传权益；
3. 支持兑换码、实物、积分三类权益；
4. 支持在 Webhook、短信、魔方落地页中插入权益；
5. 权益发放时正确扣减库存；
6. 库存不足时发放失败并记录原因；
7. 支持查看权益发放明细；
8. 支持导出权益下发明细。
