**数字大屏管理与技巧 PRD**

**1. 产品定位**

数字大屏管理与技巧模块用于解决大屏从“搭建”到“交付”的完整管理问题，覆盖以下能力：

1. 大屏设计技巧：布局、配色、字体、设计准则；
2. 大屏资产管理：模板、设计素材、自定义字体；
3. 大屏模板化：将已有大屏共享为模板、脱敏、应用模板、替换数据源；
4. 大屏版本管理：新增版本、查看、发布设置、回滚、改名、锁定、删除；
5. 大屏发布管理：选择版本发布、访问加密、密码验证、Token 验证、查看、分享、下线；
6. 演播厅：多个大屏按设定顺序和时长自动轮播；
7. DevTools 搭建助手：识别搭建问题、性能问题、查询问题并给出修复入口；
8. 智能小助手：移动端布局转换、指标体系生成大屏、主题风格切换、文档检索。

本 PRD 的目标是让前端、后端和 Codex 能直接按本文完成开发，不依赖口头补充。

**5. 设计技巧产品化 PRD**

**5.1 设计技巧模块定位**

“布局、配色、字体、设计准则”不能只作为帮助文档存在，而要落地为以下产品能力：

1. 新建大屏时提供布局预设；
2. 编辑器中提供设计规范检测；
3. DevTools 中输出设计问题；
4. 智能小助手 生成大屏时遵守设计规则；
5. 用户应用模板、切换主题、转移动端布局时复用这些规则。

**6. 布局规范与布局模板**

**6.1 画布尺寸预设**

新建大屏时提供尺寸选择：

| **预设** | **宽** | **高** | **适用场景** |
| --- | --- | --- | --- |
| 16:9 信息屏 | 1920 | 1080 | 普通电视、显示器、会议室大屏 |
| 32:9 拼接屏 | 3840 | 1080 | 展厅、作战指挥室、拼接屏 |
| 自定义 | 用户输入 | 用户输入 | 特殊屏幕尺寸 |

创建逻辑：

用户点击新建大屏

→ 选择尺寸预设

→ 系统写入 canvas.width / canvas.height / ratioType

→ 根据尺寸推荐布局模板

→ 用户选择模板或空白画布

→ 创建大屏

校验规则：

1. width 必须大于 0。
2. height 必须大于 0。
3. 自定义尺寸宽高比如果小于 1 或大于 5，提示“当前比例非常规，请确认是否适配目标屏幕”。
4. 16:9 默认 1920x1080。
5. 32:9 默认 3840x1080。

**6.2 16:9 稀疏信息布局**

适用场景：

1. 页面有强主视觉；
2. 中央需要展示 3D 模型、地图、车辆模型、点阵视觉等；
3. 图表数量少；
4. 主要靠视觉中心传达主题。

布局规则：

const sparseCenterPreset = {

title: { x: 0, y: 0, w: 1920, h: 90 },

mainVisual: { x: 420, y: 120, w: 1080, h: 720 },

leftBottomChart: { x: 60, y: 820, w: 540, h: 220 },

rightBottomChart: { x: 1320, y: 820, w: 540, h: 220 },

rightTopCards: [

{ x: 1500, y: 120, w: 360, h: 120 },

{ x: 1500, y: 260, w: 360, h: 120 }

]

};

交互逻辑：

1. 用户选择“稀疏信息布局”后，系统在画布上生成占位框。
2. 占位框不是最终组件，而是 layout guide。
3. 用户拖入组件到占位框时，组件自动吸附到占位框尺寸。
4. 用户可以删除占位框。
5. 用户点击“一键生成组件”时，系统按占位框生成默认组件。

**6.3 16:9 密集信息布局**

适用场景：

1. 图表数量多；
2. 需要展示多个指标、趋势、排行榜；
3. 中央仍保留主视觉或核心图表；
4. 两侧采用列表型图表或指标卡。

布局规则：

const denseCenterPreset = {

title: { x: 0, y: 0, w: 1920, h: 80 },

mainVisual: { x: 480, y: 140, w: 960, h: 620 },

topMetrics: [

{ x: 60, y: 100, w: 220, h: 100 },

{ x: 300, y: 100, w: 220, h: 100 }

],

leftCharts: [

{ x: 60, y: 230, w: 360, h: 220 },

{ x: 60, y: 470, w: 360, h: 220 },

{ x: 60, y: 710, w: 360, h: 300 }

],

rightCharts: [

{ x: 1500, y: 230, w: 360, h: 220 },

{ x: 1500, y: 470, w: 360, h: 220 },

{ x: 1500, y: 710, w: 360, h: 300 }

],

bottomCharts: [

{ x: 520, y: 800, w: 420, h: 220 },

{ x: 980, y: 800, w: 420, h: 220 }

]

};

规则：

1. 主视觉区域不能被两侧图表遮挡。
2. 顶部指标卡优先靠近标题区域。
3. 同一侧图表宽度必须一致。
4. 同一列组件 x 值必须一致。
5. 同一行组件 y 值必须一致。
6. DevTools 检测到左右两列不对齐时，提示“组件未对齐，建议使用自动对齐”。

**6.4 无主视觉布局**

适用场景：

1. 页面没有明确主视觉；
2. 多个图表同等重要；
3. 需要用横纵搭配减少单调；
4. 无法选出一个核心图表。

布局逻辑：

1. 系统将画布划分为 3x2 或 4x2 栅格。
2. 每个图表占用 1 到 2 个栅格。
3. 不允许所有图表等宽等高，至少一个图表需要跨两列或两行形成视觉节奏。
4. 如果用户选择“平均网格布局”，系统提示：“无主视觉布局建议保留至少一个大图表作为视觉节奏点”。

**6.5 32:9 拼接屏布局**

适用场景：

1. 展厅；
2. 作战指挥室；
3. 指挥中心；
4. 横向超宽屏幕。

默认尺寸：

canvas.width = 3840;

canvas.height = 1080;

推荐布局：

const wideThreeColumnPreset = {

title: { x: 0, y: 0, w: 3840, h: 90 },

leftPanel: { x: 60, y: 130, w: 760, h: 880 },

centerPanel: { x: 880, y: 130, w: 2080, h: 880 },

rightPanel: { x: 3020, y: 130, w: 760, h: 880 }

};

规则：

1. 32:9 不允许直接使用 16:9 模板拉伸。
2. 主视觉可以横向扩展，但图表字号不能按比例无脑放大。
3. 左右侧栏应保持对称或近似对称。
4. 中央区域适合地图、3D 场景、总览趋势。
5. 若页面信息过多，建议使用轮播组件在局部区域切换，不建议无限增加小图表。

**6.6 布局吸附与自动对齐**

前端需要提供：

1. 组件拖拽吸附；
2. 组件边缘对齐提示线；
3. 组件等宽等高快捷操作；
4. 水平分布；
5. 垂直分布；
6. 区域成组；
7. 一键套用布局模板。

自动对齐逻辑：

用户选中多个组件

→ 点击自动对齐

→ 判断组件主要排列方向

→ 如果 x 值接近，按左对齐

→ 如果 y 值接近，按上对齐

→ 如果宽度接近，统一宽度

→ 如果高度接近，统一高度

→ 保持组件相对顺序不变

判定阈值：

const ALIGN\_THRESHOLD = 12;

若两个组件 x 坐标差小于 12px，认为用户意图是同列。

**7. 配色规范 PRD**

**7.1 配色原则**

数字大屏通常展示面积大、亮度高、内容多，因此默认推荐暗色背景，不建议使用大面积高亮背景。亮色应该用于指标数字、告警、重点趋势、选中态、流光装饰等小面积区域。

**7.2 配色模式**

系统内置两种配色模式：

| **模式** | **适用场景** | **示例** |
| --- | --- | --- |
| 色板配色 | 类别区分 | 柱状图、饼图、折线图多系列 |
| 连续配色 | 数值大小映射 | 地图、热力图、矩阵图、进度类图表 |

**7.4 配色检查规则**

DevTools 需要检查以下问题：

**7.4.1 背景过亮**

计算背景色亮度：

function getRelativeLuminance(hex: string): number {

const { r, g, b } = hexToRgb(hex);

const srgb = [r, g, b].map(v => {

const x = v / 255;

return x <= 0.03928 ? x / 12.92 : Math.pow((x + 0.055) / 1.055, 2.4);

});

return 0.2126 \* srgb[0] + 0.7152 \* srgb[1] + 0.0722 \* srgb[2];

}

规则：

1. 背景亮度大于 0.6 时提示：“当前背景亮度较高，长时间观看可能刺眼，建议使用暗色背景。”
2. 只提示，不阻止保存。
3. 用户可点击“忽略此问题”。

**7.4.2 高亮色面积过大**

规则：

1. 统计页面中高亮色组件面积。
2. 高亮色定义为 saturation > 0.55 且 luminance > 0.45。
3. 高亮面积占画布面积超过 20% 时提示：“高亮色面积过大，建议只用于关键指标或告警信息。”

**7.4.3 类别配色过近**

规则：

1. 对同一图表系列色计算色差。
2. 如果任意两个系列色过近，提示“当前系列颜色过近，可能难以区分。”
3. 提供“一键替换为推荐色板”。

**7.4.4 连续配色错误使用**

规则：

1. 如果饼图、柱状图多个类别使用连续渐变色，提示“类别图表建议使用色板配色，而不是连续配色。”
2. 如果热力图、地图使用大量离散颜色，提示“数值映射建议使用同色系连续配色。”

**8. 字体规范 PRD**

**8.1 字体使用原则**

大屏字体需要体现层级：

大屏标题

→ 分区标题

→ 图表标题

→ 指标数字

→ 图例 / 标签

→ 注脚 / 补充说明

规则：

1. 一个大屏不建议超过 3 种字体。
2. 大标题可使用更有风格的字体。
3. 普通说明和图表标签应使用现代、简洁、易读字体。
4. 数字内容推荐使用专门数字字体。
5. 中文字体选择应优先保证可读性与版权安全。

→ 提取 fontFamily

→ 去重

→ 如果数量 > 3，生成设计问题

问题提示：

修复动作：

1. 点击“统一标题字体”；
2. 点击“统一正文字体”；
3. 点击“统一数字字体”。

**8.5 字体层级检查**

规则：

1. 大屏标题字号应大于分区标题字号。
2. 分区标题字号应大于图表标签字号。
3. 指标数字可以大于标题，但需要配套说明文本。
4. 注脚字号应小于正文。
5. 如果页面存在标题字号小于普通标签字号，提示“字体层级不清晰”。

**9. 设计准则规则化 PRD**

**9.1 亲密性规则**

亲密性用于判断相关信息是否放在一起，无关信息是否被区分。

产品化方式：

1. 用户可手动创建“信息组”；
2. 系统根据组件距离和类型自动建议分组；
3. DevTools 检测信息组内间距是否过大；
4. DevTools 检测不同信息组之间是否缺少留白。

信息组模型：

interface LayoutGroup {

id: string;

name: string;

componentIds: string[];

boundingBox: Rect;

groupType: 'metric-group' | 'chart-group' | 'title-section' | 'custom';

}

自动分组规则：

读取所有组件

→ 按空间距离聚类

→ 按组件类型辅助判断

→ 生成候选信息组

→ 如果同组组件间距过大，提示“相关信息距离过远”

→ 如果不同组之间间距过小，提示“信息组之间缺少留白”

**9.2 对齐规则**

对齐用于保证页面整洁。

检测规则：

1. 同一列组件 x 坐标差异小于 12px，则认为应对齐。
2. 如果差异大于 12px 且小于 30px，提示“疑似未对齐”。
3. 同一行组件 y 坐标差异同理。
4. 同尺寸卡片宽高差异小于 20px 时，提示可一键等宽等高。

修复动作：

1. 左对齐；
2. 右对齐；
3. 顶部对齐；
4. 底部对齐；
5. 水平居中；
6. 垂直居中；
7. 等宽；
8. 等高；
9. 等间距分布。

**9.3 留白规则**

规则：

1. 组件之间最小间距建议不小于 12px。
2. 大屏标题与顶部边距建议不小于 24px。
3. 左右边缘核心组件不建议贴边，小于 20px 时提示。
4. 高密度页面中，如果组件总面积超过画布面积 75%，提示“当前页面信息密度较高，建议减少组件或使用轮播区域。”

**11. 自定义模板 PRD**

**11.1 功能定位**

自定义模板用于将已有大屏沉淀为可复用模板。用户可以将优秀大屏一键脱敏并共享为模板，其他用户应用模板后替换为自己的数据源，从而提升搭建效率。

**11.2 共享为模板入口**

支持两个入口：

入口一：大屏列表

→ 点击大屏卡片右下角三个点

→ 共享为模板

入口二：大屏编辑器

→ 顶部工具栏

→ 共享为模板

**11.3 共享为模板弹窗**

字段：

| **字段** | **必填** | **说明** |
| --- | --- | --- |
| 模板名称 | 是 | 模板展示名称 |
| 封面 | 否 | 默认使用当前大屏截图 |
| 范围 | 是 | 私有 / 项目内 / 指定成员 |
| 是否脱敏 | 是 | 默认开启 |
| 描述 | 否 | 模板说明 |

校验：

1. 模板名称不能为空。
2. 模板名称长度不超过 50。
3. 范围不能为空。
4. 如果未上传封面，系统自动生成画布截图作为封面。
5. 用户点击确定后生成模板快照。

**11.4 模板生成逻辑**

读取当前大屏配置

→ 复制画布、页面、组件、交互、主题、资源引用

→ 判断是否脱敏

→ 处理数据源

→ 生成模板 snapshot

→ 保存模板记录

规则：

1. 模板创建后与原大屏解耦。
2. 原大屏后续编辑不影响模板。
3. 原大屏删除后模板仍保留。
4. 同一个大屏可以多次共享为模板，每次生成一个新模板。
5. 模板中引用的素材需要复制引用关系，不能因原大屏删除而丢失。

**11.5 数据源模板化逻辑**

如果大屏使用非静态数据源：

读取图表实际使用字段

→ 将查询中用到的维度、指标转换为静态字段

→ 保留字段名称和字段类型

→ 生成示例静态数据

→ 移除无用查询

规则：

1. 模板不保留原始数据库连接、API 密钥、Token、SQL 等敏感信息。
2. 只保留图表展示所需字段。
3. 未被图表使用的数据查询必须剔除。
4. 模板应用后默认使用静态数据。
5. 用户可在编辑器底部将静态数据切换为自己的数据集。

**11.6 脱敏逻辑**

开启脱敏后：

**数值字段**

desensitizedValue = originalValue \* randomInt(1, 10)

规则：

1. 每个数值单元格独立生成 1-10 随机整数。
2. 保留正负号。
3. null 保持 null。
4. 非数值不按数值处理。

**文本字段**

规则：

1. 长度 <= 2 的文本全部替换为 \*。
2. 长度 > 2 的文本保留首尾字符，中间替换为 \*。
3. 邮箱、手机号、身份证等字段如果被识别，应使用专门规则脱敏。
4. 空字符串保持空字符串。

示例：

北京大区 → 北\*\*区

张三 → \*\*

customer@example.com → c\*\*\*\*\*\*r@example.com

**12.1 功能定位**

版本管理用于保存大屏关键节点，支持发布指定版本、回滚历史版本，避免用户误操作或发布错误草稿。

**12.2 入口**

| 操作 | 查看、发布设置、回滚、改名、锁定、删除 |

**12.4 新增版本**

流程：

用户点击版本管理

→ 点击新增版本

→ 系统检查版本数量

→ 如果 <20，生成当前草稿快照

→ 创建版本记录

→ 列表刷新

规则：

1. 最多 20 个版本。
2. 达到 20 个版本时，新增按钮置灰。
3. 鼠标悬停提示“最多支持创建 20 个版本，请删除旧版本后再创建。”
4. 新版本默认名称为 版本N。
5. N 使用当前最大版本号 + 1。
6. 新版本默认未锁定。
7. 新版本默认未发布。

**12.5 查看大屏**

流程：

点击查看

→ 新标签页打开该版本预览 URL

→ 预览使用版本 snapshot

规则：

1. 查看不会修改当前草稿。
2. 查看不会改变发布版本。
3. 查看态不允许编辑。
4. 查看态数据请求按版本快照中的配置执行。

**12.6 发布设置**

从版本管理中点击“发布设置”：

1. 打开发设置弹窗；
2. 当前版本自动作为发布版本；
3. 用户可设置访问加密；
4. 用户点击发布后，该版本成为线上版本。

规则：

1. 已发布其他版本时，发布新版本会替换线上版本。
2. 发布替换前需要二次确认。
3. 发布后版本列表中该版本显示“已发布”。
4. 线上链接保持不变，内容切换为新版本快照。

**12.7 回滚**

流程：

点击目标版本回滚

→ 弹出确认

→ 用户确认

→ 将目标版本 snapshot 写入当前草稿

→ 当前画布刷新

→ 不自动创建新版本

确认文案：

确认回滚到该版本吗？当前未保存的画板内容将被覆盖。

规则：

1. 回滚不改变已发布版本。
2. 回滚后用户需要点击保存才能持久化草稿。
3. 回滚后用户可以再新增版本。
4. 回滚到锁定版本允许，因为锁定只限制改名和删除，不限制作为回滚来源。

**12.8 修改名称**

规则：

1. 未锁定版本可以改名。
2. 锁定版本不可改名。
3. 名称不能为空。
4. 名称长度不超过 50。
5. 同一大屏下版本名称可以重复，但不推荐；如果重复，提示“存在同名版本，建议使用更清晰名称”。

**12.9 锁定 / 解锁**

规则：

1. 点击锁定后版本进入 locked 状态。
2. 锁定版本不可删除。
3. 锁定版本不可修改名称。
4. 再次点击可解锁。
5. 解锁后恢复改名和删除能力。
6. 已发布版本允许锁定，建议默认提示“当前版本正在发布，建议保持锁定”。

**12.10 删除版本**

规则：

1. 锁定版本不可删除。
2. 已发布版本不可直接删除，需要先下线或发布其他版本。
3. 删除前二次确认。
4. 删除后不可恢复。
5. 删除后版本号不重排。
6. 如果删除后版本数量小于 20，新增版本按钮恢复可用。

**14. Token 发布 PRD**

**14.1 功能定位**

Token 验证用于将大屏访问权限接入外部系统权限体系。外部系统通过 SecretKey 生成短期 Token，再将 Token 拼接到大屏访问链接中。

**14.2 Token 验证开启流程**

发布设置

→ 开启访问加密

→ 选择 Token 验证

→ 系统生成 SecretKey

→ 用户发布

→ 系统返回访问 URL 和 SecretKey

规则：

1. SecretKey 首次开启 Token 验证时生成。
2. 同一个大屏的 SecretKey 固定。
3. SecretKey 不支持用户手动修改。
4. 如需更换 SecretKey，应提供“重置 SecretKey”能力，但本期可不开放。
5. SecretKey 只展示给有发布权限的用户。

**14.3 获取 Token 接口**

接口：

POST /api/v3/largeScreen/sharingToken

请求：

{

"secretKey": "string",

"expireTime": 8400

}

字段规则：

| **字段** | **必填** | **说明** |
| --- | --- | --- |
| secretKey | 是 | 大屏 Token 访问密钥 |
| expireTime | 是 | 过期时间，单位秒，最大 86400 |

返回：

{

"code": "ok",

"data": "token\_string",

"msg": "成功"

}

校验：

1. secretKey 不能为空。
2. secretKey 必须存在。
3. expireTime 必须为正整数。
4. expireTime 不能超过 86400。
5. 服务器时间必须使用统一时区标准。
6. Token 生成失败时返回明确错误码。

**14.4 URL 拼接规则**

发布链接示例：

https://host/vScreen/preview?appId=xxx&id=xxx&openMode=1&accessKey=xxx

Token 访问链接：

https://host/vScreen/preview?appId=xxx&id=xxx&openMode=1&accessKey=xxx&accessToken=TOKEN

规则：

1. 参数名固定为 accessToken。
2. 如果 URL 已有 query 参数，使用 &accessToken= 拼接。
3. 如果 URL 无 query 参数，使用 ?accessToken= 拼接。
4. accessToken 为空时拒绝访问。
5. accessToken 过期时拒绝访问。
6. accessToken 与当前大屏 SecretKey 不匹配时拒绝访问。

**14.5 发布页访问校验**

访问流程：

用户打开发布链接

→ 后端读取 screenId / accessKey

→ 查询发布配置

→ 如果 public，直接返回大屏

→ 如果 password，进入密码校验

→ 如果 token，读取 accessToken

→ 校验 Token

→ 校验通过后返回发布版本 snapshot

错误态：

| **场景** | **页面提示** |
| --- | --- |
| 未传 Token | 当前大屏需要 Token 验证 |
| Token 过期 | Token 已过期，请重新获取 |
| Token 无效 | Token 无效，无法访问 |
| 大屏已下线 | 当前大屏已下线 |
| 大屏不存在 | 大屏不存在或无访问权限 |

**15. 演播厅 PRD**

**15.1 功能定位**

演播厅用于配置多个大屏的自动轮播方案。适用于展厅、会议室、监控中心等需要连续展示多个大屏的场景。

**15.2 入口**

数字大屏左侧导航

→ 演播厅

**15.3 演播厅列表**

字段：

| **字段** | **说明** |
| --- | --- |
| 方案名称 | 用户自定义 |
| 大屏数量 | 当前方案包含的大屏数 |
| 总时长 | 所有轮播项时长之和 |
| 创建人 | 创建者 |
| 更新时间 | 最近修改时间 |
| 操作 | 投屏、编辑、删除 |

**15.4 新建演播方案**

流程：

进入演播厅

→ 点击新建演播方案

→ 输入方案名称

→ 添加大屏

→ 配置每个大屏播放时长

→ 调整顺序

→ 点击生成方案

→ 方案创建成功

**15.5 添加大屏**

添加规则：

1. 只允许添加已发布的大屏。
2. 未发布大屏不可添加，列表置灰并提示“请先发布大屏”。
3. 同一方案中允许同一个大屏出现多次。
4. 每次出现都作为独立轮播项。
5. 添加时默认使用该大屏当前发布版本。

**15.6 播放时长配置**

规则：

1. durationSeconds 必须为正整数。
2. 默认值 30 秒。
3. 最小 5 秒。
4. 最大 3600 秒。
5. 小于 5 时提示“单屏播放时长不能小于 5 秒”。
6. 大于 3600 时提示“单屏播放时长不能大于 3600 秒”。

**15.7 轮播运行逻辑**

用户点击投屏

→ 打开演播播放页

→ 加载方案 items

→ 从第一项开始播放

→ 当前项播放 durationSeconds

→ 切换下一项

→ 到最后一项后按 loopMode 处理

loopMode：

| **模式** | **逻辑** |
| --- | --- |
| loop | 最后一项结束后回到第一项 |
| once | 最后一项结束后停止在最后一项 |

**15.8 播放页异常处理**

| **异常** | **处理** |
| --- | --- |
| 某个大屏已下线 | 跳过该项，进入下一项 |
| 某个大屏无访问权限 | 显示 3 秒错误提示后跳过 |
| 大屏加载超时 | 10 秒后跳过 |
| 所有大屏均不可播放 | 显示“当前方案无可播放大屏” |
| 网络断开 | 保留当前画面并提示网络异常 |

**15.9 编辑与删除方案**

编辑：

1. 可修改方案名称。
2. 可新增、删除、调整轮播项。
3. 可修改播放时长。
4. 保存后立即影响下次投屏。
5. 已打开的投屏页可选择是否自动拉取最新方案，本期默认不自动拉取。

删除：

1. 删除前二次确认。
2. 删除后不可恢复。
3. 删除方案不影响大屏本身。

**16. DevTools 搭建助手 PRD**

**16.1 功能定位**

DevTools 搭建助手用于在搭建过程中发现问题，而不是等发布或查看时才暴露问题。它需要监测大屏搭建行为、识别错误和性能风险，并提供直接修复建议。

**16.2 入口与状态**

入口：

编辑器顶部工具栏

→ 灯泡图标

图标状态：

| **状态** | **含义** |
| --- | --- |
| 红点 | 存在无法跑通或影响展示的严重问题 |
| 黄点 | 存在阻塞搭建体验或性能风险的问题 |
| 绿点 | 当前画板搭建合理，暂无问题 |
| 无点 | 未执行检测或检测结果未知 |

点击图标打开 DevTools 侧边栏。

**16.3 问题模型**

interface DevIssue {

id: string;

screenId: string;

pageId?: string;

componentId?: string;

**16.4 检测流程**

打开大屏

→ 初始化检测

→ 用户编辑组件 / 数据 / 页面 / 资源时触发增量检测

→ 点击 DevTools 图标时执行全量检测

→ 按严重级别排序

→ 展示问题列表

排序规则：

error

→ warning

→ resolved

同级别内按规则优先级排序。

**16.5 严重问题规则**

**16.5.1 查询失败**

条件：

任一组件最近一次 queryState.status = error

提示：

当前查询失败，请检查查询配置或重试。

修复动作：

1. 定位到组件；
2. 打开数据配置面板；
3. 重试查询。

严重级别：

error

**16.5.2 大屏版本非最新**

条件：

项目版本低于当前系统要求版本

提示：

当前项目版本非最新，请保存项目后继续使用。

动作：

1. 保存项目；
2. 升级版本。

严重级别：

warning 或 error，根据是否影响编辑决定

**16.6 性能问题规则**

**页面过多**

条件：

screen.pages.length > 10

提示：

当前页面数量过多，请考虑优化页面以提高加载性能。

**3D 组件过多**

条件：

count3DComponents(screen) > 10

提示：

当前 3D 组件数量过多，请考虑删减组件以提高渲染性能。

**图片过大**

条件：

asset.type === 'image' && asset.fileSize > 4 \* 1024 \* 1024

提示：

当前图片体积过大，请优化图片大小以加快加载速度。

**视频过大**

条件：

asset.type === 'video' && asset.fileSize > 10 \* 1024 \* 1024

提示：

当前视频体积过大，请考虑压缩视频以加快加载速度。

**查询间隔过小**

条件：

refreshMode === 'auto' && intervalSeconds < 5

提示：

当前查询间隔过小，请增加查询间隔时间以降低服务器压力。

**慢查询**

条件：

queryDurationMs > 10000

提示：

当前查询耗时过久，请优化查询或减少数据量。

**HTTP 协议性能风险**

条件：

查询网络协议为 HTTP/1.1

提示：

当前查询网络协议为 HTTP/1.1，请升级至更高协议版本以提升并发性能。

**16.7 终端问题规则**

**断网**

条件：

navigator.onLine === false

提示：

当前网络中断，无法进行保存或发布，请检查网络状态。

**弱网**

条件：

network.downlink < threshold || requestTimeoutRate > threshold

提示：

当前网速较差，可能影响保存、发布和预览。

**16.8 问题解决态**

当检测到问题已解决：

1. 问题卡片置灰；
2. 显示绿色图标；
3. 标记 severity = resolved；
4. 默认保留在列表底部；
5. 用户可点击“清除已解决问题”。

如果全部问题解决：

图标显示绿点

侧边栏显示：您的画板当前搭建合理，暂无问题。

**17.4 转换移动端布局**

**17.4.1 触发方式**

方式一：

点击预置卡片“转换移动端布局”

方式二：

输入“转换移动端布局”

**17.4.2 执行流程**

读取当前网页端大屏

→ 内容识别

→ 背景色提取

→ 布局类型识别

→ 组件区块分组

→ 区块重排序

→ 生成移动端画布

→ 重新布局组件

→ 适配字体和间距

→ 展示生成结果

**17.4.3 内容识别逻辑**

识别对象：

1. 大屏标题；
2. 指标卡；
3. 图表组件；
4. 地图 / 3D 组件；
5. 装饰素材；
6. 背景图；
7. 信息组。

规则：

1. 标题优先放在移动端顶部。
2. KPI 指标卡优先放在标题后。
3. 主视觉组件放在第一屏或第二屏。
4. 宽图表转换为纵向卡片。
5. 多列布局转换为单列或双列。
6. 装饰组件如果影响移动端阅读，可以隐藏或缩小。

**17.4.4 移动端画布规则**

默认：

mobileCanvas.width = 375;

mobileCanvas.height = auto;

规则：

1. 移动端宽度固定为 375 或用户选择设备宽度。
2. 高度根据组件纵向排列自动扩展。
3. 组件间距默认 12px。
4. 页面左右边距默认 16px。
5. 标题字号不得小于 18px。
6. 图表卡片高度不得小于 220px。
7. 指标卡高度不得小于 72px。

**17.4.5 结果处理**

生成后用户可：

1. 接受结果；
2. 点击重新生成；
3. 输入修改要求继续调整；
4. 手动微调。

重新生成逻辑：

用户点击重新生成

→ 保留原网页端大屏

→ 丢弃上一次移动端生成草稿

→ 使用相同输入重新运行

进一步输入修改要求逻辑：

用户输入“把地图放到第一屏”

→ 智能小助手 读取当前移动端草稿

→ 定位地图组件

→ 调整组件顺序

→ 重新生成移动端布局

**17.5.1 触发方式**

方式一：

点击预置卡片“指标体系生成大屏”

**17.5.2 输入流程**

新建空白大屏

→ 选择指标体系生成大屏

→ 输入大屏名称

→ 编辑指标体系表格

→ 选择大屏模板

→ 点击生成

**17.5.3 指标体系表格字段**

| **字段** | **是否必填** | **说明** |
| --- | --- | --- |
| 位置 | 是 | 板块大致位置，如左边、右边、中间、顶部 |
| 板块名称 | 是 | 某一业务板块名称 |
| 指标 | 是 | 该板块展示的指标，支持多个 |
| 维度 | 否 | 时间、地区、类型等分析维度 |
| 图表类型 | 是 | 柱状图、折线图、地图、指标卡等 |
| 数据查询 | 否 | 使用的数据查询名称，不填则生成 mock 数据 |

**17.5.4 生成逻辑**

读取指标体系

→ 校验必填字段

→ 解析板块位置

→ 解析图表类型

→ 选择模板布局

→ 生成组件结构

→ 生成数据配置

→ 绑定 mock 或指定查询

→ 应用主题风格

→ 在画布中创建大屏

→ 展示生成过程

规则：

1. 缺少位置、板块名称、指标、图表类型时阻止生成。
2. 位置字段不合法时提示用户修改。
3. 如果数据查询为空，系统为该图表生成 mock 数据。
4. 如果数据查询存在，绑定到对应组件。
5. 生成过程中需要展示步骤，例如“正在生成布局”“正在绑定图表”“正在应用主题”。
6. 生成失败时保留错误日志。

**17.6 一键切换主题风格**

适用范围：

1. 通过智能小助手 指标体系生成的大屏；
2. 普通大屏也可支持，但本期优先保障智能生成大屏。

流程：

用户点击一键切换主题风格

→ 选择目标主题

→ 系统替换背景、色板、字体、装饰素材

→ 保留组件位置和数据绑定

→ 重新渲染

规则：

1. 不改变数据源。
2. 不删除组件。
3. 不改变交互。
4. 只修改样式属性。
5. 用户可撤销主题切换。

**17.7 智能文档检索**

流程：

用户输入问题

→ 系统检索数字大屏文档库

→ 返回匹配内容摘要

→ 给出操作建议

规则：

1. 只回答大屏相关问题。
2. 如果检索不到结果，提示“未找到相关文档”。
3. 回答中可提供操作路径。
4. 不自动修改大屏配置，除非用户明确要求执行操作。

**21. 异常处理**

| 字体未授权声明 | 禁止上传 |
| 模板删除 | 二次确认并提示不可恢复 |

**21.4 智能小助手 异常**

| **场景** | **处理** |
| --- | --- |
| 任务超时 | 标记 failed，可重新生成 |
| 指标体系缺少必填项 | 阻止生成并定位字段 |
| 模型返回结构不合法 | 不写入画布，提示生成失败 |
| 移动端转换失败 | 保留原网页端大屏 |
| 主题切换失败 | 回滚到切换前样式 |
| 文档检索无结果 | 返回无结果提示 |

**22. 验收标准**

**22.1 布局与设计技巧验收**

1. 新建大屏支持 16:9、32:9、自定义尺寸。
2. 16:9 默认尺寸为 1920x1080。
3. 32:9 默认尺寸为 3840x1080。
4. 用户可选择稀疏信息布局、密集信息布局、无主视觉布局、拼接屏布局。
5. 选择布局后画布生成对应占位框。
6. 组件拖入占位框可自动吸附。
7. DevTools 能检测未对齐问题。
8. DevTools 能检测组件过密问题。
9. DevTools 能检测背景过亮问题。
10. DevTools 能检测字体超过 3 种问题。
11. DevTools 能检测图片大于 4MB。
12. DevTools 能检测视频大于 10MB。

**22.2 资源管理验收**

1. 资源管理包含大屏模板、设计素材、自定义字体。
2. 大屏模板展示用户有权限的模板。
3. 设计素材按主标题、小标题、背景框、装饰线、图标、其他分类。
4. 素材区分官方和本地上传。
5. 图片、视频可上传并在编辑器使用。
6. 自定义字体支持 .ttf、.otf、.woff、.woff2。
7. 上传字体必须勾选授权声明。
8. 被引用资源删除时必须提示风险。
9. 缺失资源组件显示占位。

**22.3 自定义模板验收**

1. 大屏列表可共享为模板。
2. 编辑器内可共享为模板。
3. 共享模板时可设置名称、封面、范围、是否脱敏。
4. 模板创建后不受原大屏后续编辑影响。
5. 删除原大屏不删除模板。
6. 同一大屏可多次共享为模板。
7. 非静态数据源共享为模板时转换为静态字段。
8. 无用查询被剔除。
9. 数值字段按 1-10 随机倍数脱敏。
10. 文本字段按首尾保留、中间星号脱敏。
11. 用户可应用模板创建新大屏。
12. 应用模板后可将静态数据切换为数据集。
13. 模板删除不进入回收站，删除后不可恢复。

**22.4 版本管理验收**

1. 版本管理入口在编辑器顶部。
2. 一个大屏最多创建 20 个版本。
3. 达到 20 个版本后禁止新增。
4. 新增版本保存当前草稿快照。
5. 支持查看版本大屏。
6. 支持从版本进行发布设置。
7. 支持回滚到指定版本。
8. 回滚不影响线上发布版本。
9. 支持修改版本名称。
10. 锁定版本不可改名。
11. 锁定版本不可删除。
12. 已发布版本不可直接删除。
13. 删除版本需要二次确认。

**22.5 发布功能验收**

1. 编辑器顶部可发布。
2. 大屏列表可发布未发布大屏。
3. 发布时可选择“当前画板最新内容”。
4. 发布时可选择历史版本。
5. 当前画板最新内容发布时自动创建版本。
6. 支持访问加密开关。
7. 支持密码验证。
8. 支持 Token 验证。
9. 发布前需要二次确认。
10. 发布成功后支持查看。
11. 发布成功后支持分享。
12. 发布成功后支持下线。
13. 下线后链接不可访问。
14. 下线不删除版本和草稿。

**22.6 Token 发布验收**

1. 开启 Token 验证后生成 SecretKey。
2. SecretKey 不支持用户修改。
3. SecretKey 仅授权用户可查看和复制。
4. Token 获取接口支持 secretKey 和 expireTime。
5. expireTime 最大 86400 秒。
6. Token 访问链接使用 accessToken 参数。
7. 未传 Token 时拒绝访问。
8. Token 过期时拒绝访问。
9. Token 无效时拒绝访问。
10. Token 校验通过后加载发布版本 snapshot。

**22.7 演播厅验收**

1. 左侧导航可进入演播厅。
2. 支持新建演播方案。
3. 支持自定义方案名称。
4. 支持添加已发布大屏。
5. 未发布大屏不可添加。
6. 支持配置每个大屏播放时长。
7. 支持调整播放顺序。
8. 点击生成方案后方案保存成功。
9. 方案列表支持投屏。
10. 方案列表支持编辑。
11. 方案列表支持删除。
12. 播放时按顺序自动切换。
13. 最后一项播放后可循环回第一项。
14. 某个大屏下线时播放页可跳过该项。

**22.8 DevTools 验收**

1. 顶部灯泡图标可打开 DevTools。
2. 无问题时显示绿点。
3. 严重问题时显示红点。
4. 性能或阻塞问题时显示黄点。
5. 查询失败被识别为严重问题。
6. 页面数大于 10 被识别为问题。
7. 3D 组件数大于 10 被识别为问题。
8. 图片大于 4MB 被识别为问题。
9. 视频大于 10MB 被识别为问题。
10. 查询间隔小于 5 秒被识别为问题。
11. 查询耗时大于 10 秒被识别为慢查询。
12. 问题解决后卡片置灰并显示绿色图标。
13. 点击问题可定位到相关组件或配置区域。
14. 支持清除已解决问题。

**22.9 智能小助手 验收**

1. 编辑器左下角显示智能小助手 入口。
2. 点击后右侧打开对话侧边栏。
3. 支持自然语言输入。
4. 支持预置卡片。
5. 支持转换移动端布局。
6. 移动端转换包括内容识别、背景色提取、布局识别、区块重排序、页面重新布局。
7. 生成结果可重新生成。
8. 生成结果可通过追加要求继续调整。
9. 支持指标体系生成大屏。
10. 指标体系中位置、板块名称、指标、图表类型为必填。
11. 数据查询为空时生成 mock 数据。
12. 生成时展示过程步骤。
13. 支持一键切换主题风格。
14. 主题切换不改变数据源和交互。
15. 支持智能文档检索。
16. 检索不到内容时返回无结果提示。
