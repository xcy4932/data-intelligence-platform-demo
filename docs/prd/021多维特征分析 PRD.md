**多维特征分析 PRD**

**1. 模块定位**

多维特征分析用于在已知“正样本”和“负样本”的前提下，通过模型与算法自动挖掘最能区分两类人群的标签值组合，帮助业务人员识别高价值客户、潜在转化客户、风险客户或可扩量运营人群。

该模块的核心不是单标签画像，而是从多个标签维度中自动组合特征，计算每个特征组合对目标人群的识别效果，并输出综合评分、精确率、召回率、正样本人数、扩量后人数等结果。

典型业务目标包括：

1. 找出正样本人群相较负样本人群最显著的标签组合。
2. 根据历史成功样本和失败样本，推荐下一轮营销触达的人群筛选规则。
3. 将高评分特征组合一键保存为分群，用于广告投放、私域触达、门店邀约、拉新、复购、风险预警等后续运营。
4. 帮助运营人员从“经验圈人”升级为“基于正负样本的模型辅助圈人”。

**2. 产品能力范围**

多维特征分析模块包含以下能力：

1. 多维特征分析报告创建。
2. 多维特征分析报告列表管理。
3. 报告收藏。
4. 报告授权，仅支持授予查看权限。
5. 报告删除。
6. 报告计算状态查看。
7. 报告计算失败原因查看。
8. 重新发起计算。
9. 报告详情查看。
10. 正显著分群、负显著分群查看与跳转。
11. 参与分析标签查看。
12. 要点解读。
13. 多维特征分析结果明细。
14. 特征组合综合评分排序。
15. 精确率、召回率、正样本人数、扩量后人数展示。

19. 将生成分群沉淀到用户分群模块，用于下游运营。

   * 报告结果中不允许通过该标签继续生成新的分群规则。

   * “存为分群”按钮置灰。
   * 悬停提示：暂无创建分群权限，请联系管理员开通。

**4. 核心概念**

**4.1 正显著分群**

正显著分群是用户希望系统学习和扩量的目标样本。

示例：

1. 历史购买金额最高的人群。
2. 活动中成功转化的人群。
3. 高活跃用户。
4. 未违约客户。
5. 高复购客户。
6. 已到店试驾用户。

创建规则：

1. 正显著分群只能从已创建的人群包中下拉选择。
2. 不支持在多维特征分析页面中临时创建正样本。
3. 用户必须拥有该分群查看权限。
4. 分群主体必须与报告主体一致。
5. 分群人数必须大于 0。
6. 正显著分群作为模型学习的正样本集合。

**4.2 负显著分群**

负显著分群是用于对比正样本的反向样本或背景样本。

支持三种方式：

1. 大盘随机抽样。
2. 指定分群随机抽样。
3. 自定义分群。

**4.2.1 大盘随机抽样**

逻辑：

1. 系统以当前主体的大盘总体作为基础集合。
2. 从大盘总体中排除正显著分群用户。
3. 在剩余人群中随机抽样生成负显著分群。
4. 抽样数量由系统根据算法配置决定，默认建议与正样本规模一致或按后台比例配置。
5. 抽样结果随报告计算版本固定，不因页面刷新改变。

适用场景：

用户没有明确失败样本，只希望系统从大盘中自动找出与正样本形成对照的人群。

**4.2.2 指定分群随机抽样**

逻辑：

1. 用户选择一个已有分群作为负样本总体。
2. 系统从该指定分群中随机抽样。
3. 若指定分群中包含正显著分群用户，系统默认排除重叠用户。
4. 抽样后生成负显著分群。
5. 用户必须拥有该指定分群查看权限。

适用场景：

用户希望负样本来自特定业务范围，例如“未转化线索池”“低活跃用户池”“未购买人群”。

**4.2.3 自定义分群**

逻辑：

1. 用户直接选择一个已有分群作为负显著分群。
2. 系统不再随机抽样。
3. 该分群完整作为负样本集合。
4. 若正负样本存在重叠，系统保存前必须提示。
5. 默认建议系统自动剔除重叠用户，并展示剔除人数。

适用场景：

用户已有明确失败样本，例如“触达未转化用户”“违约客户”“流失用户”。

**4.3 参与分析标签**

参与分析标签是模型用于组合计算的候选标签集合。

选择方式：

1. 系统推荐。
2. 自定义选择。

限制：

1. 标签上限 200 个。
2. 未选择的标签不参与特征分析。
3. 未选择的标签不会出现在特征组合结果中。
4. 标签被删除或失效后，历史报告展示为失效标签，重新计算时需剔除。
5. 多值标签需要按标签值展开参与组合。
6. 标签值为空的用户不参与该标签对应特征值组合计算。

**4.4 特征组合**

特征组合是由 1 个、2 个或 3 个标签值组成的筛选条件。

示例：

1. 性别 = 女性
2. 性别 = 女性 AND 年龄 = 20-30岁
3. 性别 = 女性 AND 消费水平 = 中高档 AND 年龄 = 20-30岁

输出特征组合包含的标签值数量由用户在创建报告时配置。

支持选项：

1. 1 个标签值。
2. 2 个标签值。
3. 3 个标签值。

默认值：

3 个标签值

注意：

标签值数量越大，组合搜索空间越大，对计算资源依赖越高，报告计算速度越慢。

**4.5 综合评分**

综合评分用于衡量一个特征组合的整体效果。

取值范围：

0 ~ 1

计算逻辑：

综合评分 = 精确率 \* 0.8 + 召回率 \* 0.2

解释：

1. 综合评分越高，说明该特征组合越适合用于识别目标人群。
2. 精确率权重更高，因为业务更关注筛出来的人是否足够像正样本。
3. 召回率用于补充衡量覆盖规模，避免只找到极少数高纯度人群。
4. 默认结果明细按综合评分降序排列。

**4.6 召回率**

召回率表示：正样本中满足该特征组合的人数，在全体正样本中的占比。

计算公式：

召回率 = 正样本中满足该特征组合的人数 / 正样本总人数 \* 100%

示例：

正样本中满足该特征的人群为 100 人，全体正样本为 1000 人，则：

召回率 = 100 / 1000 \* 100% = 10%

业务含义：

召回率越高，说明该特征组合覆盖了更多正样本。

**4.7 精确率**

精确率表示：满足该特征组合的人群中，正样本人数占正负样本总人数的比例。

计算公式：

精确率 = 正样本中满足该特征组合的人数 /（正样本中满足该特征组合的人数 + 负样本中满足该特征组合的人数）\* 100%

示例：

正样本中满足该特征的人群为 400 人，负样本中满足该特征的人群为 100 人，则：

精确率 = 400 / (400 + 100) \* 100% = 80%

业务含义：

精确率越高，说明该特征组合更能区分正样本与负样本。

**4.8 正样本中的人数**

含义：

正样本中符合该特征组合的人数。

用途：

1. 判断该组合在正样本中的实际覆盖规模。
2. 配合召回率理解是否只是小样本偶然特征。
3. 作为“导出正样本人群”的人数基础。

**4.9 扩量后的人数**

含义：

在全量私域人群中，筛选满足该特征组合的人进行扩量后得到的人数。

用途：

1. 判断该特征组合可扩量运营的人群规模。
2. 作为“导出扩量后人群”的人数基础。
3. 用于评估后续广告投放、私域触达、门店邀约的人群容量。

**7.3 顶部按钮**

**7.3.1 新建报告**

按钮名称：新建报告

位置：

页面右上角。

点击后进入新建报告页面。

权限规则：

**7.4 搜索与筛选区**

**7.4.1 搜索框**

占位文案：

搜索报告名称

逻辑：

1. 支持按报告名称模糊搜索。
2. 输入后按 Enter 或点击搜索图标触发查询。
3. 搜索结果与筛选条件共同生效。
4. 清空搜索框后恢复当前筛选条件下的列表。

**7.4.2 我创建的**

控件类型：复选框。

勾选后：

1. 只展示当前登录用户创建的报告。
2. 与其他筛选条件共同生效。
3. 取消勾选后恢复展示当前用户可见的全部报告。

**7.4.3 我收藏的**

控件类型：复选框。

勾选后：

1. 只展示当前用户收藏的报告。
2. 收藏状态基于当前用户维度，不影响其他用户。
3. 与“我创建的”同时勾选时，展示“我创建且我收藏”的报告。

**7.4.4 已人授权 / 已授权给我**

如产品界面存在该筛选项，建议统一命名为：

他人授权给我

勾选后：

1. 展示他人授权当前用户查看的报告。
2. 不展示当前用户自己创建的报告，除非同时被授权。
3. 与搜索、状态等筛选共同生效。

**7.4.5 报告状态筛选**

控件类型：多选下拉。

选项：

1. 计算中。
2. 计算成功。
3. 计算失败。
4. 已删除，不在默认列表展示。
5. 已失效。

逻辑：

1. 默认展示全部未删除报告。
2. 勾选“计算失败”后，只展示失败报告。
3. 用户可根据状态判断报告计算情况。
4. 失败报告行内展示失败原因入口和重新计算入口。

**7.4.6 主体筛选**

控件类型：多选下拉。

选项来源：

当前项目已配置主体，例如：

1. 用户。
2. 会员。
3. 车辆。
4. 门店。
5. 商品。
6. 线索。

逻辑：

1. 默认不限主体。
2. 选择主体后，仅展示对应主体报告。
3. 用户无该主体权限时不展示该主体选项。

**7.4.7 重置按钮**

按钮名称：重置

点击后：

1. 清空搜索框。
2. 取消“我创建的”。
3. 取消“我收藏的”。
4. 取消“他人授权给我”。
5. 清空报告状态筛选。
6. 清空主体筛选。
7. 分页回到第 1 页。
8. 重新查询列表。

**12.2 负显著分群**

字段名称：负显著分群

控件类型：单选卡片 + 配置项。

支持三种方式：

1. 大盘随机抽样。
2. 指定分群随机抽样。

默认值：

**12.2.1 大盘随机抽样**

选择后展示说明：

系统将在当前主体大盘中排除正显著分群后，随机抽样生成负显著分群。

保存逻辑：

1. 不需要用户额外选择分群。
2. 系统计算时读取当前主体大盘。
3. 自动排除正显著分群用户。
4. 生成负样本集合。
5. 若排除后可抽样人数不足，保存前或计算时提示样本不足。

**12.2.2 指定分群随机抽样**

选择后展示分群选择框。

字段：

指定分群

规则：

1. 必填。
2. 下拉展示当前主体下用户有权限的人群包。
3. 指定分群人数必须大于 0。
4. 系统在该指定分群中随机抽样生成负显著分群。
5. 若指定分群与正显著分群有交集，系统默认从指定分群中排除正样本用户后再抽样。
6. 如果排除后人数不足，提示：
   * 指定分群剔除正样本后人数不足，请更换分群或选择其他负样本方式。

**12.2.3 自定义分群**

选择后展示分群选择框。

字段：

负样本分群

规则：

1. 必填。
2. 用户直接选择一个分群作为负样本。
3. 分群主体必须与报告主体一致。
4. 用户必须拥有该分群查看权限。
5. 分群人数必须大于 0。
6. 若与正显著分群存在交集，系统展示交集提示。

交集处理建议：

1. 默认自动剔除负样本中与正样本重叠的用户。
2. 保存时展示：
   * 正负样本存在重叠用户，系统将从负样本中剔除重叠用户后计算。
3. 若剔除后负样本为空，则禁止保存。

**13. 参与分析标签配置**

**13.1 配置方式**

字段名称：选择参与分析的标签

**13.2 系统推荐**

4. 用户可从推荐列表中移除不想参与计算的标签。
5. 若推荐标签数量为 0，提示：

| **字段** | **说明** |

3. 用户可按标签名称搜索。
4. 用户可多选标签。
5. 最多选择 200 个标签。
6. 超过 200 个时禁止继续选择，并提示：
   * 最多可选择200个标签参与分析。

1. 只展示当前用户有权限的标签。
2. 只展示当前主体可用的标签。
3. 已删除标签不展示。
4. 不支持分析的标签类型不展示或置灰。
5. 被置灰标签悬停说明原因，例如：
   * 该标签数据未就绪，暂不支持参与分析。

**13.4 未选择标签的影响**

1. 未选择的标签不参与模型计算。
2. 未选择的标签不会出现在特征组合结果中。
3. 报告生成后不能在详情中补看未参与计算标签的结果。

**14. 特征组合配置**

**14.1 输出特征组合包含的标签值数量**

字段名称：

输出特征组合包含的标签值数量

控件类型：

单选下拉。

选项：

1. 1 个标签值。
2. 2 个标签值。
3. 3 个标签值。

默认值：

3

说明：

1. 选择 1 时，系统只输出单标签值特征，例如“性别=女性”。
2. 选择 2 时，系统输出最多包含 2 个标签值的组合，例如“性别=女性 AND 年龄=20-30岁”。
3. 选择 3 时，系统输出最多包含 3 个标签值的组合。
4. 数量越大，计算组合数量越多，计算速度越慢。
5. 页面必须展示性能提示：
   * 标签值数量越大，报告计算耗时可能越长。

**15. 保存与计算逻辑**

**15.1 保存按钮逻辑**

用户点击 保存 后，系统执行以下校验：

1. 用户是否有增删改报告权限。
2. 任务名称是否填写。
3. 主体是否选择。
4. 正显著分群是否选择。
5. 负显著分群是否配置完整。
6. 正负样本人数是否大于 0。
7. 正负样本是否存在无法处理的重叠。
8. 参与分析标签数量是否大于 0。
9. 参与分析标签数量是否小于等于 200。
10. 输出特征组合标签值数量是否为 1、2 或 3。
11. 授权对象是否合法。

校验通过后：

1. 创建报告记录。
2. 创建报告计算任务。
3. 报告状态变为“计算中”。
4. 页面跳转到报告详情页或报告列表页。
5. 推荐跳转详情页，展示计算中状态。

**15.2 计算任务逻辑**

计算任务执行步骤：

1. 读取正显著分群 ID 集合。
2. 根据负样本配置生成负显著分群 ID 集合。
3. 读取参与分析标签及标签值。
4. 对正负样本进行标签值命中计算。
5. 生成候选特征组合。
6. 对每个特征组合计算：
   * 正样本命中人数。
   * 负样本命中人数。
   * 召回率。
   * 精确率。
   * 综合评分。
   * 扩量后人数。
7. 按综合评分降序排序。
8. 生成报告结果明细。
9. 生成要点解读。
10. 报告状态更新为“计算成功”。

**15.3 计算失败逻辑**

计算失败时：

1. 报告状态更新为“计算失败”。
2. 记录失败原因。
3. 列表展示失败状态。
4. 行级操作展示“失败原因”和“重新计算”。
5. 详情页展示失败原因卡片。
6. 用户可重新计算。

**17.4 标签信息展示**

参与分析标签展示方式：

1. 默认展示前若干个标签名称。
2. 超出展示上限时，显示 +N。
3. 点击 +N 打开标签列表弹窗。
4. 标签列表展示标签名称、标签目录、标签类型。
5. 无权限标签展示为脱敏或“无权限标签”，不允许跳转。

**18. 要点解读区**

**18.1 功能说明**

要点解读用于自动总结当前报告中最显著的特征组合与后续营销建议。

展示内容：

1. 最显著特征组合。
2. 综合评分。
3. 适合扩量的人群说明。
4. 后续营销建议。
5. 一键保存扩量后分群入口。

**18.2 最显著特征组合**

系统默认选择综合评分最高的特征组合。

展示示例：

最显著特征组合：性别=女性、消费水平=中高档、年龄=20-30岁

展示字段：

1. 标签名称。
2. 标签值。
3. 综合评分。
4. 精确率。
5. 召回率。
6. 扩量后人数。

**18.3 营销建议生成逻辑**

建议文案基于以下信息生成：

1. 特征组合标签含义。
2. 综合评分。
3. 精确率。
4. 召回率。
5. 扩量后人数。
6. 正样本业务语义，若报告名称或分群名称能体现业务含义。

示例建议：

该特征组合在正样本人群中表现显著，且在全量私域人群中具备一定扩量规模，建议将扩量后人群作为高潜客户运营对象，用于下游渠道触达、到店邀约或复购促进。

**18.4 收起 / 展开**

按钮名称：

收起 / 展开

逻辑：

1. 默认展开要点解读。
2. 点击“收起”后，仅展示标题栏。
3. 点击“展开”后恢复完整内容。
4. 展开状态仅在当前用户当前浏览会话中保存。

**18.5 要点解读中的存为分群**

按钮名称：

一键保存扩量后分群

点击后：

1. 默认选中综合评分最高的特征组合。
2. 默认导出类型为“扩量后人群”。
3. 打开存为分群弹窗。
4. 用户填写分群名称、描述、授权和分组后保存。

**19. 多维特征分析结果明细区**

**19.1 功能说明**

结果明细展示系统计算出的所有有效特征组合，帮助用户从多种候选组合中选择最适合业务目标的人群规则。

默认排序：

按特征组合综合评分降序展示。

**19.2 表格字段**

| **字段** | **说明** |
| --- | --- |
| 选择框 | 用于勾选特征组合并存为分群 |
| 序号 | 当前排序下的序号 |
| 特征名称和值1 | 第一个标签值条件 |
| 特征名称和值2 | 第二个标签值条件，没有则展示 -- |
| 特征名称和值3 | 第三个标签值条件，没有则展示 -- |
| 特征组合综合评分 | 0~1，越大越好 |
| 精确率 | 满足该组合的人群中正样本占比 |
| 召回率 | 正样本中满足该组合的人群占比 |
| 正样本中的人数 | 正样本中命中该组合的人数 |
| 扩量后的人数 | 全量私域人群中满足该组合的人数 |
| 操作 | 可选查看详情或存为分群 |

**19.3 表格排序**

支持排序字段：

1. 综合评分。
2. 精确率。
3. 召回率。
4. 正样本中的人数。
5. 扩量后的人数。

默认排序：

综合评分降序

点击列头排序：

1. 第一次点击：降序。
2. 第二次点击：升序。
3. 第三次点击：恢复默认排序。
4. 当前排序状态在表头显示箭头。

**19.4 表格筛选**

建议支持以下筛选：

1. 综合评分区间。
2. 精确率区间。
3. 召回率区间。
4. 正样本人数区间。
5. 扩量后人数区间。
6. 标签名称筛选。
7. 标签值搜索。

筛选逻辑：

1. 多个筛选条件之间为 AND。
2. 筛选只影响当前表格展示，不改变报告计算结果。
3. 清空筛选后恢复全部结果。
4. 勾选状态在筛选后保留，但若被筛掉的行不可见，需要在存为分群时提示已选择多少不可见项。

**19.5 勾选特征组合**

每行左侧展示复选框。

规则：

1. 用户可勾选一个或多个特征组合。
2. 勾选后右侧或表格上方的“存为分群”按钮可用。
3. 如果当前用户无创建分群权限，复选框可勾选但存为分群置灰，或直接禁用复选框。建议禁用存为分群按钮即可。
4. 支持当前页全选。
5. 如果支持跨页选择，需要明确提示跨页选择数量。默认建议仅选择当前页。

**19.6 分页**

默认每页：

20 条。

可选：

10、20、50、100。

逻辑：

1. 切换页码时保留筛选和排序。
2. 切换每页条数后回到第 1 页。
3. 勾选状态跨页保留，前提是使用后端唯一特征组合 ID。
4. 无结果时展示空状态。

**20. 存为分群**

**20.1 入口**

存为分群入口包括：

1. 要点解读区的一键保存扩量后分群。
2. 结果明细区勾选特征组合后点击 存为分群。
3. 单行操作中的 存为分群，如产品支持。

**20.2 操作流程**

1. 用户勾选一个或多个特征组合。
2. 点击右侧或表格上方 存为分群。
3. 打开存为分群弹窗。
4. 用户选择导出人群类型：
   * 正样本人群。
   * 扩量后人群。
5. 用户填写分群基础信息。
6. 点击确定。
7. 系统生成用户分群。
8. 保存成功后提示并提供跳转入口。

**20.3 导出人群类型**

**20.3.1 正样本人群**

含义：

正样本中符合所选特征组合的人群。

生成逻辑：

1. 取当前报告正显著分群。
2. 对其中用户应用勾选的特征组合条件。
3. 得到符合条件的正样本用户。
4. 生成新分群。

适用场景：

1. 希望对历史成功样本进行再运营。
2. 希望沉淀正样本内部更精准的小群体。
3. 希望对已转化人群做复购、会员升级或深度运营。

**20.3.2 扩量后人群**

含义：

在全量私域人群中，筛选满足所选特征组合的人群。

生成逻辑：

1. 取当前主体全量私域人群。
2. 应用勾选的特征组合条件。
3. 得到满足条件的人群。
4. 生成新分群。

适用场景：

1. 希望基于正样本特征扩量高潜客户。
2. 希望将模型推荐的特征组合用于广告投放或私域触达。
3. 希望在全量人群中寻找类似成功样本的人。

**20.4 多个特征组合的合并逻辑**

当用户勾选多个特征组合时，需要明确组合之间的关系。

建议弹窗提供：

组合关系

选项：

1. 满足任意特征组合。
2. 满足所有特征组合。

默认值：

满足任意特征组合

**满足任意特征组合**

逻辑：

1. 多个特征组合之间取并集。
2. 用户只要满足任一组合，即进入分群。
3. 适合扩量场景。

**满足所有特征组合**

逻辑：

1. 多个特征组合之间取交集。
2. 用户必须同时满足所有组合，才进入分群。
3. 适合极高精准筛选场景。
4. 若交集人数为 0，保存前提示：
   * 当前条件下分群人数为0，请调整组合关系或减少特征组合。

**20.5 存为分群弹窗字段**

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| 导出人群类型 | 单选 | 是 | 正样本人群、扩量后人群 |
| 组合关系 | 单选 | 是 | 满足任意组合、满足所有组合 |
| 输出 ID 类型 | 下拉 | 是 | 选择生成分群的 ID 类型 |
| 分群名称 | 输入框 | 是 | 新分群名称 |
| 分群描述 | 文本域 | 否 | 分群说明 |
| 授权给 | 对象选择器 | 否 | 授权用户、用户组、角色、部门 |
| 分组 | 下拉多选 | 否 | 用户分群模块中的分组 |
| 预估人数 | 只读 | 否 | 根据导出类型和组合关系计算 |

**20.6 预估人数**

在存为分群弹窗中，当用户改变以下字段时，需要重新预估人数：

1. 导出人群类型。
2. 组合关系。
3. 勾选特征组合。
4. 输出 ID 类型。

预估逻辑：

1. 后端根据当前配置计算目标 ID 数。
2. 预估中展示 loading。
3. 预估成功后展示人数。
4. 预估失败时不允许保存，并展示失败原因。

**20.7 确定按钮**

按钮名称：

确定

点击后校验：

1. 用户是否拥有分群创建权限。
2. 至少勾选一个特征组合。
3. 导出人群类型是否选择。
4. 组合关系是否选择。
5. 输出 ID 类型是否选择。
6. 分群名称是否填写。
7. 预估人数是否大于 0。
8. 授权对象是否合法。
9. 分组是否存在。

校验通过后：

1. 创建用户分群。
2. 记录来源为多维特征分析报告。
3. 保存报告 ID、特征组合 ID、导出类型、组合关系。
4. 生成分群初始版本。
5. 返回成功提示。

成功提示：

分群保存成功，可前往用户分群模块查看和编辑。

按钮：

1. 继续查看报告
2. 前往用户分群

**21. 报告详情失败状态**

**21.1 详情页失败状态展示**

当报告计算失败时，详情页展示：

1. 报告基础信息。
2. 失败状态卡片。
3. 失败原因。
4. 重新计算按钮。
5. 返回列表按钮。

不展示：

1. 要点解读。
2. 结果明细表格。
3. 存为分群按钮。

**21.2 失败状态按钮**

**重新计算**

点击后逻辑同列表页重新计算。

**返回列表**

点击后返回报告列表页，并保留当前筛选状态。

**22. 报告详情计算中状态**

当报告处于计算中：

1. 顶部展示基础信息。
2. 主内容区展示计算中状态。
3. 展示预计说明：
   * 报告正在计算中，计算完成后将自动展示分析结果。
4. 支持自动轮询任务状态。
5. 轮询间隔建议 5 秒。
6. 计算成功后自动刷新为结果详情页。
7. 计算失败后自动刷新为失败状态。

**23. 空状态与异常状态**

**23.1 报告列表为空**

如果用户有创建权限：

暂无多维特征分析报告，你可以点击“新建报告”创建第一份报告。

如果用户无创建权限：

暂无可查看的多维特征分析报告。

**23.2 搜索无结果**

文案：

未找到符合条件的报告，请调整搜索或筛选条件。

按钮：

重置筛选

**23.3 结果明细为空**

可能原因：

1. 正负样本差异不明显。
2. 参与分析标签过少。
3. 标签覆盖率过低。
4. 正样本人数过少。
5. 所选特征组合数量限制过严。

文案：

当前配置下暂无有效特征组合，请尝试增加参与分析标签、调整正负样本或降低特征组合复杂度。

按钮：

1. 返回编辑
2. 重新计算

**23.4 存为分群人数为 0**

文案：

当前特征组合下没有可保存的人群，请调整导出类型或组合关系。

**27. 验收标准**

**27.1 报告列表**

1. 用户只能看到自己创建或他人授权查看的报告。
2. 报告列表展示报告名称、正显著分群、负显著分群、计算完成时间、主体、创建人、报告状态。
3. 支持按报告名称搜索。
4. 支持“我创建的”“我收藏的”“他人授权给我”筛选。
5. 支持按报告状态筛选。
6. 报告状态为失败时，可查看失败原因。
7. 报告状态为失败时，可重新发起计算。
8. 用户可收藏和取消收藏报告。
9. 报告创建者可删除报告。
10. 报告创建者可授权他人查看报告。
11. 授权仅支持查看权限，不支持编辑权限。

**27.2 报告创建**

1. 用户有增删改报告权限时可以点击新建报告。
2. 任务名称必填。
3. 主体必选。
4. 正显著分群必选，且只能从已创建人群包中选择。
5. 负显著分群支持大盘随机抽样、指定分群随机抽样、自定义分群。
6. 指定分群随机抽样必须选择指定分群。
7. 自定义分群必须选择负样本分群。
8. 正负样本人数必须大于 0。
9. 系统推荐标签最多不超过 200 个。
10. 自定义选择标签最多可选 200 个。
11. 未选择标签不参与特征分析，也不会出现在结果中。
12. 特征组合标签值数量支持 1、2、3，默认 3。
13. 保存后创建报告并发起计算任务。

**27.3 报告详情**

1. 报告顶部展示正显著分群、负显著分群、标签、计算完成时间、创建人、主体、状态。
2. 点击正显著分群可跳转用户分群详情。
3. 点击负显著分群时，若负样本有对应分群，则可跳转详情。
4. 大盘随机抽样负样本不支持跳转。
5. 要点解读展示最显著特征组合和营销建议。
6. 结果明细默认按综合评分降序展示。
7. 结果明细展示综合评分、精确率、召回率、正样本人数、扩量后人数。
8. 综合评分计算逻辑为精确率 0.8 + 召回率 0.2。
9. 召回率表示正样本中满足条件的人群占正样本总人数比例。
10. 精确率表示满足条件的人群中正样本占正负样本总人数比例。

**27.4 存为分群**

1. 用户可勾选一个或多个特征组合。
2. 点击存为分群后打开配置弹窗。
3. 支持选择正样本人群。
4. 支持选择扩量后人群。
5. 正样本人群表示正样本中符合该特征组合的人群。
6. 扩量后人群表示全量私域人群中满足该特征组合的人群。
7. 多个特征组合支持满足任意组合或满足所有组合。
8. 分群名称必填。
9. 输出 ID 类型必填。
10. 保存成功后可在用户分群模块查看。
11. 无分群创建权限时，存为分群按钮置灰。

**27.5 状态与异常**

1. 报告计算中时，详情页展示计算中状态并自动轮询。
2. 报告计算成功后展示要点解读和结果明细。
3. 报告计算失败后展示失败原因和重新计算按钮。
4. 正显著分群删除后，报告进入失效或局部失效状态。
5. 参与分析标签全部失效时，报告重新计算失败。
6. 结果明细为空时展示空状态和调整建议。
7. 删除报告后不可恢复。
