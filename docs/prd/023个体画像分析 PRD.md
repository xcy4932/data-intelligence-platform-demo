**个体画像分析 PRD**

**1. 模块定位**

个体画像分析用于围绕某一个具体主体，展示其基础档案、标签信息、行为轨迹、所在分群、身份关系和跨主体关系。主体可以是用户、客户、会员、设备、车辆、门店、商品、线索等，具体取决于项目在 ID Mapping 与个体画像配置中的主体定义。

该模块的核心目标是：

1. 支持业务人员通过手机号、用户 ID、设备 ID、基准 ID 等 ID 类型精准查找某个个体。
2. 支持通过标签、行为、明细数据、用户属性等条件批量筛选目标个体。
3. 支持查看某个个体的完整画像详情，包括档案信息、客户概览、行为细查、用户标签和关系图谱。
4. 支持从标签、分群等其他模块联动进入个体画像。
5. 支持项目管理员在项目中心配置检索列表、详情看板、行为细查展示规则、行为名称和属性显示规则。
6. 所有展示内容必须受模块权限、资源权限和字段配置共同控制，避免用户看到无权限数据。

**2. 角色与权限**

**2.1 角色定义**

| **角色** | **权限范围** |
| --- | --- |
| 项目管理员 | 可配置个体画像看板、检索列表字段、详情页展示内容、行为细查分类、行为过滤规则；可查看权限范围内的个体画像 |
| 普通业务用户 | 可进入个体画像分析页面，按权限查看检索结果和详情内容 |
| 数据分析用户 | 可使用精准筛选、自定义筛选、列表自定义列、行为细查筛选等能力 |
| 资源受限用户 | 只能看到被授权的标签、行为、明细数据和字段 |
| 系统管理员 | 可维护 ID Mapping、主体转换关系、元数据事件名称、事件属性展示名、属性字典等底层配置 |

**2.2 权限项**

| **权限项** | **控制内容** |
| --- | --- |
| 个体画像-查看 | 是否允许进入个体画像模块 |
| 个体画像-检索 | 是否允许使用精准筛选、自定义筛选检索个体 |
| 个体画像-详情查看 | 是否允许进入个体画像详情页 |
| 标签资源权限 | 控制标签是否可用于筛选、列表展示、详情展示 |
| 行为资源权限 | 控制行为是否可用于筛选和行为细查展示 |
| 明细数据权限 | 控制明细字段是否可用于自定义筛选 |
| 用户属性权限 | 控制用户属性是否可展示、筛选 |
| 分群查看权限 | 控制所在分群是否可展示和跳转 |
| 关系图谱查看权限 | 控制是否展示关系图谱 Tab |
| 多主体能力权限 | 控制关系图谱是否可用 |
| 项目中心配置权限 | 控制是否可配置看板、字段、行为细查规则 |

**2.3 无权限处理规则**

1. 用户无“个体画像-查看”权限时，不展示“分析洞察 > 个体画像”菜单。
2. 用户有模块权限但无某类资源权限时：
   * 检索条件中不展示该资源。
   * 列表列中不展示该字段。
   * 详情页不展示该标签、属性、行为或分群。
3. 用户通过 URL 直接访问无权限个体详情时，页面展示无权限状态：
   * 文案：暂无该个体画像查看权限。
   * 按钮：返回个体画像列表
4. 用户无关系图谱权限或项目未开通多主体能力时：
   * 不展示“关系图谱”Tab，或展示置灰态。
   * 鼠标悬停提示：当前项目未开通多主体能力或暂无关系图谱查看权限。

**3. 前置配置**

个体画像分析必须依赖项目中心中的画像配置。未完成配置时，前台页面不能直接进入可用状态。

**3.1 配置入口**

路径：

左侧导航 > 用户洞察 > 个体画像配置

配置流程：

1. 选择主体。
2. 新建看板。
3. 配置检索列表。
4. 配置个像详情页。
5. 配置行为细查。
6. 保存配置。
7. 前往 用户洞察 > 个体画像 查看结果。

**3.2 新建看板**

**3.2.1 新建看板按钮**

按钮名称：新建看板

点击后打开新建看板弹窗。

弹窗字段：

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| 看板名称 | 输入框 | 是 | 用于前台切换看板 |
| 主体 | 下拉框 | 是 | 选择该看板服务的主体 |
| 描述 | 文本域 | 否 | 看板说明 |
| 是否默认看板 | 开关 | 否 | 开启后，该主体下默认进入该看板 |

校验逻辑：

1. 看板名称不能为空。
2. 同一主体下看板名称不允许重复。
3. 一个主体至少保留 1 个看板。
4. 一个主体只能有 1 个默认看板。
5. 若用户将当前看板设置为默认看板，系统自动取消同主体下其他看板的默认状态。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 确定 | 校验通过后创建看板 |
| 保存并配置 | 创建看板后进入配置页面 |

**5. 个体画像检索列表页**

**5.1 页面入口**

路径：

用户洞察 > 用户画像>个体画像

进入页面时，系统按以下顺序加载数据：

1. 判断当前用户是否有个体画像查看权限。
2. 获取当前项目已配置的主体列表。
3. 获取当前用户可见的看板列表。
4. 默认选中当前主体的默认看板。
5. 加载该看板的检索列表配置。
6. 默认不执行用户检索，除非 URL 中携带联动条件。

**5.2 页面布局**

页面从上到下分为：

1. 顶部模块标题区。
2. 看板选择区。
3. 检索方式切换区。
4. 精准筛选区或自定义筛选区。
5. 搜索结果统计区。
6. 搜索结果列表区。
7. 分页区。

**6. 看板选择**

**6.1 看板按钮**

按钮名称：看板：{当前看板名称}

点击后展开看板选择下拉面板。

面板内容：

1. 当前主体下所有用户可见看板。
2. 每个看板展示看板名称。
3. 默认看板带有“默认”标记。
4. 当前选中的看板高亮。

交互逻辑：

1. 用户点击看板按钮。
2. 展开下拉面板。
3. 用户选择另一个看板。
4. 系统切换检索列表配置和详情页配置。
5. 当前已输入但未执行的筛选条件清空。
6. 已执行的结果列表清空。
7. 页面恢复到该看板的初始状态。

异常逻辑：

1. 如果该主体下没有可用看板，页面展示空状态：
   * 文案：当前主体暂无可用个体画像看板，请联系管理员配置。
2. 如果当前看板被删除，刷新后切换到默认看板。
3. 如果默认看板也不存在，展示无配置状态。

**7. 检索方式切换**

检索页支持两种方式：

1. 精准筛选。
2. 自定义筛选。

页面以 Tab 或分段按钮展示。

**7.1 精准筛选 Tab**

按钮名称：精准筛选

点击后：

1. 展示 ID 类型选择器。
2. 展示 ID 输入框。
3. 展示查询按钮。
4. 隐藏自定义圈选条件区域。
5. 若原来已有自定义筛选结果，切换时保留结果列表但顶部筛选条件切换为精准筛选输入区。建议产品策略为切换后清空结果，避免用户误解，本文采用清空结果逻辑。

**7.2 自定义筛选 Tab**

按钮名称：自定义筛选

点击后：

1. 展示主体选择。
2. 展示“添加筛选”按钮或已配置的筛选摘要。
3. 展示搜索结果内二次精准搜索区域。
4. 清空精准筛选输入值。
5. 结果列表清空。

**8. 精准筛选**

**8.1 主体选择**

字段名称：主体

控件类型：下拉选择器。

选项来源：

1. 当前看板对应主体。
2. 如果看板只绑定单一主体，则主体固定不可修改。
3. 如果看板允许多主体检索，则展示用户有权限查看的主体。

默认值：

1. 默认选择当前看板绑定主体。
2. 若从标签或分群联动进入，使用联动来源指定主体。

**8.2 ID 类型选择**

字段名称：ID类型

控件类型：下拉选择器。

选项来源：

1. 当前主体在 ID Mapping 中配置的 ID 类型。
2. 当前看板允许检索的 ID 类型。
3. 当前用户有权限查看的 ID 类型。

常见选项：

1. 基准 ID。
2. 用户 ID。
3. 会员 ID。
4. 手机号。
5. 设备 ID。
6. OpenID。
7. UnionID。
8. 车辆 ID。
9. 门店 ID。

交互逻辑：

1. 用户切换主体后，ID 类型下拉选项同步刷新。
2. 若当前已选择 ID 类型不属于新主体，自动清空 ID 类型。
3. ID 类型为空时，查询按钮不可点击。
4. 若只有一个 ID 类型，默认选中。

**8.3 ID 输入框**

字段名称：请输入具体ID

规则：

1. 必填。
2. 支持输入单个 ID。
3. 前后空格自动 trim。
4. 不允许输入纯空格。
5. 手机号类型可根据项目规则校验长度和格式。
6. 其他 ID 类型默认按字符串处理，不做格式强校验。
7. 输入内容不自动脱敏，但结果展示需遵守脱敏规则。

**8.4 查询按钮**

按钮名称：查询

可点击条件：

1. 已选择主体。
2. 已选择 ID 类型。
3. 输入框不为空。
4. 用户拥有检索权限。

点击后执行：

1. 请求后端查询 ID Mapping。
2. 查找该 ID 对应的主体档案。
3. 返回匹配到的个体列表。
4. 列表展示 ID、标签、自定义列、收藏状态等。
5. 若只命中一个个体，仍停留在列表页，不自动跳转，避免用户误入详情。
6. 用户点击列表中的基准 ID 后进入详情页。

加载态：

1. 查询按钮展示 loading。
2. 列表区域展示骨架屏。
3. 防止重复点击，查询过程中按钮不可再次点击。

异常：

| **场景** | **提示** |
| --- | --- |
| 未选择 ID 类型 | 请选择ID类型 |
| 未输入 ID | 请输入具体ID |
| 无权限 | 暂无检索权限 |
| 未找到结果 | 未找到匹配的个体 |
| 查询失败 | 查询失败，请稍后重试 |

**8.5 重置按钮**

按钮名称：重置

点击后：

1. 清空 ID 输入框。
2. ID 类型恢复默认值。
3. 清空结果列表。
4. 清空分页。
5. 清空是否包含当日最新用户 ID 筛选项。

**9. 自定义筛选**

**9.1 功能说明**

自定义筛选允许用户通过人群圈选组件构建筛选条件，批量筛出符合条件的个体，再进入具体用户画像详情查看。

圈选规则与私域分群规则保持一致，包括：

1. 标签条件。
2. 行为条件。
3. 用户属性条件。
4. 明细数据条件。
5. 已有人群包条件。
6. 满足条件。
7. 排除条件。
8. 组内 AND / OR。
9. 组间 AND / OR。

**9.2 添加筛选按钮**

按钮名称：添加筛选

点击后打开自定义筛选弹窗。

弹窗标题：

添加筛选

弹窗结构：

1. 主体选择区。
2. 满足条件区。
3. 排除条件区。
4. 数量预估区。
5. 底部按钮区。

**9.3 满足条件区**

默认展示一个条件组。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 添加条件 | 在当前组内新增筛选条件 |
| 添加条件组 | 新增一个条件组 |
| 删除条件 | 删除当前条件 |
| 删除条件组 | 删除当前条件组 |
| 且/或切换 | 控制条件之间取交集或并集 |
| 重命名条件组 | 修改条件组名称 |

计算逻辑：

1. 同一条件组内，AND 表示取交集，OR 表示取并集。
2. 多个条件组之间同样支持 AND / OR。
3. 满足条件结果作为候选结果集。

**9.4 排除条件区**

排除条件用于快速圈选“不包含”的人群。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 添加排除条件 | 新增排除条件组 |
| 添加条件 | 在排除组中添加条件 |
| 删除排除条件 | 删除整个排除区 |
| 且/或切换 | 控制排除条件内部逻辑 |

计算逻辑：

最终结果 = 满足条件结果 - 排除条件结果

规则：

1. 排除条件可为空。
2. 排除条件为空时，不执行剔除。
3. 排除条件支持标签、行为、属性、明细、人群包。
4. 用户无权限的资源不展示在排除条件选择器中。

**9.5 自定义筛选弹窗按钮**

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗，不保存当前筛选条件 |
| 清空 | 清空已配置条件，保留主体 |
| 预估数量 | 根据当前条件返回预估人数 |
| 确定 | 校验条件并执行筛选 |

点击确定后：

1. 校验至少有一个满足条件。
2. 校验每条条件字段完整。
3. 校验用户资源权限。
4. 生成筛选任务或同步查询。
5. 返回检索列表页。
6. 展示筛选摘要。
7. 展示命中的个体列表。

**9.6 筛选摘要**

自定义筛选执行后，在筛选区展示摘要：

示例：

已筛选：满足 条件组A 且 排除 条件组B

摘要右侧按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 编辑筛选 | 重新打开弹窗，回显当前条件 |
| 清除筛选 | 清空自定义筛选条件和结果列表 |
| 重新查询 | 使用当前条件重新执行筛选 |

**10. 搜索结果内二次精准搜索**

自定义筛选得到一批个体后，用户可在结果中继续按 ID 搜索。

**10.1 控件**

1. ID 类型下拉框。
2. ID 输入框。
3. 搜索图标按钮。
4. 清空按钮。

**10.2 逻辑**

1. 二次搜索只在当前筛选结果范围内检索。
2. 若用户未执行自定义筛选，二次搜索不可用。
3. 用户输入 ID 后点击搜索，仅返回当前结果集中匹配的个体。
4. 清空二次搜索后，恢复自定义筛选的完整结果。
5. 二次搜索不改变原筛选条件。

**11. 是否包含当日最新用户 ID**

**11.1 控件**

控件名称：是否包含当日最新用户ID

建议表现为复选框或开关。

**11.2 逻辑**

1. 默认关闭。
2. 关闭时，结果基于最近稳定数据版本。
3. 开启时，结果查询包含当日最新接入的用户 ID。
4. 开启后查询性能可能下降，页面需要提示：
   * 开启后将包含当日最新用户ID，查询耗时可能增加。
5. 该设置作用于当前查询条件。
6. 切换该选项后，需要用户重新点击查询，或系统自动刷新，建议采用手动刷新，避免频繁请求。

**12. 搜索结果列表**

**12.1 列表内容**

列表默认展示：

1. 选择框，可选。
2. 基准 ID 或当前主 ID。
3. 昵称或名称。
4. 标签列。
5. 项目配置的自定义字段。
6. 收藏状态。
7. 操作列。

实际展示字段由以下配置共同决定：

1. 项目中心检索列表配置。
2. 用户个人自定义列配置。
3. 当前用户资源权限。
4. 字段是否支持实时展示。

**12.2 点击基准 ID**

点击基准 ID 后：

1. 跳转个体画像详情页。
2. URL 携带主体、ID 类型、ID 值、看板 ID。
3. 详情页按当前看板配置展示。
4. 返回按钮返回当前列表查询结果。

**12.3 收藏按钮**

按钮样式：

1. 未收藏：空心星标。
2. 已收藏：实心星标。

点击未收藏：

1. 调用收藏接口。
2. 成功后星标变为实心。
3. 当前个体进入用户个人收藏列表。

点击已收藏：

1. 调用取消收藏接口。
2. 成功后星标变为空心。
3. 从用户个人收藏列表移除。

异常：

| **场景** | **处理** |
| --- | --- |
| 收藏失败 | 提示：收藏失败，请稍后重试 |
| 取消失败 | 提示：取消收藏失败，请稍后重试 |
| 无权限查看该个体 | 星标不可点击 |

**12.4 自定义列按钮**

按钮名称：自定义列

点击后打开自定义列弹窗。

弹窗内容：

1. 可选字段列表。
2. 已选字段列表。
3. 字段搜索框。

**19. 行为细查 Tab**

典型场景：

用户来到 4S 店后，门店人员输入用户手机号找到该用户，进入行为细查，查看其来店之前是否在小程序、微信文章、广告触达、车机端等渠道浏览过某车型，从而进行有针对性的推荐。

1. 筛选区。
2. 行为时间线。
3. 行为事件列表。
4. 事件详情面板。
5. 空状态。
6. 加载状态。

**19.3 筛选区**

筛选项包括：

1. 平台。
2. 流程。

1. 小程序。
2. 微信。
3. Finder。
4. GMP。
5. App。
6. Web。

交互逻辑：

1. 用户选择平台后，事件分类和事件下拉选项联动刷新。

字段名称：流程

**19.7 全部事件筛选**

字段名称：事件

控件类型：单选下拉。

逻辑：

**21.3 行为过滤配置**

用于过滤不需要在行为细查中展示的事件和属性。

**事件过滤**

配置方式：

1. 选择事件。
2. 设置是否展示。
3. 保存。

逻辑：

1. 被设置为不展示的事件，前台事件下拉不出现。
2. 行为时间线中也不展示该事件。
3. 事件过滤对所有用户生效。

**属性过滤**

配置方式：

1. 选择事件。
2. 选择事件属性。
3. 设置是否展示。
4. 保存。

逻辑：

1. 被过滤属性不出现在事件详情中。
2. 被过滤属性不出现在事件属性筛选器中。
3. 适合过滤技术字段，例如 item\_id、IP 地址、current\_id、设备型号、user\_agent、广告计划 ID、schedule\_id、event\_time 等。

1. Finder 数据管理 > 一般事件
2. CDP 数据融合 > 元数据管理 > 事件名称

操作逻辑：

1. 搜索事件名称。
2. 在展示名列填写业务可读名称。
3. 保存。
4. 前台行为细查优先展示展示名。

示例：

gmp\_sdk\_logs 修改为 GMP触达

**21.5 修改行为属性展示名**

路径：

1. Finder 数据管理 > 事件属性
2. CDP 数据融合 > 元数据管理 > 事件属性

操作逻辑：

1. 搜索事件属性。
2. 在展示名列填写中文名称。
3. 保存。
4. 前台事件详情和筛选器展示中文名称。

示例：

| **原属性名** | **展示名** |
| --- | --- |
| task\_id | 任务编号 |
| task\_type | 任务类型 |
| status\_code | 状态码 |
| send\_id | 发送ID |
| sub\_task\_id | 子任务编号 |
| channel\_type | 通道类型 |
| channel\_id | 通道ID |

**21.6 修改行为属性值字典**

用途：

将技术枚举值转换为业务可读值。

操作：

1. 进入事件属性管理。
2. 搜索属性字段。
3. 在“字典”列上传字典文件。
4. 保存。
5. 前台展示属性值时优先展示字典值。

规则：

1. 字典必须包含原始值和展示值。
2. 原始值匹配成功时展示字典值。
3. 匹配失败时展示原始值。
4. 字典更新后，前台刷新即可生效。
5. 字典配置失败时，不影响行为原始值展示。

**22. 用户标签 Tab**

**22.1 功能说明**

用户标签 Tab 展示当前个体拥有的所有标签，并支持按标签目录结构或平铺方式查看。

**22.2 页面结构**

1. 展示方式切换。
2. 标签目录树。
3. 标签列表区。
4. 标签搜索框。
5. 标签详情区域。

**22.3 展示方式切换**

按钮：

1. 按目录展示
2. 平铺展示

**按目录展示**

逻辑：

1. 左侧展示标签目录树。
2. 右侧展示当前目录下标签。
3. 点击目录节点刷新右侧标签。
4. 目录无标签时展示空状态。

**平铺展示**

逻辑：

1. 不展示目录层级。
2. 按标签名称、标签分类或更新时间排序展示全部可见标签。
3. 支持搜索。

**22.4 标签搜索**

输入框占位：

搜索标签名称

逻辑：

1. 支持标签名称模糊搜索。
2. 搜索范围为当前用户有权限查看的标签。
3. 输入后按 Enter 或点击搜索图标查询。
4. 清空后恢复原展示。

**22.5 标签项展示**

每个标签项展示：

1. 标签名称。
2. 标签值。
3. 标签类型。
4. 更新时间。
5. 来源。
6. 说明 tooltip。

点击标签：

1. 跳转标签体系详情页。
2. 若无权限，提示无权限。
3. 若标签已删除，提示标签不存在。

**23. 关系图谱 Tab**

**23.1 前置条件**

关系图谱可用必须满足：

1. 项目已开通多主体功能。
2. 项目已在 ID Mapping 中配置主体转换关系。
3. 当前用户拥有关系图谱查看权限。
4. 当前主体存在至少一个可关联主体关系。

若不满足：

1. 不展示关系图谱 Tab，或展示空状态。
2. 空状态文案：
   * 当前主体暂无可展示关系图谱，请确认是否已配置多主体关系。

**23.2 页面结构**

关系图谱包含：

1. 图谱视图。
2. 表格视图。
3. 身份信息表格。
4. 视图切换按钮。
5. 放大、缩小、全屏按钮。

**23.3 图谱视图**

展示逻辑：

1. 当前主体作为中心节点。
2. 以当前主体向外展示有关联关系的主体节点。
3. 不同主体使用不同底纹颜色。
4. 主体名称展示在节点上方。
5. 主体 ID 展示在节点内部。
6. 主体间箭头名称为 ID Mapping 中配置的主体转换关系名称。
7. ID Mapping 最多支持 20 个主体，图谱最多按项目配置展示可用主体。

节点点击：

1. 点击不同主体卡片。
2. 跳转该主体下的个体画像详情页。
3. 跳转时携带目标主体、目标 ID、当前看板。
4. 若目标主体没有可用看板，提示暂无看板配置。

箭头点击：

1. 展示关系详情。
2. 包括关系名称、来源、更新时间、关系 ID。
3. 若无详情，仅展示关系名称。

**23.4 图谱操作按钮**

| **按钮** | **逻辑** |
| --- | --- |
| 放大 | 图谱按比例放大 |
| 缩小 | 图谱按比例缩小 |
| 适应画布 | 图谱自动缩放至全部节点可见 |
| 全屏 | 进入全屏图谱模式 |
| 退出全屏 | 返回详情页内嵌模式 |
| 转为表格 | 切换到表格视图 |

**23.5 表格视图**

表格展示每个有关联主体的 ID 列表以及关键标签、属性信息。

字段：

1. 主体名称。
2. ID 类型。
3. ID 值。
4. 关系名称。
5. 关键标签。
6. 关键属性。
7. 更新时间。
8. 操作。

操作：

| **按钮** | **逻辑** |
| --- | --- |
| 查看详情 | 跳转该主体个体画像详情页 |
| 复制ID | 复制当前 ID 值 |

**23.6 身份信息表格**

身份信息表格展示当前查询个体的所有 ID 类型和值。

字段：

1. ID 类型。
2. ID 值。
3. 是否主 ID。
4. 是否脱敏。
5. 来源。
6. 更新时间。

规则：

1. 所有 ID 类型受权限控制。
2. 敏感 ID 按脱敏策略展示。
3. 同一 ID 类型多个值时全部展示，区别于档案栏只展示前 30 个。
4. 支持复制 ID，但复制权限需受控。
5. 无复制权限时复制按钮隐藏。

**24. 个体画像详情页返回逻辑**

**24.1 返回按钮**

按钮名称：返回

点击后：

1. 如果从检索列表进入，返回原检索结果页。
2. 保留原筛选条件、页码、滚动位置。
3. 如果从关系图谱跳转进入，返回上一个主体详情页。
4. 如果直接打开 URL，返回个体画像检索首页。

**24.2 浏览器后退**

浏览器后退行为必须与页面返回一致：

1. 保留列表状态。
2. 不重新丢失筛选条件。
3. 不重复请求无必要数据。
4. 如果缓存过期，则重新请求并恢复筛选条件。

**27. 状态与异常处理**

**27.1 页面无配置**

文案：

当前项目尚未完成个体画像配置，请联系管理员在项目中心完成配置。

按钮：

1. 刷新
2. 去配置，仅配置权限用户可见。

**27.2 检索无结果**

文案：

未找到符合条件的个体，请检查ID或调整筛选条件。

按钮：

1. 重置筛选
2. 重新查询

**27.3 详情无数据**

文案：

当前个体暂无可展示画像信息。

展示规则：

1. 保留档案基础区域。
2. 各组件分别展示空状态。
3. 不因为某个组件无数据导致整个页面报错。

**27.4 行为细查无数据**

文案：

当前条件下暂无行为记录。

按钮：

重置筛选

**27.5 关系图谱无数据**

文案：

当前个体暂无可展示关系。

**27.6 权限变更**

如果用户已进入页面后权限被回收：

1. 下一次请求返回无权限。
2. 页面展示无权限提示。
3. 清空敏感数据缓存。
4. 不允许继续操作。

**28. 数据权限与合规要求**

1. 个体画像中应用的数据必须来自客户自身数据，并在合法合规场景下使用。
2. 所有标签、行为、属性、明细、ID 字段必须经过资源权限判断。
3. 手机号、身份证号、OpenID、设备 ID 等敏感字段必须支持脱敏展示。
4. 用户无复制权限时，不允许复制敏感 ID。
5. 列表导出能力本文不默认提供，如后续增加，必须单独做权限控制和审计。
6. 用户访问个体详情、行为细查、关系图谱时，需要记录审计日志。

审计日志字段建议：

| **字段** | **说明** |
| --- | --- |
| user\_id | 操作人 |
| action | search / view\_detail / view\_behavior / view\_relation / favorite |
| subject\_type | 主体 |
| id\_type | 查询 ID 类型 |
| id\_value\_masked | 脱敏后的查询值 |
| board\_id | 看板 |
| timestamp | 操作时间 |
| result\_count | 返回结果数量 |
| ip | 操作 IP |

**29. 验收标准**

**29.1 检索列表页**

1. 用户有权限时可以进入个体画像页面。
2. 用户无权限时不展示菜单或展示无权限页。
3. 可切换不同看板。
4. 切换看板后，检索配置和详情配置同步变化。
5. 精准筛选支持选择 ID 类型并输入 ID 查询。
6. 自定义筛选支持标签、行为、属性、明细、人群包条件。
7. 自定义筛选支持满足和排除。
8. 结果列表展示项目配置字段。
9. 用户个人自定义列优先于项目默认列。
10. 点击基准 ID 可进入详情页。
11. 星标可收藏和取消收藏。
12. 分页、每页条数切换正常。
13. 是否包含当日最新用户 ID 筛选生效。

**29.2 个体画像详情页**

1. 左侧档案栏按项目配置展示。
2. 同一 ID 类型多个值时档案栏最多展示前 30 个。
3. 全局描述只读展示。
4. 收藏按钮状态正确。
5. 看板切换后详情内容重新加载。
6. 无权限字段不展示。
7. 空字段按规则展示或隐藏。
8. 返回列表后保留筛选条件和页码。

**29.3 客户概览**

1. 客户重点信息最多完整展示 5 个卡片。
2. 超过 5 个卡片出现滚动条和左右切换按钮。
3. 客户旅程最多支持 14 个节点。
4. 每组关键标签最多展示 10 条。
5. 点击更多可查看全部标签。
6. 点击重点标签跳转标签体系。
7. 点击所在分群跳转用户分群。
8. 点击重点身份标识跳转身份信息。

**29.4 行为细查**

1. 支持按平台筛选。
2. 支持按流程筛选。
3. 支持按事件分类筛选。
4. 支持按事件筛选。
5. 支持按事件属性筛选。
6. 支持按时间范围筛选。
7. 行为按时间线倒序展示。
8. 事件详情展示属性展示名和字典值。
9. 被过滤事件不展示。
10. 被过滤属性不展示。
11. 无权限行为不展示。
12. 无行为时展示空状态。

**29.5 用户标签**

1. 支持按目录展示标签。
2. 支持平铺展示标签。
3. 支持搜索标签。
4. 标签受资源权限控制。
5. 点击标签可跳转标签体系。

**29.6 关系图谱**

1. 未配置多主体能力时不展示或置灰关系图谱。
2. 图谱以当前主体为中心展示关系。
3. 不同主体使用不同底纹颜色。
4. 箭头名称使用 ID Mapping 主体转换关系名称。
5. 支持放大、缩小、全屏、适应画布。
6. 支持切换表格视图。
7. 点击主体卡片跳转对应主体详情页。
8. 身份信息表格展示当前用户所有 ID 类型值。
9. 敏感 ID 按脱敏规则展示。

**29.7 配置后台**

1. 项目管理员可以新建看板。
2. 同一主体至少保留一个看板。
3. 可以配置检索列表字段。
4. 可以配置详情页档案栏、客户概览、Tab。
5. 可以配置行为细查分类。
6. 可以过滤不需要展示的行为和属性。
7. 可以通过元数据配置修改事件名称展示名。
8. 可以通过元数据配置修改事件属性展示名。
9. 可以上传属性字典，使属性值展示为业务可读值。
