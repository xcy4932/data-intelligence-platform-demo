**可视化建模详细 PRD**

**1. 产品定位**

可视化建模是数据平台中的低代码数据处理与建模模块，位于“数据连接 / 数据输入”和“数据集 / 标签 / 外部系统输出”之间。用户通过拖拽算子、连接节点、配置参数、预览数据、运行任务的方式，完成从原始数据到可分析数据集、实时标签、Kafka 流、外部存储表、机器学习预测结果的加工过程。

本 PRD 不按“功能清单”描述，而是按照可直接开发的产品逻辑定义每个页面、状态、交互、数据结构、校验规则、任务运行逻辑和验收标准。

**2. 功能边界**

**2.1 本期必须支持的能力**

可视化建模模块需要支持以下完整闭环：

1. 新建可视化建模任务。
2. 选择离线任务或实时任务类型。
3. 从数据连接、数据集或自定义 SQL 创建输入节点。
4. 在画布中拖拽添加数据清洗、数据拆分、特征工程、自然语言处理、机器学习、输出类算子。
5. 支持节点之间连线，形成 DAG 有向无环流程。
6. 支持每个节点配置参数、字段映射、输出字段、预览数据。
7. 支持保存草稿、参数校验、运行任务。
8. 支持输出为平台数据集、外部存储、Kafka、实时标签、分流输出。
9. 支持任务列表、任务详情、运行记录、血缘查看、回收站。
10. 支持资源导出与导入迁移。

**2.2 本期不做的能力**

1. 不做自动机器学习 AutoML 全流程推荐，只做可配置的机器学习算子。
2. 不做复杂代码编辑 IDE，只提供自定义 SQL 与计算列表达式编辑。
3. 不做多人实时协同编辑。
4. 不做画布版本 Git 化管理，但保留任务版本字段。
5. 不做在线实时调参训练，只做保存配置后运行生成结果。

**6.1 页面目标**

任务概览页用于让用户查看项目内所有可视化建模任务，并完成搜索、筛选、运行、查看详情、编辑、删除等操作。

**6.3 状态统计卡片**

展示四类状态：

| **状态卡片** | **统计逻辑** |
| --- | --- |
| 运行成功 | 最近一次运行中，所有输出节点均成功 |
| 运行失败 | 最近一次运行中，任一输出节点失败或终止 |
| 正在运行 | 存在等待调度、等待上游依赖、同步中、运行中输出，且无失败输出 |
| 其他 | 从未运行、草稿、无明确运行状态 |

**交互逻辑**

1. 用户点击“运行成功”卡片。
2. 前端将 statusFilter=success 写入 URL query。
3. 表格重新请求任务列表。
4. 被选中的卡片高亮。
5. 再次点击同一卡片，取消筛选。

请求：

**8.3 自动保存逻辑**

为了避免用户长时间建模丢失配置，系统支持草稿自动保存。

规则：

1. 用户每次新增节点、删除节点、修改节点配置、修改连线后，将任务状态标记为“未保存”。
2. 3 秒内无继续操作，触发草稿保存。
3. 自动保存只保存草稿，不触发任务发布。
4. 用户点击“保存”时，保存为正式配置。
5. 自动保存失败时，顶部展示“自动保存失败，可手动重试”。

接口：

PUT /api/visual-modeling/tasks/{taskId}/draft

**8.4 画布操作**

**添加节点**

方式一：左侧点击算子。

1. 用户点击算子。
2. 系统在画布中心新增节点。
3. 如果当前选中节点存在可连接输出端口，且算子输入类型兼容，则自动连线。
4. 新节点被选中，右侧配置面板打开。

方式二：拖拽算子到画布。

1. 用户从左侧拖拽算子。
2. 鼠标释放位置即节点坐标。
3. 节点坐标保存为画布坐标，不是屏幕坐标。
4. 如果释放位置重叠已有节点，自动向右下偏移 24px。

方式三：从节点加号添加。

1. 用户点击节点右侧“+”。
2. 展示可用下游算子列表。
3. 用户选择算子后，系统自动创建节点并连线。

**删除节点**

1. 用户选中节点后按 Delete 或点击节点菜单“删除”。
2. 如果节点存在下游连线，弹窗提示：

删除该节点会同时删除与其相连的上下游连线，但不会删除其他节点。确认删除？

1. 删除节点后：
   * 删除与该节点相关的 edges。
   * 下游节点变为“输入不完整”。
   * 下游节点 previewStatus 变为 empty。
   * 整个任务标记未保存。

**连线规则**

系统必须保证 DAG 无环。

连线校验：

| **规则** | **说明** |
| --- | --- |
| 不能连接自己 | sourceNodeId != targetNodeId |
| 不能从输入端口连到输入端口 | 必须 output -> input |
| 数据类型兼容 | table 只能接 table，stream 只能接 stream，model 只能接 model |
| 不能形成环 | 新增边后做拓扑检测 |
| 输入端口连接数限制 | required input 通常最多 1 条，合并类算子可多条 |
| 输出节点不能有下游 | 输出类算子为最终节点 |

如果连线失败，展示具体原因，例如：

**12.1 拆分字段算子**

**使用场景**

**输入限制**

**分隔符拆分逻辑**

[

**使用场景**

**17. 分流输出 PRD**

**17.1 使用场景**

分流输出用于实时任务中将一条实时流按规则拆分成多条子流输出。

**17.2 输入输出限制**

1. 仅支持实时任务。
2. 输入节点只能是读节点或数据清洗节点。
3. 分流输出是最终算子，不允许接下游算子。
4. 一条实时流拆成多条流时，只启动一个 Flink 任务。

**17.3 配置项**

| **字段** | **类型** | **必填** |
| --- | --- | --- |

**17.4 分流匹配逻辑**

默认：

1. 规则按从上到下执行。
2. 一条数据进入第一个满足条件的子流。
3. 如果未命中任何规则且配置默认分流，则进入默认分流。
4. 如果未配置默认分流，则丢弃或进入内置 Topic，具体由高级配置决定。

可选高级模式：

allowMultiMatch: boolean

开启后，一条数据可进入多个子流。

**22. 保存与运行 PRD**

**22.1 保存**

点击保存时：

1. 前端执行本地校验。
2. 调用后端 DAG 校验。
3. 校验通过后保存正式配置。
4. 保存成功后状态变为“已保存”。
5. 保存失败展示错误。

接口：

PUT /api/visual-modeling/tasks/{taskId}

**22.2 运行**

点击运行时：

1. 如果有未保存变更，先保存。
2. 执行全量校验。
3. 弹出运行配置。
4. 用户确认后提交运行。
5. 跳转运行记录或停留当前页展示运行中状态。

**22.3 离线任务运行逻辑**

1. 根据 DAG 生成执行计划。
2. 拓扑排序节点。
3. 从输入节点开始执行。
4. 中间节点生成临时表或临时视图。
5. 输出节点写入目标数据集或外部表。
6. 每个输出节点生成独立运行结果。
7. 如果任一输出失败，任务状态为运行失败。
8. 如果全部输出成功，任务状态为运行成功。

**22.4 实时任务运行逻辑**

1. 根据 DAG 生成 Flink 作业。
2. 校验实时输入源和实时输出源。
3. 启动作业后状态为 running。
4. 持续监控消费延迟、写入状态、脏数据。
5. 用户可终止任务。
6. 终止后状态为 terminated。

6. 配置是否导入权限。
7. 执行导入。

**输入节点数据集**

输入数据集不直接导入，只能关联当前项目已有数据集。

逻辑：

1. 用户必须为每个输入数据集选择当前项目中的目标数据集。
2. 系统比对字段结构。
3. 如果字段缺失，标红。
4. 如果字段类型不一致，标黄。
5. 用户必须解决红色问题才能导入。

**输出节点数据集**

支持：

新建 / 关联已有数据集

新建逻辑：

1. 如果当前项目存在同名数据集，导入失败。
2. 用户可修改新数据集名称。

关联已有逻辑：

1. 系统比对元信息。
2. 用户可选择是否覆盖元信息。
3. 不自动删除已有数据。

**25.4 覆盖导入**

覆盖逻辑：

1. 用户选择被覆盖任务。
2. 可选择是否覆盖任务名称、描述、存储目录。
3. DAG、节点配置、运行配置被导入包覆盖。
4. 数据集、数据连接、资源队列根据映射关系替换。
5. 权限是否覆盖由用户选择。

**25.5 导入结果**

导入中展示进度：

解析资源包

校验资源

创建 / 覆盖任务

映射数据集

映射数据连接

写入权限

完成

导入完成后展示：

| **字段** | **说明** |
| --- | --- |
| 总任务数 | 导入包内任务数 |
| 成功数 | 导入成功 |
| 失败数 | 导入失败 |
| 失败原因 | 可下载明细 |

**28. 异常与边界场景**

**28.1 上游字段变化**

当上游节点 schema 变化时：

1. 系统重新计算所有下游节点 schema。
2. 如果下游引用字段不存在，下游节点标红。
3. 配置面板中具体字段展示“字段已不存在”。
4. 用户必须重新选择字段。

**28.2 输出字段重名**

处理规则：

1. 默认不允许同一节点输出字段重名。
2. Join 场景可自动加前缀。
3. 用户手动改名后才能保存。

**28.3 节点未配置完成**

1. 节点显示红色感叹号。
2. 鼠标悬停展示缺失参数。
3. 保存草稿允许。
4. 正式运行不允许。

**28.4 数据源权限丢失**

1. 打开任务时后端校验权限。
2. 无权限的数据源节点标红。
3. 预览和运行被禁止。
4. 提示用户联系管理员授权。

**28.5 任务运行中编辑**

1. 允许编辑。
2. 当前运行实例使用旧配置。
3. 保存的新配置用于下一次运行。
4. 如果用户删除正在运行的输出节点，需要提示不会影响当前运行。

**29. 验收标准**

**29.1 任务创建**

1. 用户可成功创建离线任务和实时任务。
2. 任务名称重复时不能保存。
3. 实时任务不展示离线专用算子。
4. 离线任务不展示实时专用输出算子。

**29.2 画布建模**

1. 用户可拖拽新增节点。
2. 用户可连接节点。
3. 系统能阻止形成环。
4. 类型不兼容节点不能连接。
5. 删除节点后相关连线同步删除。
6. 保存后刷新页面，画布节点位置和配置保持一致。

**29.3 节点配置**

1. 每个算子必填项为空时明确提示。
2. 字段类型不符合时不能保存运行。
3. 上游 schema 变化后，下游引用字段能正确失效。
4. 节点预览返回正确字段和数据。

**29.4 任务运行**

1. 离线任务可手动运行。
2. 周期任务可按调度配置运行。
3. 实时任务可启动和终止。
4. 运行失败时可查看错误信息。
5. 运行记录支持重跑。
6. 运行中任务在列表和详情页状态一致。

**29.5 输出**

1. 输出为数据集后，可在数据集列表看到结果。
2. 外部输出能正确写入目标表。
3. Kafka 输出只允许实时任务使用。
4. 实时标签输出在无 CDP 权限时不可见。
5. 分流输出能按规则拆分数据流。

**29.6 资源迁移**

1. 有权限用户可导出可视化建模任务。
2. 每次导出超过 100 个任务时不能提交。
3. 只能上传 .prep 文件导入。
4. 新建导入能完成数据集、数据连接、队列映射。
5. 覆盖导入能替换目标任务配置。
6. 导入失败时可下载失败明细。
