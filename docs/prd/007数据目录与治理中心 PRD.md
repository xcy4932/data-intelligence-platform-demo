**数据目录与治理中心 PRD**

**1. 产品定位**

**1.1 模块定位**

数据目录与治理中心是数据平台中负责“让数据资产可被发现、可被理解、可信任、可追责、可治理”的核心模块。

它不直接承担数据开发、权限审批、数据安全策略执行、资源调度、审计留痕等能力，而是作为这些能力的治理入口和元数据枢纽，统一管理以下内容：

1. 数据资产目录；
2. 技术元数据；
3. 业务元数据；
4. 数据标准；
5. 数据质量规则；
6. 数据血缘；
7. 资产负责人；
8. 治理问题；
9. 资产生命周期；
10. 数据治理看板。

**1.2 与其他中心的边界**

**1.2.1 与资源与资产中心的边界**

资源与资产中心负责底层资源、数据源、计算资源、存储资源、连接资源的创建、配置、授权和状态管理。

数据目录与治理中心不创建底层数据源，不直接管理数据库连接参数，只消费资源与资产中心同步过来的数据资产元信息，并在此基础上补充目录、标准、血缘、质量、治理状态等信息。

**1.2.2 与权限与策略中心的边界**

权限与策略中心负责权限模型、访问策略、角色授权、数据访问控制。

数据目录与治理中心展示某个资产的权限状态、申请入口和可见范围，但不直接执行权限授权。用户点击“申请权限”后，系统跳转或唤起权限与策略中心的申请流程。

**1.2.3 与数据安全与合规中心的边界**

数据安全与合规中心负责敏感数据识别、脱敏策略、合规规则、风险处置。

数据目录与治理中心可以展示字段分级分类结果、敏感标记、合规风险提示，但不直接配置脱敏算法和安全策略。需要处理安全问题时，通过治理问题或安全策略入口跳转到数据安全与合规中心。

**1.2.4 与审计与可观测中心的边界**

审计与可观测中心负责操作日志、访问日志、任务运行日志、系统可观测指标。

数据目录与治理中心展示资产最近访问、最近变更、同步状态、质量运行状态等摘要信息，但详细审计日志通过审计与可观测中心查看。

**2. 用户角色与权限**

**2.1 角色定义**

**2.1.1 平台管理员**

平台管理员拥有数据目录与治理中心的全部管理权限，包括：

1. 查看全部资产；
2. 配置目录结构；
3. 配置元数据采集任务；
4. 配置数据标准；
5. 配置质量规则；
6. 分配数据负责人；
7. 处理治理问题；
8. 执行资产上下架、归档、废弃；
9. 查看全部治理看板。

**2.1.2 数据治理管理员**

数据治理管理员负责数据治理规则和治理流程，不一定拥有底层数据读取权限。

可执行操作包括：

1. 查看资产元数据；
2. 编辑业务元数据；
3. 维护数据标准；
4. 维护质量规则；
5. 创建治理问题；
6. 分派治理责任人；
7. 查看治理进度；
8. 提交标准变更；
9. 发起资产上下架申请。

不可执行操作包括：

1. 直接读取数据明细；
2. 修改底层数据源连接；
3. 绕过审批修改权限；
4. 删除物理数据。

**2.1.3 数据负责人**

数据负责人是某个数据资产的业务或技术负责人。

可执行操作包括：

1. 维护自己负责资产的描述；
2. 维护字段说明；
3. 维护业务口径；
4. 处理分派给自己的治理问题；
5. 审核资产说明变更；
6. 确认资产上下架；
7. 查看自己负责资产的质量问题；
8. 查看自己负责资产的血缘影响。

**2.1.4 数据开发人员**

数据开发人员主要关注数据表、字段、任务、血缘、质量规则。

可执行操作包括：

1. 查看自己有权限范围内的数据目录；
2. 查看技术元数据；
3. 查看血缘；
4. 查看质量运行结果；
5. 维护技术说明；
6. 响应质量问题；
7. 发起元数据刷新；
8. 提交字段说明修改。

**2.1.5 数据分析师 / 业务用户**

数据分析师和业务用户主要使用目录搜索、资产详情、业务口径、质量评分和权限申请。

可执行操作包括：

1. 搜索数据资产；
2. 查看资产业务说明；
3. 查看字段口径；
4. 查看质量评分；
5. 收藏资产；
6. 申请权限；
7. 反馈资产问题；
8. 查看推荐资产。

不可执行操作包括：

1. 修改资产技术结构；
2. 修改标准规则；
3. 修改质量规则；
4. 分派治理问题；
5. 删除资产。

**4. 通用页面规则**

**4.1 顶部区域**

所有页面顶部统一包含：

1. 面包屑；
2. 页面标题；
3. 页面说明；
4. 项目空间切换器；
5. 刷新按钮；
6. 帮助按钮。

**4.1.1 项目空间切换器**

显示当前项目空间名称。

点击后展示下拉面板，面板内容包括：

1. 最近访问空间；
2. 我有权限的空间；
3. 搜索框；
4. 空间名称；
5. 空间类型；
6. 我的角色。

切换空间后：

1. 页面数据重新加载；
2. 当前筛选条件清空；
3. 当前分页回到第一页；
4. 浏览器地址栏中的 projectId 更新；
5. 若用户无目标空间访问权限，则提示“你暂无该空间访问权限”。

**4.1.2 刷新按钮**

点击后重新请求当前页面数据。

刷新规则：

1. 保留当前筛选条件；
2. 保留当前分页；
3. 保留当前排序；
4. 不清空用户已输入但未提交的搜索关键字；
5. 若请求失败，显示错误提示；
6. 刷新期间按钮进入 loading 状态，禁止重复点击。

**4.1.3 帮助按钮**

点击后打开右侧帮助抽屉。

帮助抽屉内容包括：

1. 当前页面用途；
2. 常见操作说明；
3. 字段解释；
4. 权限说明；
5. 常见问题。

点击抽屉右上角关闭按钮后关闭抽屉。

**4.2 通用列表规则**

所有列表页面默认包含：

1. 搜索框；
2. 高级筛选；
3. 排序；
4. 批量操作；
5. 表格；
6. 分页；
7. 列设置；
8. 刷新；

**4.2.1 搜索框**

搜索框支持输入关键字。

搜索范围根据页面不同而变化。

在数据目录页中，搜索范围包括：

1. 资产名称；
2. 中文名称；
3. 描述；
4. 字段名称；
5. 字段描述；
6. 标签；
7. 负责人；
8. 业务术语；
9. 数据标准编码。

用户输入关键字后：

1. 按 Enter 触发搜索；
2. 点击搜索图标触发搜索；
3. 点击清空按钮清空关键字并重新查询；
4. 搜索结果默认按相关性排序；
5. 关键字命中的字段在列表中高亮显示；
6. 若无结果，显示“未找到匹配资产”。

**4.2.2 高级筛选**

点击“筛选”按钮打开筛选面板。

筛选面板从右侧滑出。

筛选项包括：

1. 资产类型；
2. 数据源；
3. 所属目录；
4. 负责人；
5. 治理状态；
6. 质量评分；
7. 安全等级；
8. 生命周期状态；
9. 最近更新时间；
10. 最近访问时间；
11. 是否已收藏；
12. 是否有质量异常；
13. 是否有关联标准；
14. 是否有负责人。

点击“应用筛选”后：

1. 关闭筛选面板；
2. 更新列表；
3. 在列表上方展示已选筛选标签；
4. 分页回到第一页。

点击“重置”后：

1. 清空所有筛选项；
2. 不关闭筛选面板；
3. 用户可重新选择筛选条件。

点击“取消”后：

1. 关闭筛选面板；
2. 不保存本次未应用的筛选条件。

**4.2.3 表格列设置**

点击“列设置”按钮后打开列设置弹窗。

弹窗内容包括：

1. 可展示字段列表；
2. 当前已展示字段；
3. 拖拽排序；
4. 恢复默认；
5. 确定；
6. 取消。

字段展示规则：

1. 固定字段不可取消；
2. 可选字段最多展示 15 个；
3. 用户配置保存在个人维度；
4. 同一用户在同一页面再次进入时沿用上次配置；
5. 点击“恢复默认”恢复系统默认列。

**4.2.4 分页规则**

列表默认每页 20 条。

支持切换：

1. 20 条 / 页；
2. 50 条 / 页；
3. 100 条 / 页。

切换每页条数后：

1. 当前页回到第一页；
2. 保留筛选和搜索；
3. 重新请求数据。

**5.4 治理状态**

type GovernanceStatus =

| "ungoverned"

| "in\_progress"

| "qualified"

| "warning"

| "risk";

状态计算规则：

1. 无负责人、无描述、无字段说明、无标准映射时，为 ungoverned；
2. 存在治理任务进行中时，为 in\_progress；
3. 必填治理项完整且质量评分大于等于 90 时，为 qualified；
4. 存在非阻断性质量异常时，为 warning；
5. 存在高风险质量异常、安全风险或无人负责时，为 risk。

**6. 治理总览页面**

**6.1 页面用途**

治理总览用于让平台管理员和治理管理员快速掌握当前项目空间内的数据资产规模、治理覆盖率、质量状况、问题分布和待处理事项。

**6.2 页面布局**

页面从上到下分为：

1. 时间范围选择区；
2. 核心指标卡片区；
3. 资产分布区；
4. 治理健康度区；
5. 质量异常趋势区；
6. 待处理事项区；
7. 风险资产列表区。

**6.3 时间范围选择区**

组件包括：

1. 时间范围下拉框；
2. 自定义日期选择器；
3. 刷新按钮；
4. 导出按钮。

**6.3.1 时间范围下拉框**

默认选择“近 30 天”。

可选项包括：

1. 今日；
2. 昨日；
3. 近 7 天；
4. 近 30 天；
5. 近 90 天；
6. 本月；
7. 上月；
8. 自定义。

选择非自定义选项后，页面自动刷新。

选择“自定义”后，展示日期范围选择器。

**6.3.2 自定义日期选择器**

用户选择开始日期和结束日期。

规则：

1. 开始日期不可晚于结束日期；
2. 最大跨度 365 天；
3. 未选择完整日期范围时，不触发查询；
4. 日期选择完成后自动刷新页面。

**6.3.3 刷新按钮**

点击后刷新当前总览数据。

刷新期间：

1. 按钮显示 loading；
2. 各图表显示局部 loading；
3. 保留当前时间范围。

**6.3.4 导出按钮**

点击后导出当前总览报告。

导出内容包括：

1. 核心指标；
2. 资产分布；
3. 治理健康度；
4. 质量异常趋势；
5. 风险资产列表。

点击后弹出导出设置弹窗。

弹窗字段：

| **字段** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| 文件名称 | 输入框 | 是 | 默认“数据治理总览\_日期” |
| 文件格式 | 单选 | 是 | Excel / PDF |
| 是否包含明细 | 开关 | 否 | 默认关闭 |
| 时间范围 | 只读 | 是 | 当前页面时间范围 |

按钮：

1. 取消：关闭弹窗；
2. 导出：提交导出任务。

导出提交后：

7. 是否存在重复资产；
8. 是否关联必要标准。

检查结果展示：

1. 通过；
2. 未通过；
3. 警告。

未通过项必须处理后才能上架。

**15.3 已上架资产**

展示可被用户搜索和使用的资产。

操作按钮：

1. 查看；
2. 编辑；
3. 发起归档；
4. 发起废弃；
5. 查看使用情况。

**15.4 待归档资产**

系统根据规则自动推荐待归档资产。

推荐规则：

1. 近 90 天无人访问；
2. 无下游依赖；
3. 质量长期异常；
4. 已存在替代资产；
5. 负责人标记不再维护。

操作按钮：

1. 查看原因；
2. 忽略推荐；
3. 发起归档；
4. 设置替代资产。

**15.4.1 忽略推荐**

点击后弹窗要求填写忽略原因。

忽略后：

1. 30 天内不再推荐；
2. 记录忽略人和原因；
3. 可在配置中调整忽略周期。

**15.5 已归档资产**

已归档资产仍可查看，但默认不推荐使用。

操作按钮：

1. 查看；
2. 恢复上架；
3. 废弃；
4. 设置替代资产。

**15.5.1 恢复上架**

点击后执行上架检查。

检查通过后：

1. 状态变为已上架；
2. 恢复搜索推荐；
3. 记录生命周期变更。

**15.6 已废弃资产**

废弃资产仅保留历史引用。

操作按钮：

1. 查看；
2. 查看历史引用；
3. 恢复申请。

恢复申请规则：

1. 必须填写恢复原因；
2. 必须经过审批；
3. 审批通过后进入未上架状态；
4. 需要重新完成上架检查。

**18.1 页面用途**

治理配置用于维护数据目录与治理中心的基础规则。

**18.2 配置项**

包括：

1. 资产上架检查规则；
2. 治理状态计算规则；
3. 质量评分规则；
4. 生命周期推荐规则；
5. 元数据采集默认规则；
6. 问题 SLA 规则；
7. 通知规则；
8. 目录展示规则。

**18.3 资产上架检查规则**

配置字段：

1. 是否必须有负责人；
2. 是否必须有业务描述；
3. 字段说明完整率阈值；
4. 是否必须归属目录；
5. 是否允许存在高危质量问题；
6. 是否允许存在安全风险；
7. 是否必须完成标准映射。

按钮：

1. 保存；
2. 恢复默认；
3. 取消。

保存后：

1. 新规则立即对后续上架检查生效；
2. 已上架资产不自动下架；
3. 配置变更写入审计日志。

**18.4 质量评分规则**

质量评分默认由以下因素计算：

1. 完整性；
2. 唯一性；
3. 准确性；
4. 一致性；
5. 及时性；
6. 稳定性。

每项可配置权重。

规则：

1. 权重总和必须等于 100；
2. 权重为 0 的维度不参与计算；
3. 保存前必须校验总和；
4. 修改权重后可选择是否重新计算历史评分。

**18.5 问题 SLA 规则**

按严重级别配置默认处理时限：

| **严重级别** | **默认 SLA** |
| --- | --- |
| 严重 | 24 小时 |
| 高 | 3 天 |
| 中 | 7 天 |
| 低 | 15 天 |

可配置：

1. 默认责任人；
2. 超时提醒时间；
3. 超时升级对象；
4. 是否自动升级。

**24. 验收标准**

**24.1 数据目录验收**

1. 用户可以按名称、字段、描述、标签、负责人搜索资产；
2. 搜索结果能正确高亮命中内容；
3. 用户可以按资产类型、生命周期、负责人、质量评分筛选资产；
4. 用户可以进入资产详情；
5. 用户可以收藏和取消收藏资产；
6. 用户无权限时不能查看受限资产详情；
7. 管理员可以新建、编辑、删除空目录；
8. 目录树点击后资产列表正确刷新；
9. 批量操作对选中资产生效；
10. 导出结果与当前筛选条件一致。

**24.2 资产详情验收**

1. 资产基础信息展示完整；
2. 字段列表展示完整；
3. 编辑元数据后变更生效；
4. 字段说明修改后完整率重新计算；
5. 风险提示能根据资产状态正确展示；
6. 上架检查能正确识别未通过项；
7. 归档和废弃必须经过确认；
8. 所有变更写入变更记录；
9. 无权限用户不能执行编辑操作。

**24.3 元数据采集验收**

1. 管理员可以创建采集源；
2. 连接测试成功后才能进入采集范围配置；
3. 采集任务可手动运行；
4. 采集日志能展示成功和失败详情；
5. 元数据变更记录能识别新增、删除和字段变更；
6. 采集源停用后定时任务不再执行；
7. 采集失败时能查看失败原因。

**24.4 数据标准验收**

1. 可以新建标准分类；
2. 可以新建命名、类型、值域、格式、口径标准；
3. 草稿、审核中、已发布、已停用状态流转正确；
4. 已发布标准可以映射到资产字段；
5. 停用标准后不可新增映射；
6. 自动推荐映射结果可以接受或忽略；
7. 标准版本可追溯。

**24.5 数据质量验收**

1. 可以创建不同类型质量规则；
2. 规则测试通过后才能启用；
3. 启用规则可以手动运行；
4. 运行结果能展示扫描行数、异常行数、质量分；
5. 严重异常可自动创建治理问题；
6. 异常数据下载受权限控制；
7. 质量评分能根据规则结果更新。

**24.6 血缘分析验收**

1. 可以查询资产上游血缘；
2. 可以查询资产下游血缘；
3. 可以切换血缘层级；
4. 点击节点能展示详情；
5. 展开节点能加载更多血缘；
6. 影响分析能输出受影响资产列表；
7. 血缘图谱可导出。

**24.7 治理问题验收**

1. 可以手动创建治理问题；
2. 问题可以分派给责任人；
3. 责任人可以提交处理结果；
4. 创建人可以确认关闭或驳回；
5. 问题状态流转符合规则；
6. 超时问题能被标记；
7. 治理问题可关联资产和字段。

**24.8 生命周期验收**

1. 未上架资产必须通过上架检查才能上架；
2. 已上架资产可以发起归档；
3. 已归档资产可以废弃；
4. 废弃资产不可被新引用；
5. 归档资产可设置替代资产；
6. 生命周期变更有记录；
7. 生命周期操作受权限控制。

**25. 关键非功能要求**

**25.1 性能要求**

1. 数据目录列表首屏加载时间不超过 2 秒；
2. 普通搜索响应时间不超过 3 秒；
3. 高级筛选响应时间不超过 5 秒；
4. 资产详情加载时间不超过 3 秒；
5. 血缘 3 层以内查询时间不超过 5 秒；
6. 质量结果列表加载时间不超过 3 秒；
7. 大批量导出必须异步处理。

**25.2 权限要求**

1. 所有页面进入前校验菜单权限；
2. 所有按钮展示前校验操作权限；
3. 所有接口执行前校验数据权限；
4. 无权限资产不得泄露字段明细；
5. 敏感字段样例值必须脱敏；
6. 批量操作必须逐条校验权限。

**25.3 审计要求**

以下操作必须写入审计日志：

1. 新建目录；
2. 编辑目录；
3. 删除目录；
4. 编辑资产元数据；
5. 修改负责人；
6. 修改字段说明；
7. 创建标准；
8. 发布标准；
9. 停用标准；
10. 创建质量规则；
11. 修改质量规则；
12. 运行质量规则；
13. 创建治理问题；
14. 关闭治理问题；
15. 资产上架；
16. 资产归档；
17. 资产废弃；
18. 批量导入；
19. 批量导出。

**25.4 数据一致性要求**

1. 元数据采集结果必须与资产目录同步；
2. 字段变更后字段说明不能错误绑定到其他字段；
3. 标准停用后资产映射状态必须同步更新；
4. 质量规则删除后历史运行结果保留；
5. 资产废弃后下游引用关系保留；
6. 负责人删除或离职后资产必须进入“负责人缺失”风险状态。
