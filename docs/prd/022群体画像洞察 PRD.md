**群体画像洞察 PRD**

**1. 模块定位**

群体画像洞察用于帮助用户围绕一个或多个目标分群，生成私域群体画像报告，通过标签分析、指标分析、TGI 对比、UV 占比、交叉分析、下钻分析、图表联动、存为分群、报告下载、报告分享等能力，识别目标人群的显著特征和差异，为精细化营销、用户运营、策略制定提供依据。

该模块不是单纯展示报表，而是围绕“目标群体是谁、他们有什么显著特征、与大盘或对照人群有什么差异、这些特征是否可以沉淀为新分群继续运营”构建完整分析链路。

**2. 功能范围**

群体画像洞察包含以下能力：

1. 创建群体画像报告。
2. 管理群体画像报告。
3. 选择目标分群与对比分群。
4. 基于标签进行群体特征洞察。
5. 基于指标进行群体表现分析。
6. 支持报告手动更新与按天定时更新。
7. 支持报告描述、权限管理、复制、下载、嵌出链接。
8. 支持标签分析中的人群占比、有效人群占比、TGI、UV、标签值排序、图表排序分组。
9. 支持图表标题修改、标签值展示调整、图表联动、图表类型切换、图表放大。
10. 支持将标签分析结果或报告分析对象存为用户分群。
11. 支持模板管理，包括标签分析模板、指标分析模板、个人模板、项目模板、共享模板。
12. 支持自定义 TGI 配置。
13. 支持报告解读，包括自动总结、显著特征识别、散点图、单分群/多分群标签概览、标签详情、交叉分析。

**4. 核心概念**

**4.1 群体画像报告**

群体画像报告是围绕一个或多个目标分群生成的分析报告。报告包含：

1. 报告名称。
2. 报告描述。
3. 分析主体。
4. 分析对象分群。
5. 对比分群。
6. 标签分析配置。
7. 指标分析配置。
8. 图表配置。
9. 更新方式。
10. 授权配置。
11. 下载与嵌出配置。

**4.2 分析对象**

分析对象是报告主要研究的人群。可以来自：

1. 已有用户分群。
2. 创建报告时临时圈选生成的目标分群。
3. 复制报告后继承的原报告分析对象。
4. 从标签分析结果中存为分群后再次作为分析对象。

**4.3 对比分群**

对比分群用于和目标分群进行差异比较。一个报告可以添加多个对比分群。

规则：

1. 对比分群必须与目标分群属于同一主体。
2. 对比分群必须使用可识别的 ID 类型。
3. 用户必须有对比分群查看权限。
4. 对比分群数量建议限制，默认最多 5 个，避免图表难以阅读。
5. 多分群分析时，同一图表中需展示不同分群的标签占比、TGI 或指标值。

**4.4 标签分析**

标签分析用于观察目标分群在某些标签上的人数分布、占比和显著性。

支持分析：

1. 标签占比。
2. 标签有效占比。
3. 大盘 TGI。
4. 标签 TGI。
5. UV。
6. 多分群差异对比。
7. 标签值排序。
8. 标签交叉分析。
9. 图表联动分析。
10. 存为分群。

**4.5 指标分析**

指标分析用于观察目标分群在某一维度下某一指标的表现。

支持维度：

1. 时间。
2. 标签。
3. 分群。
4. 属性。
5. 明细属性。
6. 行为属性。

支持指标来源：

1. 已有标签。
2. 已定义指标。
3. 新建指标。
4. 单一指标。
5. 组合指标。

指标分析属于增值模块。未开通时入口置灰或隐藏。

**4.6 TGI**

TGI 用于衡量目标分群在某标签值上的显著程度。

**4.6.1 大盘 TGI**

计算逻辑：

大盘TGI = （分群中某标签值用户量 / 分群用户总量） / （项目下某标签值用户量 / 项目下用户总量） \* 100

解释：

| **值** | **含义** |
| --- | --- |
| > 100 | 目标分群相对大盘更偏好该标签值 |
| = 100 | 与大盘平均水平一致 |
| < 100 | 目标分群相对大盘偏好较弱 |

**4.6.2 标签 TGI**

计算逻辑：

标签TGI = （分群中某标签值用户量 / 分群中该标签有值用户量） / （项目下某标签值用户量 / 项目下该标签有值用户量） \* 100

适用场景：

当只希望在“有该标签值的人群”范围内比较标签值偏好时，使用标签 TGI。

**4.7 UV 与占比**

| **指标** | **计算逻辑** | **用途** |
| --- | --- | --- |
| 标签占比 | 分群中标签值用户数量 / 分群用户数量 \* 100% | 看标签值在整体分群中的覆盖程度 |
| 标签有效占比 | 分群中标签值用户数量 / 分群中该标签有值用户数量 \* 100% | 看标签值在有该标签的人群中的分布 |
| 有效分群占比 | 分群中该标签有值用户数量 / 分群用户数量 \* 100% | 看该标签在分群中的有效覆盖率 |

**5. 数据时效性**

**5.1 标签分析时效性**

1. 群体画像标签分析使用 T-1 数据。
2. 如果标签是实时标签，报告中仍取 T-1 的标签数据。
3. 例如报告 1 月 3 日创建，实时标签使用 1 月 2 日数据。
4. 报告顶部需展示数据更新时间，格式建议：
   * 数据更新时间：2026-05-26
5. 如果用户手动查询报告，仍以当前可用最新离线分区为准。

**5.2 指标分析时效性**

1. 指标分析中的行为、明细、属性按所选数据计算时间范围计算。
2. 如果指标为标签，或维度为标签/分群，则取最近一天数据。
3. 时间范围可选择单个日期、固定日期区间、动态日期区间。
4. 若选择未来日期，系统禁止查询并提示：
   * 数据计算时间不能晚于当前日期。

**8. 新建报告流程**

**8.1 新建报告入口**

点击列表页 新建报告。

系统流程：

1. 校验用户是否有增改报告权限。
2. 打开主体选择弹窗。
3. 用户选择主体。
4. 进入新建报告页面。
5. 页面默认处于编辑态。

**8.2 主体选择弹窗**

字段：

| **字段** | **说明** |
| --- | --- |
| 主体 | 选择报告分析主体，例如用户、门店、车辆等 |

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗 |
| 确定 | 进入新建报告页 |

校验：

1. 主体必填。
2. 用户必须拥有该主体下至少一个可使用的分群包权限。
3. 如果没有可用分群，进入页面后展示空状态：
   * 当前主体下暂无可用分群，请先创建或申请分群权限。

**9. 新建 / 编辑报告页面**

**9.1 页面结构**

新建报告页面包含：

1. 报告名称区。
2. 分析对象区。
3. 对比分群区。
4. 预估分群区。
5. 分析方式选择区。
6. 标签分析配置区。
7. 指标分析配置区。
8. 报告预览区。
9. 顶部操作区。
10. 保存操作区。

**9.2 报告名称**

字段名称：画像报告名称

位置：

页面左上角。

规则：

1. 必填。
2. 用户可直接点击名称区域输入。
3. 最大长度建议 100 字。
4. 不允许仅输入空格。
5. 同一项目下允许重名，但列表需通过报告 ID 区分。
6. 保存时若为空，提示：
   * 请输入报告名称。

**9.3 分析对象**

分析对象用于配置报告主要分析的目标人群。

**9.3.1 分群名称**

字段名称：分群名称

逻辑：

1. 分析对象中的分群支持自定义展示名称。
2. 用户点击分群名称旁的编辑图标。
3. 输入新名称。
4. 回车或失焦保存到页面状态。
5. 该名称用于报告图表展示，不修改原用户分群名称。

**9.3.2 生成目标分群包**

用户可以通过自定义圈选创建新的目标分群包。

按钮名称：自定义圈选

点击后：

1. 打开分群规则配置区域。
2. 用户按用户分群规则配置条件。
3. 支持标签、行为、属性、明细数据、人群包。
4. 支持满足和排除。
5. 点击预估分群后计算分群数量。
6. 保存报告时，若该圈选条件未生成正式分群，系统需生成临时分析分群或正式用户分群，取决于产品策略。

建议策略：

1. 创建报告时自定义圈选生成的是报告内分析对象。
2. 如果用户点击“存为分群”，才生成用户分群模块中的正式分群。
3. 报告计算时记录圈选规则和版本。

**9.3.3 选择已有分群包**

按钮名称：+ 人群包

点击后：

1. 打开分群选择弹窗。
2. 展示当前用户有权限使用的分群包。
3. 支持按分群名称、创建人搜索。
4. 支持按主体、分组、状态筛选。
5. 用户选择一个分群后点击确定。
6. 系统将该分群作为报告分析对象。

校验：

1. 分群主体必须与报告主体一致。
2. 分群状态必须为可用。
3. 当前用户必须拥有分群查看权限。
4. 分群数量为 0 时允许选择，但报告生成后图表展示空状态。

**9.4 增加对比分群**

按钮名称：增加对比分群

点击后：

1. 新增一个对比分群配置块。
2. 用户可选择已有分群或自定义圈选。
3. 对比分群与目标分群共同进入报告分析。
4. 图表中展示多分群对比。

规则：

1. 至少有 1 个目标分群。
2. 对比分群最多建议 5 个。
3. 对比分群不能与目标分群完全相同，若相同提示：
   * 对比分群与目标分群一致，无法形成差异对比。
4. 可删除对比分群。
5. 删除后图表自动更新为剩余分群。

**9.5 预估分群**

按钮名称：预估分群

点击后：

1. 系统校验目标分群和对比分群配置。
2. 对自定义圈选条件执行数量预估。
3. 对已有分群读取最新可用数量。
4. 展示每个分群包的预估人数。
5. 预估完成后允许进入分析方式选择。

展示字段：

| **字段** | **说明** |
| --- | --- |
| 分群名称 | 目标分群或对比分群名称 |
| 分群来源 | 已有分群、自定义圈选 |
| 预估人数 | 当前可识别用户数 |
| 状态 | 预估成功、预估失败、计算中 |
| 失败原因 | 预估失败时展示 |

异常：

| **场景** | **提示** |
| --- | --- |
| 未选择分群 | 请先配置分析对象 |
| 无分群权限 | 暂无该分群使用权限 |
| 规则不完整 | 请完善分群圈选条件 |
| 预估失败 | 分群预估失败，请稍后重试 |

**10. 分析方式选择**

预估分群完成后，用户选择分析方式。

支持：

1. 标签分析。
2. 指标分析。

**10.1 标签分析**

标签分析用于观察目标分群在标签维度上的人数、占比和 TGI。

入口按钮：

标签分析

点击后：

1. 展示标签分析配置区。
2. 用户可以选择模板快速生成分析内容。
3. 用户也可以手动选择标签并生成图表。

**10.2 指标分析**

指标分析用于观察目标分群在某一维度下某一指标的表现。

入口按钮：

指标分析

规则：

1. 指标分析为增值模块。
2. 未购买时入口置灰。
3. 悬停提示：
   * 指标分析为增值模块，如需使用请联系商务人员。
4. 已购买且用户有权限时可进入配置。

**11. 标签分析配置**

**11.1 标签分析入口**

在报告编辑页选择 标签分析。

页面展示：

1. 模板选择区。
2. 标签选择区。
3. 图表生成区。
4. 保存为模板按钮。
5. 查询报告按钮。
6. 保存报告按钮。

**11.2 使用模板**

按钮名称：使用模板

点击后打开模板选择弹窗。

模板来源：

1. 个人模板。
2. 项目模板。
3. 他人分享的模板。

模板弹窗字段：

| **字段** | **说明** |
| --- | --- |
| 模板名称 | 模板标题 |
| 模板类型 | 标签分析模板、指标分析模板 |
| 创建人 | 模板创建者 |
| 权限来源 | 自建、项目模板、他人分享 |
| 更新时间 | 最近更新时间 |

操作：

| **按钮** | **逻辑** |
| --- | --- |
| 预览 | 查看模板包含的标签、图表、分组 |
| 使用 | 将模板应用到当前报告 |
| 取消 | 关闭弹窗 |

使用模板后：

1. 当前标签分析配置被模板覆盖。
2. 如果页面已有未保存配置，弹窗提示：
   * 使用模板将覆盖当前分析配置，是否继续？
3. 模板中的标签如果当前用户无权限，则自动剔除，并提示剔除数量。
4. 若模板中所有标签均无权限，使用失败。

**11.3 手动选择标签**

用户可从标签体系中选择要分析的标签。

支持：

1. 按标签目录选择。
2. 按标签名称搜索。
3. 多选标签。
4. 按标签分组展示。

选择规则：

1. 至少选择一个标签。
2. 仅展示当前用户有权限的标签。
3. 已删除或不可用标签不展示。
4. 实时标签参与分析时仍按 T-1 数据计算。
5. 多值标签需要按标签值展开统计。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 添加标签 | 打开标签选择面板 |
| 删除标签 | 从分析配置中移除该标签 |
| 清空 | 清空已选标签 |
| 查询报告 | 按当前配置计算报告 |
| 存为模板 | 将当前标签配置保存为模板 |

**11.4 查询报告**

按钮名称：查询报告

点击后：

1. 校验分群预估已完成。
2. 校验至少选择一个标签。
3. 校验用户标签权限。
4. 创建报告计算任务。
5. 计算标签占比、标签有效占比、大盘 TGI、标签 TGI。
6. 生成图表数据。
7. 页面展示计算结果。
8. 如果报告更新方式为手动更新，该按钮也是后续刷新报告数据的入口。

任务状态：

| **状态** | **展示** |
| --- | --- |
| 计算中 | 页面展示 loading |
| 成功 | 展示报告图表 |
| 失败 | 展示失败原因 |
| 部分失败 | 成功图表展示，失败图表展示错误提示 |

**12. 指标分析配置**

**12.1 添加指标分析图表**

按钮名称：添加指标图表

点击后打开指标图表配置弹窗。

前置校验：

1. 指标分析能力已开通。
2. 用户有指标分析权限。
3. 已完成分群配置。
4. 已完成分群预估。

**12.2 选择图表类型**

字段名称：图表类型

支持：

1. 折线图。
2. 柱状图。
3. 卡片。
4. 表格。

选择逻辑：

| **图表类型** | **适用场景** |
| --- | --- |
| 折线图 | 展示指标随时间变化趋势 |
| 柱状图 | 比较不同维度值下的指标表现 |
| 卡片 | 展示单一指标汇总值 |
| 表格 | 展示明细化维度与指标结果 |

**12.3 配置 X 轴维度**

字段名称：维度（X轴）

可选：

1. 时间。
2. 标签。
3. 分群。
4. 属性。
5. 明细属性。
6. 行为属性。

规则：

1. X 轴选择时间时，图表类型建议为折线图或柱状图。
2. X 轴选择标签时，支持文本类型和数值类型标签。
3. X 轴选择分群时，用于对比目标分群与对比分群。
4. X 轴选择属性、明细属性、行为属性时，必须校验用户资源权限。
5. 如果选择的维度与图表类型不兼容，保存时提示。

**12.4 配置 Y 轴指标**

字段名称：指标（Y轴）

可选：

1. 标签。
2. 已定义指标。
3. 新建指标。

规则：

1. Y 轴所有类型标签均支持，包含多值类型标签。
2. 用户选择标签作为指标时，系统按标签值或标签有值人数计算。
3. 用户选择已定义指标时，直接引用指标配置。
4. 用户选择新建指标时，打开新建指标配置区域。

**12.5 新建指标**

**12.5.1 基础字段**

| **字段** | **说明** |
| --- | --- |
| 指标名称 | 用户自定义 |
| 指标描述 | 非必填 |
| 指标分组 | 下拉选择 |
| 指标类型 | 单一指标、组合指标 |

**12.5.2 单一指标**

单一指标字段：

| **字段** | **说明** |
| --- | --- |
| 计算条件 | 行为、明细、标签、属性 |
| 展示格式 | 整数、小数、百分比整数、百分比小数 |
| ID 类型 | 自定义选择 |

逻辑：

1. 计算条件选择行为时，需配置事件、事件属性、时间条件、聚合方式。
2. 计算条件选择明细时，需配置明细表、字段、聚合方式。
3. 计算条件选择标签时，需选择标签和标签值口径。
4. 计算条件选择属性时，需选择属性字段。
5. 展示格式决定图表中指标值的格式化方式。

**12.5.3 组合指标**

组合指标用于基于已有指标进行四则运算。

字段：

| **字段** | **说明** |
| --- | --- |
| 参与指标 | 选择一个或多个已有指标 |
| 计算方式 | 加、减、乘、除、括号组合 |
| 展示格式 | 整数、小数、百分比整数、百分比小数 |

校验：

1. 公式不能为空。
2. 公式中的指标必须存在。
3. 不能出现除以 0 的计算。
4. 公式括号必须成对。
5. 保存前展示公式预览。

**12.6 数据计算时间**

字段名称：数据计算时间

支持：

1. 单个日期。
2. 固定日期区间。
3. 动态日期区间。

动态日期示例：

1. 最近 7 天。
2. 最近 30 天。
3. 本周。
4. 本月。
5. 上月。

规则：

1. 若指标为标签，或维度为标签/分群，则取最近一天数据。
2. 时间范围不能为空。
3. 开始日期不能晚于结束日期。
4. 结束日期不能晚于当前日期。

**12.7 保存指标图表**

按钮名称：确定

点击后：

1. 校验图表类型。
2. 校验 X 轴维度。
3. 校验 Y 轴指标。
4. 校验时间范围。
5. 校验资源权限。
6. 生成指标分析图表配置。
7. 返回报告编辑页。
8. 图表进入待查询状态。
9. 用户点击查询报告后生成图表数据。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 确定 | 保存图表配置 |
| 预览 | 可选，按当前配置预估图表结构 |

**13. 报告详情页**

**13.1 页面入口**

1. 报告列表点击报告名称。
2. 报告列表点击查看。
3. 复制报告成功后进入副本详情。
4. 外部系统通过嵌出链接访问报告。

**13.2 页面结构**

报告详情页包含：

1. 顶部操作区。
2. 报告描述区。

4. 标签分析页签。
5. 指标分析页签。
6. 报告解读区。
7. 图表区。

**14. 报告顶部操作区**

顶部操作区是报告核心控制区域。

**14.1 编辑按钮**

按钮名称：编辑

点击后：

1. 报告进入编辑模式。
2. 图表标题、图表配置、描述、分组、排序等可编辑。
3. 顶部显示保存按钮。
4. 若用户无编辑权限，按钮隐藏或置灰。

编辑模式下可执行：

1. 添加描述。
2. 添加/删除图表。
3. 修改图表标题。
4. 图表排序分组。
5. 设置更新方式。
6. 查询报告。
7. 保存报告。

**14.2 描述按钮**

按钮名称：描述

仅编辑模式下可用。

点击后：

1. 弹出描述输入框。
2. 用户填写报告说明。
3. 字数上限 200 字。
4. 点击确定后保存到页面状态。
5. 最终点击保存报告后才持久化。

字段规则：

1. 非必填。
2. 超过 200 字禁止输入或提示超限。
3. 描述可用于报告目的、分析主题、主要结论说明。

**14.3 查询报告按钮**

按钮名称：查询报告

点击后：

1. 使用当前报告配置重新计算报告。
2. 手动更新报告必须通过该按钮刷新数据。
3. 查询前校验分析对象、图表配置、资源权限。
4. 查询中按钮置灰并展示 loading。
5. 查询完成后刷新所有图表。
6. 查询失败时展示失败原因。

**14.4 保存按钮**

按钮名称：保存

点击后：

1. 校验报告名称。
2. 校验分析对象。
3. 校验图表配置。
4. 校验更新方式。
5. 校验分组与授权配置。
6. 保存当前报告配置。
7. 首次保存时弹出分组与授权设置。
8. 保存成功后退出编辑模式。

**14.5 更多按钮**

按钮名称：...

点击后展示菜单：

1. 复制嵌出链接。
2. 设置报告更新方式。
3. 权限管理。
4. 复制报告。
5. 删除报告。
6. 存为模板，编辑态下展示。
7. 图表排序分组，编辑态下展示。

**14.6 复制嵌出链接**

菜单项：复制嵌出链接

点击后：

1. 校验用户是否有嵌出权限。
2. 生成报告 URL。
3. 将 URL 写入剪贴板。
4. 提示：
   * 嵌出链接已复制。

规则：

1. 链接访问仍需鉴权。
2. 如果配置为免登录嵌出，必须单独开启，并做有效期与访问白名单控制。
3. 链接中不暴露敏感参数。

**14.7 设置报告更新方式**

菜单项：设置报告更新方式

点击后打开弹窗。

支持：

1. 手动更新。
2. 按天更新。

**14.7.1 手动更新**

逻辑：

1. 报告不会自动更新。
2. 用户需要在编辑页面点击 查询报告 更新。
3. 保存后列表更新方式展示为“手动”。

适合场景：

1. 数据变化快但用户不需要每日固定刷新。
2. 用户经常调整分析方法。
3. 临时分析报告。

**14.7.2 按天更新**

配置字段：

| **字段** | **说明** |
| --- | --- |
| 执行时间 | 每天自动更新的时间 |
| 生效日期 | 从哪天开始执行 |
| 结束日期 | 可选，到期后停止自动更新 |

规则：

1. 用户必须拥有定时更新权限。
2. 执行时间必填。
3. 每天按配置时间触发一次报告更新。

**15. 报告解读**

**15.1 功能定位**

报告解读帮助用户快速理解目标群体的核心特征和行为倾向。

内容包括：

1. 标签分析概览。
2. 自动总结描述。
3. 散点图。
4. 单分群标签概览。
5. 多分群标签概览。
6. 标签分析详情。
7. 交叉分析。
8. 指标分析详情。

**15.2 自动总结描述**

系统自动展示 UV 和 TGI 综合最高的前 5 个特征。

排序规则：

综合得分 = UV \* TGI

逻辑：

1. 遍历当前报告中可展示的标签值。
2. 排除无权限标签。
3. 排除样本量过低的标签值，样本量阈值可后台配置。
4. 按 UV\*TGI 从高到低排序。
5. 取前 5 个特征。
6. 自动生成总结描述。

展示规则：

1. 总结区展示在报告顶部或标签分析概览上方。
2. 每条总结包含标签名称、标签值、占比、TGI。
3. 如果没有足够特征，展示：
   * 当前报告暂无足够显著特征。

**15.3 散点图**

散点图用于展示标签覆盖率和显著性的关系。

数据规则：

1. 按覆盖率排序后取 top 标签值。
2. 覆盖率页面显示为“占比”。
3. 占比计算：
   * 分群包中标签值用户数量 / 分群包用户数量
4. X 轴建议展示占比。
5. Y 轴建议展示 TGI。
6. 点大小可表示用户数量。
7. 鼠标悬停展示标签名称、标签值、用户数、占比、TGI。

**20. 自定义 TGI 配置**

**20.1 功能说明**

群体画像支持自定义 TGI，用于自定义项目大盘的规模。用户可以选择标签或人群包数据作为基准分群，从而提升计算准确率。

**20.2 配置入口**

分析洞察 > 私域群体画像 > TGI配置

**20.3 配置字段**

| **字段** | **说明** |
| --- | --- |
| TGI 名称 | 自定义名称，一般与业务场景相关 |
| 计算方式 | 标签占比或标签有效占比 |
| 基准分群 | 作为公式分母的比较基准 |
| 公式预览 | 展示当前 TGI 计算公式 |
| 适用范围 | 全项目、指定报告、指定标签分析模板 |

**20.4 计算方式**

**标签占比**

作为公式分子时，表示：

分群中标签值用户数量 / 分群用户总量

**标签有效占比**

作为公式分子时，表示：

分群中标签值用户数量 / 分群中该标签有值用户量

**20.5 基准分群**

基准分群作为分母。

规则：

1. 可选择标签或人群包作为基准。
2. 用户必须拥有基准分群查看权限。
3. 基准分群主体必须与报告主体一致。
4. 基准分群数量不能为 0。
5. 基准分群删除后，使用该 TGI 的报告需提示基准失效。

**22. 报告状态机**

**22.1 报告状态**

| **状态** | **说明** |
| --- | --- |
| 草稿 | 已创建但未成功保存或未查询 |
| 待查询 | 已配置但尚未计算 |
| 计算中 | 报告正在计算 |
| 成功 | 最近一次计算成功 |
| 失败 | 最近一次计算失败 |
| 部分成功 | 部分图表成功，部分图表失败 |
| 已删除 | 报告已删除 |
| 已失效 | 分群、标签、权限或基准 TGI 失效导致无法正常查看 |

**22.2 状态流转**

1. 新建报告后进入草稿。
2. 保存配置后进入待查询。
3. 点击查询报告后进入计算中。
4. 全部计算成功后进入成功。
5. 部分图表失败后进入部分成功。
6. 全部失败后进入失败。
7. 删除后进入已删除。
8. 引用资源失效后进入已失效或局部失效。

**23. 异常与空状态**

**23.1 列表为空**

文案：

暂无群体画像报告。你可以点击“新建报告”创建第一份报告。

如果用户无创建权限：

暂无可查看的群体画像报告。

**23.2 无分群权限**

文案：

当前暂无可使用的分群包，请先创建分群或联系分群创建者授权。

**23.3 无标签权限**

文案：

暂无可用于分析的标签，请联系管理员配置标签资源权限。

**23.4 指标分析未开通**

文案：

指标分析为增值模块，如需使用请联系商务人员。

**23.5 报告计算失败**

展示：

1. 失败图表位置展示错误状态。
2. 错误信息包含失败原因。
3. 提供重新查询按钮。

常见失败原因：

1. 分群已删除。
2. 分群无权限。
3. 标签已删除。
4. 标签无权限。
5. 基准 TGI 配置失效。
6. 上游数据未就绪。
7. 指标公式错误。
8. 数据计算时间无数据。

**25. 核心接口建议**

请求参数：

1. keyword。
2. subject\_type。
3. report\_type。
4. creator\_id。
5. update\_mode。
6. favorite\_only。
7. page。
8. page\_size。

返回：

1. 报告列表。
2. 总数。
3. 当前用户对每个报告的操作权限。

**25.2 创建报告**

POST /api/insight/reports

请求参数：

1. name。
2. subject\_type。
3. segments。
4. charts。
5. update\_mode。
6. schedule\_config。
7. permission\_config。

返回：

1. report\_id。
2. status。

POST /api/insight/reports/{report\_id}/query

逻辑：

1. 创建计算任务。
2. 返回 task\_id。
3. 前端轮询任务状态。

**25.4 获取报告详情**

GET /api/insight/reports/{report\_id}

返回：

1. 报告基础信息。
2. 分析对象。
3. 图表配置。
4. 图表数据。
5. 权限信息。
6. 数据更新时间。

PUT /api/insight/reports/{report\_id}

保存内容：

1. 名称。
2. 描述。
3. 分群配置。
4. 图表配置。
5. 排序分组。
6. 更新方式。

**25.6 下载报告**

POST /api/insight/reports/{report\_id}/download

**27. 验收标准**

**27.1 报告列表**

1. 用户只能看到自己创建、被授权或管理员可见范围内的报告。
2. 支持按报告名称和创建人搜索。
3. 支持按分组、主体、类型、创建人、更新方式、收藏状态筛选。
4. 新建报告按钮受权限控制。
5. 编辑按钮只对有编辑权限用户展示。
6. 删除按钮只对创建者展示。
7. 收藏状态可正常切换。
8. 复制报告后生成新的报告副本。
9. 下载报告导出内容与界面展示一致。

**27.2 报告创建**

1. 新建报告必须选择主体。
2. 报告名称必填。
3. 至少配置一个目标分群。
4. 可通过已有分群或自定义圈选配置目标分群。
5. 支持增加对比分群。
6. 预估分群能返回每个分群人数。
7. 标签分析至少选择一个标签。
8. 指标分析未开通时不可使用。
9. 保存报告后在列表可见。
10. 查询报告后生成图表数据。

**27.3 报告顶部操作**

1. 描述最多 200 字。
2. 复制嵌出链接后剪贴板可获取 URL。
3. 手动更新报告需要点击查询报告才更新。
4. 按天更新报告按配置时间自动更新。
5. 权限管理支持查看和编辑两种权限。
6. 下载支持 Excel 和 PNG。
7. 保存后报告配置持久化。
8. 编辑模式下才能修改图表和描述。

**27.4 标签分析**

1. 支持人群占比和有效人群占比切换。
2. 人群占比展示大盘 TGI 和标签占比。
3. 有效人群占比展示标签 TGI 和标签有效占比。
4. 支持全局标签值排序。
5. 支持单图标签值排序。
6. 支持 TGI 展示开关。
7. 开启 TGI 展示后显示 TGI=100 参考线。
8. 支持图表排序分组。
9. 支持使用标签体系分组和自定义分组。
10. 支持存为模板。

**27.5 标签分析图表操作**

1. 支持修改图表标题。
2. 鼠标悬停可查看分群有效占比数据。
3. 支持调整标签值展示。
4. 支持图表联动分析。
5. 支持柱状图、条形图、饼状图、环状图、表格切换。
6. 支持图表放大与缩小。
7. 支持删除图表。
8. 支持将勾选标签值存为分群。
9. 存为分群支持“满足所有条件”和“满足任意条件”。
10. 存为分群成功后可在用户分群模块查看。

**27.6 指标分析**

1. 指标分析受增值模块开关控制。
2. 支持折线图、柱状图、卡片、表格。
3. X 轴支持时间、标签、分群、属性、明细属性、行为属性。
4. Y 轴支持标签、已有指标、新建指标。
5. 新建指标支持单一指标和组合指标。
6. 单一指标支持行为、明细、标签、属性作为计算条件。
7. 组合指标支持四则运算。
8. 数据计算时间支持单日期、固定区间、动态区间。
9. 指标为标签或维度为标签/分群时取最近一天数据。
10. 图表保存后可查询并展示结果。

**27.7 模板管理**

1. 支持标签分析模板和指标分析模板。
2. 支持个人模板、项目模板、共享模板。
3. 用户可编辑自己创建的模板。
4. 被分享用户只能查看和使用模板。
5. 被分享用户不能编辑、删除或二次分享模板。
6. 删除模板不影响已创建报告。
7. 使用模板时无权限标签自动剔除并提示。

**27.8 TGI 配置**

1. 支持自定义 TGI 名称。
2. 支持选择标签占比或标签有效占比作为计算方式。
3. 支持选择基准分群。
4. 基准分群主体必须与报告主体一致。
5. 基准分群失效时报告需提示。
6. 自定义 TGI 可用于提升特定业务场景下显著性计算准确率。
