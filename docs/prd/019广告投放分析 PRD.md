**广告投放分析 PRD**

**1. 模块定位**

广告投放分析用于接入广告监测数据，并将广告行为数据与后链路转化数据串联起来，帮助企业从广告投放、媒体渠道、转化路径、频次、重合度、投放指标、转化漏斗、人群导出等角度评估广告效果，最终支持企业找到更优的“人群 + 渠道 + 创意 + 转化路径”组合。

该模块核心目标不是单纯展示广告数据，而是帮助业务人员回答以下问题：

1. 哪些媒体渠道带来的曝光、点击、花费、转化效果更好。
2. 用户从广告点击到留资、试驾、成交等后链路行为之间如何转化。
3. 不同媒体渠道之间是否存在用户重合。
4. 用户接触广告的频次与转化效果之间是什么关系。
5. 哪些广告主、广告组、广告计划、广告创意的 ROI 更高。
6. 哪些转化效果好的人群可以被导出为分群，用于后续营销应用。
7. 如何通过广告报表、广告效果分析、媒体渠道分析共同支撑投放优化。

**2. 版本与使用限制**

**2.1 功能版本说明**

广告投放分析属于历史能力。

规则：

1. 广告投放分析功能对 V1.26 及更高版本的新用户停止开放。
2. 已有用户如已购买并部署该模块，仍可继续使用。
3. 新部署环境默认不开放该模块入口。
4. 如果项目未开通模块，菜单不展示或展示置灰态。

**2.2 增值模块限制**

广告投放分析为增值模块能力。

使用前提：

1. 企业已购买广告投放分析模块。
2. 部署时已开启广告投放分析能力。
3. 项目管理员已为用户开通广告投放分析模块权限。
4. 已完成数据融合模块中的前置数据准备。
5. 如果使用广告报表分析，需要同时采购 veCDP 和 iAD。
6. 广告监测链接需要在 iAD 内生成，CDP 仅支持广告监测数据接入和分析展示。

未满足条件时：

1. 菜单入口不展示，或展示置灰。
2. 用户点击时提示：当前项目未开通广告投放分析能力，请联系商务或管理员开通。
3. 无权限用户提示：暂无广告投放分析权限，请联系项目管理员开通。

11. 广告效果分析报告详情。
12. 媒体渠道分析报告详情。
13. 广告投放报表。
14. 广告效果趋势分析。

**4. 角色与权限**

**4.1 角色定义**

| **角色** | **权限范围** |
| --- | --- |
| 项目管理员 | 可为用户开通广告投放分析权限，可查看和管理项目内广告模板、报告和数据权限 |
| 报告创建者 | 可创建、编辑、查看、删除自己创建的广告分析报告 |
| 普通分析用户 | 可查看自己有权限的广告报告，可根据权限查询数据、下载明细、导出分群 |
| 被授权用户 | 可查看被授权的报告，能否编辑、下载、导出分群取决于具体权限 |
| 无权限用户 | 不展示广告投放分析入口 |

**4.2 模块权限**

| **权限项** | **控制内容** |
| --- | --- |
| 广告投放分析-查看 | 可进入广告投放分析模块，查看报告列表和报告详情 |
| 广告投放分析-增删改 | 可新建、编辑、删除广告分析报告 |
| 广告元数据模板管理 | 可新建、编辑、删除广告元数据模板 |
| 广告报表查看 | 可查看广告投放报表 |
| 数据下载权限 | 可下载广告效果明细、频次明细、重合度明细、报表明细 |
| 分群创建权限 | 可将广告分析中的人数导出为用户分群 |
| 数据权限 | 控制用户可查看哪些广告主、渠道、账户、分群、行为、标签数据 |

**4.3 无权限处理**

1. 用户无广告投放分析查看权限时，不展示菜单。
2. 用户有查看权限但无新增权限时：
   * 可查看报告列表和详情。
   * 新建报告、新建广告元数据模板按钮置灰。
3. 用户无下载权限时：
   * 下载明细数据按钮隐藏或置灰。
4. 用户无分群创建权限时：
   * 人数点击后只展示数据详情，不展示导出分群入口。
5. 用户无某广告主或渠道数据权限时：
   * 查询条件中不展示对应广告主或渠道。
   * 报表结果中不展示对应数据。

**5. 数据与业务流程**

**5.1 总体流程**

广告投放分析完整使用链路如下：

1. 开通广告投放分析模块。
2. 完成广告监测数据接入。
3. 完成数据融合前置数据准备。
4. 创建广告元数据模板。
5. 配置广告行为事件。
6. 配置广告指标。
7. 创建广告分析报告。
8. 查询报告数据。
9. 查看广告效果或媒体渠道分析。
10. 下载明细或导出分群。
11. 将导出人群用于营销应用。

**5.2 数据流转逻辑**

广告投放分析依赖以下数据链路：

1. 广告监测数据接入。
2. ID Mapping 或 ID 关联。
3. 元数据注册。
4. 元数据配置。
5. 广告行为事件映射。
6. 广告指标配置。
7. 报告创建。
8. 分析计算。
9. 人群包导出。
10. 营销应用。

**5.3 数据来源**

广告数据来源包括：

1. iAD 生成的广告监测链接数据。
2. 巨量引擎等媒体渠道数据。
3. 腾讯广告等媒体渠道数据。
4. 企业自有投放渠道数据，前提是完成数据接入。
5. 后链路行为数据，例如点击、留资、试驾、成交等。
6. CDP 内部用户标签、行为、人群包数据。

2. 广告行为事件配置。

**8. 创建广告元数据模板页面**

**8.1 页面结构**

元数据模板创建分为两步：

1. 广告行为事件配置。
2. 选择广告指标。

页面顶部展示步骤条：

1 广告行为事件配置 > 2 选择广告指标

右上角按钮：

1. 取消
2. 下一步
3. 上一步
4. 保存

**8.2 第一步：广告行为事件配置**

**8.2.1 基本信息**

字段：

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| 模板名称 | 输入框 | 是 | 广告元数据模板名称 |
| 主体 | 下拉框 | 是 | 模板适用主体 |
| 描述 | 文本域 | 否 | 模板说明 |

**模板名称**

规则：

1. 必填。
2. 同项目内不允许重复。
3. 最大长度建议 100 字。
4. 不允许仅输入空格。
5. 保存时为空提示：请输入模板名称。

**主体**

规则：

1. 必填。
2. 下拉展示当前项目已配置主体。
3. 选择主体后，广告行为事件、ID 类型、后链路行为数据均按主体过滤。
4. 如果切换主体时已配置事件，系统提示：
   * 切换主体将清空已配置的广告行为事件，是否继续？

**8.2.2 广告行为事件配置**

配置区标题：

广告行为事件配置

每一行代表一个广告行为事件映射。

字段：

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| 广告行为 | 下拉框 | 是 | 系统内广告行为语义，例如点击、留资、试驾、成交 |
| 行为事件 | 下拉框 | 是 | CDP 行为事件，例如 click、phone、buycar |
| 展示名称 | 输入框 | 是 | 在报告中展示的名称 |
| 顺序 | 数字/拖拽 | 是 | 转化链路顺序 |
| 删除 | 图标按钮 | 否 | 删除当前行为配置 |

示例配置：

| **广告行为** | **行为事件** | **展示名称** |
| --- | --- | --- |
| 点击 | click | 点击 |
| 留资 | phone | 留资 |
| 试驾 | buycar | 试驾 |

**8.2.3 添加事件按钮**

按钮名称：

添加事件

点击后：

1. 在配置区新增一行空白事件。
2. 默认顺序为当前最大顺序 + 1。
3. 用户必须填写广告行为、行为事件、展示名称。
4. 未填写完整时不能进入下一步。

**8.2.4 删除事件按钮**

按钮：

每行右侧删除图标。

点击后：

1. 如果当前行为空，直接删除。
2. 如果当前行已填写内容，弹窗确认：
   * 删除后该广告行为事件不会参与指标生成和报告分析，是否继续？
3. 确认后删除该行。
4. 删除后顺序自动重排。

**8.2.5 下一步按钮**

按钮名称：

下一步

点击后校验：

1. 模板名称必填。
2. 主体必选。
3. 至少配置 1 个广告行为事件。
4. 每个广告行为事件配置完整。
5. 行为事件不能重复配置为同一广告行为。
6. 展示名称不能重复。
7. 顺序不能重复。

校验通过后进入第二步：选择广告指标。

**8.3 第二步：选择广告指标**

**8.3.1 系统自动生成指标**

进入第二步后，系统根据第一步广告行为事件自动生成基础指标。

自动生成逻辑：

1. 对每个广告行为事件生成对应人数指标。
2. 对事件之间的链路生成转化指标。
3. 对广告监测行为生成基础广告效果指标。
4. 自动生成指标默认展示在指标列表中。

指标列表字段：

| **字段** | **说明** |
| --- | --- |
| 指标名称 | 指标展示名称 |
| 指标类型 | 单一指标 / 组合指标 |
| 创建人 | 系统 / 用户 |
| 操作 | 查看、移除 |

**8.3.2 新建广告指标按钮**

按钮名称：

新建广告指标

点击后打开新建广告指标弹窗。

**9. 新建广告指标弹窗**

**9.1 弹窗结构**

弹窗标题：

快速新建广告指标

字段区：

1. 指标名称。
2. 描述。

底部按钮：

1. 取消

**9.2 指标名称**

字段名称：

指标名称

规则：

1. 必填。
2. 同一模板下指标名称不允许重复。
3. 最大长度建议 100 字。
4. 不允许仅输入空格。

**9.3 描述**

字段名称：

描述

规则：

1. 非必填。
2. 最大长度建议 500 字。
3. 用于解释指标业务含义。

**9.4 指标分组**

字段名称：

指标分组

控件类型：

下拉框。

逻辑：

1. 可选择已有分组。
2. 可为空。
3. 分组用于指标列表展示分类。

**9.5 指标类型**

字段名称：

指标类型

选项：

1. 单一指标。
2. 组合指标。

**单一指标**

用于直接统计某个广告行为或后链路行为的数据。

配置项：

1. 计算对象。
2. 统计口径。
3. ID 类型。
4. 聚合方式。

示例：

点击人数 = 广告行为 click 的去重用户数。

**组合指标**

用于基于多个指标进行计算。

示例：

留资率 = 留资人数 / 点击人数

**9.6 计算条件**

组合指标示例配置：

| **条件** | **数据来源** | **事件** | **统计口径** |
| --- | --- | --- | --- |
| A | 媒体监测数据 | click | 人数 |
| B | 留资行为 | phone | 人数 |

计算公式：

B / A

展示格式：

百分比小数

**9.7 添加筛选条件**

按钮名称：

添加筛选条件

点击后：

1. 为当前指标条件增加过滤条件。
2. 支持按行为属性、标签、属性、明细字段过滤。
3. 多个筛选条件默认 AND。
4. 用户无权限字段不展示。

**9.8 添加行为 / 明细 / 标签 / 属性**

按钮：

1. + 行为
2. + 明细
3. + 标签
4. + 属性

点击后：

1. 在计算条件中新增一个条件项。
2. 条件项自动分配变量名，例如 A、B、C。
3. 用户可在公式编辑区引用变量。

**9.9 计算方式编辑区**

支持：

1. 变量 A、B、C。
2. 运算符：+、-、\*、/。
3. 括号。
4. 数字常量。

校验：

1. 公式不能为空。
2. 公式中的变量必须存在。
3. 括号必须成对。
4. 不允许连续运算符。
5. 除法分母不能为固定 0。
6. 若运行时分母为 0，结果展示为 --。

**9.10 展示格式**

字段名称：

展示格式

选项：

1. 整数。
2. 小数。
3. 百分比整数。
4. 百分比小数。

**9.11 确定按钮**

点击后：

1. 校验指标名称。
2. 校验指标类型。
3. 校验计算条件。
4. 校验计算公式。
5. 校验展示格式。
6. 校验通过后将指标加入指标列表。
7. 不立即保存到后端，需要点击模板页面右上角保存后才持久化。

**9.12 取消按钮**

点击后：

1. 如果未修改，直接关闭弹窗。
2. 如果有修改，弹窗提示：
   * 当前指标配置尚未保存，是否确认关闭？

2. 用户需要同时采购 veCDP 和 iAD。
3. 监测链接需在 iAD 内生成。
4. CDP 只支持广告数据接入和报表分析。
5. 未满足条件时入口置灰。

**22.3 查询条件**

字段：

1. 媒体渠道。
2. 广告主。
3. 广告组。
4. 广告创意。
5. 时间范围。

**媒体渠道**

广告数据来源渠道，例如巨量引擎等。

**广告主**

目标分析广告账号主。

**广告组**

目标分析广告所在广告组。

**广告创意**

目标分析广告创意。

**时间范围**

业务需要分析的时间段。

建议规则：

1. 时间范围必填。
2. 开始时间不能晚于结束时间。
3. 最大范围可按系统配置，建议不超过 30 天。

**22.4 查询按钮**

点击后：

1. 校验查询条件。
2. 拉取广告投放报表数据。
3. 刷新广告效果趋势。
4. 刷新广告指标明细。

**22.5 重置按钮**

点击后：

1. 清空媒体渠道。
2. 清空广告主。
3. 清空广告组。
4. 清空广告创意。
5. 时间范围恢复默认。
6. 清空查询结果。

**23. 广告效果趋势**

**23.1 功能说明**

广告效果趋势支持以天为时间维度进行广告效果趋势分析。

**23.2 指标选择**

控件名称：

指标

支持：

1. 展示数。
2. 点击数。
3. 总花费。
4. 点击率。

切换逻辑：

1. 默认展示点击数或系统默认指标。
2. 用户选择指标后，趋势图重新渲染。
3. X 轴为日期。
4. Y 轴为所选指标值。

**23.3 趋势图**

图表类型：

折线图。

交互：

下载明细数据

可根据系统配置扩展：

**25. 导出分群**

**25.1 入口**

广告投放分析中的导出分群入口包括：

1. 广告效果明细表格中的人数。
2. 转化漏斗中的人数。
3. 媒体渠道分析路径节点或连线。
4. 频次分析明细。
5. 重合度分析单元格。
6. 广告效果分析报告中的转化效果好的人群。

**25.2 导出分群弹窗**

字段：

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| 导出来源 | 只读 | 是 | 广告效果明细、漏斗、频次、重合度等 |
| 导出规则 | 只读/可编辑 | 是 | 当前点击位置对应的筛选规则 |
| 输出 ID 类型 | 下拉 | 是 | 基准 ID、手机号、设备 ID 等 |
| 分群名称 | 输入框 | 是 | 新分群名称 |
| 分群描述 | 文本域 | 否 | 导出说明 |
| 授权给 | 对象选择器 | 否 | 用户、用户组、角色、部门 |
| 分组 | 下拉多选 | 否 | 用户分群分组 |
| 预估人数 | 只读 | 是 | 当前规则下可导出人数 |

**25.3 保存按钮**

点击后校验：

1. 用户是否有分群创建权限。
2. 输出 ID 类型是否选择。
3. 分群名称是否填写。
4. 预估人数是否大于 0。
5. 授权对象是否合法。
6. 分组是否存在。

保存成功后：

1. 创建用户分群。
2. 分群来源记录为广告投放分析。
3. 保存当前广告筛选条件、报告 ID、点击来源和指标规则。
4. 提示：
   * 分群导出成功，可前往用户分群模块查看。

按钮：

1. 继续分析
2. 前往用户分群

**26. 状态与异常**

**26.1 无数据状态**

文案：

当前条件下暂无广告数据，请调整筛选条件或确认数据是否已接入。

展示场景：

1. 查询结果为空。
2. 数据接入未完成。
3. 用户无当前渠道数据权限。
4. 时间范围无广告数据。

**26.2 查询失败**

文案：

查询失败，请稍后重试。

并展示失败原因：

1. 数据源不可用。
2. 元数据模板失效。
3. 指标公式错误。
4. 权限不足。
5. 时间范围超过限制。
6. 后链路事件缺失。

**26.3 模板失效**

如果报告引用的元数据模板被删除或禁用：

1. 报告详情展示失效状态。
2. 查询按钮置灰。
3. 提示：
   * 当前报告引用的广告元数据模板已失效，无法继续查询。

**26.4 导出人数为 0**

文案：

当前规则下暂无可导出用户，无法生成分群。

保存按钮置灰。

**30. 验收标准**

**30.1 模块入口**

1. 未开通广告投放分析模块时，不展示入口或入口置灰。
2. 无权限用户不能进入广告投放分析。
3. 已开通且有权限用户可进入广告投放分析页面。
4. V1.26 及更高版本新用户默认不开放广告投放分析能力。

**30.2 元数据模板**

1. 用户可新建广告元数据模板。
2. 模板名称必填。
3. 主体必选。
4. 至少配置一个广告行为事件。
5. 广告行为事件配置完整后才能进入下一步。
6. 系统可根据广告行为事件自动生成指标。
7. 用户可新建广告指标。
8. 组合指标支持变量和四则运算。
9. 指标可查看和移除。
10. 点击保存后模板持久化。

**30.3 报告列表**

1. 报告列表展示广告效果分析和媒体渠道分析报告。
2. 支持按报告名称搜索。
3. 支持按报告类型筛选。
4. 点击新建报告可创建报告。
5. 点击报告名称可进入报告详情。
6. 支持编辑报告。
7. 支持删除报告。
8. 删除后报告不可恢复。

**30.4 广告效果分析报告**

1. 查询条件支持聚合维度、投放渠道、广告主、广告组、广告计划、广告创意。
2. 时间范围最多支持 30 天。
3. 查询按钮可生成广告效果明细。
4. 广告效果明细展示曝光、点击、留资等关键指标。
5. 支持自定义指标展示。
6. 点击明细表内人数可导出人群包。
7. 转化漏斗支持人数和次数口径切换。
8. 点击漏斗阶段可联动右侧渠道分布环形图。
9. 支持下载明细数据。

**30.5 媒体渠道分析报告**

1. 全局筛选必须选择投放渠道和时间范围。
2. 时间范围最多 30 天。
3. 必须选择起点事件和终止事件。
4. 支持增加中间节点事件。
5. 支持标签、行为、人群包筛选。
6. 广告媒体转化路径以桑基图展示。
7. 支持选择转化步数。
8. 频次分析支持选择事件。
9. 频次分析支持下载明细数据。
10. 重合度分析支持选择事件。
11. 重合度分析支持重合人数和百分比切换。
12. 重合度分析支持下载明细数据。

**30.6 广告投放报表**

1. 可从广告投放分析进入广告投放报表。
2. 查询条件支持媒体渠道、广告主、广告组、广告创意、时间范围。
3. 查询后展示广告效果趋势。
4. 广告效果趋势支持按天分析。
5. 趋势指标支持展示数、点击数、总花费、点击率、平均点击价格。
6. 支持下载趋势明细数据。
7. 广告指标明细展示多维广告渠道数据。
8. 支持下载广告指标明细 Excel。

**30.7 导出分群**

1. 广告效果明细人数可导出分群。
2. 转化漏斗人数可导出分群。
3. 媒体渠道路径节点或连线可导出分群。
4. 频次分析和重合度分析可导出对应人群。
5. 分群名称必填。
6. 输出 ID 类型必填。
7. 预估人数为 0 时不可保存。
8. 保存成功后可在用户分群模块查看。
9. 无分群创建权限时按钮置灰。

**30.8 下载与权限**

1. 无下载权限用户不能下载明细数据。
2. 下载数据必须与当前筛选条件一致。
3. 下载数据必须与当前展示指标一致。
4. 用户无广告主或渠道权限时，查询条件和结果均不展示对应数据。
5. 所有下载和导出操作必须记录审计日志。
