**热力图分析 PRD**

**1. 产品定位**

热力图分析用于把用户在网页或 App 页面上的浏览、点击、触达、停留、误点击、异常点击等行为，以可视化方式叠加到页面底图、页面截图或移动端快照上，帮助产品、运营、数据分析人员理解用户在页面中的真实行为。

热力图分析不只分析按钮和链接，也必须分析非可点击区域的点击。原因是非可点击元素上的点击通常代表用户预期和页面设计不一致，例如用户以为图片、价格、标题、标签、卡片区域可以点击，但实际不可点击，这类行为往往能暴露页面设计问题。DataFinder 文档也明确说明，热图不能只包含链接或按钮，还要包含非可点击元素的点击。

本功能支持以下分析场景：

| **场景** | **说明** |
| --- | --- |
| 页面点击分析 | 看用户主要点击哪里，哪些模块被忽略 |
| 误点击分析 | 看不可点击元素是否被大量点击 |
| 改版前后对比 | 对比页面改版前后的点击区域、触达深度、点击率变化 |
| 异常流量识别 | 判断点击是否集中在异常点位、是否存在刷量或模拟点击 |
| 页面触达分析 | 分析用户实际浏览到页面哪个深度 |
| 元素价值评估 | 判断页面元素曝光、点击、点击率、点击用户数、点击比 |
| 用户下钻 | 从点击元素下钻到具体用户列表，用于行为追踪 |
| 看板沉淀 | 将热力图配置保存为书签或看板组件，复用到日常监控 |

**4. 数据前置条件**

**4.1 全埋点依赖**

热力图依赖全埋点事件。创建热力图前，系统必须检查对应端是否已经接入 SDK 并开启全埋点。网页端至少需要页面浏览事件和点击事件。

| **事件类型** | **标准事件名** | **用途** |
| --- | --- | --- |
| 页面浏览 | page\_view / bav2b\_page | PV、UV、页面匹配、跳出率、停留时长 |
| 页面点击 | click / bav2b\_click | 点击热区、元素点击、点位云图 |
| 页面心跳 | page\_beat / \_\_bav\_beat | 停留时长、触达时长 |
| 页面滚动 | page\_scroll | 触达率图、滚动深度 |
| 页面曝光 | element\_exposure | 元素曝光、曝光点击率 |
| App 页面浏览 | app\_page\_view | 移动端页面匹配 |
| App 点击 | app\_click | 移动端点击热图 |

**4.2 数据延迟**

默认使用 T+1 数据。创建网页端热力图时，需要展示近 48 小时 PV 趋势，帮助用户确认页面规则是否正确；如果页面未接入 SDK、未开启全埋点或没有 T+1 数据，趋势图可能为空。配置页面需要有 T+1 数据上报，否则近 48 小时 PV 趋势无法正常展示。

**5.5 点位数据 heatmap\_click\_point**

用于点位云图。

| **字段** | **类型** | **说明** |
| --- | --- | --- |
| x | number | 点击点 x 坐标 |
| y | number | 点击点 y 坐标 |
| count | number | 该点位聚合点击次数 |
| user\_count | number | 点击用户数 |
| element\_key | string | 命中的元素 |
| is\_clickable | boolean | 是否可点击区域 |

点位聚合规则：

normalized\_x = click\_x / viewport\_width

normalized\_y = click\_y / page\_height

bucket\_x = round(normalized\_x \* 1000)

bucket\_y = round(normalized\_y \* 1000)

同一个 bucket\_x + bucket\_y 归为一个点位桶。渲染时再按当前底图尺寸换算为实际坐标。

**5.6 触达率数据 heatmap\_reach\_stats**

| **字段** | **类型** | **说明** |
| --- | --- | --- |
| section\_index | number | 页面分段序号 |
| start\_y | number | 分段起始 y |
| end\_y | number | 分段结束 y |
| reach\_user\_count | number | 触达到该区域的用户数 |
| reach\_rate | number | 触达率 |
| avg\_stay\_ms | number | 该区域平均停留时长 |
| click\_count | number | 该区域点击次数 |
| section\_name | string | 分段名称，例如“首屏”“第二屏” |

触达率计算：

触达率 = 触达到该页面深度的用户数 / 进入页面总用户数

触达判断：

用户最大滚动位置 + 视口高度 >= 当前分段 start\_y

**8. 网页端热力图配置**

**8.1 配置目标**

网页端创建的核心不是单个 URL，而是“合并页面”。用户可以把多个 URL 不同但内容相同，或者内容不同但结构相同的页面定义为一个页面组，用于整体分析同一类页面的数据。

**8.2 抽屉结构**

右侧抽屉宽度 720px：

创建网页端热力图

1. 基础信息

2. 页面定义方式

3. URL/标题规则

4. Hash 匹配

5. 支持分析类型

6. 近 48 小时数据校验

7. 底部按钮：取消 / 保存并查看

**8.3 基础信息**

| **字段** | **类型** | **必填** | **逻辑** |
| --- | --- | --- | --- |
| 热力图名称 | input | 是 | 最多 50 字 |
| 底图地址 | input | 是 | URL 校验，自动解析域名、路径、query、hash |
| 版本名称 | input | 是 | 默认“默认版本” |
| 版本说明 | textarea | 否 | 最多 200 字 |
| 备注 | textarea | 否 | 最多 200 字 |

底图地址用于热力图背景，并可初步解析页面规则；底图地址是热力图可视化的一部分，用于展示用户交互数据位置。

**8.4 定义方式**

定义方式：[按 URL] [按标题]

按 URL：

| **字段** | **逻辑** |
| --- | --- |
| 域名 | 从底图地址自动识别，不可编辑 |
| 页面路径 | 对应页面浏览事件中的 page\_path |
| 查询参数 | 支持空、任意、等于、包含、正则 |
| Hash 匹配 | 开启后配置 Hash 路径和 Hash 查询参数 |

按标题：

| **字段** | **逻辑** |
| --- | --- |
| 页面标题 | 对应页面浏览事件中的 page\_title |

**15. 点位云图模式**

**15.1 目标**

点位云图不是按元素框展示，而是按点击坐标聚合展示真实点击点位，适合发现异常点击、误点、刷量点击、页面空白区域点击等问题。

异常流量可能表现为点击集中在一点、几点，或平均分布于某些位置，热力图可帮助发现这类行为。

**15.2 页面布局**

**15.3 点位聚合逻辑**

standard\_x = click\_x / viewport\_width

| **粒度** | **说明** |
| --- | --- |
| 精细 | 1000 x 1000 网格 |
| 标准 | 500 x 500 网格 |
| 粗略 | 200 x 200 网格 |

默认使用标准粒度。

**15.4 点位展示逻辑**

点大小：

point\_radius = min\_radius + log(click\_count + 1) \* scale

点颜色强度：

intensity = click\_count / max\_click\_count

悬停点位展示：

点击次数

点击用户数

命中元素

是否可点击区域

异常标识

| **类型** | **判断** |

| 单点异常集中 | 某点点击数占页面点击数比例超过阈值 |
| 多用户同坐标 | 多用户点击坐标高度一致 |
| 不可点击区域高点击 | 非可点击区域点击数进入 Top N |

**16. 触达率图模式**

**16.1 目标**

触达率图用于分析用户实际浏览到页面哪个深度，帮助判断页面内容是否被看到。点击热图只能说明点击，触达率图说明页面内容是否进入用户视野。

**16.2 数据依赖**

优先级：

1. page\_scroll 事件，记录最大滚动深度。
2. page\_beat 事件，记录页面停留和可见区间。
3. 页面浏览事件中的首屏高度、页面高度、视口高度。

如果缺失滚动事件：

当前项目未采集滚动深度事件，触达率图无法准确计算。请开启页面滚动采集。

**16.3 页面分段**

支持两种分段：

| **分段方式** | **说明** |
| --- | --- |
| 按屏分段 | 按用户视口高度分为首屏、第二屏、第三屏 |
| 按百分比分段 | 0-25%、25-50%、50-75%、75-100% |

默认按屏分段。

**16.4 指标**

| **指标** | **计算** |
| --- | --- |
| 首屏触达率 | 触达首屏用户 / 页面进入用户 |
| 第二屏触达率 | 触达第二屏用户 / 页面进入用户 |
| 底部触达率 | 触达到页面底部用户 / 页面进入用户 |
| 平均触达深度 | 用户最大触达深度平均值 |
| 平均滚动次数 | 滚动事件次数 / 用户数 |
| 分段停留时长 | 用户在该段可见时长平均值 |
| 分段点击次数 | 该区域点击次数 |

**16.5 热区渲染**

触达率越高，色块越强

**17. 改版前后热图对比**

**17.1 目标**

可以将改版前后的热图放在一起比较，直观了解用户点击位置差异。

**17.2 对比入口**

入口：

1. 列表卡片“对比”
2. 详情页模式切换“改版对比”
3. 版本管理页“与此版本对比”

**17.3 对比配置**

对比面板分左右两组：

| **配置** | **左侧 A** | **右侧 B** |
| --- | --- | --- |
| 版本 | 改版前 | 改版后 |
| 时间范围 | 自定义 | 自定义 |
| 用户筛选 | 可独立设置 | 可独立设置 |
| 设备筛选 | 可独立设置 | 可独立设置 |
| 热图类型 | 点击/点位/触达 | 与左侧同步或独立 |

默认规则：

1. 如果存在两个版本，左侧选择较旧版本，右侧选择较新版本。

**17.4 对比视图模式**

| **模式** | **说明** |
| --- | --- |
| 并排对比 | 左右两个热图并排展示 |
| 叠加差异 | 同一底图上展示差异色块 |
| 指标对比 | 以表格展示元素级变化 |
| 排名变化 | 展示元素点击排名上升/下降 |

默认并排对比。

**17.5 并排对比逻辑**

页面结构：

左侧：版本 A 热图

右侧：版本 B 热图

顶部：对比配置

底部：差异指标表

交互：

1. 左右热图滚动同步。
2. 左侧悬停元素，右侧尝试高亮同 element\_key 元素。
3. 若右侧找不到对应元素，提示“右侧版本未匹配到对应元素”。
4. 点击元素后，下方差异表定位到该元素。

**17.6 差异计算**

元素差异：

点击次数变化 = B.click\_count - A.click\_count

点击次数变化率 = (B.click\_count - A.click\_count) / A.click\_count

点击率变化 = B.click\_rate - A.click\_rate

点击比变化 = B.click\_share - A.click\_share

触达率变化 = B.reach\_rate - A.reach\_rate

当 A 为 0：

如果 A = 0 且 B > 0，变化率显示“新增”

如果 A = 0 且 B = 0，变化率显示“--”

**17.7 差异表字段**

| **字段** | **说明** |
| --- | --- |
| 元素 | 元素文本或元素编号 |
| A 点击次数 | 左侧版本 |
| B 点击次数 | 右侧版本 |
| 点击变化 | B - A |
| 点击率变化 | B - A |
| 排名变化 | A rank → B rank |
| 状态 | 新增 / 消失 / 上升 / 下降 / 持平 |

**17.8 叠加差异模式**

要求两个版本底图结构一致或元素匹配率超过阈值。

差异颜色逻辑：

| **状态** | **展示** |
| --- | --- |
| B 明显上升 | 上升色 |
| B 明显下降 | 下降色 |
| 新增点击 | 新增标记 |
| 消失点击 | 消失标记 |
| 持平 | 中性展示 |

阈值：

明显变化 = abs(变化率) >= 20% 且 abs(点击次数变化) >= 10

**18.5 元素匹配**

版本间元素匹配优先级：

1. element\_key 完全一致

2. data-track-id 一致

3. 文本 + 元素类型 + 相对位置相近

4. 人工确认匹配

当匹配率低于 60%：

两个版本页面结构差异较大，叠加差异模式可能不准确，建议使用并排对比。

**20.5 恢复逻辑**

2. 还原热力图 ID。

**23. 异常处理**

**23.1 无 PV**

展示：

当前页面规则未匹配到浏览数据。

请检查页面路径、查询参数、Hash 匹配或 SDK 全埋点配置。

**23.2 无点击**

展示：

当前筛选条件下暂无点击数据。

可以调整时间范围、用户筛选条件或确认点击事件是否正常上报。

**23.3 无触达数据**

展示：

当前项目未采集滚动深度或页面可见事件，暂无法生成触达率图。

**23.4 iframe 不可加载**

展示：

当前页面无法在系统内嵌加载。

可能是目标页面禁止 iframe 嵌入，或页面发生自动跳转。

你可以使用“在原页面打开”查看热图。

网页热图无法加载的原因包括页面设置不允许嵌入 iframe、页面自动跳转，并通过“在原页面打开”解决。

**23.5 SVG 无热区**

展示：

部分 SVG 元素可能未采集点击数据。如需更精细的 SVG 热区，请检查 SDK 是否开启 SVG 采集。

JS SDK 默认不采集 SVG 元素，如需更精细热图可开启 SVG 采集。

**27. 验收标准**

**27.1 创建能力**

1. 可以创建网页端热力图。
2. 可以创建移动端热力图。
3. 网页端支持按 URL 和按标题定义页面。
4. 支持 Hash 匹配。
5. 支持近 48 小时 PV 校验。
6. 创建时自动生成默认版本。

**27.2 点击热图**

1. 能展示元素点击热区。
2. 能展示元素分布柱图。
3. 点击柱图能联动页面元素。
4. 悬停元素能展示点击次数、点击率、用户数、点击比。
5. 能显示不可点击区域误点。

**27.3 点位云图**

1. 能按坐标聚合点击点。
2. 能展示点位大小和强度。
3. 能识别异常点位。
4. 点位能下钻点击用户列表。

**27.4 触达率图**

1. 能展示页面分段触达率。
2. 能展示平均触达深度。
3. 能展示分段停留时长和点击次数。
4. 点击分段能过滤元素列表。

**27.5 点击用户列表**

1. 选中元素后能打开点击用户列表。
2. 用户列表支持分页、筛选、搜索。
3. 能识别高频点击、固定点点击等异常用户。
4. 无权限时不能查看用户级数据。

**27.6 改版对比**

1. 能选择两个版本。
2. 能选择两个时间段。
3. 能并排展示热图。
4. 能展示元素级差异表。
5. 能展示新增、消失、上升、下降元素。
6. 能支持叠加差异模式。

**27.7 版本管理**

1. 能创建新版本。
2. 能编辑版本名称、说明、底图、生效时间。
3. 能设为默认版本。
4. 能从版本列表发起对比。

**27.8 分享二维码**

1. 能生成分享链接。
2. 能生成二维码。
3. 能设置有效期。
4. 能控制是否允许查看用户列表。
5. 分享页能按配置只读展示。

**27.9 保存分析**

1. 能保存当前热图配置。
2. 能从保存分析恢复查询状态。
3. 能恢复模式、版本、时间、筛选、选中元素、透明度。
4. 原热图删除时有明确提示。

**27.10 保存到看板**

1. 能保存指标卡片、热力图快照、元素排行、触达率图、改版对比、趋势图。
2. 看板组件能刷新。
3. 点击看板组件能回到热图详情页。
4. 组件配置与保存分析配置复用。
