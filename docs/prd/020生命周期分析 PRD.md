**生命周期分析 PRD**

**1. 模块定位**

生命周期分析用于基于“生命周期标签”对用户在不同生命周期阶段中的规模、变化、流转、跃迁路径和阶段价值进行持续分析，帮助运营人员判断用户处于哪个阶段、各阶段用户数量如何变化、用户如何从一个阶段流转到另一个阶段，以及哪些阶段适合导出分群进行精细化运营。

生命周期分析不是一个独立创建分析模型的模块，它依赖标签体系中的生命周期标签。用户需要先在标签体系中创建生命周期标签，例如 AIPL、5A 模型标签，系统才会自动生成对应的生命周期分析报告。

模块核心目标包括：

1. 基于生命周期标签自动生成生命周期分析报告。
2. 展示各生命周期阶段的用户资产规模、日环比、当日新增、当日流失。
3. 支持查看各阶段用户趋势，包括总用户趋势、新增用户趋势、流失用户趋势。
4. 支持配置业务图表，用于观察不同生命周期阶段下的关键指标。
5. 支持查看生命周期阶段之间的关系流转。
6. 支持配置路径跃迁分析，观察用户从起始节点到终止节点的行为路径。
7. 支持从生命周期阶段、关系流转节点、路径跃迁节点导出分群。
8. 支持将指定生命周期阶段用户联动到群体画像洞察。
9. 支持生命周期分析权限管理、路径管理、报告查看和删除。

**2. 前置条件**

**2.1 生命周期标签前置条件**

生命周期分析必须依赖标签体系中的生命周期标签。

用户使用生命周期分析前，必须先完成以下操作：

1. 进入 标签体系 > 标签管理。
2. 创建生命周期标签。
3. 配置生命周期标签的阶段值。
4. 配置每个生命周期阶段的判断规则。
5. 保存并上线生命周期标签。
6. 系统根据生命周期标签自动生成生命周期分析报告。

生命周期标签示例：

**AIPL 模型**

| **阶段** | **英文** | **含义** |
| --- | --- | --- |
| A | Awareness / 认知 | 用户被动接触品牌，对品牌有初步了解 |
| I | Interest / 兴趣 | 用户主动接触品牌，例如点击广告、互动、预约体验 |
| P | Purchase / 购买 | 用户已完成购买行为 |
| L | Loyalty / 忠诚 | 用户形成复购、推荐、口碑传播等忠诚行为 |

**5A 模型**

| **阶段** | **英文** | **含义** |
| --- | --- | --- |
| A1 | Aware / 了解 | 用户初步知道品牌存在 |
| A2 | Appeal / 吸引 | 用户对品牌形成好感或兴趣 |
| A3 | Ask / 问询 | 用户主动搜索、咨询或收集信息 |
| A4 | Act / 行动 | 用户完成购买或关键转化行为 |
| A5 | Advocate / 拥护 | 用户形成忠诚并愿意推荐品牌 |

**2.2 权限前置条件**

项目管理员需要在：

项目中心 > 权限 > 按内容管理 > 模块

为用户授予生命周期分析相关权限。

生命周期分析至少包含以下权限：

| **权限** | **说明** |
| --- | --- |
| 查看 | 授权后，用户可查看自己创建的历史报告以及他人分享的报告 |
| 管理路径跃迁 | 授权后，用户可创建、编辑、删除路径，可根据路径生成分群并查看分群结果 |
| 生命周期分析编辑权限 | 可编辑生命周期分析相关配置 |
| 生命周期分析管理权限 | 可管理生命周期分析报告、路径、授权等配置 |

**2.3 资源权限前置条件**

项目管理员需要在：

项目中心 > 权限 > 按内容管理 > 资源

为用户授予生命周期分析中使用的标签权限。

资源权限包括：

1. 生命周期标签查看权限。
2. 生命周期标签中使用的底层标签权限。
3. 路径跃迁中使用的标签权限。
4. 路径跃迁中使用的行为事件权限。
5. 导出分群时需要的分群创建权限。
6. 洞察分群时需要的群体画像查看权限。

权限联动规则：

1. 开通生命周期分析编辑权限或报告管理权限时，系统自动为授权对象提供对应生命周期标签的查看权限。
2. 报告中展示的数据受数据权限，也就是行权限约束。
3. 用户无某标签资源权限时，不能在路径配置中选择该标签。
4. 用户无分群创建权限时，导出分群按钮置灰。
5. 用户无群体画像权限时，洞察此分群按钮置灰。

**5. 生命周期分析报告列表页**

**5.1 页面定位**

生命周期分析报告列表页用于展示所有用户有权限查看的生命周期分析报告。每个报告本质上对应一个生命周期标签。

报告列表页不只是报告管理页，同时也是生命周期标签分析入口。

**5.2 页面布局**

页面从上到下分为：

1. 页面标题区。
2. 搜索区。
3. 筛选区。
4. 报告列表表格区。
5. 分页区。
6. 权限管理入口，若当前用户具备管理权限。

**5.3 搜索框**

控件名称：

搜索报告名称或创建人

占位文案：

请输入报告名称或报告创建人

输入逻辑：

1. 支持按报告名称模糊搜索。
2. 支持按报告创建人模糊搜索。
3. 输入后按 Enter 触发查询。
4. 点击搜索图标触发查询。
5. 搜索条件与筛选条件共同生效。
6. 清空搜索框后，恢复当前筛选条件下的报告列表。

**5.4 筛选项**

**5.4.1 主体筛选**

控件类型：

多选下拉框。

选项来源：

当前项目中已配置生命周期标签的主体。

示例：

1. 用户。
2. 会员。
3. 车辆。
4. 线索。
5. 门店。

逻辑：

1. 默认展示全部主体。
2. 选择一个或多个主体后，仅展示对应主体的生命周期报告。
3. 用户无该主体权限时，不展示该主体选项。

**5.4.2 生命周期阶段筛选**

控件类型：

多选下拉框。

选项来源：

所有可见生命周期报告中的阶段值。

示例：

1. 认知。
2. 兴趣。
3. 购买。
4. 忠诚。
5. 了解。
6. 吸引。
7. 问询。
8. 行动。
9. 拥护。

逻辑：

1. 选择阶段后，列表仅展示包含该阶段的生命周期报告。
2. 多个阶段之间为 OR 关系。
3. 如果某报告包含任意一个已选阶段，则命中。

**5.4.3 创建人筛选**

控件类型：

多选下拉框。

逻辑：

1. 展示当前用户可见报告的创建人。
2. 选择后仅展示对应创建人的报告。
3. 与搜索框共同生效。

**5.4.4 创建时间筛选**

控件类型：

日期范围选择器。

逻辑：

1. 支持选择开始日期和结束日期。
2. 开始日期不能晚于结束日期。
3. 选择后按报告创建时间筛选。
4. 清空后不限制创建时间。

**5.5 重置按钮**

**5.8 行级操作**

**5.8.1 查看**

按钮名称：

查看

点击后进入报告详情页。

展示条件：

1. 用户拥有生命周期分析查看权限。
2. 用户拥有对应生命周期标签查看权限。

**5.8.2 权限管理**

按钮名称：

权限管理

点击后打开权限管理弹窗。

展示条件：

1. 当前用户拥有生命周期分析管理权限。
2. 或当前用户为项目管理员。
3. 或当前用户为该生命周期标签创建者，且系统允许创建者管理授权。

权限管理支持：

1. 授权给用户。
2. 授权给用户组。
3. 授权给角色。
4. 授权给部门。
5. 批量授权。

权限类型包括：

1. 查看。
2. 编辑。
3. 管理路径跃迁。
4. 报告管理。

授权规则：

1. 开通编辑或报告管理权限时，系统自动为授权对象提供生命周期标签查看权限。
2. 批量授权时，对所有选中对象统一授予所选权限。
3. 如果授权对象已存在权限，则更新为最新权限集合。
4. 授权变更立即生效。
5. 授权和取消授权需要记录审计日志。

**5.8.3 删除**

生命周期分析报告删除不是直接删除普通报告，而是通过删除对应生命周期标签实现。

按钮名称：

删除

点击后：

1. 系统提示用户将跳转到标签体系删除对应生命周期标签。
2. 如果产品允许在报告列表直接删除，则本质仍调用生命周期标签删除逻辑。
3. 删除前必须二次确认。
4. 删除生命周期标签后，对应生命周期分析报告同时删除。
5. 删除后不可恢复。

确认文案：

删除生命周期标签后，与之对应的生命周期分析报告也将同时被删除，且无法恢复。请确认是否继续？

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 取消 | 关闭弹窗 |
| 确认删除 | 删除生命周期标签及对应生命周期分析报告 |

删除权限：

1. 用户必须拥有标签删除权限。
2. 用户必须拥有生命周期分析管理权限。
3. 无权限时按钮隐藏或置灰。

**6. 生命周期分析报告生成逻辑**

**6.1 自动生成报告**

生命周期分析报告由生命周期标签自动生成。

生成条件：

1. 标签体系中成功创建生命周期标签。
2. 生命周期标签状态为启用。
3. 生命周期标签包含至少 1 个阶段值。
4. 生命周期标签绑定了主体。
5. 生命周期标签规则配置完整。

生成逻辑：

1. 用户创建并保存生命周期标签。
2. 系统生成对应生命周期分析报告记录。
3. 报告名称默认与生命周期标签名称一致。
4. 报告主体与生命周期标签主体一致。
5. 报告阶段值与生命周期标签阶段值一致。
6. 报告默认展示在生命周期分析报告列表中。
7. 用户点击报告可进入详情页查看分析结果。

**6.2 标签更新后的报告更新**

当生命周期标签配置发生变化时：

1. 阶段值新增后，报告详情页新增对应生命周期阶段卡片。
2. 阶段值删除后，报告详情页不再展示该阶段。
3. 阶段规则修改后，报告后续计算结果按新规则展示。
4. 历史数据是否重算由系统策略决定，建议展示最新分区结果。
5. 标签被禁用后，对应报告进入不可用状态。
6. 标签被删除后，对应报告同步删除。

当前可用最新数据日期。

逻辑：

**10.3 用户资产概览**

用户资产概览以卡片形式展示各生命周期阶段的数据。

每个生命周期阶段展示一个卡片。

卡片字段包括：

1. 阶段名称。
2. 总用户量。
3. 日环比。
4. 当日新增。
5. 当日流失。

**10.4 总用户量**

含义：

在所选日期，处于该生命周期阶段的用户总数。

计算逻辑：

总用户量 = 所选日期生命周期标签值等于当前阶段的用户数

展示规则：

1. 数字使用千分位。
2. 无数据时展示 0。
3. 用户无标签权限时不展示该阶段卡片。
4. 点击总用户量可打开阶段用户操作菜单：
   * 导出分群。
   * 洞察此分群。

**10.5 日环比**

含义：

该阶段当天总用户量与前一天总用户量相比的变化比例。

计算公式：

日环比 = (当天总人数 / 前一天总人数 - 1) \* 100%

异常处理：

1. 前一天总人数为 0 且当天总人数为 0，日环比展示 0%。
2. 前一天总人数为 0 且当天总人数大于 0，日环比展示 --，并提示 前日人数为0，无法计算环比。
3. 当天无数据时展示 --。
4. 日环比为正显示上升标识。
5. 日环比为负显示下降标识。
6. 日环比为 0 显示持平。

**10.6 当日新增**

含义：

昨天不在该阶段，但今天进入该阶段的用户数。

计算逻辑：

当日新增 = 今日在当前阶段的用户集合 - 昨日在当前阶段的用户集合

展示规则：

1. 展示人数。
2. 鼠标悬停说明：当日新增表示昨天还不在该阶段，但今天已进入该阶段的用户数。
3. 点击可导出该新增人群分群。

**10.7 当日流失**

含义：

昨天在该阶段，但今天不在该阶段的用户数。

计算逻辑：

当日流失 = 昨日在当前阶段的用户集合 - 今日在当前阶段的用户集合

展示规则：

1. 展示人数。
2. 鼠标悬停说明：当日流失表示昨天还在该阶段，但今天已经不在该阶段的用户数。
3. 点击可导出该流失人群分群。

**14. 路径跃迁页签**

**14.1 功能定位**

路径跃迁分析用于观察用户在生命周期中的具体行为路径。它支持针对全量用户或指定分群，分析用户从起始事件到终止事件之间的行为过程，帮助运营人员发现关键路径、流失节点和高转化路径。

路径跃迁与关系流转不同：

| **功能** | **分析对象** | **分析重点** |
| --- | --- | --- |
| 关系流转 | 生命周期阶段之间的变化 | 用户从阶段 A 到阶段 B 的流转 |
| 路径跃迁 | 起始事件、中间事件、终止事件 | 用户在事件路径中的行为过程 |

**14.2 页面结构**

路径跃迁页签包含：

1. 路径选择区。
2. 分析对象区。
3. 日期筛选区。
4. 路径操作区。
5. 路径图展示区。
6. 节点详情区。
7. 空状态区。

**16.7 窗口期**

窗口期定义：

前一个事件触发开始到当前事件被计算的时间长度。

示例：

如果前一个事件开始后，规定当前事件需要在 3 天内完成才算有效，则窗口期为 3 天。

配置规则：

1. 窗口期必填。
2. 窗口期单位支持分钟、小时、天。
3. 窗口期必须大于 0。
4. 中间节点按配置顺序依次计算。
5. 如果用户未在窗口期内完成该节点，则视为未通过该路径节点。

2. 起始事件固定在第一位。
3. 终止事件固定在最后一位。
4. 中间节点可拖动。
5. 保存后按新顺序重新分析。

**当前阶段全部人群**

导出昨天不在该阶段、今天进入该阶段的用户。

**当日流失**

导出昨天在该阶段、今天不在该阶段的用户。

**流转人群**

导出从某一阶段流转到另一阶段的人群。

1. 系统根据当前导出规则计算用户数。

3. 预估成功展示人数。
4. 预估为 0 时允许用户查看，但禁止保存，提示：

**22. 删除生命周期分析报告**

**22.1 删除逻辑**

生命周期分析报告与生命周期标签绑定。

删除报告的本质是删除对应生命周期标签。

操作路径：

1. 打开 标签体系 > 标签管理。
2. 找到对应生命周期标签。
3. 点击标签右侧 更多。
4. 选择 删除标签。
5. 系统弹出确认窗口。
6. 点击确定。
7. 生命周期标签删除。
8. 对应生命周期分析报告同步删除。

**22.2 删除影响**

删除后：

1. 生命周期标签不可恢复。
2. 生命周期分析报告不可恢复。
3. 报告中的用户资产、关系流转、路径跃迁结果不可恢复。
4. 与该生命周期标签相关的路径配置不可用。
5. 已导出的用户分群不自动删除，因为它们已经是独立分群。
6. 群体画像中已生成的洞察报告不自动删除。

**27. 验收标准**

**27.1 报告生成**

1. 用户在标签体系中创建生命周期标签后，系统自动生成生命周期分析报告。
2. 生命周期标签包含阶段值时，报告详情页展示对应阶段。
3. 删除生命周期标签后，对应生命周期分析报告同步删除。
4. 禁用生命周期标签后，报告不可正常分析并提示标签不可用。
5. 用户可从分析洞察入口进入报告列表。
6. 用户可从生命周期标签详情页点击生命周期分析进入报告详情。

**27.2 报告列表**

1. 报告列表展示报告名称、主体、生命周期阶段、创建人、创建时间等信息。
2. 支持按报告名称搜索。
3. 支持按报告创建人搜索。
4. 支持主体筛选。
5. 支持生命周期阶段筛选。
6. 点击报告名称进入详情页。
7. 删除报告时必须提示会删除生命周期标签及对应报告。
8. 无权限用户不能看到报告或操作按钮。

**27.3 权限管理**

1. 支持为用户、用户组、角色、部门授予生命周期分析权限。
2. 支持批量授权。
3. 授予编辑或管理权限时，系统自动提供生命周期标签查看权限。
4. 报告展示数据受行权限约束。
5. 无管理权限用户不能授权他人。
6. 权限变更后立即生效。

**27.4 用户资产**

1. 用户资产页签展示所有生命周期阶段卡片。
2. 每个阶段展示总用户量、日环比、当日新增、当日流失。
3. 日环比按 (当天总人数 / 前一天总人数 - 1) \* 100% 计算。
4. 当日新增表示昨天不在该阶段、今天进入该阶段的用户数。
5. 当日流失表示昨天在该阶段、今天不在该阶段的用户数。
6. 支持按日期查看某天阶段数据。
7. 点击阶段卡片可联动趋势和关系流转。
8. 阶段无用户时可正常展示 0 和空状态。

**27.5 用户趋势**

1. 支持查看过去 7 天、14 天、3 个月、6 个月、12 个月趋势。
2. 最大支持查看过去 12 个月。
3. 支持总用户趋势、新增用户趋势、流失用户趋势。
4. 支持折线图视图。
5. 支持表格视图。
6. 多阶段趋势支持图例切换。
7. 切换时间范围后趋势图和表格刷新。

**27.6 添加图表**

1. 用户有编辑权限时可添加图表。
2. 图表名称必填。
3. 生命周期阶段必选。
4. 度量必选。
5. 时间范围必选。
6. 支持折线图、柱状图、环形图、指标卡、表格。
7. 保存后图表展示在用户资产页签。
8. 图表支持编辑、删除、刷新、放大、下载。
9. 图表数据受用户资源权限和行权限控制。

**27.7 关系流转**

1. 关系流转展示生命周期阶段之间的流转情况。
2. 支持选择起始日期和结束日期。
3. 节点展示阶段名称和用户数。
4. 连线展示流转人数和占比。
5. 点击节点可导出分群。
6. 点击连线可导出流转人群。
7. 大盘无数据时展示空状态。
8. 导出的分群可在用户分群模块查看。

**27.8 路径跃迁**

1. 无路径时展示快速新建和自定义新建入口。
2. 点击快速新建后系统创建默认路径。
3. 用户可通过更多菜单编辑路径。
4. 用户可自定义创建路径。
5. 路径名称必填。
6. 更新频次必填。
7. 起始事件和终止事件必填。
8. 中间节点支持标签和行为事件。
9. 窗口期必填且必须大于 0。
10. 节点按配置顺序分析。
11. 路径图展示节点人数、转化人数、转化率、流失人数。
12. 点击路径节点可导出分群。
13. 用户无管理路径跃迁权限时不可新建、编辑、删除路径。

**27.9 导出分群**

1. 支持从生命周期阶段导出分群。
2. 支持从当日新增导出分群。
3. 支持从当日流失导出分群。
4. 支持从关系流转节点导出分群。
5. 支持从关系流转连线导出分群。
6. 支持从路径跃迁节点导出分群。
7. 分群名称必填。
8. 输出 ID 类型必填。
9. 预估人数为 0 时不可保存。
10. 保存成功后可前往用户分群查看。
11. 无分群创建权限时按钮置灰。

**27.10 洞察分群**

1. 支持选择一个生命周期阶段进行洞察。
2. 支持选择多个生命周期阶段合并洞察。
3. 系统将选中阶段人群作为群体画像分析对象。
4. 用户无群体画像权限时不可使用。
5. 洞察后可跳转群体画像模块查看结果。
