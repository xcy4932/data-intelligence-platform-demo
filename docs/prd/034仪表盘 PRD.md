**仪表盘 PRD**

**1. 产品定位**

仪表盘模块用于将可视化查询中生成的图表，以及文本、图片、网页、筛选器、参数、标签页、关系图、拼接表格、分析树等控件组合成业务看板。用户可以在仪表盘中完成数据展示、筛选联动、跨页面跳转、订阅推送、监控报警、评论协作、授权分享、嵌出集成和版本发布。

仪表盘不是单一图表页面，而是一个可编辑的数据故事画布。系统需要同时支持“搭建态”“阅览态”“嵌出态”“订阅态”“监控态”“版本态”等多种运行场景。

**3. 用户角色与权限模型**

**3.1 角色定义**

系统至少需要支持以下角色：

| **角色** | **定义** |
| --- | --- |
| 项目管理员 | 拥有当前项目下仪表盘、图表、模板、订阅、监控、Webhook、标签管理等高权限操作 |
| 仪表盘 Owner | 仪表盘所有者，默认拥有该仪表盘管理权限 |
| 仪表盘管理员 | 被授权拥有管理权限的用户或用户组 |
| 仪表盘编辑者 | 可编辑仪表盘布局、控件、图表配置，但不一定能管理权限 |
| 仪表盘阅览者 | 可查看仪表盘内容，可根据权限执行评论、订阅、下载等操作 |
| 文件夹管理员 | 可管理文件夹下的仪表盘和授权 |
| 图表 Owner | 图表所有者，拥有图表管理能力 |
| 数据集查看者 | 对某数据集有查看权限，可查看基于该数据集的图表 |
| 普通项目成员 | 拥有项目访问权限，但具体资源能力受资源授权限制 |

**3.2 权限判断通用规则**

系统中每个操作入口必须在前端和后端同时做权限校验。

前端负责入口显隐和禁用提示，后端负责最终鉴权。

权限判断优先级如下：

1. 项目管理员拥有项目内最高资源操作权限。
2. 仪表盘 Owner 默认拥有当前仪表盘全部管理权限。
3. 仪表盘管理员拥有当前仪表盘管理权限。
4. 仪表盘编辑者可进入编辑器，但不一定可转移所有者、管理标签或授权。
5. 仪表盘阅览者只允许查看、评论、个人书签、个人订阅等低风险操作。
6. 涉及底层数据导出、复制图表、复制仪表盘、监控创建时，还必须校验图表对应数据集权限。
7. 群组推送、邮件组推送、Webhook 配置等存在数据扩散风险的能力，应增加管理员或权限依据人校验。

**6.3 仪表盘分组逻辑**

**6.3.1 个人仪表盘**

个人仪表盘用于存放个人关注、未完成、不适合放入公共仪表盘的内容。

规则：

1. 默认仅创建人可见。
2. 可以分享给其他用户查看。
3. 不允许其他用户直接编辑个人仪表盘。
4. 只有创建人自己的仪表盘才能移动到自己的个人仪表盘。

**6.3.2 与我共享**

与我共享用于展示其他用户授权给当前用户查看的仪表盘。

规则：

1. 当前用户只可查看。
2. 当前用户不能修改仪表盘位置。
3. 当前用户是否可复制、订阅、下载，取决于被授权能力和底层数据权限。

**6.3.3 公共仪表盘**

公共仪表盘用于体系化报表管理。

规则：

1. 适合由数据分析师、数据 BP、业务分析师搭建。
2. 可以授权多人协同管理。
3. 只有公共仪表盘下的资源适合进行多人协作编辑。
4. 资源是否可编辑取决于当前用户对该仪表盘或文件夹的授权。

**6.4 新建仪表盘**

**6.4.1 入口**

点击目录区顶部“+”按钮，弹出菜单：

1. 新建仪表盘
2. 新建网页仪表盘
3. 新建文件夹
4. 仪表盘模板

**6.4.2 新建普通仪表盘**

字段：

| **字段** | **类型** | **必填** | **规则** |
| --- | --- | --- | --- |
| 仪表盘名称 | string | 是 | 1-50 字符，同目录下不可重名 |
| 保存路径 | folderId | 是 | 可选个人仪表盘或公共仪表盘下有编辑权限的文件夹 |

提交逻辑：

1. 校验用户是否有项目权限。
2. 校验目标路径是否可写。
3. 创建 Dashboard。
4. 默认创建一个 Page。
5. 默认 layoutMode 取系统默认值。
6. 创建成功后进入仪表盘阅览页或编辑页，建议默认进入编辑页。

**6.4.3 新建网页仪表盘**

字段：

| **字段** | **类型** | **必填** | **规则** |
| --- | --- | --- | --- |
| 名称 | string | 是 | 同目录下不可重名 |
| 保存路径 | folderId | 是 | 需有写权限 |
| 网页地址 | url | 是 | 必须是合法 URL |

URL 类型识别逻辑：

1. 如果 URL 匹配平台仪表盘嵌出链接，则类型为 dashboard\_embed。
2. 如果 URL 匹配飞书文档、多维表格、云文档链接，则类型为 cloud\_doc。
3. 其他合法 URL 识别为 external\_web。

创建后：

1. 在目录中新增一个网页仪表盘资源。
2. 阅览区以 iframe 方式展示 URL 内容。
3. 不展示普通仪表盘操作栏。
4. 不允许编辑 iframe 内部内容。
5. 允许编辑网页仪表盘的名称、路径和 URL。

**6.4.4 新建文件夹**

字段：

| **字段** | **类型** | **必填** |
| --- | --- | --- |
| 文件夹名称 | string | 是 |
| 保存路径 | folderId | 是 |

规则：

1. 文件夹名称同级不可重复。
2. 个人仪表盘和公共仪表盘下均可创建文件夹。
3. 与我共享分组不可创建文件夹。

1. 需要仪表盘编辑或管理权限。

2. 基础信息。
3. 标签选择器。

1. 一个仪表盘可绑定多个标签。
2. 标签用于分类和识别。

**6.7.2 标签管理**

入口：

基础信息弹窗右下角“标签管理”。

权限：

仅项目管理员可新建、删除、修改标签。

标签数据模型：

interface DashboardTag {

id: string;

projectId: string;

name: string;

}

校验：

1. 标签名不能为空。
2. 同项目标签名不可重复。
3. 删除标签时，需解除所有仪表盘的标签绑定。
4. 删除前二次确认。

**6.8 编辑仪表盘**

入口：

1. 阅览区右上角“编辑”按钮。
2. 列表更多菜单中的“编辑”。

并发编辑规则：

1. 若无其他用户正在编辑，点击后进入编辑页。
2. 若已有用户正在编辑，入口置灰。
3. 鼠标悬停提示：“xxx 正在编辑仪表盘”。
4. 后端需维护编辑锁。
5. 编辑锁建议包含 dashboardId、userId、lockExpireAt、heartbeatAt。
6. 编辑页每 30 秒发送心跳。
7. 心跳超时后释放锁。

**6.9 移动仪表盘**

移动方式：

1. 拖拽仪表盘到目标文件夹。
2. 更多菜单选择“移动”。

规则：

1. 个人仪表盘和公共仪表盘之间只能通过“移动”弹窗修改路径，不允许直接跨分组拖拽。
2. 分组内部可以通过拖拽调整顺序和路径。
3. 目标路径必须有写权限。
4. 与我共享下的仪表盘不可移动。
5. 移动后资源 ID 不变。
6. 原访问链接不变。
7. 目录树局部刷新。

**6.10 复制仪表盘**

入口：

更多菜单选择“复制仪表盘”。

字段：

| **字段** | **说明** |
| --- | --- |
| 仪表盘名称 | 默认“原名称 副本”，可修改 |
| 路径 | 目标保存目录 |
| 粘贴的图表为原图表副本 | 勾选后复制图表资源，不勾选则引用原图表 |

逻辑：

1. 校验用户对源仪表盘有管理权限。
2. 校验用户对目标路径有写权限。
3. 校验用户对源仪表盘内图表对应数据集至少有查看权限。
4. 创建新仪表盘。
5. 复制页面、组件、布局、主题、筛选器、交互配置。
6. 如果勾选“图表副本”：
   * 为每个图表创建新图表资源。
   * 新仪表盘组件引用新图表 ID。
   * 后续源图表变化不影响复制仪表盘。
7. 如果不勾选：
   * 新仪表盘组件引用原图表 ID。
   * 后续源图表变化会影响复制仪表盘中的对应图表。
8. 源仪表盘后续新增图表，不会同步到复制仪表盘。
9. 复制完成后跳转新仪表盘。

**6.11 授权仪表盘**

入口：

更多菜单选择“授权”。

逻辑：

1. 用户输入用户或用户组名称。
2. 系统搜索并展示匹配项。
3. 用户选择一个或多个授权对象。
4. 为每个对象设置权限级别。
5. 可选择是否发送飞书通知。
6. 点击确认后写入授权关系。

授权对象模型：

interface ResourcePermission {

resourceId: string;

notifyEnabled: boolean;

}

**6.12 转移所有者**

入口：

更多菜单选择“转移所有者”。

逻辑：

1. 打开转移所有者弹窗。
2. 支持输入用户名、姓名、邮箱搜索。
3. 支持单个仪表盘转移。
4. 支持批量选择多个仪表盘转移。
5. 转移后新 Owner 拥有管理权限。
6. 原 Owner 是否保留管理权限，由系统权限策略决定，建议默认保留管理员权限，避免误丢失。

**6.13 访问统计**

入口：

更多菜单选择“访问统计”。

页面展示：

1. 访问次数。
2. 访问用户数。
3. 最近访问时间。
4. 访问明细。
5. 支持下载访问数据。
6. 支持资源移动与删除入口。

**6.14 设置重定向**

入口：

更多菜单选择“设置重定向”。

字段：

| **字段** | **类型** | **必填** |
| --- | --- | --- |
| 重定向地址 | url | 是 |
| 是否启用 | boolean | 是 |

规则：

1. 仅 V2.91.0 及以上能力逻辑。
2. 仅有编辑权限的用户可设置。
3. 只对查看态 URL 生效。
4. 编辑态 URL 不重定向。
5. 三方嵌出 URL 不重定向。
6. 移动端访问不重定向。
7. 用户访问查看页时，如果重定向启用，前端或后端返回 redirect。
8. 适用于旧仪表盘下线后引导至新仪表盘。

**6.15 删除仪表盘**

规则：

1. 点击删除后弹出二次确认。
2. 确认后进入回收站。
3. 删除后目录树移除。
4. 已删除仪表盘访问时展示“资源已删除或已回收”。
5. 删除普通仪表盘不删除其引用的图表资源。
6. 删除文件夹时，如果包含子资源，必须明确提示影响范围。

**6.16 设为默认仪表盘**

规则：

1. 每个用户在每个项目下最多设置一个默认仪表盘。
2. 设置后进入仪表盘模块自动打开该仪表盘。
3. 可以取消默认。
4. 默认仪表盘被删除或无权限后，自动清空默认配置。

**7. 仪表盘模板 PRD**

**7.1 功能目标**

模板用于复用仪表盘结构、样式、图表布局和部分配置，帮助用户快速搭建类似业务看板。

**7.2 模板入口**

入口位于：

1. 顶部导航“仪表盘”下的“仪表盘模板”。
2. 仪表盘列表“+”菜单中的“仪表盘模板”。
3. 仪表盘更多菜单中的“导出为模板”。

**7.3 模板数据模型**

interface DashboardTemplate {

id: string;

projectId?: string;

name: string;

description?: string;

coverImageUrl?: string;

sourceDashboardId?: string;

scope: "official" | "project" | "personal";

resourcePackageUrl: string;

createdBy: string;

createdAt: string;

}

**7.4 导入模板**

流程：

1. 用户进入模板库。
2. 点击“导入模板”。
3. 上传模板资源包。
4. 系统校验资源包结构。
5. 用户选择目标目录。
6. 点击确认。
7. 系统创建模板记录。
8. 模板列表刷新。

校验：

1. 文件格式必须是系统支持的模板包格式。
2. 模板包中必须包含仪表盘结构描述。
3. 模板包中的图表、图片、主题等资源缺失时，导入失败并展示缺失项。
4. 同名模板允许存在，但建议提示用户区分。

**7.5 导出为模板**

入口：

仪表盘更多菜单选择“导出为模板”。

流程：

1. 选择要导出的仪表盘。
2. 打开导出弹窗。
3. 设置模板名称。
4. 可选择是否对数据抽样脱敏。
5. 点击导出。
6. 后端生成模板资源包。
7. 返回下载链接或保存到模板库。

抽样脱敏逻辑：

1. 如果勾选脱敏，导出的数据样例需要经过字段脱敏策略。
2. 图表结构、布局、样式保留。
3. 敏感数据样例不应被明文写入模板包。

**7.6 应用模板**

流程：

1. 用户进入模板列表。
2. 选择模板。
3. 点击“应用模板”。
4. 选择目标目录。
5. 系统基于模板创建新仪表盘。
6. 用户进入新仪表盘。
7. 如果模板含数据集占位符，用户需要进行替换数据集。

规则：

1. 应用模板后生成的是新的仪表盘。
2. 模板修改不影响已应用的仪表盘。
3. 已应用仪表盘可以独立编辑。

**8. 网页仪表盘 PRD**

**8.1 功能目标**

网页仪表盘是一种特殊仪表盘类型，用于嵌入其他仪表盘、外部网页、飞书文档、多维表格或云文档，并隐藏普通仪表盘操作栏，让用户集中查看嵌入内容。

**8.2 创建逻辑**

字段：

interface CreateWebDashboardPayload {

name: string;

folderId: string;

url: string;

}

提交规则：

1. 校验 URL 合法。
2. 识别 URL 类型。
3. 保存为 type = web 的 Dashboard。
4. 生成 iframe 展示配置。
5. 创建后进入网页仪表盘阅览页。

**8.3 阅览逻辑**

渲染规则：

1. 页面主体仅展示 iframe。
2. 不展示普通仪表盘顶部操作栏。
3. iframe 高度跟随右侧内容区域高度。
4. iframe 加载中展示 loading。
5. iframe 加载失败展示错误状态。
6. URL 为空或非法时展示配置错误。

**8.4 嵌入仪表盘场景**

如果嵌入的是平台仪表盘嵌出链接：

1. 嵌入内容支持原仪表盘已有的交互和筛选。
2. 不允许在网页仪表盘中编辑源仪表盘。
3. 不允许对网页仪表盘再次嵌出。
4. 不允许复制 iframe 内部仪表盘。
5. 源仪表盘修改后，网页仪表盘自动展示更新后的内容。
6. 源仪表盘删除后，展示“仪表盘已回收”。

**8.5 嵌入普通网页**

规则：

1. 用户可在 iframe 中搜索、翻阅、点击网页内部链接。
2. 如果目标网站不允许 iframe 嵌入，系统展示“目标网页不允许嵌入”。
3. 系统不负责突破目标网站 X-Frame-Options 或 CSP 限制。

**8.6 嵌入飞书云文档**

规则：

1. 用户需先在飞书文档中设置链接分享范围。
2. 将链接填入网页地址。
3. iframe 中展示云文档。
4. 文档是否可编辑取决于飞书侧权限。

**8.7 编辑网页仪表盘**

允许操作：

1. 重命名。
2. 修改 URL。
3. 移动路径。
4. 删除。
5. 授权。
6. 设置默认仪表盘。

不允许操作：

1. 进入普通仪表盘编辑器。
2. 添加图表控件。
3. 配置普通仪表盘页面主题。
4. 再次嵌出网页仪表盘内部内容。

**9. 仪表盘编辑器总体 PRD**

**9.1 编辑器目标**

编辑器用于通过可视化拖拽、配置和布局，完成仪表盘页面搭建。

**9.2 编辑器区域**

编辑器包含：

1. 顶部导航区
2. 左侧控件区
3. 中心画布区
4. 右侧配置区
5. 底部多页面编辑区

**9.3 编辑器初始化逻辑**

进入编辑页时：

1. 后端校验编辑权限。
2. 校验编辑锁。
3. 获取仪表盘结构。
4. 获取当前发布模式。
5. 获取页面列表。
6. 获取组件列表。
7. 获取主题。
8. 获取用户最近图表列表。
9. 获取本地编辑缓存。
10. 如果存在可恢复缓存，弹窗提示是否恢复。
11. 初始化撤销/重做栈。

**9.4 编辑锁逻辑**

interface DashboardEditLock {

dashboardId: string;

userId: string;

userName: string;

lockedAt: string;

heartbeatAt: string;

expireAt: string;

}

规则：

1. 用户进入编辑页时尝试获取锁。
2. 获取成功后进入编辑页。
3. 获取失败时展示占用人。
4. 编辑页每 30 秒发送心跳。
5. 用户正常退出释放锁。
6. 心跳超时释放锁。
7. 项目管理员可强制释放锁，但必须记录审计日志。

**9.5 撤销/重做**

规则：

1. 每次用户产生可逆编辑操作时，写入 undo stack。
2. 支持撤销到上一步。
3. 支持前进到下一步。
4. 保存后如果仍停留在当前编辑页，撤销/重做仍有效。
5. 关闭页面重新进入后，撤销/重做栈清空。
6. 撤销/重做操作不直接请求后端，只修改前端编辑状态。
7. 点击保存后统一提交最新状态。

可逆操作包含：

1. 添加组件。
2. 删除组件。
3. 移动组件。
4. 调整大小。
5. 修改样式。
6. 修改页面配置。
7. 修改图表配置。
8. 修改筛选器配置。
9. 修改页面顺序。
10. 组合/取消组合。
11. 图层变化。

**10. 顶部导航区 PRD**

**10.1 顶部导航组件结构**

顶部导航区从左到右包含：

1. 仪表盘名称
2. 撤销
3. 重做
4. 图层顺序
5. 组合/取消组合
6. 对齐方式
7. 页面缩放
8. 替换数据集
9. 页面配置
10. 移动端布局
11. 预览
12. 保存 / 保存并发布

**10.2 仪表盘重命名**

交互：

1. 点击顶部仪表盘名称。
2. 名称变为输入框。
3. 输入新名称。
4. 按 Enter 或失焦保存到编辑状态。
5. 点击保存时提交后端。

校验：

1. 名称不能为空。
2. 最长 50 字符。
3. 同目录不可重名。
4. 校验失败时保持编辑态并展示错误。

**10.3 图层顺序**

支持操作：

1. 置于顶层。
2. 置于底层。
3. 上移一层。
4. 下移一层。

规则：

1. 仅自由布局或悬浮组件存在明显图层意义。
2. tile 布局普通组件默认不重叠，但悬浮组件仍可调整 zIndex。
3. 多选组件时，整体按相对顺序调整。
4. zIndex 变化后写入组件 layout。

**10.4 控件组合**

触发条件：

1. 用户圈选多个控件。
2. 或按住 Ctrl/Command 多选多个控件。

操作：

1. 点击组合按钮。
2. 系统生成 groupId。
3. 选中组件写入相同 groupId。
4. 移动组合时，组合内所有组件按相同 delta 移动。
5. 调整组合外观时，可批量修改共同属性。
6. 支持取消组合。

规则：

1. 不允许跨页面组合。
2. 不允许将已属于不同父容器的组件组合。
3. 不允许将置顶容器和普通组件组合。
4. 不允许将标签页内部组件与标签页外部组件组合。

**10.5 对齐方式**

激活条件：

1. 选中 2 个及以上组件时，启用对齐。
2. 选中 3 个及以上组件时，启用等距分布。

支持：

1. 左对齐。
2. 水平居中。
3. 右对齐。
4. 顶部对齐。
5. 垂直居中。
6. 底部对齐。
7. 水平等距。
8. 垂直等距。

规则：

1. 对齐以选中组件集合的最外包围盒为基准。
2. 等距分布保持首尾组件位置不变，中间组件重新计算间距。
3. 操作后写入 undo stack。

**10.6 页面缩放**

支持：

1. 放大。
2. 缩小。
3. 适应视窗。
4. 实际大小。

规则：

1. 缩放只影响编辑器视图，不改变组件真实坐标。
2. 用户手动设置缩放后，不再自动跟随视窗缩放。
3. 当自动缩放低于最小宽度阈值时，出现横向滚动条。

**10.7 替换数据集入口**

点击后打开替换数据集弹窗。详细逻辑见“替换数据集 PRD”。

**10.8 页面配置入口**

点击后右侧配置区切换为页面配置。

**10.9 移动端布局入口**

点击进入移动端布局配置。

基础规则：

1. PC 端配置在移动端有默认展示效果。
2. 用户可单独调整移动端图表排列。
3. 移动端详细布局编辑能力由移动端布局模块承接。

**10.10 预览与保存**

**10.10.1 预览**

规则：

1. 点击预览打开预览页。
2. 预览展示当前编辑状态。
3. 预览不影响线上已发布版本。
4. 预览页可复制预览链接。
5. 有预览链接权限的用户可查看当前预览内容。

**10.10.2 保存**

实时发布模式：

1. 点击保存后，编辑内容立即成为线上内容。
2. 阅览页、订阅、监控、下载均使用最新保存内容。

版本发布模式：

1. 点击保存只保存草稿。
2. 不影响线上已发布版本。
3. 点击保存并发布才更新线上版本。

**11. 中心画布区 PRD**

**11.1 画布布局模式**

仪表盘支持两种布局：

1. 磁贴布局
2. 自由布局

**11.2 磁贴布局**

规则：

1. 所有普通组件自动吸附布局。
2. 普通组件默认不重叠。
3. 同一图层下系统计算智能排列。
4. 拖动或调整大小后，系统重新计算附近组件位置。
5. 支持单个组件设置为悬浮。
6. 悬浮组件可以覆盖在其他组件上。
7. 磁贴布局下画布和组件可随视窗自动缩放。
8. 当缩放达到最小宽度阈值后，不再继续缩放，显示横向滚动条。

实现建议：

interface TileLayoutEngine {

compact(components: DashboardComponent[]): DashboardComponent[];

move(componentId: string, target: Rect): DashboardComponent[];

resize(componentId: string, target: Rect): DashboardComponent[];

}

**11.3 自由布局**

规则：

1. 组件不自动吸附。
2. 组件可以重叠。
3. 支持调整图层顺序。
4. 拖动组件时展示对齐线。
5. 拖动组件接近画布中线时展示中线。
6. 支持等距线。
7. 支持多个组件编组。
8. 支持一键对齐。

**11.4 组件选择**

交互：

1. 单击组件选中。
2. 按住 Ctrl/Command 可多选。
3. 鼠标框选可批量选择。
4. 点击画布空白处取消选择。
5. 选中组件后右侧面板展示组件配置。
6. 未选中组件时右侧面板展示页面配置。

**11.5 组件拖拽**

规则：

1. 拖拽时实时更新临时位置。
2. 松手后写入真实位置。
3. 如果目标在容器内，则写入 parentComponentId。
4. 如果从容器拖出，则清空 parentComponentId。
5. 如果拖入标签页，则写入对应 tabId。
6. 如果拖入置顶容器，则写入 topContainerId。
7. 非法拖入时显示禁用光标并回弹。

**11.6 图表编辑**

图表组件右上角支持“编辑图表”。

点击后：

1. 跳转到可视化查询编辑页。
2. 携带 chartId。
3. 图表保存后返回仪表盘时刷新图表实例。
4. 如果仪表盘处于版本发布模式，图表编辑本身按图表资源规则保存，仪表盘发布状态不自动改变。

**11.7 复制与删除图表组件**

复制组件：

1. 复制的是仪表盘中的组件实例。
2. 默认引用同一个图表资源。
3. 如果用户选择复制为图表副本，则创建新图表资源。
4. 新组件位置相对原组件偏移一定距离。

删除组件：

1. 删除仪表盘组件实例。
2. 不删除图表资源。
3. 写入撤销栈。
4. 保存后生效。

**17. 筛选与过滤 PRD**

**17.1 功能目标**

**17.2 控件类型**

| **控件** | **作用** |
| --- | --- |
| 全局筛选器 | 对多个图表同时设置筛选条件 |
| 动态维度/指标 | 切换图表当前使用的维度或指标 |
| 全局参数 | 同时调整多个图表的公共参数 |
| 查询容器 | 收纳全局筛选器、动态维度/指标、全局参数 |

**17.3 全局筛选器通用模型**

6. 如果字段类型不一致，不允许绑定。
7. 用户保存后，筛选器值变化时，系统为每个图表生成对应查询条件。

**17.5 普通全局筛选器**

流程：

1. 点击左侧“全局筛选器”。
2. 选择关联图表。
3. 选择筛选字段。
4. 设置默认筛选条件。
5. 设置筛选方式。
6. 设置筛选器样式。
7. 设置名称。
8. 可选择是否置顶。
9. 保存仪表盘后生效。

**17.6 子筛选器**

用途：

用于省/市、一级分类/二级分类等层级字段，避免用户选到无效干扰项。

添加方式：

1. 将两个已建筛选器拖拽关联。
2. 直接在筛选器内添加子筛选器。

规则：

1. 子筛选器最多支持 20 层。
2. 父级选择后，子级选项根据父级值重新加载。
3. 父级清空后，子级清空。
4. 并排子筛选器通过拖动已有筛选器建立。
5. 独立子筛选器通过直接添加建立。

**17.7 树状筛选器**

用途：

将层级字段以树形结构展示。

配置流程：

1. 创建公共筛选器。
2. 绑定图表和字段。
3. 字段类型必须为文本或数值。
4. 筛选器设置选择“树状筛选”。
5. 选择树状层级来源数据集。
6. 配置层级字段。
7. 设置单选或多选。
8. 设置默认值。
9. 配置各图表字段与树状层级的关联关系。
10. 点击确认保存。

规则：

1. 存在多个数据集时，必须逐一配置映射。
2. 设置树状筛选器后，不支持再配置普通关联关系。
3. 默认勾选上级时自动勾选所有下级。
4. 如果开启“不自动勾选下级”，允许单独选择上级或选择勾选范围。

**17.8 树状筛选 AND/OR 规则**

**17.8.1 多层级字段 AND 生效**

适用：

关联图表数据集包含多个层级字段，例如地区、省份、城市。

生成条件示例：

(地区 = '东北' AND 省份 = '黑龙江')

OR

(地区 = '中南' AND 省份 = '湖南' AND 城市 = '浏阳')

**17.8.2 单层级字段 OR 生效**

适用：

数据集只有一个地址字段，字段值是最小层级，例如城市。

规则：

1. 用户选择省份=黑龙江。
2. 系统展开黑龙江下所有城市。
3. 查询条件为城市 in 黑龙江下所有城市。

**17.8.3 单字段包含多层级值**

适用：

一个地址字段中可能包含地区、省份、城市多级值。

规则：

1. 用户选择省份=黑龙江。
2. 查询字段值包含黑龙江或黑龙江下属城市。
3. 条件按 OR 拼接。

**17.9 组合筛选器**

用途：

允许用户配置多个条件组，并通过 AND/OR 组合过滤数据。

数据模型：

interface CompositeFilter {

4. 选择筛选维度或指标。
5. 设置字段显示名称。
6. 点击加号增加字段。
7. 点击减号删除字段。
8. 在右侧设置字段间 AND/OR 关系。
9. 可添加同级筛选项。
10. 可添加子筛选组。
11. 点击确认保存。

规则：

1. 同一个组合筛选器中筛选字段名不得重复。
2. 组合表达式必须至少包含一个条件。

**17.10 截止日期筛选器**

用途：

统一控制仪表盘中多个 OKR 图表的截止日期。

流程：

1. 点击全局筛选器。
2. 更多菜单选择“新增截止日期筛选器”。
3. 选择关联图表。
4. 仅允许选择 OKR 图表。
5. 选择截止日期时间。
6. 支持最近有数 1 天、T-1、T-N、自定义截止日期。
7. 保存后覆盖原 OKR 图表中的截止日期配置。

**17.11 动态维度/指标**

用途：

无需修改图表本身，即可切换图表当前维度或指标。

流程：

1. 点击左侧“维度/指标”。
2. 选择关联图表。
3. 选择对应动态维度或指标。
4. 设置默认值。
5. 设置样式。
6. 保存仪表盘后生效。

跨数据集规则：

1. 如果不同图表来自不同数据集，但字段业务含义一致，可配置字段关联。
2. 例如数据集 A 字段“城市”与数据集 B 字段“地点”关联。
3. 用户选择“城市”时，第二个数据集图表自动切换为“地点”。

**17.12 全局参数**

用途：

多个图表使用相同参数时，通过全局参数统一调整。

规则：

1. 多个图表关联的参数必须是同一个参数。
2. 用户选择参数值后，所有绑定图表重新查询。
3. 可配置参数样式和控件可见性。
4. 支持添加多个参数。

**17.13 查询容器**

用途：

将全局筛选器、动态维度/指标、全局参数收纳到一个容器内，改善布局。

规则：

1. 点击左侧查询容器后，画布生成容器。
2. 容器右上角提供添加控件入口。
3. 可添加全局筛选器、动态维度/指标、全局参数。
4. 容器内控件按配置顺序排列。
5. 查询容器可置顶。
6. 同页面只允许一个置顶容器类能力存在。

**17.14 显示查询按钮**

用途：

减少无效查询开销。

规则：

1. 开启后，用户修改筛选条件不会立即触发查询。
2. 用户点击“查询”按钮后才执行查询。
3. 公共筛选器和图表筛选器均支持。
4. 多个筛选器在同一查询容器中时，点击查询统一提交容器内所有条件。

**17.15 图表筛选器激活**

规则：

1. 当公共筛选器字段与图表内部筛选器字段重合时，公共筛选器优先生效。
2. 用户可点击图表筛选器“激活”。
3. 激活后，当前图表使用图表内部筛选器。
4. 当前图表屏蔽作用于它的公共筛选器。
5. 其他图表不受影响。

**17.16 图表筛选器隐藏**

规则：

1. 入口位于图表右上角“图内控件显示”。
2. 点击隐藏后立即隐藏图表筛选器。
3. 隐藏不删除筛选条件。
4. 再次显示后恢复原配置。

**17.17 筛选影响提示**

规则：

1. 公共筛选器生效后，被控制图表显示筛选图标。
2. 鼠标悬浮图标，展示影响该图表的公共筛选器名称。
3. 如果多个公共筛选器生效，按顺序全部展示。

**18. 网页插入 PRD**

**18.1 功能目标**

网页控件用于在普通仪表盘中嵌入网页、嵌出图表、嵌出仪表盘或外部平台内容。

**18.2 嵌入普通网页**

2. 当前页面置顶公共筛选器值变化后，网页控件 URL 参数同步更新。
3. URL 更新后 iframe 重新加载。
4. 日期类型字段支持默认值和绝对值传参。
5. 绝对值传参时，日期选择转换为时间范围。
6. 如果筛选器值为空，则不附加该字段参数或按目标约定传空。

**19. 替换数据集 PRD**

**19.1 功能目标**

替换数据集用于在保留上层仪表盘、图表配置和样式的前提下，将图表底层数据集切换为新的目标数据集。

**19.2 使用场景**

1. 底层数据集发生变化，但希望保留仪表盘图表。
2. 仪表盘具有通用性，希望复制到多个业务线后替换数据。
3. 使用模板后，将模板数据替换为自己的业务数据。

**19.3 替换入口**

支持三类入口：

1. 项目中心图表管理页面：批量替换项目下图表数据集。
2. 仪表盘编辑页面：批量替换仪表盘上图表的数据集。
3. 可视化查询页面：替换单张图表的数据集。

仪表盘页面规则：

1. 支持对仪表盘上的图表批量替换数据集。
2. 暂不支持仅针对仪表盘单个图表替换。
3. 如果只想替换单个图表，应进入可视化查询页面操作。

权限：

1. 项目管理员可操作。
2. 图表 Owner 可操作。
3. 图表所在仪表盘管理员可操作。

**19.4 批量替换规则**

规则：

1. 批量替换仅支持单一源数据集。
2. 如果选中的图表来自多个源数据集，不允许批量替换。
3. 用户必须选择一个目标数据集。
4. 目标数据集必须与源数据集类型兼容。
5. 字段匹配完成后才允许提交。

**19.5 字段匹配类型**

**19.5.1 数据源字段匹配**

含义：

将图表字段表达式中引用的旧数据集数据源字段替换为新数据集的数据源字段。

适用：

1. 旧字段和新字段在底层数据源字段层面一一对应。
2. 图表表达式中直接引用源字段。

**19.5.2 数据集字段匹配**

含义：

将当前图表中的字段完整替换为新数据集的某个数据集字段。

适用：

1. 目标字段已经在新数据集中建模。
2. 不希望仅替换表达式内部的源字段。
3. 希望字段语义整体切换。

**19.6 字段映射模型**

interface DatasetReplaceTask {

id: string;

sourceDatasetId: string;

targetDatasetId: string;

chartIds: string[];

mappingMode: "source\_field" | "dataset\_field";

fieldMappings: FieldMapping[];

}

interface FieldMapping {

oldFieldId: string;

oldFieldName: string;

oldFieldType: FieldType;

newFieldId: string;

newFieldName: string;

newFieldType: FieldType;

status: "matched" | "manual\_required" | "type\_mismatch";

}

**19.7 校验规则**

1. 所有必需字段必须完成映射。
2. 新旧字段数据类型必须一致。
3. 日期字段只能映射日期或时间字段。
4. 数值字段只能映射数值字段。
5. 文本字段只能映射文本字段。
6. 表达式中引用的字段必须全部替换。
7. 存在类型不匹配时不可提交。
8. 字段信息获取失败时不可提交。

**19.8 替换影响**

**19.8.1 数据集参数**

如果源图表使用数据集参数：

1. 目标数据集存在同名同类型参数，可自动匹配。
2. 不存在时需要用户手动选择。
3. 未匹配参数会导致替换失败或图表查询失败。

**19.8.2 层级结构和类目**

1. 源数据集层级结构不会自动迁移。
2. 若图表依赖层级结构，目标字段必须重新配置层级。
3. 类目配置需要按目标数据集重新匹配。

**19.8.3 权限**

1. 替换后图表数据权限按目标数据集权限生效。
2. 用户需要拥有目标数据集查看权限。
3. 阅览者如果没有目标数据集权限，图表展示无权限状态。

**19.8.4 仪表盘**

1. 替换后仪表盘布局不变。
2. 图表样式不变。
3. 图表查询字段切换为目标字段。
4. 公共筛选器关联字段可能需要重新映射。
5. 联动、跳转、钻取依赖字段的配置需要校验是否仍有效。

**19.9 报错处理**

字段数据类型不匹配：

展示：

字段「xxx」类型不匹配：源字段类型为 数值，目标字段类型为 文本。请选择相同类型字段。

字段信息获取失败：

展示：

目标数据集字段信息获取失败，请刷新后重试；若仍失败，请检查数据集权限或数据集状态。

**20. 仪表盘阅览页 PRD**

**20.1 页面目标**

阅览页用于查看仪表盘内容，并进行刷新、全屏、授权、分享、编辑、订阅、预警、评论、快捷查询、下载、嵌出等操作。

**20.2 顶部整体操作**

入口只展示当前用户有权限的功能。

包含：

1. 刷新。
2. 全屏。
3. 授权。
4. 分享。
5. 编辑。
6. 更多菜单。

**20.3 刷新**

规则：

1. 点击刷新后，重新请求当前页面所有图表数据。
2. 不改变筛选器当前值。
3. 不改变当前激活 sheet。
4. 不改变快捷查询状态。
5. 刷新失败的图表单独展示错误状态。

**20.4 全屏**

规则：

1. 点击进入全屏模式。
2. 全屏模式隐藏浏览器外层干扰区域。
3. 高级仪表盘全屏右下角可切换“自适应宽度”和“实际大小”。
4. Esc 退出全屏。
5. 退出后恢复原页面滚动位置。

**20.5 分享**

用途：

快速将当前仪表盘内容分享给其他用户，并保留筛选项设置。

规则：

1. 点击分享生成访问链接。
2. 如果当前页面有筛选条件，链接中需要编码当前筛选状态。
3. 被分享者打开链接后，如果有权限，看到与分享者一致的筛选结果。
4. 如果无权限，展示无权限状态。
5. 分享链接不提升权限。

**21. 上钻下钻 PRD**

**21.1 功能目标**

上钻下钻基于字段层级结构，让用户在图表中点击数据项后，快速从上层维度下钻到下层维度，或通过面包屑返回上级。

**21.2 前提条件**

两种实现方式：

1. 通过数据集字段层级实现：需要数据集编辑权限。
2. 通过图表钻取设置实现：需要数据集查看权限。

**21.3 支持图表类型**

支持：

1. 表格。
2. 透视表。
3. 并列柱状图。
4. 堆叠柱状图。
5. 百分比柱状图。
6. 并列条形图。
7. 堆叠条形图。
8. 百分比条形图。
9. 折线图。
10. 面积图。
11. 百分比面积图。
12. 双轴图。
13. 饼图。
14. 环形饼图。
15. 南丁格尔玫瑰图。
16. 填充地图。
17. 标记地图。
18. 双向条形图。
19. 组合图。
20. 散点图。
21. 圆视图。
22. 词云。
23. 雷达图。
24. 构成瀑布图。

**21.4 通过层级实现**

流程：

1. 在数据集中创建层级，例如地区 -> 省 -> 城市。
2. 将省、城市加入层级。
3. 在图表维度中添加地区字段。
4. 如果字段前展示“+”，表示可下钻。
5. 用户点击数据项。
6. 选择“聚焦下钻”。
7. 图表查询维度切换到下一层。
8. 查询条件加入当前点击值。
9. 页面展示下钻面包屑。
10. 点击面包屑上级字段完成上钻。

**21.5 通过钻取设置实现**

流程：

1. 图表中选择指标和需要下钻的维度。
2. 点击维度胶囊前倒三角。
3. 打开字段配置。
4. 选择“钻取设置”。
5. 添加下钻维度。
6. 勾选目标维度。
7. 点击确定。
8. 图表获得下钻能力。

**21.6 仪表盘内生效**

规则：

1. 图表保存到仪表盘后，下钻能力在仪表盘中可用。
2. 下钻状态是阅览态临时状态。
3. 刷新页面后恢复默认层级，除非书签保存了下钻状态。
4. 联动和跳转配置需要支持下钻字段。

**22. 图表联动 PRD**

**22.1 功能目标**

图表联动允许将一个图表作为筛选器。用户点击源图表中的数据项后，被联动图表按对应条件筛选数据。

**22.2 配置流程**

1. 进入仪表盘编辑页。
2. 点击源图表右上角更多。
3. 选择“联动设置”。
4. 勾选需要联动的目标图表。
5. 如果目标图表与源图表使用相同数据集，直接确认。
6. 如果使用不同数据集，配置字段对应关系。
7. 点击确定。
8. 保存仪表盘。

**22.3 字段关联规则**

1. 至少关联一个字段。
2. 字段配置满足条件后配置框从红色变为绿色。
3. 字段类型必须兼容。
4. 字段值为 null 时，联动不生效。
5. 如果当前一级字段下还有下钻字段，下钻字段也支持联动配置。

**22.4 单点联动**

规则：

1. 用户点击源图表维度值。
2. 系统提取该维度值。
3. 为目标图表生成筛选条件。
4. 目标图表重新查询。

如果点击指标值：

1. 系统取该指标值所在行的全部维度字段值。
2. 将这些维度字段值传给目标图表。
3. 目标图表按多个字段过滤。

**22.5 多点联动**

规则：

1. 用户在源图表中选择多个数据点。
2. 系统将多个数据点条件合并。
3. 同字段多值使用 in。
4. 不同字段按配置关系组合。
5. 目标图表重新查询。

**22.6 取消联动**

触发：

1. 再次点击已选中的字段。
2. 或点击图表空白处。

结果：

1. 清除当前联动状态。
2. 目标图表恢复到联动前的筛选状态。
3. 公共筛选器仍继续生效。

**22.7 删除联动配置**

入口：

编辑模式下点击“取消联动”。

结果：

1. 清空该源图表的联动配置。
2. 保存后生效。
3. 阅览态不再响应联动。

**23. 图表跳转 PRD**

**23.1 功能目标**

图表跳转允许用户点击图表字段后，跳转到其他仪表盘或外部网页，并可传递筛选条件或字段参数。

**23.2 配置方式**

支持两种：

1. 仪表盘配置图表跳转。
2. 可视化查询配置模板链接。

**23.3 仪表盘配置图表跳转**

特点：

1. 配置仅作用于当前仪表盘中的该图表。
2. 同一图表在其他仪表盘不受影响。

流程：

1. 进入仪表盘编辑页。
2. 选中图表。
3. 点击图表右上角更多。
4. 选择“跳转设置”。
5. 选择绑定字段。
6. 配置跳转方式。
7. 保存仪表盘。

**23.4 多字段多跳转规则**

部分图表支持给不同字段配置不同跳转方式，条件：

1. 图表支持多指标绘图。
2. 多个指标不在同一个 mark 中。
3. 下钻字段也支持配置。
4. 表格类图表可为不同字段配置不同跳转规则。

**23.5 跳转至仪表盘**

配置：

1. 目标仪表盘。
2. 是否带筛选条件跳转。
3. 字段匹配关系。

规则：

1. 目标仪表盘只能选择当前项目下仪表盘。
2. 开启带筛选条件后，将当前图表维度项作为目标仪表盘公共筛选器输入值。
3. 点击后打开目标仪表盘。
4. 目标仪表盘中匹配字段的公共筛选器自动赋值。
5. 支持字段多语言适配。

**23.6 跳转至网页**

配置：

1. 目标网页 URL。
2. 字段参数模板。
3. 是否带全局筛选条件。
4. 打开方式。

字段参数规则：

1. URL 中支持 {字段名}。
2. 点击时用当前数据点对应字段值替换。
3. 字段值需要 URL encode。

示例：

https://www.baidu.com/s?wd={省份}

点击山东后跳转为：

https://www.baidu.com/s?wd=山东

带筛选条件规则：

1. 将影响当前图表的全局筛选条件附加到 URL。
2. 参数建议使用 query。
3. 多值筛选需要编码为 in 表达式。

**23.7 打开方式**

支持：

1. 新开窗口。
2. 当前窗口。
3. 居中弹窗。
4. 右侧弹窗。

规则：

1. 当前窗口会替换当前页面。
2. 弹窗模式需支持关闭。
3. 弹窗 URL 加载失败时展示错误。

**23.8 模板链接跳转**

配置位置：

可视化查询编辑页字段配置中的“解析文本 - 模板链接”。

规则：

1. 配置保存后，在所有包含此图表的仪表盘中生效。
2. 只支持网页跳转。
3. 支持 {字段} 参数替换。
4. 仪表盘级跳转优先级高于图表模板链接，若同一字段均配置，应优先使用仪表盘级配置。

**24. 智能归因 PRD**

**24.1 功能目标**

智能归因用于在可视化看板中对指标异常波动进行多维度归因分析，识别影响指标变化的维度和维度项。

**24.2 前提条件**

1. 仅支持抽取数据集。
2. 暂不支持直连数据集。
3. 图表 X 轴必须为日期字段。
4. 日期聚合粒度支持日、周、月。
5. 图中至少一个指标满足归因表达式要求。
6. 当前分析点、对比时间点不为空、null 或 0。
7. 需要足够连续数据：
   * 天级至少 14 天。
   * 周级至少 8 周。
   * 月级至少 24 个月。

**24.3 触发流程**

1. 用户在折线图中发现指标异常。
2. 点击异常数据点。
3. 选择“默认归因分析”或自定义归因分析。
4. 系统提交归因任务。
5. 计算完成后展示“查看归因结果”。
6. 用户打开归因报告。

**24.4 对比时间**

默认归因：

1. 天级：当前日期与 7 天前对比。
2. 周级：当前周与前一周对比。
3. 月级：当前月与前一月对比。

自定义归因：

1. 用户自行选择对比时间点。
2. 系统校验对比点是否有数据。
3. 无数据时不允许提交。

**24.5 归因报告结构**

报告展示：

1. 波动状态。
2. 指标变化。
3. 维度贡献排名。
4. 维度项分析。

维度贡献排名包含：

1. 维度名称。
2. 基尼系数。
3. 大盘贡献度 TOP3 维度项。
4. 如果集成 CDP，可出现新建群体能力。

**24.6 归因配置**

配置入口：

1. 可视化查询左侧数据集信息更多菜单。
2. 数据集页面右上角归因分析配置。

配置项：

interface AttributionConfig {

datasetId: string;

globalConfig: AttributionRule;

metricSpecificConfigs: Record<string, AttributionRule>;

}

interface AttributionRule {

anomalyJudgeType: "time\_series\_prediction" | "change\_rate\_threshold";

threshold?: number;

dimensionLimit?: {

enabled: boolean;

maxCardinality?: number;

excludedDimensionIds?: string[];

};

resultLimit?: {

enabled: boolean;

maxDimensions: number;

};

}

**24.7 全局配置与个性配置**

规则：

1. 全局配置作用于所有未设置个性配置的指标。
2. 个性配置作用于指定指标。
3. 个性配置优先级高于全局配置。
4. 如果没有个性配置，全局配置作用于所有指标。

**24.8 异常判断依据**

支持：

1. 时序预测：基于系统预测范围判断异常。
2. 波动大于：基于同环比波动阈值判断异常。

**24.9 维度限制**

规则：

1. 可设置维度项少于 N 个才参与归因。
2. 可手动排除部分维度。
3. 用于排除 ID、设备号等高基数字段。
4. 可限制最终展示维度数量。

**24.10 不参与归因展示的维度**

以下维度不展示：

1. 表达式为 id 或 date 的维度。
2. Top1 维度项贡献百分比小于 1% 的维度。
3. 只有一个维度项的维度。
4. 分区字段。
5. 没有维度项的维度。
6. 时间段分析中维度项个数过大。
7. 维度数量过多时，仅取基尼系数高且用户常用的部分维度。

**25. 交互事件 PRD**

**25.1 功能目标**

交互事件用于在仪表盘嵌入到父系统后，用户点击图表字段值时，将当前行或数据点信息传递给父页面，供外部系统继续处理。

**25.2 适用范围**

1. 仅私有化部署支持。
2. 需要提前开启功能。
3. 配置为仪表盘级别。
4. 同一图表在不同仪表盘可配置不同交互事件。
5. 配置保存后，需要保存仪表盘并返回查看页才生效。

**25.3 配置流程**

1. 进入仪表盘编辑页。
2. 选中目标图表。
3. 点击图表右上角更多。
4. 选择“交互事件”。
5. 选择绑定字段。
6. 输入事件名称。
7. 事件类型默认为“向父页面发送消息”。
8. 可点击加号添加更多事件。
9. 点击确认。
10. 保存仪表盘。
11. 返回查看页。
12. 点击绑定字段值触发事件。

**25.4 消息格式**

统一格式：

{

"version": 0,

"event": "事件名称",

"payload": {

"row": [

{

"triggered": true,

"name": "字段名",

"displayName": "字段展示名",

"rawValue": "原始值",

"displayValue": "展示值"

}

]

}

}

发送方式建议：

window.parent.postMessage(message, "\*");

安全建议：

1. 支持配置允许发送的父域名白名单。
2. 生产环境不要固定使用 \*。
3. 父系统应校验 message 来源。

**25.5 表格/明细表事件**

规则：

1. 点击绑定字段后，传递该行所有数据。
2. 被点击字段 triggered = true。
3. 其他字段 triggered = false。

**25.6 透视表事件**

规则：

1. 点击维度字段，传递级联维度值。
2. 点击指标字段，传递该指标及对应行列维度值。
3. 被点击指标或维度设置 triggered = true。

**25.7 直方图事件**

规则：

1. 直方图只有一个维度字段。
2. 配置时无需选择绑定字段。
3. 点击柱体或标记点触发。
4. 传递区间、值、占比等数据。

**25.8 其他图表事件**

规则：

1. 支持大部分图表类型。
2. 如果编辑页无交互事件选项，表示暂不支持。
3. 除特殊图表外，点击标记点或区域后传递维度值和指标值。

**25.9 取消交互事件**

流程：

1. 进入仪表盘编辑页。
2. 已设置交互事件的图表，更多菜单展示“取消交互事件”。
3. 点击后清空事件配置。
4. 保存仪表盘后生效。

**26. 授权分享 PRD**

**26.1 功能目标**

仪表盘或文件夹管理员可通过授权能力完成分享与权限管理。

**26.2 操作入口**

入口：

1. 仪表盘阅览页右上角授权按钮。
2. 仪表盘列表更多菜单。
3. 文件夹更多菜单。

入口展示条件：

1. 当前用户有仪表盘管理权限。
2. 或当前用户有项目管理权限。
3. 文件夹授权要求文件夹管理权限。

**26.3 授权流程**

1. 点击授权。
2. 输入用户或用户组名称。
3. 搜索并选择目标对象。
4. 可重复添加多个对象。
5. 为每个对象设置权限级别。
6. 选择是否发送飞书通知。
7. 点击确认。
8. 后端保存授权关系。
9. 前端刷新权限列表。

**26.4 一键授权**

规则：

1. 支持快速输入对象并直接授权。
2. 默认权限级别由系统配置决定，建议默认“阅览”。
3. 管理权限需用户明确选择。

**26.5 便捷管理**

授权弹窗中应支持：

1. 查看已授权对象。
2. 修改权限级别。
3. 移除授权。
4. 搜索授权对象。
5. 区分用户和用户组。

**26.6 权限控制**

规则：

1. 授权不能超过当前用户自身权限。
2. 编辑者不能授予他人管理员权限。
3. 管理员移除自身管理权限时需二次确认。
4. 最后一个管理员不可被移除，除非项目管理员操作。

**27. 数据订阅 PRD**

**27.1 功能目标**

用户可通过订阅仪表盘，定时或在数据同步完成后接收仪表盘信息推送。

**27.2 前置条件**

1. 邮件订阅需要管理员完成企业邮箱或办公平台集成。
2. IM 订阅需要完成飞书、钉钉、企业微信、Webex 等应用集成。
3. 群推送需要群内添加对应机器人。
4. Webhook 推送需要完成 Webhook 配置。
5. 用户至少需要仪表盘查看权限才可创建订阅。

**27.3 新建订阅入口**

入口：

仪表盘查看页右上角更多菜单，点击“新建订阅”。

**27.4 新建订阅流程**

1. 点击新建订阅。
2. 选择订阅范围。
3. 填写订阅标题。
4. 填写订阅说明。
5. 配置推送内容。
6. 配置推送时间。
7. 配置推送语言。
8. 配置推送方式。
9. 配置接收人。
10. 可点击发送测试。
11. 测试无误后确认保存。
12. 订阅记录进入订阅管理。

**27.5 订阅范围**

**27.5.1 仪表盘页面**

规则：

1. 当仪表盘存在多个 sheet，可指定推送部分 sheet。
2. 推送多 sheet 或全部页面时，系统分别对每个 sheet 截图。
3. 多个截图合并在一条推送消息中发送。
4. 选中几个 sheet，消息中就包含几个页面截图。
5. 不支持推送标签页控件中的多个内部标签页，只推送默认保存的标签页状态。

**27.5.2 依据书签**

规则：

1. 用户可选择已有书签。
2. 订阅推送时按书签保存的筛选条件、动态维度、全局参数、自定义字段等状态生成截图。
3. 书签被删除后，订阅应提示异常并要求重新配置。

**27.5.3 快捷书签**

规则：

1. 用户在当前仪表盘调整筛选条件后，可勾选“快捷书签”。
2. 系统直接保存当前页面状态用于订阅。
3. 不要求用户先创建正式书签。
4. 快捷书签仅服务于当前订阅，不在书签列表中展示。

**27.6 推送消息配置**

**27.6.1 订阅标题**

规则：

1. 支持自定义标题。
2. 可勾选附加日期。
3. 勾选后推送标题格式为“YYYY-MM-DD 标题”。

**27.6.2 说明**

支持：

1. 文本。
2. 修改字体。
3. 插入超链接。
4. 插入图片。
5. 圈出接收人。

**27.6.3 订阅总结/解读**

规则：

1. 默认不勾选。
2. 开启后通过大模型对订阅内容生成解读。
3. 需要购买并开启分析助手增值模块。
4. 当前仅支持飞书推送方式。
5. 其他方式下该选项置灰并提示原因。

**27.6.4 内容**

可选：

1. 仪表盘访问链接。
2. 仪表盘截图平铺大图。
3. 仪表盘截图缩略小图。
4. 仪表盘 PDF 下载链接。
5. 截图时间。
6. 订阅管理链接。
7. 备注。

规则：

1. 访问链接默认勾选。
2. 截图或 PDF 默认勾选。
3. 取消后推送消息不包含对应内容。
4. 截图时间仅在选择截图或 PDF 时可配置。
5. 备注展示在推送消息结尾。
6. 备注支持文本、超链接和字体格式。

**27.7 订阅时间**

支持两种：

1. 定时推送。
2. 数据完成同步时触发。

**27.7.1 定时推送**

支持：

1. 天级。
2. 周级.
3. 月级。
4. 工作日。
5. 交易日。
6. 每天。

规则：

1. 到达指定时间后进行图表查询和截图。
2. 截图对应数据查询时间是在推送之前。
3. 如果查询超时，按异常处理规则处理。

**27.7.2 数据完成同步时触发**

规则：

1. 抽取数据集可直接支持。
2. 多图表多数据集场景下，推送前监测对应数据集业务日期同步状态。
3. 如果数据同步完成早于设定推送时间，则等到设定推送时间发送。
4. 如果数据同步完成晚于设定推送时间，则同步完成后立即发送。
5. 直连数据集在私有化版本可通过配置上游数据源就绪信息实现。

**27.8 推送语言**

支持：

1. 自动。
2. 中文。
3. 英文。

规则：

1. 自动模式按创建订阅时的语言设置或当前用户语言设置推送。
2. 明确指定中文或英文后，不随用户切换语言改变。

**27.9 推送方式**

支持：

1. 飞书。
2. 飞书群。
3. 企业微信。
4. 企业微信群。
5. Webex。
6. Webex 群。
7. 邮件。
8. 邮件组。
9. 钉钉。
10. 钉钉群。
11. 钉钉普通群。
12. 通用 IM。
13. Webhook。

**27.10 管理员与非管理员可选推送方式**

规则：

1. 飞书、企业微信、钉钉个人推送：管理员和非管理员均支持。
2. 邮件：管理员和非管理员均支持。
3. 飞书群、钉钉群：仅管理员支持，且需要群中添加应用机器人。
4. 邮件组：仅管理员支持。
5. Webhook：管理员和非管理员均可支持，但具体配置创建仅项目管理员可操作。

**27.11 群组推送安全规则**

必须提示：

1. 群组订阅不会对群成员逐个执行仪表盘鉴权。
2. 群成员变化会影响可见范围。
3. 新增群成员可能查看历史订阅消息。
4. 配置群组订阅需谨慎。

**27.12 权限依据人**

使用场景：

1. 群组推送。
2. 邮件组推送。

规则：

1. 必须指定权限依据人。
2. 推送内容按权限依据人的数据权限生成。
3. 如果数据集设置行权限，不同权限依据人生成的数据可能不同。
4. 被设置为权限依据人的用户应收到提示。

**27.13 异常处理**

规则：

1. 仪表盘内存在图表无数据、查询失败、查询超时时，不发送截图消息。
2. 推送失败后 1 小时自动重试一次。
3. 仪表盘内存在图表数据为空时，不推送。
4. 订阅失败需记录失败原因。
5. 订阅管理中展示最近一次推送状态。

**27.14 订阅修改通知**

规则：

1. 订阅创建、修改、删除可发送通知。
2. 通知对象可选接收人或创建者。
3. 通知内容包括订阅名称、操作类型、操作人、操作时间。

**28. Webhook 推送配置 PRD**

**28.1 功能目标**

Webhook 配置用于将仪表盘订阅消息推送到企业微信群、钉钉普通群、飞书外部群、通用 IM 或自建系统 API。

**28.2 权限**

仅项目管理员可进入项目中心 Webhook 配置页并创建配置。

**28.3 Webhook 配置模型**

interface WebhookConfig {

id: string;

projectId: string;

name: string;

url: string;

secretType?: "none" | "static\_token" | "dynamic\_token";

staticToken?: string;

dynamicTokenConfig?: {

tokenApiUrl: string;

tokenParamName: string;

};

remark?: string;

interfaceType:

| "api"

| "generic\_im\_robot"

| "dingtalk\_robot"

| "wechat\_work\_robot"

| "feishu\_external\_robot";

subscribedEvents: WebhookSubscribedEvent[];

createdBy: string;

createdAt: string;

}

**28.4 新建 Webhook 配置**

字段：

| **字段** | **规则** |
| --- | --- |
| 名称 | 建议不超过 30 字 |
| URL | Webhook 推送目的地址 |
| Secret | 可选，支持静态 token 或动态 token |
| 备注 | 可选 |
| 接口类型 | API、通用 IM、钉钉群机器人、企业微信群机器人、飞书外部群机器人 |
| 订阅事件 | 可选订阅推送、评论等事件 |

提交规则：

1. URL 必须合法。
2. 接口类型必填。
3. 静态 token 模式必须填写 token。
4. 动态 token 模式必须填写获取 token 的接口和参数名。
5. 创建后可在订阅配置中选择。

**28.5 企业微信群 Webhook**

流程：

1. 在企业微信群中添加群机器人。
2. 获取机器人 Webhook 地址。
3. 在项目中心 Webhook 配置中新建配置。
4. 输入名称和 URL。
5. 选择企业微信群机器人接口类型。
6. 创建订阅时推送方式选择企业微信群。
7. 接收人选择该 Webhook。
8. 发送测试。
9. 测试成功后保存。

**28.6 钉钉普通群 Webhook**

流程：

1. 进入钉钉群设置。
2. 创建自定义群机器人。
3. 获取 Webhook 地址。
4. 在项目中心创建钉钉普通群 Webhook。
5. 创建订阅时选择钉钉普通群。
6. 发送测试。
7. 保存。

**28.7 飞书外部群 Webhook**

流程：

1. 进入飞书外部群设置。
2. 添加自定义机器人。
3. 获取 Webhook 地址。
4. 在项目中心创建飞书外部群 Webhook。
5. 创建订阅时推送方式选择 Webhook。
6. 选择对应接收人配置。
7. 发送测试。
8. 保存。

**28.8 系统 API Webhook**

规则：

1. 接口类型选择 API。
2. URL 为业务系统接收订阅消息的 API。
3. 可配置鉴权 token。
4. 订阅推送时系统发送 HTTP 请求。
5. 接口响应 2xx 视为成功。
6. 非 2xx 或超时视为失败。
7. 失败进入订阅重试机制。

**28.9 通用 IM 机器人**

规则：

1. 管理员在项目中心新建 Webhook 配置。
2. 接口类型选择通用 IM 机器人。
3. 填入 IM API 地址和密钥。
4. 创建订阅时推送方式选择通用 IM。
5. 接收人选择配置好的 IM 机器人。
6. 发送测试验证。

**29. 监控报警 PRD**

**29.1 功能目标**

监控报警用于监控图表中的指标或维度变化，支持小时、日、月等粒度，满足业务异常发现和主动通知。

**29.2 前置条件**

离线数据监控前置条件：

1. 底表需要例行更新。
2. 日期筛选需要设置为最近或最近有数。
3. 图表必须已保存。

入口展示条件：

1. 用户具有仪表盘查看及以上权限。
2. 图表满足监控前置条件。
3. 图表类型和字段配置满足所选监控类型要求。

**29.3 新建监控流程**

1. 用户在图表更多菜单点击“新建监控”。
2. 打开设置弹窗。
3. 输入监控名称。
4. 选择时间范围。
5. 选择触发因素。
6. 配置报警规则。
7. 配置监控时间。
8. 配置推送方式。
9. 配置处理建议。
10. 点击发送测试。
11. 测试无误后点击确认。
12. 监控创建成功。
13. 可在监控列表管理中查看。

**29.4 时间范围**

**29.4.1 日期维度**

可选择的日期来源于图表维度栏中的日期维度。

范围选项：

1. 最近 1 个时间点。
2. 最近 N 个时间点。
3. 已选择的时间范围。

规则：

1. 最近 1 个时间点只监控最新一行时间数据。
2. 最近 N 个时间点监控最近 N 个时间点范围。
3. 已选择时间范围监控当前图表日期筛选下所有数据。

**29.4.2 最近 1 个时间点粒度**

规则：

1. 时间字段为 1/5/15 分钟等粒度时，最近 1 个时间点按该粒度计算。
2. datetime 秒级、10 分钟、20 分钟等未标准枚举时，最近 1 个时间点按 1 秒。
3. date 双周、双月、季度等类型，最近 1 个时间点按 1 天。

**29.5 触发因素**

支持：

1. 指标值变化。
2. 维度值变化。
3. 智能波动检测。

**29.6 指标值变化**

规则：

1. 支持多个报警规则。
2. 可选择满足全部规则报警。
3. 可选择满足任一规则报警。
4. 指标条件必填。
5. 维度条件可选。

**29.6.1 维度筛选**

规则：

1. 每条规则下可配置维度筛选。
2. 可选择对指定维度项监控。
3. 多个维度条件支持 AND/OR。
4. OR：满足任一维度条件的数据被监控。
5. AND：同时满足所有维度条件的数据被监控。

**29.6.2 指标监控条件**

支持：

1. 任一条件。
2. 全部条件。
3. 全部数据。
4. 任一数据。

对比范围：

1. 比 1 天前。
2. 比 7 天前。
3. 比 30 天前。
4. 绝对值。
5. 原始值。
6. 前一时间点。
7. 比前 7 天均值。
8. 比前 30 天均值。

对比方式：

1. 波动超过。
2. 上升超过。
3. 下降超过。
4. 大于。
5. 大于等于。
6. 小于。
7. 小于等于。
8. 等于。

对比口径：

1. 固定数值。
2. 百分比。
3. 其他指标。

**29.7 维度值变化**

用途：

监控某个维度枚举值是否新增或消失。

规则：

1. 可监控图表维度项。
2. 支持隐藏维度。
3. 支持和 1 天前、7 天前、30 天前对比。
4. 枚举值发生新增或消失时触发报警。

**29.8 智能波动检测**

规则：

1. 使用时序异常检测算法。
2. 仅支持折线图。
3. 监控时间至少需要 15 个时间点。
4. 可监控当前图表指标栏指标。
5. 支持隐藏字段和分析功能衍生字段。

**29.9 监控时间**

**29.9.1 定时**

支持：

1. 天级。
2. 小时级。
3. 分钟级。
4. 周级。
5. 月级。
6. 自定义工作日、交易日、每天。

规则：

1. 天级可选固定时间点。
2. 自定义时间支持精确到分钟。
3. 监控最小间隔 10 分钟。
4. 小时级支持每 1、2、3、4、6、8、12 小时。
5. 分钟级支持每 10、15、20、30 分钟。
6. 周级可选择周一至周日。
7. 月级支持每月第 1-31 天；如果某月没有该日期，则不触发。
8. 支持 UTC 时区选择。

**29.9.2 数据完成同步时触发**

规则：

1. 图表数据集为天级同步时支持。
2. 触发需满足 T-N 分区数据完成同步。
3. 触发需到达最早触发时间。
4. 如果数据早于最早触发时间完成，则等到最早触发时间。
5. 如果数据晚于最早触发时间完成，则完成后立即触发。

**29.10 推送方式**

支持：

1. 邮件。
2. 飞书。
3. 企业微信。
4. Webex。
5. 钉钉。
6. Webhook。

规则：

1. 推送方式取决于管理员完成的办公平台集成。
2. IM 群推送支持多个群号，用英文逗号分隔。
3. 每个群内必须有对应机器人。
4. Webhook 请求失败需要记录失败日志。

**29.11 处理建议**

规则：

1. 支持文本。
2. 支持 URL。
3. 处理建议展示在报警消息中。
4. 用于指导接收人下一步处理。

**29.12 警报结果**

规则：

1. 可勾选“警报中显示监控条件”。
2. 勾选后报警卡片展示监控规则。
3. 未勾选时仅展示报警结论。

**29.13 发送测试**

规则：

1. 立即发送一条测试消息。
2. 测试不会发送到群。
3. 测试用于预览监控效果。
4. 测试不创建监控记录。

**29.14 监控列表管理**

入口：

1. 可视化页面监控下拉栏。
2. 项目中心 - 定时任务 - 监控管理。

查看和操作范围：

| 项目成员 | 自己创建的监控 | 全部操作 |

| 项目成员 | 自己是接收人的监控 | 无操作权限 |

**30. 图表/仪表盘嵌出 PRD**

**30.1 功能目标**

用户可将图表或仪表盘以 iframe 形式嵌入外部系统、文档或其他平台。

**30.2 图表嵌出流程**

1. 进入仪表盘预览或阅览状态。
2. 点击目标图表右上角更多。
3. 选择“嵌出图表”。
4. 系统复制嵌出链接。
5. 用户将链接粘贴到外部系统或浏览器。
6. 外部系统通过 iframe 加载图表。

**30.3 仪表盘嵌出流程**

1. 进入仪表盘预览或阅览状态。
2. 点击右上角更多。
3. 选择“嵌出仪表盘”。
4. 打开嵌出配置弹窗。
5. 选择嵌出页面范围。
6. 配置仪表盘显示项。
7. 配置图表显示项。
8. 配置是否带筛选器条件。
9. 点击复制嵌出链接。

**30.4 嵌出配置项**

仪表盘配置：

1. 是否显示仪表盘名称。
2. 是否显示仪表盘所有者。
3. 是否显示仪表盘操作按钮。

图表配置：

1. 是否显示图表名称。
2. 是否显示提示类图标。
3. 是否显示工具条图标。

页面范围：

1. 全部页面。
2. 部分 sheet。

筛选器：

1. 是否带当前筛选条件。
2. 是否显示筛选器控件。

**30.5 权限规则**

1. 嵌出链接不代表公开访问。
2. 访问嵌出内容前仍需平台鉴权。
3. 数据权限按访问用户在平台内的权限生效。
4. 嵌出图表支持下载数据，但下载权限仍按平台权限校验。

评论功能支持用户对仪表盘上的图表添加、查看、回复、删除评论，用于数据场景下的协同沟通。

**31.2 前提条件**

2. 评论通知需要完成飞书集成。

**31.4 添加评论**

流程：

1. 用户点击某条评论的回复。
2. 输入回复内容。
3. 回复作为 parentCommentId 的子评论保存。
4. 评论列表按时间顺序展示。

规则：

1. 评论创建人可删除自己的评论。

3. 删除后前端隐藏或展示“该评论已删除”。
4. 删除评论不删除其回复时，需保留占位。

**31.7 评论通知**

规则：

1. 评论中 @ 用户时，发送飞书通知。
2. 回复评论时，可通知原评论创建人。
3. 未完成飞书集成时，不发送通知，但评论仍可保存。
4. 通知中应包含仪表盘名称、图表名称、评论内容摘要和跳转链接。

**32. 仪表盘版本管理 PRD**

**32.1 发布模式**

支持两种：

1. 实时发布。
2. 版本发布。

默认：

1. 默认为实时发布。

**32.2 开启版本发布**

入口：

项目中心 - 项目信息 - 仪表盘发布类型。

规则：

1. 版本发布按项目粒度开启。
2. 开启后不可恢复为实时发布。
3. 切换前必须二次确认。

**32.3 实时发布模式**

规则：

1. 保存即发布。
2. 阅览页展示最新保存内容。
3. 订阅、监控、下载、复制均基于最新保存内容。

**32.4 版本发布模式**

规则：

1. 保存和发布拆分。
2. 点击保存只保存草稿。
3. 线上用户仍看到当前已发布版本。
4. 点击保存并发布后，草稿成为线上版本。
5. 每次发布保存一个历史版本。
6. 最多保存 3 个历史版本。
7. 超过 3 个时，发布前需要用户选择删除一个历史版本。

**32.5 历史版本模型**

interface DashboardVersion {

id: string;

dashboardId: string;

versionNo: number;

description?: string;

snapshot: DashboardSnapshot;

status: "published" | "history";

createdBy: string;

createdAt: string;

}

**32.6 保存并发布流程**

1. 用户完成编辑。
2. 点击保存并发布。
3. 弹窗输入版本描述。
4. 系统检查历史版本数量。
5. 如果已满 3 个，要求选择删除一个。
6. 点击确认。
7. 系统创建新版本。
8. 更新 currentPublishedVersionId。
9. 阅览页展示新版本。

**32.7 回滚流程**

1. 进入仪表盘编辑页。
2. 点击历史版本。
3. 弹窗展示最近 3 个历史版本。
4. 当前线上版本标记为已发布。
5. 用户可预览版本。
6. 点击回滚。
7. 编辑器内容恢复为该版本快照。
8. 用户确认无误后点击保存并发布。
9. 回滚内容成为新线上版本。

**32.8 版本描述**

规则：

1. 发布时可填写版本描述。
2. 历史版本中可修改描述。
3. 描述用于审计和版本识别。
4. 描述为空时展示“无描述”。

**32.9 预览与分享**

规则：

1. 点击预览打开预览页。
2. 预览页支持复制预览链接。
3. 他人通过链接查看当前预览内容。
4. 预览内容不影响线上版本。

**32.10 编辑缓存**

规则：

1. 编辑器每分钟将当前编辑内容写入浏览器本地缓存。
2. 浏览器崩溃或异常退出后，再次进入编辑页时弹窗提示恢复。
3. 用户选择恢复后，编辑器加载缓存内容。
4. 用户选择不恢复后，清除缓存。
5. 缓存仅用于当前用户当前浏览器。

**32.11 版本发布对功能影响**

版本发布模式下：

| **功能** | **使用最近保存草稿** | **使用当前发布版本** |
| --- | --- | --- |
| 进入仪表盘编辑页 | 是 | 否 |
| 进入图表可视化页 | 是 | 否 |
| 订阅 | 否 | 是 |
| 监控 | 否 | 是 |
| 下载 | 否 | 是 |
| 仪表盘复制 | 是 | 否 |
| 图表管理跳转可视化 | 是 | 否 |
| 监控管理跳转可视化 | 是 | 否 |
| 指标播报跳转可视化 | 是 | 否 |

未发布仪表盘访问规则：

1. 创建后从未发布的仪表盘，其他用户打开链接时展示“仪表盘尚未发布”。
2. 创建人和有编辑权限用户可进入编辑页继续编辑。

**33. 仪表盘版本、订阅、监控、下载之间的一致性规则**

**33.1 已发布内容优先原则**

面向消费侧的能力必须读取已发布版本：

1. 阅览页。
2. 订阅。
3. 监控。
4. 下载。
5. 嵌出。
6. 分享链接。

**33.2 编辑侧读取草稿原则**

面向编辑侧能力读取最近保存草稿：

1. 编辑器。
2. 图表管理跳转。
3. 仪表盘复制。
4. 替换数据集。
5. 预览链接。

**33.3 冲突处理**

如果草稿引用的图表或数据集已删除：

1. 编辑器展示异常组件。
2. 用户可删除异常组件或重新绑定。
3. 发布前必须通过完整性检查。
4. 检查失败不允许发布。

**36.2 编辑器**

7. 保存后阅览页展示最新内容。
8. 版本发布模式下，保存不影响线上，发布后才影响线上。

**36.3 筛选与交互**

1. 全局筛选器可控制多个图表。
2. 不同数据集字段映射后筛选正确。
3. 树状筛选器上下级选择逻辑正确。

6. 图表跳转到仪表盘时可传递筛选条件。
7. 图表跳转到网页时字段参数替换正确。
8. 上钻下钻面包屑返回正确。
9. 交互事件 postMessage 数据格式正确。

**36.4 阅览与协作**

1. 刷新只刷新数据，不改变筛选状态。
2. 全屏模式可进入和退出。
3. 书签能保存和恢复筛选状态。
4. 公共书签权限符合规则。
