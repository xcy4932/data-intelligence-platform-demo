**资源与资产中心 PRD**

**4.1 模块定位**

资源与资产中心用于统一管理数据平台内所有“可被使用、可被授权、可被检索、可被复用、可被治理”的对象。该中心既管理底层技术资源，也管理面向业务使用的数据资产。

在本系统中，需要明确区分两个概念：

**4.1.1 资源**

资源是系统中的底层对象或运行对象，偏技术视角，通常由平台、项目、任务、连接、文件、模型、接口等产生。

资源包括但不限于：

1. 数据源连接资源：MySQL、PostgreSQL、ClickHouse、Hive、Doris、API、文件上传、对象存储等。
2. 数据表资源：物理表、视图表、临时表、外部表。
3. 数据集资源：可视化建模生成的数据集、SQL 查询保存的数据集、API 数据集。
4. 分析资源：事件分析、留存分析、漏斗分析、路径分析、LTV 分析、热力图分析等保存分析。
5. 看板资源：仪表盘、数字大屏、数据概览。
6. 文件资源：图片、Excel、CSV、PDF、JSON、附件、模板文件。
7. 任务资源：同步任务、加工任务、调度任务、导出任务、标签计算任务。
8. API 资源：数据服务 API、Webhook、外部回调接口。
9. 模型资源：预测模型、分群模型、标签模型、规则模型。

**4.1.2 资产**

资产是经过登记、描述、授权、治理后，可以被组织成员理解和使用的资源，偏业务视角。

一个资源不一定是资产。例如临时查询结果、系统中间表、失败任务日志等可以是资源，但不一定进入资产目录。

一个资产必须具备以下信息：

1. 资产名称。
2. 资产类型。
3. 所属项目或空间。
4. 资产负责人。
5. 可见范围。
6. 权限策略。
7. 业务描述。
8. 技术来源。
9. 生命周期状态。
10. 最近更新时间。
11. 使用统计。
12. 变更记录。

资源与资产中心的核心目标是：

1. 让用户能快速找到已有数据、看板、报表、分析、文件、接口等对象。
2. 让管理员能统一治理资产的归属、状态、权限、标签、目录和生命周期。
3. 让业务用户能通过目录、搜索、标签、收藏、最近使用等方式复用已有资产。
4. 让开发和管理人员能追踪资产来源、使用情况、权限申请、变更历史和下线影响。

**4.3 全局通用规则**

**4.3.1 资产唯一标识规则**

每个资产创建后，系统生成唯一资产 ID。

字段规则：

assetId: string

生成规则：

AST + yyyyMMddHHmmss + 6位随机码

示例：

AST20260528163122039281

资产 ID 一旦生成，不允许修改。

即使资产名称变更，资产 ID 也不变。

如果资产被删除后恢复，仍使用原资产 ID。

如果资产被彻底物理删除，原资产 ID 不允许重新使用。

**4.3.2 资产名称规则**

资产名称字段：

assetName: string

校验规则：

1. 必填。
2. 长度为 2 到 80 个字符。
3. 支持中文、英文、数字、下划线、中划线、空格。
4. 不允许只输入空格。
5. 同一项目空间内，同一资产类型下名称不可重复。
6. 不同项目空间可以存在同名资产。
7. 不同资产类型可以存在同名资产。

当用户输入重复名称时，名称输入框下方显示：

当前项目下已存在同名资产，请修改资产名称

保存按钮保持禁用。

**4.3.4 资产生命周期状态**

资产状态包括：

type AssetStatus =

| "DRAFT"

| "ACTIVE"

| "LOCKED"

| "OFFLINE\_PENDING"

| "OFFLINE"

| "DELETED";

页面展示规则：

| **状态** | **展示名称** | **说明** |
| --- | --- | --- |
| DRAFT | 草稿 | 已创建但未发布，不进入全部资产目录 |
| ACTIVE | 已发布 | 可被检索、申请、授权、使用 |
| LOCKED | 已锁定 | 暂停编辑，仍可查看 |
| OFFLINE\_PENDING | 下线审批中 | 已发起下线，等待审批 |
| OFFLINE | 已下线 | 不允许新增使用，只保留历史引用 |
| DELETED | 已删除 | 进入回收站 |

状态流转规则：

草稿 -> 已发布

已发布 -> 已锁定

已锁定 -> 已发布

已发布 -> 下线审批中

下线审批中 -> 已下线

下线审批中 -> 已发布

已下线 -> 已发布

已发布 -> 已删除

草稿 -> 已删除

已下线 -> 已删除

已删除 -> 恢复到删除前状态

不允许的状态流转：

1. 已删除不能直接发布。
2. 下线审批中不能编辑核心信息。
3. 已下线不能直接进入下线审批中。
4. 已锁定不能删除，必须先解锁。

**4.3.5 可见范围规则**

资产可见范围包括：

type VisibilityScope =

| "PRIVATE"

| "PROJECT"

| "SPACE"

| "ORG";

展示名称：

| **枚举值** | **页面名称** | **可见范围** |
| --- | --- | --- |
| PRIVATE | 仅自己可见 | 仅创建人、负责人、管理员可见 |
| PROJECT | 项目内可见 | 当前项目成员可见 |
| SPACE | 空间内可见 | 当前空间成员可见 |
| ORG | 组织内可见 | 当前组织成员可见 |

默认值：

1. 个人创建的保存分析、文件、临时数据集，默认仅自己可见。
2. 项目内创建的数据集、仪表盘、任务，默认项目内可见。
3. 管理员登记的数据源、公共数据表，默认空间内可见。
4. 组织级资产由组织管理员设置，默认组织内可见。

可见范围只控制是否能看到资产基础信息，不等于拥有使用权限。

用户能看到资产，但没有使用权限时：

1. 列表可见。
2. 详情页可见基础信息。
3. 使用按钮置灰。
4. 显示“申请权限”按钮。

**4.3.6 操作权限规则**

资产操作权限分为：

type AssetPermission =

| "VIEW"

| "USE"

| "EDIT"

| "MANAGE"

| "DELETE"

| "AUTHORIZE";

权限含义：

| **权限** | **含义** |
| --- | --- |
| VIEW | 查看资产基础信息 |
| USE | 在分析、建模、看板、任务中使用资产 |
| EDIT | 编辑资产名称、描述、标签、目录、业务信息 |
| MANAGE | 管理负责人、状态、生命周期、版本、下线 |
| DELETE | 删除资产 |
| AUTHORIZE | 给其他用户或角色授权 |

按钮展示规则：

1. 无 VIEW 权限：资产不出现在列表中。
2. 有 VIEW 无 USE：展示“申请权限”，隐藏或禁用“使用”。
3. 有 USE 无 EDIT：可使用，不可编辑。
4. 有 EDIT 无 MANAGE：可编辑基础信息，不可变更状态和负责人。
5. 有 MANAGE：可执行发布、下线、锁定、负责人变更。
6. 有 DELETE：可删除。
7. 有 AUTHORIZE：可进入授权管理。

**4.3.7 资产负责人规则**

每个资产必须有且只能有一个主负责人。

字段：

ownerUserId: string

可选维护人：

maintainerUserIds: string[]

负责人拥有默认权限：

1. VIEW
2. USE
3. EDIT
4. MANAGE
5. DELETE
6. AUTHORIZE

维护人默认拥有：

1. VIEW
2. USE
3. EDIT
4. MANAGE

维护人默认不拥有 DELETE 和 AUTHORIZE，除非额外授权。

负责人离职、禁用或移出组织时，资产进入“负责人异常”状态。

负责人异常状态下：

1. 资产仍可被有权限用户使用。
2. 资产列表显示红色提示“负责人异常”。
3. 管理员进入详情页时顶部显示提示条：

当前资产负责人已不可用，请尽快转交负责人，否则资产下线、授权、删除等流程可能无法正常处理。

提示条按钮：

1. 转交负责人
2. 暂不处理

点击“转交负责人”后打开负责人转交弹窗。

**4.3.9 全局搜索规则**

搜索框支持搜索以下字段：

1. 资产名称。
2. 资产 ID。
3. 资产描述。
4. 负责人姓名。
5. 负责人邮箱。
6. 标签名称。
7. 目录名称。
8. 技术名称，例如表名、API 路径、文件名。

搜索触发规则：

1. 输入关键词后 300ms 防抖查询。
2. 按 Enter 立即查询。
3. 点击搜索图标立即查询。
4. 清空搜索框后恢复默认列表。
5. 关键词前后空格自动 trim。
6. 空字符串不触发搜索。

搜索结果高亮规则：

1. 命中的资产名称关键词高亮。
2. 命中的描述不在列表中高亮，仅详情页展示。
3. 多关键词按整体字符串搜索，不做分词搜索。
4. 后续可以扩展分词，但当前版本不做。

**4.3.10 全局筛选规则**

所有资产列表支持以下筛选项：

1. 资产类型。

3. 所属空间。
4. 所属项目。
5. 所属目录。
6. 负责人。
7. 标签。
8. 可见范围。
9. 更新时间。
10. 最近使用时间。
11. 是否收藏。
12. 是否有权限。
13. 是否负责人异常。

筛选按钮包括：

1. 查询。
2. 重置。
3. 收起筛选。
4. 展开筛选。

筛选交互规则：

1. 默认展示第一行筛选项：资产类型、状态、所属项目、负责人。
2. 点击“展开筛选”展示全部筛选项。
3. 点击“收起筛选”只保留第一行筛选项。
4. 点击“查询”后刷新列表。
5. 点击“重置”后清空所有筛选条件并刷新列表。
6. 重置不清空搜索关键词，搜索关键词需要用户在搜索框内清空。
7. 筛选与搜索是 AND 关系。
8. 多选筛选项内部是 OR 关系。

示例：

资产类型 = 数据集 或 仪表盘

状态 = 已发布

负责人 = 张三

含义为：

(type in [DATASET, DASHBOARD]) AND status = ACTIVE AND owner = 张三

**4.3.11 全局批量操作规则**

资产列表支持勾选。

勾选规则：

1. 每页表格第一列为复选框。
2. 表头复选框只选择当前页。
3. 跨页选择需要点击“选择全部符合条件的资产”。
4. 已选择数量在表格顶部显示。
5. 用户切换筛选条件后，已选择项自动清空。
6. 用户切换分页后，当前已选项保留。
7. 用户刷新页面后，已选项清空。

批量操作包括：

1. 批量移动目录。
2. 批量添加标签。
3. 批量移除标签。
4. 批量修改负责人。
5. 批量修改可见范围。
6. 批量申请权限。
7. 批量导出资产清单。
8. 批量下线。
9. 批量删除。

批量操作权限规则：

1. 只对当前用户有权限操作的资产生效。
2. 如果部分资产无权限，弹窗中显示不可操作资产数量。
3. 用户点击确认后，只处理可操作资产。
4. 处理完成后显示成功、失败、跳过数量。
5. 失败资产可下载失败明细。

1. 新建子目录。

5. 删除。
6. 查看资产。

**新建一级目录**

点击后打开弹窗。

字段：

1. 目录名称。
2. 目录编码。
3. 目录描述。
4. 排序号。
5. 可见范围。

目录名称规则：

1. 必填。
2. 同级目录下名称不可重复。
3. 长度 2 到 40 个字符。

目录编码规则：

1. 必填。
2. 同组织内唯一。
3. 仅支持英文、数字、下划线。
4. 创建后不允许修改。

**新建子目录**

规则：

1. 当前目录层级小于 5 时允许创建。
2. 当前目录被禁用时不允许创建。
3. 当前用户必须有目录管理权限。

如果超过 5 级，提示：

目录最多支持 5 级，不能继续创建子目录

**重命名**

规则：

1. 只修改目录名称，不修改目录编码。
2. 同级不可重名。
3. 修改后资产归属不变。
4. 生成目录变更记录。

**移动**

点击后打开目录移动弹窗。

规则：

1. 不能移动到自己下面。
2. 不能移动到自己的子孙目录下面。
3. 不能移动到禁用目录下面。
4. 移动后子目录和资产一起移动。
5. 移动后重新计算目录层级。
6. 如果移动后超过 5 级，禁止移动。

**启用 / 禁用**

禁用目录规则：

1. 禁用后目录不可被新资产选择。
2. 禁用后目录下已有资产不受影响。
3. 禁用后目录仍在资产列表中展示。
4. 禁用父目录时，子目录一起变为不可选。
5. 禁用需要二次确认。

确认文案：

禁用后，该目录及其子目录不能再被新资产选择，已有资产不受影响。确认禁用吗？

**删除目录**

删除规则：

1. 目录下没有子目录且没有资产时才允许删除。
2. 如果存在子目录，提示：

该目录下存在子目录，不能删除

1. 如果存在资产，提示：

该目录下存在资产，请先移动资产后再删除

1. 删除需要二次确认。
2. 删除后不可恢复。

**4.24 验收标准**

**4.24.1 首页验收**

1. 用户进入首页后能看到资产概览、快捷入口、最近使用、收藏、待处理、热门资产和风险提醒。
2. 点击概览卡片能跳转到正确列表并携带筛选条件。
3. 最近使用能按时间倒序展示。
4. 收藏资产能取消收藏。
5. 无权限入口必须置灰并提示原因。

**4.24.2 全部资产验收**

1. 支持搜索、筛选、排序、分页。
2. 搜索关键词能命中资产名称、ID、描述、负责人、标签和技术名称。
3. 筛选条件组合逻辑正确。
4. 用户只能看到有 VIEW 权限的资产。
5. 没有 USE 权限时必须显示申请权限，而不是使用。
6. 批量操作只能处理用户有权限的资产。
7. 删除、下线、转交、锁定必须二次确认。

**4.24.3 资产详情验收**

1. 详情页能展示资产基础、业务、技术、权限、血缘、统计和变更记录。
2. 不同资产类型展示不同内容 Tab。
3. 有权限用户可以编辑，无权限用户不能编辑。
4. 变更后必须产生变更记录。
5. 使用按钮根据资产类型跳转到正确使用入口。
6. 已下线资产不可继续使用。

**4.24.4 目录管理验收**

1. 支持新建、编辑、移动、禁用、删除目录。
2. 同级目录名称不可重复。
3. 目录最多支持 5 级。
4. 目录下存在子目录或资产时不可删除。
5. 禁用目录后不能被新资产选择，但已有资产不受影响。

**4.24.5 标签管理验收**

1. 支持新建、编辑、合并、禁用、删除自定义标签。
2. 系统标签不允许删除。
3. 标签删除后资产关联关系同步移除。
4. 标签合并后资产不重复关联目标标签。
5. 标签可用于资产筛选和搜索。

**4.24.6 权限申请验收**

1. 无 USE 权限用户可以申请权限。
2. 已拥有权限时不能重复申请。
3. 已存在相同待审批申请时不能重复提交。
4. 审批同意后权限立即生效。
5. 审批拒绝必须填写原因。
6. 申请人、审批人都能看到申请状态变化。
7. 批量申请能正确处理可申请和不可申请资产。

**4.24.7 血缘分析验收**

1. 能按资产查询上游、下游和上下游血缘。
2. 能设置血缘深度。
3. 异常节点必须高亮。
4. 点击节点能查看资产摘要。
5. 点击影响分析能看到下游影响范围。
6. 用户无权限的节点不能进入详情。

**4.24.8 回收站验收**

1. 删除资产后进入回收站。
2. 回收站展示删除人、删除时间、自动清理时间。
3. 可恢复资产。
4. 恢复时处理目录失效、名称冲突、负责人失效问题。
5. 彻底删除必须输入资产名称确认。
6. 彻底删除后不可恢复。

**4.25 非功能要求**

**4.25.1 性能要求**

1. 全部资产列表首屏加载时间不超过 2 秒。
2. 搜索响应时间不超过 1 秒。
3. 筛选响应时间不超过 1.5 秒。
4. 资产详情加载时间不超过 2 秒。
5. 血缘图 200 个节点以内加载时间不超过 3 秒。
6. 批量导入 5000 行以内必须异步处理，不阻塞页面。
7. 列表分页默认每页 20 条，支持 20、50、100 条切换。

**4.25.2 安全要求**

1. 所有资产查询必须经过权限过滤。
2. 前端隐藏按钮不能作为权限判断依据，后端必须再次校验。
3. 敏感字段预览必须走脱敏规则。
4. 文件下载必须记录审计日志。
5. API 调用文档中的密钥不得明文展示。
6. 权限扩大、永久授权、组织范围可见必须二次确认。
7. 删除、彻底删除、下线必须记录审计日志。

**4.25.3 可用性要求**

1. 所有列表支持空状态。
2. 所有异步操作支持 loading 状态。
3. 所有失败操作必须给出明确失败原因。
4. 批量操作必须展示成功、失败、跳过数量。
5. 长任务必须进入后台任务中心。
6. 表单离开前必须提示未保存内容。
7. 重要操作必须二次确认。

**4.26 本模块与其他中心的关系**

**4.26.1 与组织与身份中心**

资源与资产中心使用组织与身份中心提供的：

1. 用户。
2. 部门。
3. 角色。
4. 用户组。
5. 组织。
6. 空间成员。
7. 项目成员。

负责人、维护人、审批人、授权对象均来自组织与身份中心。

**4.26.2 与项目与空间中心**

资产必须归属到某个空间。

部分资产还必须归属到某个项目。

规则：

1. 数据源可以归属空间，也可以归属项目。
2. 数据集、分析、仪表盘、任务默认归属项目。
3. 组织级模板可以不归属项目，但必须归属空间或组织。
4. 项目归档后，项目内资产进入只读状态。
5. 项目删除前必须处理项目下资产归属。

**4.26.3 与权限与策略中心**

资源与资产中心不直接决定最终权限，而是调用权限与策略中心进行鉴权。

资源与资产中心负责：

1. 展示权限。
2. 发起申请。
3. 展示授权记录。
4. 展示权限风险。
5. 调用权限接口执行授权、撤销、审批。

权限与策略中心负责：

1. 判断用户是否有权限。
2. 存储权限策略。
3. 执行策略计算。
4. 输出鉴权结果。
5. 返回拒绝原因。

**4.26.4 与数据开发、分析、看板模块**

数据开发、分析、看板模块产生资源后，需要向资源与资产中心注册资源。

注册后：

1. 可以选择是否登记为资产。
2. 被登记为资产后进入资产目录。
3. 后续编辑、删除、下线需要同步资产状态。
4. 资产被删除或下线时，需要通知下游模块处理引用。
