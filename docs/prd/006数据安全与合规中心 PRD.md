**数据安全与合规中心 PRD**

**5.1 模块定位**

数据安全与合规中心用于统一管理数据平台内所有与数据安全、敏感识别、分级分类、脱敏、导出管控、访问审计、风险告警、合规检查、数据留存与销毁相关的能力。

该中心不是普通权限管理模块。权限与策略中心负责“谁能访问什么”，数据安全与合规中心负责“数据本身是否敏感、访问是否安全、使用是否合规、导出是否受控、风险是否被发现、审计是否可追溯”。

核心目标：

1. 对数据源、数据表、字段、数据集、报表、看板、文件、API 等资产进行安全分级。
2. 自动识别手机号、身份证号、邮箱、银行卡、地址、姓名、设备号、用户 ID、订单号等敏感字段。
3. 对敏感字段设置脱敏规则、访问策略、下载策略、水印策略和审计策略。
4. 对数据查询、预览、下载、导出、API 调用、看板查看等行为进行安全审计。
5. 对异常访问、批量下载、越权尝试、高频查询、敏感数据暴露等风险进行告警。
6. 支持合规检查、合规报告生成、问题整改和留存销毁管理。
7. 为资源与资产中心、权限与策略中心、数据开发、分析、看板、数据服务、触达营销等模块提供统一安全能力。

对象优先级规则：

1. 字段级策略优先级最高。
2. 表级策略次之。
3. 数据集级策略次之。
4. 资产级策略次之。
5. 项目级策略次之。
6. 空间级策略次之。
7. 组织级默认策略优先级最低。

当多个策略同时命中同一对象时，系统按照“更严格优先”原则执行。

更严格优先规则：

1. 禁止访问优先于允许访问。
2. 强脱敏优先于弱脱敏。
3. 禁止下载优先于允许下载。
4. 需要审批优先于无需审批。
5. 强水印优先于普通水印。
6. 永久审计优先于普通审计。

**5.3.2 数据分级枚举**

数据安全等级采用 5 级：

type DataSecurityLevel =

| "L1\_PUBLIC"

| "L2\_INTERNAL"

| "L3\_SENSITIVE"

| "L4\_HIGHLY\_SENSITIVE"

| "L5\_CRITICAL";

页面展示名称：

| **枚举值** | **展示名称** | **含义** |
| --- | --- | --- |
| L1\_PUBLIC | 公开数据 | 对组织公开无明显风险的数据 |
| L2\_INTERNAL | 内部数据 | 仅组织内部使用的数据 |
| L3\_SENSITIVE | 敏感数据 | 包含个人信息、业务敏感信息或经营数据 |
| L4\_HIGHLY\_SENSITIVE | 高敏数据 | 泄露后可能造成严重业务、法律或个人权益风险 |
| L5\_CRITICAL | 核心机密 | 涉及核心商业秘密、密钥、支付、风控、身份等最高敏感数据 |

默认规则：

1. 新建数据资产默认等级为 L2\_INTERNAL。
2. 文件上传默认等级为 L2\_INTERNAL。
3. 识别出敏感字段后，所在字段等级自动调整为 L3\_SENSITIVE。
4. 如果识别出身份证号、银行卡号、支付账号、精确地址、健康信息、密钥，字段等级自动调整为 L4\_HIGHLY\_SENSITIVE。
5. 如果识别出访问密钥、数据库密码、加密私钥、生产支付凭证，等级自动调整为 L5\_CRITICAL。
6. 用户可手动提高等级。
7. 用户不可手动将系统识别的高敏字段降低到 L2 以下，除非走例外审批。

**5.3.4 策略状态枚举**

type PolicyStatus =

| "DRAFT"

| "ACTIVE"

| "DISABLED"

| "EXPIRED"

| "DELETED";

状态含义：

| **状态** | **页面展示** | **说明** |
| --- | --- | --- |
| DRAFT | 草稿 | 已创建但未生效 |
| ACTIVE | 已启用 | 策略正在生效 |
| DISABLED | 已停用 | 策略暂不生效 |
| EXPIRED | 已过期 | 超过有效期自动失效 |
| DELETED | 已删除 | 逻辑删除，不再展示在默认列表 |

状态流转规则：

草稿 -> 已启用

草稿 -> 已删除

已启用 -> 已停用

已启用 -> 已过期

已启用 -> 已删除

已停用 -> 已启用

已停用 -> 已删除

已过期 -> 已启用

已过期 -> 已删除

不允许：

1. 已删除策略恢复为启用。
2. 已删除策略再次编辑。
3. 已启用策略直接修改核心匹配条件，必须创建新版本。
4. 已启用策略修改名称、描述、通知人时可直接保存，不生成新版本。

**5.3.5 风险等级枚举**

type RiskLevel = "LOW" | "MEDIUM" | "HIGH" | "CRITICAL";

展示规则：

| **风险等级** | **展示名称** | **处理要求** |
| --- | --- | --- |
| LOW | 低风险 | 可记录，不强制处理 |
| MEDIUM | 中风险 | 需要负责人确认 |
| HIGH | 高风险 | 必须在规定时间内处理 |
| CRITICAL | 严重风险 | 立即告警并进入安全事件 |

默认处理时限：

| **等级** | **默认处理时限** |
| --- | --- |
| LOW | 7 天 |
| MEDIUM | 3 天 |
| HIGH | 24 小时 |
| CRITICAL | 2 小时 |

超时后：

1. 风险状态变为“已逾期”。
2. 通知风险负责人。
3. 通知安全管理员。
4. 如果超过处理时限 2 倍仍未处理，升级通知组织管理员。

**5.23 与其他中心的关系**

**5.23.1 与资源与资产中心**

资源与资产中心提供：

1. 资产基础信息。
2. 资产类型。
3. 资产负责人。
4. 资产目录。
5. 资产标签。
6. 血缘关系。
7. 使用统计。

数据安全与合规中心向资源与资产中心回写：

1. 数据安全等级。
2. 敏感类型。
3. 脱敏状态。
4. 风险标识。
5. 合规状态。
6. 留存状态。

资产详情页需要展示来自本中心的安全信息。

**5.23.2 与权限与策略中心**

权限与策略中心负责基础访问控制。

数据安全与合规中心负责安全附加控制。

完整鉴权链路：

用户请求数据

-> 权限与策略中心判断是否有基础权限

-> 数据安全与合规中心判断是否命中安全策略

-> 决定允许、拒绝、脱敏、审批、告警、审计

如果基础权限不通过，直接拒绝。

如果基础权限通过但安全策略拒绝，仍然拒绝。

**5.23.3 与数据分析和看板模块**

数据分析、仪表盘、数字大屏需要调用：

1. 字段脱敏接口。
2. 水印渲染接口。
3. 数据访问安全策略接口。
4. 审计日志写入接口。
5. 导出审批接口。

任何分析结果下载都必须先经过导出与下载管控。

**5.23.4 与数据服务 API**

数据服务 API 在响应前必须调用：

1. 访问安全策略判断。
2. 脱敏策略判断。
3. 调用审计写入。
4. 高频调用风险检测。
5. 外部域名白名单判断。

**5.27 验收标准**

**5.27.1 首页验收**

1. 首页能按组织、空间、项目切换安全范围。
2. 切换范围后，全部指标、图表、风险和待办同步刷新。
3. 指标卡点击后能跳转到对应页面并携带筛选条件。
4. 风险列表只展示当前用户有权限查看的风险。
5. 安全扫描按钮能创建扫描任务。
6. 生成报告按钮能创建报告任务。

**5.27.2 数据分级分类验收**

1. 能查看资产、表、字段的安全等级。
2. 能手动调整安全等级。
3. L4、L5 降级必须触发例外审批。
4. 能批量分级，但不能默认覆盖人工确认结果。
5. 分级规则能新建、测试、启用、停用、删除。
6. 规则测试不会修改真实数据。

**5.27.3 敏感识别验收**

1. 能创建扫描任务。
2. 能选择扫描范围、识别规则和扫描策略。
3. 能运行、暂停、继续、停止扫描任务。
4. 能查看识别结果。
5. 样例值默认脱敏展示。
6. 查看明文必须二次确认并写入审计日志。
7. 能确认敏感、标记误报、配置脱敏。

**5.27.4 脱敏规则验收**

1. 能创建不同类型脱敏规则。
2. 脱敏规则能测试。
3. 自定义脚本必须测试成功后才能启用。
4. L4、L5 字段不能使用弱脱敏策略。
5. 脱敏策略能按对象、场景、用户范围生效。
6. 强制脱敏策略不能被普通用户绕过。

**5.27.5 水印策略验收**

1. 能创建水印策略。
2. 能配置水印内容变量。
3. 能预览水印效果。
4. L3 以上数据默认启用水印。
5. L4 以上数据默认启用可见水印和隐形水印。
6. 导出无水印必须走例外审批。

**5.27.6 导出与下载管控验收**

1. 导出前必须命中导出策略判断。
2. L4、L5 数据默认审批。
3. 禁止导出的对象不能提交导出申请。
4. 审批人能要求脱敏、减少字段、拒绝或同意。
5. 导出文件生成过程异步执行。
6. 下载行为必须写入审计日志。
7. 导出文件过期后不可下载。

**5.27.7 审计日志验收**

1. 能按时间、用户、对象、操作类型查询审计日志。
2. 审计日志不可编辑、不可删除。
3. 敏感参数默认脱敏。
4. 查看敏感参数必须二次确认。
5. 导出审计日志必须填写原因。
6. 导出审计日志本身必须再次写入审计日志。

**5.27.8 风险告警验收**

1. 系统能生成风险。
2. 风险能按等级、类型、状态筛选。
3. LOW、MEDIUM 可忽略。
4. HIGH、CRITICAL 不可直接忽略。
5. 风险能分派给处理人。
6. 风险处理必须填写处理说明。
7. 严重风险能升级为安全事件。

**5.27.9 安全事件验收**

1. 能手动创建事件。
2. 风险能升级为事件。
3. 事件状态必须按流程流转。
4. 关闭事件必须填写根因、影响范围、处理措施和预防措施。
5. 关闭后事件不可编辑，只能追加备注。
6. 能生成事件报告。

**5.27.10 留存与销毁验收**

1. 能配置留存策略。
2. 到期数据能进入到期列表。
3. 支持延期、销毁、冻结。
4. 已冻结对象不能销毁。
5. 销毁必须审批。
6. 执行销毁必须输入对象名称确认。
7. 销毁成功后生成销毁证明。

**5.28 非功能要求**

**5.28.1 性能要求**

1. 首页加载时间不超过 2 秒。
2. 分级分类列表查询不超过 2 秒。
3. 审计日志普通查询不超过 3 秒。
4. 审计日志大范围查询必须异步导出。
5. 脱敏策略判断接口 P95 不超过 100ms。
6. 访问安全策略判断接口 P95 不超过 100ms。
7. 水印渲染不能使页面首屏加载增加超过 500ms。
8. 扫描任务必须异步执行，不阻塞页面。
9. 单次扫描任务失败不能影响其他任务执行。

**5.28.2 安全要求**

1. 所有安全配置接口必须后端鉴权。
2. 所有敏感明文查看必须二次确认。
3. 所有敏感明文查看必须审计。
4. 所有导出下载必须审计。
5. 所有策略停用必须记录原因。
6. 所有安全等级降低必须记录原因。
7. L4、L5 数据的例外必须审批。
8. 导出文件必须有有效期。
9. 导出文件下载链接必须带一次性 token。
10. 审计日志不允许物理删除。
11. 安全配置变更记录不允许编辑。
12. 密钥、盐值、密码不允许前端明文展示。

**5.28.3 可用性要求**

1. 所有列表支持搜索、筛选、分页、排序。
2. 所有长任务支持进度展示。
3. 所有失败任务支持查看失败原因。
4. 所有批量处理支持成功、失败、跳过统计。
5. 所有危险操作必须二次确认。
6. 所有表单离开前必须提示未保存内容。
7. 所有空状态必须提供下一步操作入口。
8. 所有审批状态变化必须通知相关人员。
9. 所有风险必须有明确负责人。
10. 所有合规问题必须有整改入口。
