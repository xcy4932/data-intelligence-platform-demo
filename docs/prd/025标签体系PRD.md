**标签体系PRD**

**1. 文档目标与边界**

本 PRD 用于定义 “标签体系”模块。文档目标不是罗列功能，而是把每个页面、每个入口、每个按钮、每个状态变化、每类标签创建逻辑、每类校验规则、每类任务运行逻辑写清楚，使前端、后端、调度、权限、测试和 Codex 均可据此直接拆分开发。

标签体系模块的核心目标是：让运营、数据分析、标签管理员基于用户属性、行为、明细数据、已有标签、SQL、模型或人工录入等方式，创建可用于用户分群、画像洞察、生命周期分析、营销触达、外部系统调用的用户标签，并支持标签的分类管理、上下架、更新、授权、血缘、运行任务、元信息和价值评估。

本 PRD 覆盖以下范围：

1. 标签体系首页。
2. 标签体系树管理。
3. 标签创建入口与所有标签类型创建流程。
4. 标签详情页。
5. 标签管理页。
6. 标签上下架。
7. 标签更新策略。
8. 标签模板。
9. 标签元信息管理。
10. 实时标签构建能力。
11. 标签任务、权限、血缘、价值评估、历史操作记录。

**2. 核心业务对象**

**2.1 标签**

标签是基于主体 ID 生成的用户标识。一个标签由元信息、计算规则、调度配置、结果存储、权限、状态和运行记录组成。

每个标签必须属于一个主体，例如用户主体、会员主体、车辆主体等。标签计算结果以主体 ID 为主键，输出标签值。

标签值支持以下类型：

| **类型** | **说明** | **典型示例** |
| --- | --- | --- |
| 文本型 | 标签值为单个文本 | 城市、性别、会员等级 |
| 整数型 | 标签值为整数 | 年龄、浏览次数、到店次数 |
| 小数型 | 标签值为小数 | 消费金额、转化率、授信使用率 |
| 多值文本型 | 一个主体可拥有多个文本值 | 兴趣爱好、偏好品类、喜爱话题 |
| 多值数值型 | 一个主体可拥有多个数值 | 近 3 次消费金额 |
| 多值小数型 | 一个主体可拥有多个小数 | 近 7 日折扣率 |
| 日期型 | 精确到日期 | 生日、注册日期 |
| 时间日期型 | 精确到时分秒 | 最近登录时间、订单支付时间 |

**2.2 标签状态**

标签状态用于控制标签是否可计算、是否可被下游使用、是否可恢复。

| **状态** | **含义** | **是否可编辑** | **是否可运行** | **是否可下游使用** | **是否可恢复** |
| --- | --- | --- | --- | --- | --- |
| 草稿态 | 仅保存元信息与规则，未正式上架 | 是 | 否 | 否 | 是 |
| 已上架 | 正常计算和更新，可用于下游 | 是 | 是 | 是 | 是 |
| 已下架 | 暂停使用，任务中断，不再供下游调用 | 是 | 否 | 否 | 是 |
| 已删除 | 元信息清除，不可用，不可恢复 | 否 | 否 | 否 | 否 |

状态流转规则：

1. 企业开启“标签上下架流程”时，新建标签默认进入草稿态，必须手动上架后才能计算和使用。
2. 企业关闭“标签上下架流程”时，新建标签创建完成后直接进入已上架状态。
3. 已上架标签可下架。下架后当前标签不再更新，下游依赖该标签的标签、分群、分析任务应同步标记为“上游不可用”或“等待上游恢复”。
4. 已下架标签可重新上架。重新上架后，从重新上架时刻开始恢复更新，下游依赖任务允许恢复运行。
5. 删除标签不可恢复。删除前必须弹窗展示风险，明确说明下游依赖将中断。

**2.3 标签更新方式**

标签支持手动更新、定时更新、实时更新三类更新方式。

| **更新方式** | **说明** | **触发条件** | **是否消耗例行资源** | **依赖关系** |
| --- | --- | --- | --- | --- |
| 手动更新 | 用户手动选择日期范围运行任务 | 点击更新、批量运行、运行记录页重跑 | 通常消耗手动运行资源 | 完全独立，不因上游自动触发 |
| 定时更新 | 按天、周、月周期执行 | 调度时间到达，且上游数据就绪 | 是 | 与数据源依赖，不与手动更新上游标签建立依赖 |
| 实时更新 | 基于实时数据源增量更新标签 | 实时事件进入流式处理链路 | 使用实时资源限制 | 依赖实时数据源和实时规则能力 |

**2.4 标签更新取值逻辑**

标签计算时，当某主体在最新计算周期未命中任何标签值，系统必须按用户配置的取值逻辑处理。

| **取值逻辑** | **计算规则** | **示例** |
| --- | --- | --- |
| 计算为空时保留空缺 | 每次只保留最新周期计算结果。历史有值但最新无值，则最新结果为空 | 昨日会员等级=金卡，今日不满足任何规则，则今日为空 |
| 计算为空时保留历史值 | 若最新周期为空，则沿用该主体上一日或上一分区最近一次非空结果；若最新周期有值，则覆盖旧值 | 昨日会员等级=金卡，今日无结果，则今日仍为金卡；今日变为银卡，则更新为银卡 |

实现要求：

1. 取值逻辑必须写入标签版本配置，不能只存在前端。
2. 定时任务执行时，计算服务必须读取该字段决定是否进行历史值回填。
3. 对按周、按月调度暂不支持“计算为空时保留历史值”的场景，前端必须在用户选择该组合时阻止提交，并提示“当前更新取值逻辑暂不支持周/月调度，请改为按天调度或选择计算为空时保留空缺”。

**2.5 计算结果存储保留策略 TTL**

定时更新标签可配置计算结果历史数据保存时长。

| **策略** | **规则** |
| --- | --- |
| 与系统一致 | 使用集团配置中的标签系统表 TTL，默认 32 天。该值对新部署客户生效；老客户可保持长期有效策略 |
| 指定时长 | 用户在单标签内指定保存时长，优先级高于集团 TTL |

联动规则：

1. 当执行频率为“天”时，TTL 单位可选“天”。
2. 当执行频率为“周”时，TTL 单位可选“周”。
3. 当执行频率为“月”时，TTL 单位可选“月”。
4. 超出 TTL 的历史分区由清理任务在次日删除。若标签计算异常或清理任务延迟，允许短时间展示超过 TTL 的历史数据，但下一次清理必须补偿删除。
5. 手动更新标签不展示 TTL 配置；实时标签按实时服务存储策略处理。

**3.3 权限判定原则**

1. 页面入口必须先判定模块权限，再判定资源权限。
2. 用户无模块权限时，不展示入口；若通过 URL 访问，应返回无权限页面。
3. 用户有模块权限但无资源权限时，列表不展示无权限标签。
4. 搜索结果只返回有查看权限的标签。
5. 标签覆盖人数、有效覆盖率等全量统计不受行权限影响；标签值分布、历史分布、个体明细跳转应受行权限影响。
6. SQL 标签创建时，可用库表对项目内用户可见；标签使用时必须按单个用户行权限返回可见结果。

**4. 全局信息架构**

顶部导航路径：

标签体系模块包含以下一级页面：

1. 标签体系。
2. 标签管理。
3. 标签模板。

标签体系页面进入后，默认展示左侧标签体系树与右侧标签列表。用户可从该页面创建、搜索、查看、复制、移动、编辑、删除、上架、下架标签。

标签管理页面以任务视角管理标签，重点展示运行状态、上下架状态、创建方式、标签值类型、更新时间、运行耗时、资源管理员等信息。

标签模板页面用于启用行业预置标签模板，基于表模板映射后的数据快速创建标签。

**5. 标签体系首页 PRD**

**5.1 页面入口**

入口：左侧导航栏选择“用户洞察 > 标签管理”。

进入条件：用户必须拥有“查看标签体系”权限。

**5.2 页面布局**

页面分为三块：

1. 顶部操作区。
2. 左侧标签体系树。
3. 右侧标签列表与标签卡片区。

顶部操作区包含：

| **控件** | **类型** | **说明** |
| --- | --- | --- |
| 搜索框 | 输入框 | 支持按标签名称模糊搜索 |
| 新建标签 | 主按钮/下拉按钮 | 点击后展示可创建的标签类型 |
| 标签模板 | 按钮 | 跳转标签模板页面 |
| 刷新 | 图标按钮 | 刷新当前树与列表数据 |

左侧标签体系树展示：

1. 系统根节点。
2. 用户自建目录。
3. 默认“未分类”目录。
4. 目录下的标签数量。
5. 鼠标悬停目录时展示更多操作按钮。

右侧标签列表展示：

| **字段** | **说明** |
| --- | --- |
| 标签名称 | 点击进入标签详情页 |
| 标签 ID | 系统生成，不可编辑 |
| 创建方式 | 规则标签、统计标签、SQL 标签等 |
| 标签值类型 | 文本型、数值型、日期型等 |
| 上下架状态 | 草稿、已上架、已下架 |
| 更新方式 | 手动、定时、实时 |
| 更新频率 | 天、周、月或实时 |
| 最新数据时间 | 最近一次标签结果分区时间 |
| 创建人 | 创建者 |
| 最新更新时间 | 最后一次编辑或运行完成时间 |
| 操作 | 查看、编辑、复制、授权、上架、下架、删除等 |

**5.3 顶部“新建标签”按钮逻辑**

点击“新建标签”后，弹出下拉菜单。下拉菜单按照标签来源与构建方式分组展示。

推荐分组：

1. 规则构建：规则标签、统计标签、首末次标签、偏好标签、排序标签、运算标签。
2. 模型构建：生命周期标签、RFM 标签、自定义模型标签。
3. 数据导入：导入标签、人工录入标签、SQL 标签。

展示规则：

1. 用户无某类型新建权限时，该类型不展示。
2. 若企业未购买增值模块，对应类型置灰并展示“当前环境未开通”。
3. SQL 标签仅在私有化环境展示。
4. 点击某个类型后进入对应标签创建页面。

**5.4 搜索逻辑**

1. 用户在搜索框输入关键词后，前端 300ms 防抖触发查询。
2. 搜索范围为当前主体下用户有权限查看的标签。
3. 默认按标签名称模糊匹配。
4. 搜索结果不受左侧树节点限制；若产品需要受树限制，必须在搜索框旁展示“当前目录内搜索”开关，默认关闭。
5. 清空搜索词后恢复当前目录列表。
6. 搜索结果为空时展示空态：“未找到相关标签”。

**5.5 标签列表行操作**

每行操作包含“更多”菜单。菜单项按权限与状态动态展示。

| **操作** | **展示条件** | **点击后逻辑** |
| --- | --- | --- |
| 查看详情 | 有标签查看权限 | 进入标签详情页 |
| 编辑 | 有标签编辑权限，标签未删除 | 进入对应标签编辑页 |
| 复制 | 标签类型支持复制且有编辑权限 | 复制当前标签规则并进入新建页，名称默认“原标签名\_副本” |
| 授权 | 有标签管理权限 | 打开授权弹窗 |
| 上架 | 标签为草稿或已下架，且有上下架权限 | 打开确认弹窗，确认后状态改为已上架并触发任务 |
| 下架 | 标签为已上架，且有上下架权限 | 打开风险确认弹窗，确认后状态改为已下架并中断任务 |
| 删除 | 有标签管理权限 | 打开二次确认弹窗，确认后删除，不可恢复 |
| 移动分组 | 有标签编辑权限 | 打开目录选择弹窗，确认后变更标签目录 |
| 服务配置 | 在线服务可用且有编辑权限 | 打开在线服务配置抽屉或开关 |

**5.6 空态和异常态**

1. 用户无标签时，右侧展示空态：“暂无标签，请点击新建标签开始构建标签体系”。若用户无新建权限，不展示新建按钮，只展示“暂无可查看标签”。
2. 当前目录无标签时，展示“当前分类暂无标签”。
3. 搜索无结果时，展示“未找到相关标签，请修改关键词”。
4. 接口失败时，展示“加载失败，请刷新重试”，并提供“重新加载”按钮。

**6. 标签体系树 PRD**

**6.1 入口与权限**

标签体系树位于标签体系首页左侧。用户必须拥有“查看标签体系”权限才能查看；必须拥有“编辑标签树”权限才能创建、重命名、删除、拖拽目录。

**6.2 目录操作按钮**

鼠标悬停目录节点时展示“更多”按钮。点击后展示菜单。

| **菜单项** | **适用对象** | **功能** |
| --- | --- | --- |
| 新建同级分类 | 普通目录、系统标签旁操作入口 | 在当前目录同层级新增目录 |
| 新建子级分类 | 普通目录 | 在当前目录下新增子目录 |
| 重命名 | 普通目录 | 修改目录名称 |
| 删除 | 普通目录 | 删除空目录 |

系统默认“未分类”目录不可重命名、不可删除、不可拖出根节点。

**6.3 新建同级分类**

操作流程：

1. 用户点击目录更多菜单中的“新建同级分类”。
2. 系统在当前目录同层级下方插入一个编辑态目录节点。
3. 输入框默认聚焦，默认占位文案为“请输入分类名称”。
4. 用户输入名称后按 Enter 或点击输入框外部时提交。
5. 用户按 Esc 时取消创建。

校验规则：

1. 名称必填。
2. 名称前后空格自动 trim。
3. 同一父级下目录名称不可重复。
4. 名称长度限制为 1-50 个字符。
5. 不允许输入仅空格字符。

异常处理：

1. 校验失败时，目录节点保持编辑态并展示错误提示。
2. 接口失败时，提示“创建失败，请重试”，并保留输入内容。

**6.4 新建子级分类**

逻辑与新建同级分类一致，但 parent\_id 为当前目录 ID。

层级限制：

1. 若系统配置最大层级为 N，当前目录已达到 N 级时，不展示“新建子级分类”。
2. 若通过接口强制提交超过层级，后端返回错误，前端提示“已达到最大目录层级”。

**6.5 重命名目录**

操作流程：

1. 用户点击“重命名”。
2. 当前目录名称变为输入框。
3. 输入框默认填充原名称并全选。
4. Enter 提交，Esc 取消。
5. 提交成功后树节点更新名称。

校验与新建目录相同。

**6.6 删除目录**

删除条件：

1. 目录下没有标签。
2. 目录下没有子目录，或所有子目录均为空且产品允许级联删除。
3. 不是系统默认目录。

默认实现要求：不允许删除含子目录或含标签的目录。用户点击删除时，如目录非空，弹窗提示“当前分类下存在标签或子分类，请先移动或删除后再操作”。

删除流程：

1. 用户点击“删除”。
2. 系统弹窗确认：“删除后不可恢复，确认删除该分类吗？”
3. 点击“取消”关闭弹窗，不做变更。
4. 点击“确认删除”调用删除接口。
5. 删除成功后，从树中移除节点，并自动选中其父级目录。

**6.7 拖拽调整目录顺序**

1. 用户有编辑标签树权限时，目录节点允许拖拽。
2. 拖拽时展示目标插入位置。
3. 松手后调用排序接口，保存同父级下的新排序。
4. 若拖拽到不允许的位置，例如“未分类”下作为子目录，前端阻止并回弹。
5. 接口失败时回滚原顺序并提示“排序保存失败”。

**6.8 拖拽调整标签所属分类**

1. 用户选中或拖拽右侧标签到左侧目录。
2. 目标目录高亮。
3. 松手后弹出确认：“确认将标签移动到该分类下吗？”
4. 点击确认后调用移动接口。
5. 移动成功后，源目录标签数 -1，目标目录标签数 +1，右侧列表根据当前目录刷新。
6. 如果用户无目标目录编辑权限，目标目录不可作为放置区域。

**6.9 复制标签**

支持复制的标签类型：规则标签、组合标签、生命周期标签、RFM 标签、首末次标签、统计标签、排序标签、偏好标签。运算标签、SQL 标签、导入标签、人工录入标签、自定义模型标签是否支持复制需由系统配置控制。

复制逻辑：

1. 用户点击标签更多菜单中的“复制标签”。
2. 系统读取原标签配置，包括基础信息、规则、更新方式、TTL、在线服务开关、自定义元信息。
3. 进入对应标签创建页面。
4. 标签名称默认填充“原标签名称\_副本”。
5. 标签 ID 不复制，由创建成功后重新生成。
6. 运行记录、历史结果、授权记录、上下架状态不复制。
7. 用户点击创建完成后生成新标签。

**7. 标签创建通用流程**

所有标签类型的创建页面都应采用步骤式表单。通用步骤如下：

1. 配置基础信息。
2. 配置标签规则或数据来源。
3. 配置展示方式或输出方式。
4. 预估数量。
5. 创建完成。

不同标签类型可省略或增加步骤，但必须保留统一的底部操作区。

**7.1 通用底部按钮**

| **按钮** | **展示页面** | **逻辑** |
| --- | --- | --- |
| 取消 | 所有步骤 | 弹窗确认是否放弃创建；确认后返回来源页 |
| 上一步 | 非第一步 | 回到上一步，保留已填写内容 |
| 下一步 | 非最后一步 | 校验当前步骤，通过后进入下一步 |
| 预估数量 | 规则配置完成后 | 调用预估接口，展示各标签值覆盖人数或总人数 |
| 创建完成 | 最后一步 | 全量校验，通过后创建标签 |
| 保存草稿 | 启用上下架流程时可选 | 保存元信息和规则但不计算，不供下游使用 |

**7.2 通用基础信息字段**

| **字段** | **类型** | **是否必填** | **规则** |
| --- | --- | --- | --- |
| 标签名称 | 输入框 | 是 | 1-100 字符；同一项目同一主体下不可重复；trim 后保存 |
| 路径 | 树形下拉 | 是 | 选择标签所在目录；无目录权限时只能选“未分类” |
| 描述 | 多行文本 | 否 | 建议上限 500 字；用于给其他标签使用者参考 |
| 标签值类型 | 下拉 | 部分标签必填 | 不同标签类型可自动推断或手动选择 |
| 计算类型 | 单选 | 是 | 离线计算/实时计算；不同标签类型能力不同 |
| 标签更新取值逻辑 | 单选 | 是 | 计算为空保留空缺/计算为空保留历史值 |
| 标签值保存类型 | 单选 | 规则标签必填 | 单值/多值 |
| 更新类型 | 单选 | 是 | 定时更新/手动更新 |
| 执行频率 | 频率选择器 | 定时更新必填 | 天/周/月 + 具体执行时间 |
| 计算结果存储保留策略 | 单选 | 定时更新必填 | 与系统一致/指定时长 |
| 在线服务开关 | 开关 | 否 | 开启后支持高 QPS 低延迟在线查询 |
| 自定义标签元信息 | 动态表单 | 视元信息配置而定 | 根据管理员配置展示文本、单选、多选字段 |

**7.3 路径权限控制**

路径选择受两层开关影响：

1. 集团开关：标签目录权限控制。默认关闭。开启后，新建标签时对目录进行严格权限管控。
2. 模块权限：用户是否拥有目标目录的编辑标签树权限。

逻辑：

1. 开关关闭时，用户可选择任意目录。
2. 开关开启时，用户只能选择自己有编辑权限的目录。
3. 开关开启且用户没有任何目录编辑权限时，路径默认为“未分类”，且下拉不可选择其他目录。
4. 前端必须在路径选择器中对无权限目录置灰，并在 hover 时提示“无该目录编辑权限”。

**7.4 创建完成逻辑**

点击“创建完成”后，系统执行以下流程：

1. 前端校验全部步骤必填项、类型、规则完整性。
2. 后端校验标签名称唯一性、权限、资源额度、数据源权限、依赖合法性。
3. 后端创建标签元信息、规则版本、调度配置、权限默认记录。
4. 若上下架流程开启，标签状态为草稿态，不立即执行计算。
5. 若上下架流程关闭且更新类型为定时更新，创建后进入已上架状态，并等待下一次调度或允许立即手动运行。
6. 若上下架流程关闭且更新类型为手动更新，创建后进入已上架状态，但无结果，需用户手动运行。
7. 若为导入标签或人工录入标签，创建完成后根据上传或同步结果生成初始分区。
8. 创建成功后跳转标签详情页。

**7.5 预估数量逻辑**

“预估数量”用于在创建前快速查看规则覆盖人数。

通用规则：

1. 只有当前规则配置完整时按钮可点击。
2. 点击后按钮进入 loading 状态，文案变为“预估中”。
3. 预估任务成功后，在页面右侧或弹窗展示结果。
4. 多标签值标签展示每个标签值覆盖人数、占比和总覆盖人数。
5. 单值统计类标签展示有值人数、空值人数、覆盖率。
6. 预估结果只用于辅助判断，不写入标签结果表。
7. 用户修改任何规则后，已有预估结果标记为“已失效”，需重新点击预估。
8. 预估失败时展示失败原因，并支持复制错误信息。

**8. 规则标签 PRD**

**8.1 功能定位**

规则标签用于通过规则圈选为用户打标签。用户可为一个标签配置多个标签值，每个标签值对应一套圈选规则。系统根据主体是否满足规则，为主体赋予对应标签值。

适用场景：会员等级、优惠券使用频次、消费水平、活动响应度、是否高价值用户等。

**8.2 页面流程**

入口：标签体系首页 > 新建标签 > 规则标签。

步骤：

1. 配置基础信息。
2. 配置标签值和规则。
3. 预估数量。
4. 创建完成。

**8.3 基础信息特有字段**

| **字段** | **规则** |
| --- | --- |
| 计算类型 | 支持离线计算、实时计算 |
| 标签值保存类型 | 支持“单值”和“多值” |
| 在线服务开关 | 可开启 |

标签值保存类型逻辑：

1. 单值：当用户命中多个标签值时，按标签值排序优先级取第一个命中的标签值。
2. 多值：当用户命中多个标签值时，保留所有命中的标签值，输出为多值标签。
3. 单值模式下，标签值列表必须支持拖拽排序。
4. 多值模式下，标签值顺序只影响展示，不影响计算结果。

**8.4 标签值配置区**

页面展示标签值卡片列表。每个标签值卡片包含：

| **控件** | **功能** |
| --- | --- |
| 标签值名称输入框 | 输入当前标签值名称 |
| 重命名 | 使标签值名称进入编辑态 |
| 复制 | 复制当前标签值及其规则，新增到列表末尾 |
| 删除 | 删除当前标签值；至少保留一个标签值 |
| 拖拽手柄 | 调整标签值优先级 |
| 规则配置区 | 配置满足/排除规则 |

标签值名称校验：

1. 必填。
2. 同一标签内不可重复。
3. 不支持英文单引号、英文双引号、英文括号、英文顿点、英文逗号、反斜杠、反引号。
4. 建议长度上限 50 字符。

“新增标签值”按钮逻辑：

1. 点击后在列表末尾新增空白标签值卡片。
2. 默认名称为“标签值 N”，若重复则递增。
3. 默认规则为空，必须配置后才能提交。
4. 生命周期标签最多 8 个标签值；规则标签是否限制数量由系统配置决定，默认建议不超过 20 个。

**8.5 规则配置区结构**

每个标签值规则分为“满足”和“排除”两个平级组件。

计算逻辑：满足条件 A 且排除条件 B。

1. 若只配置满足条件，则命中满足条件的主体。
2. 若只配置排除条件，则从当前规则作用域中排除命中 B 的主体，剩余主体命中该标签值。
3. 若同时配置满足和排除，则先计算满足集合，再减去排除集合。
4. 若满足和排除均为空，不允许创建。

规则支持的数据源：

1. 标签。
2. 属性数据。
3. 行为数据。
4. 明细数据。

规则组合支持：

1. 且：满足所有规则或组合规则。
2. 或：满足任意规则或组合规则。
3. 支持嵌套规则组，但建议前端最多支持 5 层嵌套，后端必须防止无限嵌套。

**8.6 行为数据规则**

行为规则基本格式：

日期范围 + 行为逻辑 + 事件 + 聚合方式/属性条件 + 比较条件。

支持行为逻辑：

| **行为逻辑** | **含义** |
| --- | --- |
| 做过 | 在指定日期范围内发生过某事件 |
| 未做过 | 在发生过行为事件的人群中排除某事件 |
| 全局未做过 | 在全量主体中排除某事件 |
| 依次做过 | 在指定日期范围内按顺序发生多个事件步骤 |

聚合方式：总次数、每日次数、天数、连续天数、求和、平均值、最大值、最小值、去重计数。

行为属性条件支持：

1. 文本：等于、不等于、包含、不包含、全局不包含、like、正则匹配、为空、不为空。
2. 数值：等于、不等于、大于、大于等于、小于、小于等于、区间、topN。
3. 日期：等于、不等于、早于、晚于、区间、距今多少天。
4. 多值/数组：包含、不包含、包含全部。

“未做过”与“全局未做过”必须严格区分：

1. 未做过：只在指定时间内发生过任意行为的人群中排除目标事件。
2. 全局未做过：在全量主体中排除目标事件。
3. 前端在用户选择“未做过”时展示提示：“该逻辑只在发生过行为的人群中排除”。
4. 前端在用户选择“全局未做过”时展示提示：“该逻辑会从全量用户中排除命中事件的用户”。

行为路径规则：

1. 选择“依次做过”后，规则区切换为步骤式配置。
2. 每个步骤可选择一个或多个事件；同一步骤内多个事件为“或”关系。
3. 步骤之间为顺序关系。
4. 不支持跨数据源行为序列，即不能配置 A 数据源事件后接 B 数据源事件。
5. 允许配置步骤间时间间隔，例如步骤 2 在步骤 1 之后 N 天内发生；若未配置，则只要求时间顺序。

**8.7 明细数据规则**

明细数据规则基本格式：

日期范围 + 明细表 + 筛选条件 + 聚合方式 + 比较条件。

聚合方式：总次数、去重计数、求和、平均值、最大值、最小值。

去重计数逻辑：按主体 ID 分组，对指定字段去重后计数。例如同一用户近 3 天下单城市为上海、上海、北京，去重计数为 2。

支持“字段聚合后且满足”条件。例如：过去 7 天下单品牌包含 A 品牌，且下单渠道包含线上商城。

平均值计算逻辑：先按主体 ID 分组，对目标数值字段求和或聚合，再取平均值作为标签值或判断依据，具体取决于规则配置。

**8.8 属性数据规则**

属性规则基本格式：

属性表 + 属性字段 + 运算符 + 目标值。

属性表只展示用户有权限查看的数据档案。属性字段根据字段类型展示可用运算符。

**8.9 标签数据规则**

标签规则基本格式：

标签 + 标签值条件。

注意：选择标签值时，下拉只展示最近一个分区的标签值。

**8.10 日期选择器**

规则标签中的日期筛选支持三种模式：

| **模式** | **说明** |
| --- | --- |
| 固定日期 | 选择某一天或某段日期；时间日期型字段可精确到时分秒 |
| 动态日期 | 以今天为基准选择最近 N 天、本周、上周、本月、上月、本季度、上季度、今年、去年、最近 3/6 月、最近 1/2 年等 |
| 单个日期 | 点选某个日期；时间日期型字段可点选到具体时分秒 |

动态日期“最近 X 天”必须提供“是否包含今天”选项。

**8.11 实时规则限制**

当计算类型选择实时计算时，规则配置必须受以下限制：

1. 行为数据只支持实时行为数据源，不支持离线数据源。
2. 行为逻辑不支持未做过、全局未做过、依次做过。
3. 文本类型不支持全局不包含、like、正则匹配。
4. 时间日期类型不支持全局不包含。
5. 数值型不支持 topN。
6. 如用户配置了不支持逻辑，前端必须在规则保存前拦截，并提示具体不支持项。
7. 实时规则编辑和修改次日生效；不符合新规则的用户在次日离线校正任务中移除。

**8.12 创建与结果**

点击“创建完成”后：

1. 系统保存标签定义。
2. 若已上架且定时更新，生成调度任务。
3. 若实时计算，注册实时规则并创建实时任务。
4. 标签详情页展示标签分布、历史详情、规则、运行记录。

**9. 统计标签 PRD**

**9.1 功能定位**

统计标签将用户在一段时间内完成事项的统计结果作为标签值，例如最近 30 天浏览商品详情页次数、近 7 天下单金额总和。

**9.2 创建流程**

入口：标签体系首页 > 新建标签 > 统计标签。

步骤：

1. 配置基础信息。
2. 配置统计规则。
3. 配置标签展示方式。
4. 预估数量。
5. 创建完成。

**9.3 基础信息**

计算类型支持离线计算和实时计算。更新类型支持定时更新和手动更新。其余字段使用通用基础信息逻辑。

**9.4 统计规则 - 行为事件表**

当数据源为行为事件表时，配置项如下：

| **配置项** | **规则** |
| --- | --- |
| 日期范围 | 动态日期、固定日期、单个日期 |
| 行为逻辑 | 仅支持“做过”某事件 |
| 事件 | 从有权限的行为数据档案中选择 |
| 筛选条件 | 可基于事件属性添加条件 |
| 统计方式 | 总次数、天数、连续天数、求和、平均值、最大值、最小值 |
| 聚合后判断 | 支持筛选字段聚合后再判断条件 |

统计结果必须按主体 ID 聚合输出。

**9.5 统计规则 - 业务明细表**

当数据源为业务明细表时，配置项如下：

| **配置项** | **规则** |
| --- | --- |
| 日期范围 | 动态日期、固定日期、单个日期 |
| 明细表 | 从有权限的数据档案中选择 |
| 筛选条件 | 可对明细字段添加筛选 |
| 统计方式 | 总次数、去重计数、求和、平均值、最大值、最小值 |
| 聚合后判断 | 支持聚合后增加条件判断 |

平均值计算要求：先按主体 ID 分组，再对目标字段进行聚合，最终将统计算法结果作为标签值。

**9.6 标签展示方式**

统计标签支持两种展示方式。

**9.6.1 按离散数值划分**

1. 直接使用统计计算结果作为标签值。
2. 适用于离散值较少的场景。
3. 当离散值过多时，前端应提示“离散数值过多可能影响圈选与画像性能，建议使用数值区间”。

**9.6.2 按数值区间划分**

1. 用户基于统计结果设置多个区间，每个区间对应一个标签值名称。
2. 首次配置默认展示两个无穷区间：[-∞，空]、[空，+∞]。
3. 用户可新增、删除、修改区间。
4. 区间必须连续且不可重叠。
5. 分层名称不可重复。
6. 区间边界必须为数值。
7. 若用户删除无穷区间，后续点击“增加分层”时可自动恢复默认无穷区间。

**9.7 预估与创建**

点击“预估数量”展示每个区间或离散值的覆盖人数。点击“创建完成”生成统计标签，详情页展示人数分布、历史详情、运行记录和规则。

**10. 首末次标签 PRD**

**10.1 功能定位**

首末次标签用于将用户首次或末次完成某事件/某明细记录的时间、距今天数或属性作为标签值。

适用场景：首次激活 APP 时间、最后一次下单距今天数、最后一次留资渠道、首次购买商品品类。

**10.2 创建流程**

入口：标签体系首页 > 新建标签 > 首末次标签。

步骤：

1. 配置基础信息。
2. 配置首末次规则。
3. 预估数量。
4. 创建完成。

**10.3 规则配置 - 行为事件表**

行为事件表支持以下配置：

1. 日期范围：动态日期、固定日期、单个日期。
2. 行为逻辑：仅支持“完成”某事件。
3. 事件：从行为事件表中选择。
4. 筛选条件：可增加事件属性条件。
5. 首末次类型：首次发生或末次发生。
6. 计算特征：具体时间点、距离今天的天数、事件属性。

计算逻辑：

1. 在日期范围内筛选目标事件。
2. 按主体 ID 分组。
3. 根据事件发生时间升序或降序取第一条记录。
4. 若计算特征为具体时间点，输出该条记录的发生时间。
5. 若计算特征为距离今天的天数，输出当前业务日期与该时间点的日期差。
6. 若计算特征为事件属性，输出该条记录的指定属性值。

**10.4 规则配置 - 业务明细表**

业务明细表支持以下配置：

1. 日期范围：动态日期、固定日期、单个日期。
2. 基准时间字段：选择用于判断首末次的日期或时间日期字段。
3. 首末次类型：首次或末次。
4. 输出属性：选择首末次记录中的某个属性字段。
5. 筛选条件：可增加明细字段条件。

**10.5 预估与创建**

点击“预估数量”展示有值人数。点击“创建完成”生成标签，并在详情页查看分布、历史详情、规则和运行记录。

**11. 偏好标签 PRD**

**11.1 功能定位**

偏好标签根据用户完成事件或明细记录的某个属性进行分组排序，取 Top N 分组作为标签值。

适用场景：最近一周订单金额大于 100 元的偏好品类、最近 3 天购买用户所在城市 Top N、消费金额最高的品牌偏好。

**11.2 创建流程**

入口：标签体系首页 > 新建标签 > 偏好标签。

步骤：

1. 配置基础信息。
2. 配置偏好规则。
3. 预估数量。
4. 创建完成。

**11.3 基础信息限制**

偏好标签仅支持离线计算。更新类型支持定时更新和手动更新。

**11.4 行为表规则**

行为表规则格式：

分区日期 + 事件 + 筛选条件 + 排序指标 + 前 N 名 + 属性字段。

配置项：

| **配置项** | **规则** |
| --- | --- |
| 日期范围 | 动态日期、固定日期、单个日期 |
| 事件 | 选择一个行为事件 |
| 筛选条件 | 可对事件属性设置条件 |
| 排序指标 | 出现次数最多或数值最大 |
| Top N | 正整数，建议 1-20 |
| 属性字段 | 作为偏好结果的字段 |

类型限制：

1. 出现次数最多：属性字段可为所有类型。
2. 数值最大：属性字段仅可选择数值型或日期型字段。

**11.5 明细表规则**

明细表规则格式：

分区日期 + 排序指标 + 前 N 名 + 属性字段 + 筛选条件。

计算逻辑：

1. 按主体 ID 与属性字段分组。
2. 根据排序指标计算每个属性值的统计量。
3. 对每个主体内的属性值排序。
4. 取前 N 个属性值作为多值标签值；若 N=1，可输出单值。
5. 排序相同时，按属性值字典序或系统稳定排序规则处理，保证结果可复现。

**11.6 预估与创建**

预估展示有偏好结果的人数、Top 标签值样例。创建成功后在详情页展示分布、历史详情、运行记录和规则。

**12. 排序标签 PRD**

**12.1 功能定位**

排序标签使用多个同类型标签或属性按优先级生成一个新标签。典型场景是优先使用人工标签值，若为空再使用推测标签值。

示例：新标签“性别”优先取“性别-人工”，若为空取“性别-推测”。

**12.2 创建流程**

入口：标签体系首页 > 新建标签 > 排序标签。

步骤：

1. 配置基础信息。
2. 选择标签值类型。
3. 选择标签或属性字段并排序。
4. 预估数量。
5. 创建完成。

**12.3 标签类型选择**

用户先选择目标标签值类型。支持类型：文本型、数值型、小数型、日期型、时间日期型、多值文本型、多值数值型、多值小数型、多值日期型、多值时间日期型。

选择类型后，字段选择器只展示相同类型的标签或属性。

**12.4 字段选择与排序**

页面左右布局：

1. 左侧为可选标签/属性列表。
2. 右侧为已选字段列表。

交互逻辑：

1. 用户在左侧勾选字段后，字段加入右侧列表。
2. 已选字段在左侧保持勾选状态。
3. 用户取消左侧勾选或点击右侧删除按钮，字段从已选列表移除。
4. 右侧支持拖拽排序。排序越靠上，优先级越高。
5. 至少选择 2 个字段。
6. 最多选择数量由系统配置控制，默认建议不超过 10 个。

计算逻辑：

1. 对每个主体，按右侧字段顺序逐个取值。
2. 第一个非空值作为新标签值。
3. 若所有字段均为空，则输出空值。
4. 多值类型字段非空时，整体作为非空值，不拆分参与优先级判断。

**12.5 预估与创建**

预估展示最终标签分布，并可展示每个来源字段贡献人数。创建成功后，标签规则区支持点击子标签跳转到对应详情页。

**13. 运算标签 PRD**

**13.1 功能定位**

运算标签基于已有标签或属性进行二次计算，生成新的数值标签或区间标签。

适用场景：动额比例 = 放款金额 / 授信金额；购物意向总分 = 多个行为分值加总。

**13.2 创建流程**

入口：标签体系首页 > 新建标签 > 运算标签。

步骤：

1. 配置基础信息。
2. 选择参与运算字段。
3. 配置字段赋值规则。
4. 编辑表达式。
5. 配置上下限与空值处理。
6. 配置结果展示方式。
7. 预估数量。
8. 创建完成。

**13.3 字段选择**

“添加字段”按钮逻辑：

1. 点击后打开字段选择弹窗。
2. 用户可选择标签、属性，或同时选择标签和属性。
3. 标签最多选择 10 个。
4. 属性最多选择 10 个。
5. 当选择属性时，所有属性字段必须源自同一张属性表。
6. 点击“确定”后，字段出现在已选字段区。
7. 点击“取消”关闭弹窗，不保存本次选择。

**13.4 字段赋值**

每个已选字段右侧展示“赋值”按钮。

点击“赋值”后打开赋值弹窗，根据字段类型展示不同配置。

| **字段类型** | **赋值方式** |
| --- | --- |
| 文本型 | 平铺展示所有标签值，用户为每个枚举值配置数值分 |
| 数值型 | 使用原数值或按区间赋值 |
| 小数型 | 使用原数值或按区间赋值 |
| 日期型/时间日期型 | 可按距今区间赋值或使用原始数值转换结果 |

赋值弹窗按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 确定 | 校验赋值完整性，通过后保存 |
| 取消 | 关闭弹窗，不保存修改 |
| 新增区间 | 增加一行区间配置 |
| 删除区间 | 删除当前区间 |

区间赋值校验：

1. 区间不可重叠。
2. 区间边界必须合法。
3. 赋值结果必须为数值。
4. 文本枚举值不可重复。

**13.5 表达式编辑器**

表达式编辑区支持两种输入方式：

1. 点击字段按钮和运算符按钮生成表达式。
2. 键盘直接输入运算符。

支持运算符：加、减、乘、除、括号。

支持小数参与计算。

表达式校验：

1. 表达式不能为空。
2. 括号必须成对。
3. 运算符不能连续出现，除负号场景外。
4. 表达式必须至少包含一个字段。
5. 除法分母不能被静态判断为 0。
6. 表达式中的字段必须来自已选字段列表。
7. 删除字段后，表达式中引用该字段的位置必须提示错误，用户必须修复后才能保存。

**13.6 上下限与空值处理**

用户可选填上下限。

| **配置** | **说明** |
| --- | --- |
| 运算标签结果值上下限 | 限制最终计算结果的最小值和最大值 |
| 字段值上下限 | 限制参与运算的字段取值范围 |

空值处理：

| **方式** | **说明** | **推荐场景** |
| --- | --- | --- |
| 赋 0 处理 | 字段为空时按 0 参与计算 | 加减类公式 |
| 丢弃 | 只要字段为空即输出空值，或分母为空时丢弃 | 乘除类公式，避免计算异常 |

默认计算逻辑：若未开启空值赋 0，用户在涉及的任意字段上未被打标，即对应值为 null，则最终运算结果为 null。

**13.7 展示设置**

支持两种展示方式：

1. 按统计值划分：直接展示实际计算结果。
2. 按数值区间划分：按用户配置的区间展示分层标签。

区间规则与统计标签一致：区间不可重叠、名称不可重复、支持无穷区间。

**13.8 预估与创建**

点击“预估数量”展示计算结果分布。点击“创建完成”后生成运算标签。

**14. 生命周期标签 PRD**

**14.1 功能定位**

生命周期标签用于基于 AIPL、5A 或企业自定义阶段模型，对用户所处生命周期阶段进行打标，并支持后续进入生命周期分析页面洞察各阶段人群。

**14.2 创建流程**

入口：标签体系首页 > 新建标签 > 生命周期标签。

步骤：

1. 配置基础信息。
2. 选择模型类型。
3. 配置阶段标签值和规则。
4. 预估数量。
5. 创建完成。
6. 在详情页进入生命周期分析。

**14.3 模型类型**

系统内置模型：

1. AIPL：认知、兴趣、购买、忠诚。

用户可在模型阶段上进行重命名、复制、删除、新增阶段。

**14.4 阶段规则配置**

每个阶段下可添加以下数据条件：

1. 标签。
2. 行为数据。
3. 明细数据。

规则配置能力复用规则标签圈选组件。每个阶段的规则输出该阶段覆盖人群。

若同一用户命中多个阶段，默认按阶段顺序取优先级最高的阶段；如果产品允许多阶段，需要在基础信息中增加“阶段保存类型”开关。默认建议单阶段。

**14.5 阶段操作按钮**

| **按钮** | **功能** |

**14.6 详情页生命周期分析入口**

生命周期标签详情页展示“生命周期分析”按钮。

点击后逻辑：

1. 校验用户是否有生命周期分析模块权限。
2. 校验当前标签是否为生命周期标签且状态已上架。
3. 跳转分析洞察 > 生命周期分析，并携带标签 ID。
4. 若无权限，弹窗提示“暂无生命周期分析权限，请联系管理员开通”。

**15. RFM 标签 PRD**

**15.1 功能定位**

RFM 标签通过 Recency、Frequency、Monetary 三类指标划分用户价值等级。系统根据 R、F、M 高低组合输出用户价值类型。

默认用户价值类型包括：重要价值客户、重要换回客户、重要深耕客户、重要挽留客户、潜力客户、新客户、一般维持客户、流失客户。

**15.2 创建流程**

入口：标签体系首页 > 新建标签 > RFM 标签。

步骤：

1. 配置基础信息。
2. 选择数据来源与时间。
3. 定义 R、F、M 指标。
4. 配置高低阈值或分值区间。
5. 命名标签值。
6. 预估数量。
7. 创建完成。

**15.3 数据来源**

支持三类数据来源。

| **数据源** | **配置方式** | **R/F/M 计算方式** | **适用场景** |
| --- | --- | --- | --- |
| 明细数据 | 选择明细数据档案；存在分区时选择数据计算周期 | 按主体 ID 聚合订单，计算最近消费距今天数、消费频率、消费金额 | 明细表记录每次订单 |
| 属性数据 | 选择主体属性数据档案 | 选择 3 个字段分别对应 R/F/M | 属性表已加工出 R/F/M 值 |
| 标签 | 选择已有日期型或数值型标签 | 选择 3 个标签分别对应 R/F/M | 已有标签与 R/F/M 口径一致 |

明细数据存在分区时必须选择数据计算周期；属性和标签默认使用最近一天分区全量数据。

**15.4 R/F/M 定义**

| **指标** | **明细数据字段** | **属性数据字段** | **标签字段** |
| --- | --- | --- | --- |
| R | 最近一次消费日期，必须为日期或时间日期字段 | 最近消费距今天数数值字段 | 代表最近消费时间或距今天数的标签 |
| F | 消费频率，可配置按主体 ID 计数 | 购买频率数值字段 | 代表消费频率的标签 |
| M | 消费金额，可配置求和或平均值 | 消费金额数值字段 | 代表消费金额的标签 |

阈值规则：

1. 对比值支持平均值、中位数、自定义。
2. R：数值越小越好。若对应天数大于对比值，则 R 为低；否则为高。
3. F：数值越大越好。若对应频率大于对比值，则 F 为高；否则为低。
4. M：数值越大越好。若对应金额大于对比值，则 M 为高；否则为低。

分值规则：

1. R、F、M 可使用原始值，也可按区间赋值。
2. 区间赋值可配置 5 分制、10 分制或自定义区间。
3. 区间个数上限 20。
4. 使用文本型标签作为指标时，必须先按区间或枚举映射为数值。

指标开关：

1. R、F、M 均可单独开启/关闭。
2. 至少保留 2 个指标才能创建。
3. 若关闭 R，则标签值组合从 F/M 高低生成 4 类。
4. 关闭指标后，相关字段配置必须清空，避免后端误用。

**15.5 标签值命名**

默认展示系统标签值名称。用户可修改名称。

规则：

1. 标签值名称必填。
2. 同一标签内不可重复。
3. 修改名称不改变底层 RFM 组合逻辑，只改变展示标签值。

**15.6 预估与创建**

点击“预估数量”展示每个价值类型覆盖人数。点击“创建完成”生成 RFM 标签。详情页展示标签预览、历史详情、规则、RFM 定义、运行记录和授权入口。

**15.7 异常处理**

若底表字段名使用 r、f、m，可能与底层 SQL 别名冲突。后端生成 SQL 时应对字段名加安全转义或别名重命名。若仍失败，错误提示应明确：“字段名与系统别名冲突，请修改字段别名或联系管理员处理”。

**16. 导入标签 PRD**

**16.1 功能定位**

导入标签用于从已接入的数据源中选择字段，直接生成标签。导入标签的同步周期默认与数据集同步频率一致。

**16.2 创建流程**

入口：标签体系首页 > 新建标签 > 导入标签。

步骤：

1. 选择数据源。
2. 选择字段。
3. 编辑字段标签配置。
4. 配置 TTL。
5. 创建完成。

**16.3 数据源与字段选择**

页面左侧展示数据源列表，右侧展示字段列表。

交互逻辑：

1. 用户选择一个数据源后，下方加载该数据源字段。
2. 用户勾选字段后，右侧出现待创建标签配置项。
3. 每个字段可单独配置标签路径和标签数据类型。
4. 若字段类型与标签类型不一致，支持强制转换。
5. 强制转换失败的记录应进入异常记录，不影响其他记录导入。

**16.4 标签类型**

支持文本型、整数型、小数型、多值型、日期型。

类型说明必须在选择器旁提供提示：

1. 文本型：姓名、用户名、城市。
2. 整数型：年龄、点击次数。
3. 小数型：费用、占比。
4. 多值型：兴趣爱好、喜爱话题。
5. 日期型：出生日期、更新日期。

**16.5 TTL 逻辑**

导入标签支持设定 TTL：

1. 默认与系统一致。
2. 可指定时长。
3. 指定时长优先级高于集团配置。

**16.6 创建完成**

点击“创建完成”后，系统为每个勾选字段创建一个标签。若部分字段失败，必须展示失败字段及原因，并允许用户下载失败明细。

**17. 人工录入标签 PRD**

**17.1 功能定位**

人工录入标签用于由销售、运营或客服通过文件或页面为指定用户录入标签值。典型场景是线下沟通后记录婚姻状况、是否有小孩、客户意向等级等。

**17.2 创建流程**

入口：标签体系首页 > 新建标签 > 人工录入标签。

步骤：

1. 配置基础信息。
2. 上传数据。
3. 查看上传结果。
4. 创建完成。

**17.3 基础信息字段**

| **字段** | **规则** |
| --- | --- |
| 标签名称 | 100 字符以内，同项目不可重复 |
| 路径 | 受标签目录权限控制 |
| 标签值类型 | 文本型、整数型、小数型、多值型、日期型 |
| 分隔符 | 多值型时必填，支持逗号、空格、换行符 |
| 在线服务开关 | 可开启 |

**17.4 上传数据**

上传区包含：

| **控件** | **功能** |
| --- | --- |
| ID 类型下拉 | 选择上传文件第一列所对应的 ID 类型 |
| 下载模板 | 下载标准上传模板 |
| 上传文件 | 上传 csv 或 xlsx 文件 |
| 重新上传 | 替换当前待上传文件 |
| 下一步 | 校验文件并进入结果页 |

文件校验规则：

1. 支持扩展名 .csv、.xlsx。
2. 文件大小上限 100M。
3. 第 1 列表头必须为“用户ID”。
4. 第 2 列表头必须为“标签值”。
5. 默认从第 2 行开始读取数据。
6. xlsx 只读取第一个 sheet。
7. 不支持合并单元格。
8. 上传用户 ID 必须唯一。
9. 标签值必须能转换为所选标签值类型。
10. 多值型按用户选择的分隔符拆分。

异常处理：

1. 若文件结构错误，阻止上传并提示具体错误。
2. 若部分行标签值异常，系统跳过异常值，优先完成可用数据上传。
3. 上传完成后在“上传记录”中展示成功行数、失败行数、失败原因。
4. 支持下载失败明细。

**17.5 标签值移除**

移除某 ID 标签值有两种方式：

1. API 删除标签值。
2. 网页重新上传该 ID 的标签值为“无”。

**17.6 编辑人工录入标签**

人工标签创建后，点击编辑进入修改页面。修改方式分为：

| **方式** | **逻辑** |
| --- | --- |
| 覆盖 | 新上传文件中的标签数据覆盖旧数据 |
| 移除 | 移除新上传文件中 ID 对应的标签数据 |

按钮逻辑：

1. 点击“修改完成”后执行覆盖或移除。
2. 操作成功后生成新的上传记录。
3. 操作失败时保留原数据不变。

**18. SQL 标签 PRD**

**18.1 功能定位**

SQL 标签允许用户通过 SQL 语句创建标签，使用 SQL 返回结果作为标签值。该功能仅面向私有化环境。

**18.2 权限与限制**

用户必须同时满足：

1. 拥有项目编辑权限或“新建 SQL 标签”权限。
2. 拥有对应数据档案查看权限。

可用库表限制：

1. 仅限通过数据连接接入 CDP，并经可视化建模完成 ID Mapping 后输出的 Hive 或 ClickHouse 类型表。
2. SQL 创建时可见库表由项目权限控制。
3. 使用标签时结果按用户行权限过滤。

**18.3 创建流程**

入口：标签体系首页 > 新建标签 > SQL 标签。

步骤：

1. 配置基础信息。
2. 选择标签类型。
3. 选择数据档案或底表。
4. 编写 SQL。
5. 格式化、解析、预览。
6. 预估人数。
7. 创建完成。

**18.4 基础信息**

支持字段：标签名称、路径、描述、计算类型、更新类型、执行频率、TTL、在线服务开关、自定义元信息。

标签值类型支持：文本型、数值型、小数型、日期型、时间日期型、多值文本型。

**18.5 SQL 编辑页面布局**

页面分为三栏：

1. 左侧：数据档案树。
2. 中间：字段与事件列表。
3. 右侧：SQL 编辑器与辅助按钮。

左侧数据档案树按类型分组：标签、明细、属性、行为。

**18.6 标签类型数据档案 SQL 插入**

当用户选择标签类型数据档案时：

1. 点击右上角“插入 SQL 语句”。
2. 系统自动生成完整标签查询代码。
3. 生成代码插入 SQL 编辑器光标处。
4. 用户可继续编辑。

**18.7 明细/属性数据档案 SQL 插入**

当用户选择明细或属性数据档案时：

1. 字段列表展示字段名、字段类型、字段描述。
2. 点击“插入字段”将字段名插入编辑器光标处。
3. 点击“插入库表名称”将底表名插入编辑器光标处。
4. 用户需手动完成 select/from/where 逻辑。

**18.8 行为数据档案 SQL 插入**

当用户选择行为数据档案时：

1. 展示行为事件列表。
2. 展示事件属性字段。
3. 点击事件可插入 event 条件。
4. 点击属性字段可插入属性字段引用。
5. 点击“插入库表名称”插入行为底表名。

**18.9 SQL 辅助按钮**

| **按钮** | **功能** |
| --- | --- |
| 格式化 | 将 SQL 按内置格式排版，提高可读性 |
| 解析 | 检测 SQL 语法、字段、返回列是否符合标签要求 |
| 预览 | 执行限制行数查询，展示返回结果样例 |
| 展开示例 | 展示 SQL 标签注意事项和示例代码 |
| 复制错误信息 | 当解析或预览失败时复制错误文本 |
| 预估人数 | 基于 SQL 结果估算标签覆盖人数 |
| 创建完成 | 保存 SQL 标签 |

解析规则：

1. SQL 必须返回主体 ID 字段和标签值字段。
2. 返回主体 ID 字段必须能映射到当前主体。
3. 标签值字段类型必须与用户选择的标签值类型一致或可转换。
4. SQL 不允许执行危险操作，例如 drop、delete、insert、update、truncate、alter。
5. SQL 必须限定在有权限的库表范围内。

预览规则：

1. 预览仅返回前 N 行，默认 100 行。
2. 预览不写入标签结果表。
3. 预览失败时展示后端错误原因。

**18.10 血缘查询**

SQL 标签创建页顶部展示提示入口：“查询客户底表和数据档案之间的关系”。点击后打开血缘查询弹窗。

弹窗支持两种查询方式：

1. 通过底表查询对应数据档案：选择 Hive 或 ClickHouse 类型，依次选择集群、库、表，点击查询后展示对应数据档案名称和档案类型。
2. 通过数据档案查询对应底表：选择档案类型、档案名称，点击查询后展示上游底表信息。

按钮逻辑：

| **按钮** | **逻辑** |
| --- | --- |
| 查询 | 根据当前选择执行查询 |
| 重置 | 清空当前选择 |
| 关闭 | 关闭弹窗 |

**18.11 创建完成**

点击“创建完成”后：

1. 自动执行解析校验。
2. 解析通过后保存 SQL 与标签配置。
3. 若开启上下架流程，进入草稿态；否则按更新方式进入已上架。
4. 创建成功后跳转标签详情页。

**19. 自定义模型标签 PRD**

**19.1 功能定位**

自定义模型标签用于通过可视化建模构建 AI 预测模型，并将模型输出结果写入标签体系。

适用场景：购车意向预测、流失风险预测、客户价值预测、选装包消费水平预测。

**19.2 创建流程**

入口：标签体系首页 > 新建标签 > 自定义模型标签。

点击入口后跳转“可视化建模”页面，并默认展示标签模板或模型标签模板。

流程：

1. 创建模型标签入口。
2. 新建任务。
3. 添加数据连接。
4. 拖拽数据源到画布。
5. 配置数据筛选。
6. 添加处理节点。
7. 配置机器学习节点。
8. 添加输出节点。
9. 输出为标签。
10. 保存任务。
11. 返回标签体系查看模型标签。

**19.3 新建任务**

点击“新建任务”后：

1. 用户选择数据连接。
2. 支持 Hive、ClickHouse、MySQL 等数据连接。
3. 支持上传 Excel、CSV。
4. 支持从飞书表格导入。
5. 任务创建后进入画布页面。

**19.4 建模画布**

用户通过拖拽方式将数据源表拉入画布区域。

配置区支持：

1. 添加多条数据筛选条件。
2. 多条筛选条件之间默认“且”关系。
3. 预览设置中填写参与计算的数据量。
4. 预览设置只影响数据结果预览行数，不影响正式运行。

**19.5 处理节点**

支持处理类型：

1. 数据预处理。
2. 数据清理。
3. 特征工程。
4. 机器学习。

点击节点后在右侧面板配置参数。点击“执行”后，节点输出数据可在数据结果区预览。

**19.6 输出模型标签**

添加输出节点后，用户配置输出标签字段：

| **字段** | **规则** |
| --- | --- |
| 实体 ID 字段 | 必须选择，可映射到主体 ID |
| 输出标签列 | 必须选择，作为标签值 |
| 标签名称 | 必填，100 字以内，同项目不可重复 |
| 标签描述 | 可选 |
| 依赖表 | 默认开启，可手动修改 |
| 优先级 | 普通、高、超高 |
| 运行参数 | 可添加，用于提高同步成功率 |

点击“保存”后进入任务详情页，展示处理流程、数据预览、运行记录。

**19.7 标签体系联动**

模型任务保存并成功运行后，标签体系页面展示该模型标签。标签详情页可查看人数分布、历史详情、运行记录。

**20. 标签模板 PRD**

**20.1 功能定位**

标签模板用于通过行业预置表模板和标签规则快速生成标签体系。当前重点支持汽车行业标签模板和内置生命周期分析。

**20.2 前置条件**

1. 项目管理员已完成数据连接。
2. 已完成 ID 图谱配置。
3. 已在元数据管理中完成表模板映射。
4. 用户具备元数据管理编辑权限。
5. 使用生命周期分析时，用户具备生命周期分析模块权限。

**20.3 使用流程**

整体流程：

配置数据连接 -> 配置 ID 图谱 -> 元数据管理中完成表模板映射 -> 标签体系中启用标签模板 -> 使用生命周期分析。

**20.4 配置用户属性表模板**

1. 用户进入数据融合 > 元数据管理 > 表模板。
2. 点击“配置映射”。
3. 选择用户属性表。
4. 下拉框中搜索并选择已登记用户属性表。
5. 首次配置后不可更改。
6. base\_id 默认为数据源登记中的 ID 信息，不支持修改。
7. 在配置字段区，根据模板字段和类型选择实际表字段映射。
8. 点击“保存”后，系统输出用户全量表。
9. 用户全量表只保留每个字段最新导入的数据内容。

ID Mapping 处理：当同一用户出现多条属性记录时，随机保留一条。若两个手机号对应不同性别，系统仅保留其中一个性别。

**20.5 配置用户行为表模板**

1. 用户选择用户行为表映射配置。
2. 下拉框选择已登记用户行为表。
3. 首次配置后不可更改。
4. base\_id 默认为数据源登记中的 ID 信息，不支持修改。
5. 根据表模板要求完成行为表映射。
6. 事件发生时间展示数据源登记中的事件发生时间。
7. 事件展示数据源登记中的事件。
8. 事件参数展示数据源登记中的事件参数。
9. 根据模板事件配置来源事件。
10. 点击“配置属性”，右侧弹出属性配置页面。
11. 配置完成后点击“确定”。

行为表输出规则：最终为行为数据增量表，每日同步新增数据至每日分区。ID Mapping 方面，若出现多条用户记录，均保留。

**20.6 启用标签模板**

入口：标签体系 > 标签模板。

页面展示预置标签列表。每行包含标签名称、标签描述、所属目录、是否已创建、标签规则摘要。

操作：

1. 用户勾选需要创建的标签。
2. 点击“确定”。
3. 系统启用对应标签规则并生成标签。
4. 已创建过的标签置灰，不可重复创建。
5. 启用后，标签体系中出现对应标签层级和标签。
6. 模板创建的标签名称后展示“系统模板”标识。
7. 模板标签支持复制、删除，但不可重命名，不支持修改标签规则。

**20.7 生命周期模板**

汽车生命周期模板默认包括阶段：广告、留资、到店、试驾、下订、交车。

每个阶段由过去 180 天内对应行为次数是否大于等于 1 判断。

启用内置生命周期标签后，标签详情页右上角展示“生命周期分析”按钮，点击跳转预置分析模板。

预置分析图表支持编辑和删除。图表包含阶段分布、渠道分布、品牌/车型分布、到店次数、试驾人数、下定区域、交车时长等指标。

**21. 标签上下架 PRD**

**21.1 功能定位**

标签上下架用于由管理员控制标签是否可用。上架标签可正常计算、更新和被下游使用；下架标签暂停任务，不供下游调用，但可恢复。

该功能可由企业开关控制。若关闭，则新建标签自动上架。

**21.2 上架标签**

可操作对象：草稿态、已下架标签。

权限要求：

1. 模块权限：标签上下架。
2. 指定标签资源：查看权限。

单个上架入口：

1. 标签体系 > 草稿/已下架列表 > 标签更多 > 上架。
2. 标签管理 > 草稿/已下架列表 > 标签更多 > 上架标签。

批量上架入口：标签管理 > 草稿/已下架 > 勾选标签 > 底部“批量上架”。

上架确认弹窗内容：

1. 标题：确认上架标签。
2. 内容：上架后标签将开始执行更新任务，并可被下游圈选、洞察、资产输出等应用使用。
3. 按钮：取消、确认上架。

确认后逻辑：

1. 标签状态改为已上架。
2. 若为定时更新，创建或恢复调度任务。
3. 若为手动更新，允许用户手动触发运行。
4. 若有下游因该标签下架而中断，标记为可恢复。
5. 记录历史操作。

**21.3 下架标签**

可操作对象：已上架标签。

下架影响：

1. 标签不再执行任务。
2. 下游不可用该标签进行标签创建、分群圈选、分析洞察和 API 调用。
3. 下游关联资源因规则包含该下架标签而中断更新。
4. 重新上架后可恢复。

单个下架入口：标签管理 > 已上架 > 标签更多 > 下架标签。

批量下架入口：标签管理 > 已上架 > 勾选标签 > 底部“批量下架”。

下架确认弹窗必须展示风险：

1. 标题：确认下架标签。
2. 内容：下架后该标签将暂停更新，且下游标签、分群、分析、API 调用可能不可用。
3. 若存在下游依赖，展示依赖数量，并提供“查看依赖”链接。
4. 勾选确认项：“我已知晓下架影响”。
5. 按钮：取消、确认下架。

确认后逻辑：

1. 标签状态改为已下架。
2. 停止该标签后续调度任务。
3. 运行中的任务按系统策略停止或等待完成；推荐停止未开始任务，已运行任务可继续完成但结果不可供下游使用。
4. 下游依赖资源标记为上游不可用。
5. 记录历史操作。

**21.4 删除标签**

权限要求：指定标签资源管理权限。

入口：标签管理 > 标签更多 > 删除标签。

删除确认弹窗：

1. 标题：确认删除标签。
2. 内容：删除后标签相关元信息将被清除，不可恢复；如下游资源依赖该标签，将导致更新任务中断。
3. 二次确认输入：请输入标签名称确认删除。
4. 按钮：取消、确认删除。

删除后逻辑：

1. 标签状态改为已删除。
2. 从列表默认视图隐藏。
3. 保留审计日志。
4. 下游依赖标记为异常。
5. 不允许恢复。

**22.1 页面入口**

入口：点击任意标签名称进入标签详情页。

权限：用户必须拥有该标签查看权限。

**22.2 页面结构**

展示字段：

**22.5 标签分布 Tab**

标签分布卡片展示：

2. 标签覆盖总人数。
3. 标签覆盖率。
4. 各标签值人数。

按钮：

| **按钮** | **功能** |
| --- | --- |

| 排序设置 | 设置标签值排序方式 |
| 展示数量 | 设置图表最多展示标签值数量 |

“存为分群”逻辑：

1. 用户点击某标签值旁“存为分群”。
2. 弹出分群创建弹窗或跳转分群创建页。
3. 自动生成规则：标签 = 当前标签 且 标签值 = 当前值。
4. 用户填写分群名称后保存。

“查看个体明细”逻辑：

1. 点击后跳转个体画像列表。
2. URL 携带标签 ID、标签值、数据时间。
3. 个体画像列表只展示当前用户行权限内的主体。

覆盖率口径：

1. 有效标签覆盖率：全量用户中打上该标签的用户数 / 当前主体全量 ID 数。
2. 有效标签分布：该标签不同取值在已打标用户中的分布，受行权限影响。
3. 指定日期标签覆盖率：指定日期打上标签的用户数 / 指定日期全量 ID 数。
4. 指定日期标签分布：指定日期各标签值分布，受行权限影响。

覆盖人数、覆盖率按全量数据计算和展示，不受行权限影响；明细列表和分布可受行权限影响。

**22.6 标签排序**

排序方式：

1. 按标签值升序。
2. 按标签值降序。
3. 按标签覆盖数量升序。
4. 按标签覆盖数量降序。
5. 自定义排序。

规则：

1. 按标签值升降序时，中文按拼音，英文按首字母。
2. 按覆盖数量时，根据当前标签值人数排序。
3. 自定义排序时，用户可拖拽标签值顺序。
4. 只有有标签编辑权限的用户可操作排序按钮。
5. 标签值最大展示数量由项目中心集团配置控制；用户只能在配置上限内设置展示数量。

| **控件** | **功能** |

**25. 实时标签构建 PRD**

**25.3 实时能力限制**

实时规则相比离线规则有以下限制：

1. 仅支持实时行为数据源，不支持离线数据源。
2. 行为不支持未做过、全局未做过、依次做过。
3. 标签、行为属性、用户属性的文本类型不支持全局不包含、like、正则匹配。
4. 标签、行为属性、用户属性的时间日期类型不支持全局不包含。
5. 标签、行为属性、用户属性的数值型不支持 topN。
6. 如使用以上逻辑会导致创建失败，前端必须提前拦截。

**25.4 实时规则修改生效**

1. 实时规则编辑和修改次日生效。
2. 对于修改后不符合条件的用户，次日离线校正任务会移除标签值。
3. 修改规则后，详情页应展示“规则修改将于次日生效”的提示。

**26. 标签更新 PRD**

**26.1 手动更新**

入口：

1. 标签详情页运行记录 Tab。
2. 标签管理列表单行“更新”。
3. 标签管理批量运行。

手动更新弹窗字段：

1. 运行日期范围。
2. 是否覆盖已有结果。
3. 是否保留历史值，按标签配置自动展示，不允许在弹窗修改。

确认后逻辑：

1. 生成运行任务。
2. 任务进入等待就绪或运行中。
3. 运行完成后写入结果分区。
4. 失败时记录失败原因。

**26.2 定时更新**

定时更新触发条件：

1. 标签处于已上架状态。
2. 到达配置的执行时间。
3. 上游数据源就绪。
4. 资源额度可用。

若上游未就绪，任务进入等待就绪。若超时仍未就绪，标记失败或等待，取决于系统配置。

**26.3 上游依赖规则**

1. 定时更新标签与数据源建立依赖。
2. 定时更新标签不与手动更新的上游标签建立依赖。
3. 手动更新标签完全独立，不因上游档案更新自动重算。
4. 历史标签只有在编辑标签元信息时才触发依赖更新。

**26.4 全量更新取值逻辑**

更新标签时支持：

1. 历史数据合并：保留历史数据，保持连续性。
2. 全量数据更新：基于最新规则重新计算，确保准确性。

编辑标签规则后，用户必须选择是否需要重跑历史数据。默认只影响后续分区，除非用户主动重跑。

**29. 验收标准**

**29.1 标签体系首页**

1. 有权限用户可进入页面，无权限用户不可进入。
2. 标签树、标签列表、搜索、新建入口正常展示。
3. 搜索只返回有权限标签。
4. 新建标签下拉只展示用户有权限创建的标签类型。
5. 标签行操作按状态和权限动态展示。

**29.2 标签树**

1. 可新建同级目录、子目录。
2. 目录重命名校验重复、空值、长度。
3. 非空目录不可删除。
4. 未分类目录不可删除、不可重命名。
5. 可拖拽目录排序和移动标签目录。
6. 操作失败可回滚。

**29.3 标签创建**

1. 所有标签类型均可按对应流程创建。
2. 必填项缺失时不能进入下一步或提交。
3. 标签名称同项目不可重复。
4. 路径选择受目录权限控制。
5. 定时更新展示执行频率和 TTL；手动更新不展示 TTL。
6. 预估数量可执行，规则变更后预估结果失效。
7. 创建成功后进入详情页。

**29.4 规则标签**

1. 支持标签、属性、行为、明细数据规则。
2. 支持满足和排除组件。
3. 支持且、或组合。
4. 未做过和全局未做过结果口径不同。
5. 支持行为路径且不允许跨数据源路径。
6. 实时计算限制可被前端拦截。

**29.5 统计、首末次、偏好、排序、运算标签**

1. 统计标签可按行为表和明细表统计。
2. 首末次标签可输出时间点、距今天数、属性。
3. 偏好标签可取 Top N 属性值。
4. 排序标签只允许同类型字段，并按优先级取第一个非空值。
5. 运算标签支持字段赋值、表达式、上下限、空值处理和区间展示。

**29.6 生命周期与 RFM 标签**

1. 生命周期标签支持 AIPL、5A 和自定义阶段。
2. 生命周期阶段最多 8 个。
3. RFM 标签支持明细、属性、标签三类数据源。
4. RFM 至少开启两个指标。
5. R/F/M 高低规则符合业务定义。

**29.7 导入、人工、SQL、模型标签**

1. 导入标签可从数据源字段生成标签。
2. 人工录入标签文件校验完整，异常行可下载。
3. 人工录入支持覆盖和移除。
4. SQL 标签支持格式化、解析、预览、预估、创建。
5. SQL 不允许危险语句。
6. 模型标签可从可视化建模输出至标签体系。

**29.8 标签详情页**

1. 基础信息完整展示。
2. 收藏、编辑、授权、上下架、删除按钮按权限展示。
3. 标签分布、历史详情、创建规则、运行记录、授权、血缘、价值评估、历史操作记录可查看。
4. 存为分群和查看个体明细跳转参数正确。
5. 运行记录支持刷新、重跑、停止、查看日志。

**29.9 标签管理页**

1. 筛选、搜索、状态切换正常。
2. 表格视图可切换、拖拽、重置、自定义。
3. 单行操作和批量操作按权限与状态展示。
4. 批量重命名、批量授权、批量运行、同步项目、下载均可执行。
5. 元信息管理可创建文本、单选、多选字段，并在标签创建和下游筛选中生效。

**29.10 上下架与更新**

1. 草稿/已下架可上架。
2. 已上架可下架。
3. 下架后下游不可使用，任务中断。
4. 重新上架后恢复任务。
5. 删除不可恢复。
6. 手动更新、定时更新、实时更新逻辑清晰且运行记录可追踪。
