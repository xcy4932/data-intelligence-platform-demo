**用户分群PRD**

**1. 模块定位**

用户分群模块用于在 CDP 私有化环境中，基于标签、行为、属性、明细数据、已有分群、上传文件、多主体关系等数据资源，创建、管理、更新、下载、授权、拆包、转换和应用用户分群。

模块的核心目标是让运营、营销、数据分析人员能够完成以下工作：

1. 创建目标人群包。
2. 对人群包进行规则维护、周期更新和手动更新。
3. 按分组、权限、主体、ID 类型等维度管理人群包。
4. 查看人群包数量变化、运行记录和数据血缘。
5. 将人群包用于洞察、触达、实验、自由分析、API 服务等下游场景。
6. 支持上传分群、高级人工分群、主体转换、多主体圈选、分群拆包等高级能力。

**2. 角色与权限**

**2.1 角色定义**

| **角色** | **权限范围** |
| --- | --- |
| 项目管理员 | 可查看、创建、编辑、删除、授权、下载、更新项目内全部分群；可管理分组；可查看所有运行记录；可配置分群服务、TTL 等高级设置 |
| 分群创建者 | 可管理自己创建的分群，包括编辑、授权、更新、下载、删除、修改分组等，前提是拥有对应模块权限 |
| 被授权用户 | 可查看被授权分群，可进入详情、运行记录、血缘页面；是否可下载、编辑取决于额外权限 |
| 普通用户 | 仅能查看自己有权限的分群；无权限时列表不展示或操作按钮置灰 |
| 系统管理员 | 可进行项目级、集团级功能配置，例如模板管理、推荐依赖类型、数据加解密、数据脱敏、功能开关等 |

**2.2 权限项**

| **权限项** | **控制范围** |
| --- | --- |
| 私域分群-查看 | 进入用户分群列表、查看详情、查看运行记录、查看数据血缘 |
| 私域分群-增删改分群 | 创建、编辑、删除、复制、修改分组、配置 TTL、配置服务、拆包 |
| 下载分群文件权限 | 下载 ID 列表、下载历史分群包、下载运行记录 |
| 管理分群分组权限 | 新建、编辑、删除分组 |
| 多主体圈选权限 | 使用多主体圈选创建分群 |
| 分群主体转换权限 | 使用分群主体转换功能 |
| 高级人工分群权限 | 使用高级人工分群上传和变更能力 |
| 高级拆包权限 | 使用按标签拆分的高级拆包能力 |
| 下游应用权限 | 使用私域洞察、GMP 触达、自由分析、实验创建等入口 |

**2.3 无权限展示逻辑**

1. 用户无模块查看权限时，不展示“用户分群”菜单。
2. 用户有查看权限但无创建权限时：
   * 展示列表。
   * “创建分群”“分群主体转换”等按钮置灰。
   * 鼠标悬停提示：暂无创建分群权限，请联系项目管理员开通。
3. 用户无下载权限时：
   * 下载按钮隐藏或置灰。
   * 点击时提示：暂无下载分群文件权限。
4. 高级功能未购买或产品开关关闭时：
   * 入口可隐藏。
   * 若展示入口，则置灰，并提示：该功能为增值功能，请联系商务或管理员开通。

**3. 核心概念**

**3.1 分群**

分群是基于一定条件得到的一组主体 ID 集合。主体可以是用户、门店、车辆、商品、线索等。

系统中每个分群必须至少包含以下信息：

| **字段** | **说明** |
| --- | --- |
| 分群 ID | 系统生成的唯一标识 |
| 分群名称 | 用户自定义名称 |
| 分群类型 | 规则创建、上传分群、高级人工分群、主体转换、多主体圈选、拆包子包 |
| 所属主体 | 当前分群对应的主体，例如用户、门店、车辆 |
| 输出 ID 类型 | 分群最终保存的 ID 类型，例如 OneID、手机号、会员 ID、设备 ID |
| 加密方式 | 明文、SHA256 或其他已配置算法 |
| 分群数量 | 当前最新版本的 ID 数量 |
| 状态 | 计算中、成功、失败、等待更新、已过期、已删除等 |
| 更新方式 | 按需更新、按天更新、到点更新 |
| 是否到点更新 | 是否配置固定整点更新 |
| 分组 | 分群所属分组，可多选 |
| 授权对象 | 被授权使用该分群的用户、用户组、角色或部门 |
| 创建人 | 创建该分群的用户 |
| 创建人 ID | 创建人账号 ID |
| 编辑人 | 最近一次编辑该分群的用户 |
| 编辑人 ID | 编辑人账号 ID |
| 创建时间 | 分群创建时间 |
| 最近更新时间 | 最近一次成功更新或修改的时间 |
| TTL | 分群历史版本保留周期或保留版本数 |
| 描述 | 分群业务说明 |

**3.2 母包与子包**

1. 母包是原始分群。
2. 子包是通过拆包功能从母包拆分出来的分群。
3. 子包继承母包的分组。
4. 子包不支持单独修改分组。
5. 子包在列表中通过母包左侧小三角展开展示。
6. 子包可用于下载、洞察、触达等应用，但是否支持再次拆包由产品策略控制，默认不支持对子包继续拆包，避免无限嵌套。

**3.3 分群版本**

每次分群计算成功后生成一个分群版本。

| **字段** | **说明** |
| --- | --- |
| version\_id | 分群版本 ID |
| segment\_id | 分群 ID |
| count | 当前版本 ID 数量 |
| status | 版本计算状态 |
| start\_time | 任务开始时间 |
| end\_time | 任务结束时间 |
| data\_partition\_time | 使用的数据分区时间 |
| file\_path | 当前版本结果文件路径 |
| error\_message | 失败原因 |
| is\_latest | 是否为当前最新版本 |

**3.4 TTL**

TTL 用于控制单个分群历史版本保留周期。

规则如下：

1. 单分群默认 TTL 为 32 天。
2. 支持用户修改。
3. 最大支持 730 天。
4. 单分群 TTL 优先级高于集团默认 TTL。
5. 每日系统任务检查分群历史版本，删除超过 TTL 的历史版本。
6. TTL 只影响历史版本，不删除当前最新版本。
7. 已被删除的历史版本不可恢复。
8. 老用户如沿用历史规则，则按原有配置执行；新建分群默认使用新 TTL 规则。

**5. 用户分群列表页**

**5.1 页面入口**

路径：

用户洞察> 用户分群

进入页面时，系统加载当前用户有权限查看的分群列表。

**5.2 页面布局**

页面从上到下分为：

1. 页面标题区。
2. 主操作按钮区。
3. 搜索与筛选区。
4. 分群列表表格区。
5. 批量操作区。
6. 分页区。

**5.3 页面主按钮**

**5.3.1 创建分群**

按钮名称：创建分群

点击后打开创建分群入口弹窗。

按钮状态：

| **状态** | **逻辑** |
| --- | --- |
| 可点击 | 用户拥有私域分群-增删改分群权限 |
| 置灰 | 用户无创建权限 |
| 隐藏 | 项目未启用私域分群创建能力 |

点击逻辑：

1. 点击按钮。
2. 系统弹出创建分群方式选择弹窗。
3. 用户选择创建方式。
4. 点击确定后进入对应创建页面。

**5.3.2 分群主体转换**

按钮名称：分群主体转换

点击后进入分群主体转换页面。

按钮状态：

| **状态** | **逻辑** |
| --- | --- |
| 可点击 | 用户拥有用户分群模块权限，且多主体相关能力已购买或开关开启 |
| 置灰 | 无权限或功能未开通 |
| 隐藏 | 项目不支持多主体能力 |

**5.3.3 管理分组**

按钮名称：管理分组

点击后进入分组管理页或打开分组管理抽屉。

按钮状态：

| **状态** | **逻辑** |
| --- | --- |
| 可点击 | 项目管理员、项目创建者、拥有管理分群分组权限的用户 |
| 置灰 | 无分组管理权限 |

**5.3.4 编辑列**

按钮名称：编辑列

点击后打开字段配置下拉面板。

可操作项：

1. 勾选字段。
2. 取消勾选字段。
3. 点击确定。
4. 点击恢复默认。
5. 点击取消。

交互逻辑：

1. 打开面板时，展示当前已选字段。
2. 用户勾选或取消字段。
3. 点击确定后，表格立即刷新为所选字段。
4. 点击恢复默认后，系统将勾选项恢复为系统默认字段。
5. 恢复默认后仍需点击确定才生效。
6. 点击取消或点击面板外区域，关闭面板，不保存修改。

字段规则：

1. 分群名称、分群 ID、分群数量、状态、更新时间至少保留一个核心识别字段。
2. 系统可限制某些字段不可取消，例如分群名称。
3. 用户配置应保存到个人维度，不影响其他用户。

**5.4 搜索区**

**5.4.1 分群名称/创建人搜索框**

占位文案：

请输入分群名称或创建人

搜索规则：

1. 支持按分群名称模糊搜索。
2. 支持按创建人名称模糊搜索。
3. 输入后按 Enter 或点击搜索图标触发查询。
4. 清空输入框后，恢复原列表。
5. 搜索条件与筛选条件共同生效，逻辑为 AND。

**5.4.2 我创建的**

控件类型：复选框。

勾选后：

1. 列表只展示当前登录用户创建的分群。
2. 与其他筛选条件共同生效。
3. 取消勾选后恢复展示当前用户有权限查看的全部分群。

**5.5 筛选区**

筛选字段包括：

| **筛选项** | **控件类型** | **逻辑** |
| --- | --- | --- |
| 分群 ID | 输入框 | 精确匹配或模糊匹配，支持搜索母包和子包 |
| ID 类型 | 多选下拉 | 按输出 ID 类型筛选 |
| 加密方式 | 多选下拉 | 按明文、SHA256 等加密方式筛选 |
| 分群数量 | 数值区间 | 支持最小值、最大值 |
| 分组 | 多选下拉 | 支持属于任意分组、属于所有分组 |

| 所属主体 | 多选下拉 | 用户、门店、车辆、商品等 |
| 更新方式 | 多选下拉 | 按需、按天、到点更新 |

**5.5.1 分组筛选逻辑**

分组筛选必须支持两种关系：

1. 属于任意分组。
2. 属于所有分组。

当用户选择多个分组时：

| **筛选逻辑** | **说明** |
| --- | --- |
| 属于任意分组 | 分群只要属于所选分组中的任意一个，即可被命中 |
| 属于所有分组 | 分群必须同时属于所选的全部分组，才可被命中 |

默认逻辑：属于任意分组。

**5.5.2 重置筛选**

按钮名称：重置

点击后：

1. 清空所有筛选项。
2. 清空搜索框。
3. 取消“我创建的”勾选。
4. 列表恢复默认查询结果。
5. 分页回到第 1 页。

**5.6.2 展开子包**

每行操作区展示常用按钮和“更多”按钮。

**6.1 查看详情**

按钮名称：查看详情

点击后进入分群详情页。

展示条件：

**6.2 编辑详情**

按钮名称：编辑详情

编辑范围：

| **分群类型** | **可编辑内容** |
| --- | --- |

| 上传分群 | 基础信息、授权、分组、描述、源文件覆盖更新 |

**6.3 更新分群包**

按钮名称：更新

点击后手动触发当前分群计算。

适用范围：

1. 按需更新分群。
2. 到点更新分群也可手动更新。
3. 按天更新分群可支持手动更新，但需要受系统并发控制。

点击逻辑：

1. 用户点击更新。
2. 系统检查权限。
3. 系统检查当前分群是否已有运行中任务。
4. 若无运行中任务，创建新任务。
5. 状态变为计算中。
6. 任务完成后刷新分群数量、更新时间、运行记录。

异常逻辑：

| **场景** | **处理** |
| --- | --- |
| 当前已有任务运行中 | 提示：当前分群正在更新中，请稍后再试。 |
| 上游数据未就绪 | 提示：上游数据任务未就绪，当前更新已进入等待状态。 |
| 规则无效 | 提示具体无效条件 |
| 任务失败 | 状态变为失败，并在运行记录中展示失败原因 |

**6.4 下载 ID 列表**

按钮名称：下载ID列表

点击后打开下载弹窗。

下载格式：

1. .txt
2. .csv
3. .gz

下载内容：

1. 当前分群最新版本 ID 列表。
2. 用户可选择是否加密，前提是 ID 类型支持加密且项目已完成加密配置。
3. 手机 ID 类型生成的人群包支持选择加密或不加密下载。

权限：

1. 必须拥有下载分群文件权限。
2. 无权限时按钮置灰或点击提示。

**6.5 复制分群包**

按钮名称：复制

支持复制已有分群。

限制：

1. 当前仅支持标签规则创建的人群包复制。
2. 上传分群、高级人工分群、主体转换、多主体圈选、子包默认不支持复制。
3. 无复制权限时置灰。

点击逻辑：

1. 点击复制。
2. 系统打开规则创建页面。
3. 自动带入原分群的规则条件、输出 ID 类型、加密方式、任务配置。
4. 分群名称默认填充为：原分群名称\_副本。

**10. 规则圈选组件**

**10.1 总体计算逻辑**

规则创建分群通过满足和排除两类条件得到最终分群。

计算公式：

最终分群 = 满足条件结果集 - 排除条件结果集

其中：

1. 满足条件支持多个条件组。
2. 满足条件的组内、组间支持 AND / OR。
3. 排除条件支持单个条件组。
4. 排除条件组内支持 AND / OR。
5. 满足与排除为平级组件。

**10.2 满足条件区**

**10.2.1 添加组条件**

按钮名称：添加组条件

点击后：

1. 新增一个条件组。
2. 默认组名为：条件组N。
3. 默认组内逻辑为 AND。
4. 新条件组与已有条件组之间默认逻辑为 AND。
5. 用户可以切换组间逻辑。

**10.2.2 重命名条件组**

操作：

1. 点击条件组名称旁的编辑图标。
2. 输入新名称。
3. 回车或失焦保存。

校验：

1. 名称不能为空。
2. 同一规则内组名可以重复，但建议提示用户区分。
3. 最大长度 50 字。

**10.2.3 删除条件组**

操作：

1. 点击条件组右侧删除图标。
2. 若该组已有条件，弹窗确认。
3. 确认后删除该组及其全部条件。

限制：

1. 满足条件至少保留 1 个条件组。
2. 若删除后无满足条件，保存时提示：请至少配置一个满足条件。

**10.2.4 切换 AND / OR**

控件名称：且/或

逻辑：

| **选项** | **计算含义** |
| --- | --- |
| 且 | 取交集 |
| 或 | 取并集 |

适用范围：

1. 条件组内部条件之间。
2. 多个条件组之间。

**10.3 排除条件区**

排除条件用于剔除不希望进入最终分群的人群。

规则：

1. 排除条件与满足条件平级。
2. 排除条件支持单个条件组。
3. 排除条件组内支持 AND / OR。
4. 排除条件可为空。
5. 若排除条件为空，则最终结果等于满足条件结果。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 添加排除条件 | 添加排除条件组 |
| 添加条件 | 在排除组中新增条件 |
| 删除排除条件 | 删除整个排除组 |
| 且/或切换 | 控制排除组内部条件关系 |

**10.4 条件类型**

添加条件后，用户选择条件来源。

支持类型：

1. 标签。
2. 行为。
3. 用户属性。
4. 明细数据。
5. 已有人群包。

**10.4.1 标签条件**

配置项：

1. 标签分类。
2. 标签名称。
3. 运算符。
4. 标签值。
5. 时间口径，如有。

常见运算符：

1. 等于。
2. 不等于。
3. 包含。
4. 不包含。
5. 属于。
6. 不属于。
7. 大于。
8. 大于等于。
9. 小于。
10. 小于等于。
11. 有值。
12. 无值。

**10.4.2 行为条件**

配置项：

1. 行为事件。
2. 时间范围。
3. 事件发生次数。
4. 事件属性条件。
5. 聚合方式。

示例逻辑：

最近 30 天购买商品次数 >= 1 且支付金额 > 5000

**10.4.3 属性条件**

配置项：

1. 属性字段。
2. 运算符。
3. 属性值。

**10.4.4 明细数据条件**

配置项：

1. 明细数据表。
2. 字段。
3. 运算符。
4. 字段值。
5. 时间分区或数据范围。

**10.4.5 已有人群包条件**

配置项：

1. 选择已有分群。
2. 选择关系：属于 / 不属于。

使用规则：

1. 只能选择当前用户有权限查看的人群包。
2. 引用分群时，应记录数据血缘。
3. 被引用分群被删除时，当前分群规则标记异常。

**11. ID 类型与 OneID 过滤**

**11.1 输出 ID 类型**

字段名称：ID类型

说明：

1. 选择分群最终输出的 ID 类型。
2. 下拉列表展示 ID 图谱中已引入的所有 ID 类型。
3. 例如 OneID、手机号、会员 ID、设备 ID、车辆 ID 等。

校验：

1. 必填。
2. 输出 ID 类型必须属于当前主体支持的 ID 类型。
3. 若规则条件与输出 ID 类型无法转换，保存时提示。

**11.2 OneID 子档案过滤**

业务问题：

一个 OneID 可能关联多个子 ID，例如一个 OneID 对应多个会员 ID。若直接以 OneID 圈选，再转成会员 ID，可能会把不符合条件的会员 ID 一并带出。

功能逻辑：

1. 当用户选择 OneID 作为基础查询 ID 时，系统支持添加子 ID 过滤条件。
2. 用户可选择档案类型。
3. 用户选择字段。
4. 用户设置限定关系。
5. 系统先基于 OneID 得到候选人群，再基于子 ID 条件过滤关联 ID。
6. 最终只保留符合子 ID 条件的目标 ID。

按钮：

| **按钮** | **逻辑** |
| --- | --- |
| 添加筛选条件 | 新增一条子 ID 过滤规则 |
| 删除 | 删除当前过滤规则 |
| 清空 | 清空全部子 ID 过滤条件 |

保存校验：

1. 档案类型必填。
2. 字段必填。
3. 运算符必填。
4. 需要值的运算符必须填写值。

**12. 加密方式**

字段名称：加密方式

支持：

1. 不加密。
2. SHA256。
3. 项目配置的其他加密算法。

逻辑：

1. 创建分群时可选择输出 ID 是否加密。
2. 选择加密后，分群结果文件按加密后的 ID 保存。
3. 加密后的人群包可能不支持推送到部分下游平台，例如 GMP。
4. 若用户选择了会影响下游使用的加密方式，系统需在保存前提示。

提示文案：

当前加密方式可能导致该分群无法在部分下游平台使用，请确认是否继续。

加密优先级：

1. 创建分群时选择的输出加密策略。
2. 项目数据加密策略。
3. 隐私数据脱敏策略。

若三类策略同时存在，仅执行创建时的输出加密策略。

**13. 抽样结果**

字段名称：抽样结果

功能：

用户可对规则结果进行随机抽样，并指定保留数量。

配置项：

1. 是否启用抽样。
2. 保留数量。

逻辑：

1. 若未启用抽样，输出全部结果。
2. 若启用抽样，系统从规则计算结果中随机抽取指定数量 ID。
3. 当保留数量大于实际结果数量时，输出实际全部结果。
4. 抽样后的结果作为该分群最终结果。
5. 其他人群包引用该分群时，以抽样后的结果为准。
6. 同一分群版本内抽样结果固定，不因页面刷新变化。
7. 每次重新计算生成新版本时，可重新抽样。

校验：

1. 保留数量必须为正整数。
2. 最大值不能超过系统配置上限。
3. 不允许输入小数、负数、0。

3. 到点更新只能选择整点，例如 00:00、08:00、12:00。
4. 系统在指定整点触发任务。
5. 若上一任务未完成，到点任务进入等待或跳过，具体按系统配置。建议进入等待队列。

**16.3 按天更新**

说明：

按天更新表示分群每天按固定时间自动计算。

配置项：

1. 执行时间。
2. 有效更新周期起始日期。
3. 有效更新周期终止日期。
4. 上游数据任务依赖。

规则：

1. 执行时间必填。
2. 执行时间可精确到分钟。
3. 可选择“此刻”作为首次执行时间。
4. 起始日期为空时，默认从保存成功后次日生效。
5. 终止日期为空时，表示长期有效。
6. 到达终止日期后，系统不再自动更新，但分群仍可查看和手动更新。

**16.4 上游数据任务依赖**

支持两种配置方式：

**推荐配置**

系统管理员可在集团设置中配置推荐依赖类型。

用户选择推荐配置后：

1. 系统自动读取推荐依赖。
2. 用户不可单独修改依赖项。
3. 当依赖任务全部就绪后，分群任务启动。

**自定义配置**

用户可自定义选择依赖项。

逻辑：

1. 用户勾选依赖任务。
2. 只有全部依赖任务就绪后，分群任务才执行。
3. ID 依赖表示当天 ID 任务就绪后，分群才启动更新。
4. 若分群规则依赖按周或按月更新的上游数据，不建立每日依赖。
5. 每天更新的分群使用上游最新有数据的分区。

**28. 分群主体转换**

**28.1 功能说明**

2. 选择关系模型：车辆与用户的购买关系。

**28.3 页面字段**

| 授权给 | 授权对象 |

| 更新频次 | 按需或按天 |

**28.4 创建主体转换规则**

按钮名称：保存

1. 分群文件必填。
2. 输出主体必填。
3. 输出主体不能与源分群主体相同。
4. ID 类型必填。
5. 关系模型必填。

7. 用户必须具备源分群查看权限。

4. 按输出 ID 类型转换。

2. 按天更新。

1. 按需更新时，用户需要手动更新。

6. 取消按钮。

**30.4 随机拆包**

随机拆包支持 3 种方式。

**30.4.1 限制数量上限**

逻辑：

1. 用户配置多个子包。
2. 每个子包配置数量上限。
3. 系统将母包 ID 随机打散。
4. 按子包顺序依次分配 ID。
5. 每个子包最多分配到配置上限。
6. 若总上限小于母包数量，剩余 ID 不进入任何子包。
7. 若总上限大于母包数量，后续子包可能少于配置上限。

校验：

1. 至少配置 1 个子包。
2. 每个子包数量上限必须为正整数。
3. 子包名称不能为空。

**30.4.2 限制包个数**

逻辑：

1. 用户输入子包数量 N。
2. 系统随机打散母包 ID。
3. 按 N 进行平均拆分。
4. 若不能整除，余数按顺序分配给前若干个子包。
5. 每个 ID 只能进入一个子包。

校验：

1. N 必须为正整数。
2. N 不能大于系统配置上限。
3. N 不能大于母包 ID 数量，若大于则提示。

**30.4.3 按比例拆包**

逻辑：

1. 用户配置每个子包比例。
2. 系统校验比例总和必须等于 100%。
3. 系统随机打散母包 ID。
4. 按比例计算每个子包数量。
5. 小数部分按最大余数法分配，确保总数等于母包数量。
6. 每个 ID 只能进入一个子包。

校验：

1. 每个比例必须大于 0。
2. 比例总和必须为 100%。
3. 子包数量不能超过系统上限。

**30.5 高级拆包**

高级拆包是增值功能。

前置条件：

1. 功能已购买。
2. 产品开关开启。
3. 用户有拆包权限。
4. 分群类型为规则创建分群或上传分群。
5. 最大拆包额度为 10 个。

高级拆包按标签进行精细拆分。

配置字段：

1. 拆分标签。
2. 拆分逻辑。
3. 标签值。
4. Top N 数量。
5. 子包命名规则。

支持逻辑：

| **逻辑** | **说明** |
| --- | --- |
| 包含 | 指定标签值成为子分群 |
| 排除 | 排除特定标签值，其他标签值成为子分群 |
| 用户数量 Top N | 用户数量最多的前 N 个标签值成为子分群 |
| 排除后用户数量 Top N | 先排除指定标签值，再取用户数量最多的前 N 个标签值成为子分群 |

**30.6 拆包保存**

点击保存后：

1. 校验配置。
2. 创建拆包任务。
3. 生成子包。
4. 子包继承母包分组。
5. 子包记录母包 ID。
6. 列表中母包显示小三角。
7. 点击小三角展开子包。

**34. 验收标准**

**34.1 列表页**

1. 用户只能看到自己有权限查看的分群。
2. 搜索分群名称、创建人可正确返回结果。
3. “我创建的”只返回当前用户创建的分群。
4. 分组筛选支持属于任意、属于所有两种逻辑。
5. 编辑列保存后只影响当前用户。
6. 点击分群名称进入详情。
7. 点击分群数量进入运行记录。
8. 母包有子包时可展开。
9. 子包继承母包分组且不可单独修改。
10. 批量删除、授权、分组均按权限正确执行。

**34.2 规则创建**

1. 支持满足和排除条件。
2. 满足条件支持多个条件组。
3. 排除条件支持单个条件组。
4. AND 取交集，OR 取并集。
5. 最终结果等于满足结果减排除结果。
6. 支持选择输出 ID 类型。
7. 支持 OneID 子档案过滤。
8. 支持加密方式选择。
9. 支持抽样结果配置。
10. 支持自动预估和手动查询。
11. 支持按需、到点、按天更新。
12. 支持上游依赖配置。
13. 保存后生成分群和运行任务。

**34.3 上传分群**

1. 支持 txt、csv 文件。
2. 超过 1G 禁止上传。
3. 支持下载模板。
4. 支持录入 ID 类型和生成 ID 类型。
5. 支持匹配全量用户。
6. 支持未匹配 ID 自增 OneID 开关。
7. 上传后展示解析结果。
8. 普通上传分群编辑时仅支持覆盖更新。
9. 高级人工分群支持替换、追加、剔除。

**34.4 分群管理**

1. 支持更新分群包。
2. 支持复制标签规则创建分群。
3. 支持修改分组。
4. 支持授权。
5. 支持服务配置。
6. 支持 TTL 配置。
7. 支持删除前查看血缘。
8. 删除后下游不可继续使用该分群。

**34.5 运行记录**

1. 可查看分群历史数量趋势。
2. 可按时间筛选历史详情。
3. 可按状态筛选运行记录。
4. 可下载运行记录。
5. 可下载历史分群包。
6. 可查看运行视图和失败原因。

**34.6 数据血缘**

1. 可展示上下游依赖。
2. 上下游各最多展示 7 层。
3. 支持图谱视图和列表视图。
4. 支持筛选标签、分群、数据源。
5. 支持下载血缘表。
6. 删除分群前可进入血缘查看影响。

**34.7 分群拆包**

1. 随机拆包支持限制数量上限、限制包个数、按比例拆包。
2. 高级拆包支持包含、排除、用户数量 Top N、排除后用户数量 Top N。
3. 高级拆包最大 10 个子包。
4. 高级拆包受产品开关控制，默认关闭。
5. 拆包完成后列表可展开查看子包。

**34.8 多主体与主体转换**

1. 主体转换输出主体不能等于源主体。
2. 主体转换必须选择关系模型。
3. 多主体圈选最多支持 3 个主体。
4. 多主体圈选必须选择目标输出主体。
5. 每个主体都支持满足和排除条件。
6. 多主体结果按主体关系交集和输出主体投影生成。
7. 多主体下载可按开关支持目标主体或全部过程分群。
