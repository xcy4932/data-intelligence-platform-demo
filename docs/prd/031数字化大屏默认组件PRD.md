**数字化大屏默认组件PRD**

**1. 文档定位**

本文定义数字化大屏中的默认组件能力，包括基础展示组件、媒体组件、时间组件、容器组件、筛选控件、日期控件、视频流播放器等。

本文不是“组件清单”，而是面向前端开发、后端接口、组件渲染器、画布编辑器、预览运行时的功能逻辑级 PRD。Codex 可以基于本文拆分组件、编写数据结构、实现样式面板、数据配置面板、运行时事件与组件渲染逻辑。

**2. 默认组件范围**

**2.1 组件分类**

默认组件分为 6 类：

| **分类** | **组件** | **是否可绑定数据** | **是否可作为交互源** | **是否可作为交互目标** |
| --- | --- | --- | --- | --- |
| 文本类 | 标题、单行文本、多行文本 | 否 | 是 | 是 |
| 图形类 | 矩形、圆 | 否 | 是 | 是 |
| 媒体类 | 图片、普通视频、网页、热区、视频流播放器 | 部分支持 | 是 | 是 |
| 时间类 | 日期时间、日期、时间、星期 | 否 | 是 | 是 |
| 容器类 | 重复器、轮播器、标签页 | 重复器支持，轮播器/标签页内部子组件支持 | 是 | 是 |
| 控件类 | 下拉选择器、多选下拉框、树状下拉选择器、树状多选下拉框、日期选择器 | 是 | 是 | 是 |

说明：

1. 文本、图形、图片、普通视频、网页、热区、时间类组件主要用于丰富大屏展示。
2. 重复器用于按数据行重复渲染一组组件模板。
3. 轮播器用于在多个 Panel 之间循环播放。
4. 标签页用于在多个 Tab 页面之间切换内容。
5. 下拉、树状下拉、多选、日期选择器用于筛选、参数控制和交互联动。
6. 视频流播放器用于接入 HLS、FLV 类型实时视频流。

**3. 默认组件通用设计**

**3.1 组件创建方式**

用户可通过两种方式添加默认组件：

| **操作方式** | **逻辑** |
| --- | --- |
| 双击组件卡片 | 在当前画布视口中心创建组件。 |
| 长按拖拽组件卡片到画布 | 在鼠标释放位置创建组件。 |

创建流程：

用户在左侧组件区选择默认组件

↓

双击或拖拽到画布

↓

系统生成组件实例

↓

写入当前页面 componentList

↓

画布渲染组件

↓

图层面板新增对应图层

↓

默认选中新组件

↓

右侧显示该组件样式配置面板

创建规则：

1. 新组件必须生成唯一 componentId。
2. 新组件默认 visible = true。
3. 新组件默认 locked = false。
4. 新组件默认 opacity = 100。
5. 新组件默认 zIndex 为当前页面最大 zIndex + 1。
6. 新组件名称按组件类型自动生成，例如“标题 1”“矩形 1”“重复器 1”。
7. 创建后将编辑器状态标记为 dirty。
8. 创建操作写入撤销栈。

**3.3 通用样式配置**

所有默认组件都支持以下基础样式：

| **配置项** | **说明** |
| --- | --- |
| X | 组件左上角相对画布左上角的横坐标 |
| Y | 组件左上角相对画布左上角的纵坐标 |
| W | 组件宽度 |
| H | 组件高度 |
| 锁定宽高比例 | 开启后拖拽缩放时保持原始宽高比例 |
| 不透明度 | 0-100，0 为完全透明，100 为完全不透明 |
| 超出区块部分不显示 | 开启后内容超出组件矩形区域时裁剪 |
| 标记 | 用于跨页面补间动画、事件定位、组件识别 |
| 出入场动画 | 支持入场动画和出场动画 |
| 交互事件 | 支持配置单击、双击、加载完成等事件 |

基础校验：

1. W、H 必须大于 0。
2. opacity 取值范围为 0-100。
3. x、y 允许为负数。
4. 组件锁定后，样式输入框置灰，不允许拖拽、缩放、删除。
5. 隐藏组件在画布中不显示，但仍在图层中展示。
6. 隐藏组件在预览和发布态不渲染，除非作为容器内部被逻辑强制显示。

**4. 文本类组件 PRD**

文本类组件包括：

1. 标题
2. 单行文本
3. 多行文本

**4.1 标题组件**

**4.1.1 使用场景**

标题组件用于大屏主标题、分区标题、指标模块标题、说明性文字。

**4.1.2 默认配置**

interface TitleComponentStyle {

content: string;

fontFamily: string;

fontWeight: "normal" | "bold" | number;

fontSize: number;

color: string;

letterSpacing: number;

lineHeight: number;

horizontalAlign: "left" | "center" | "right";

verticalAlign: "top" | "middle" | "bottom";

textDecoration?: "none" | "underline";

fontStyle?: "normal" | "italic";

}

默认值：

const defaultTitleStyle: TitleComponentStyle = {

content: "标题",

fontFamily: "Microsoft YaHei",

fontWeight: "bold",

fontSize: 32,

color: "#FFFFFF",

letterSpacing: 0,

lineHeight: 1.2,

horizontalAlign: "center",

verticalAlign: "middle",

textDecoration: "none",

fontStyle: "normal"

};

**4.1.3 编辑逻辑**

1. 用户双击标题组件，进入文本编辑状态。
2. 文本编辑状态下，组件边框保持选中状态，但快捷键优先作用于文本输入。
3. 用户输入内容后，实时更新画布。
4. 用户点击画布其他区域或按 Enter 完成编辑。
5. 用户按 Esc 取消本次编辑，恢复进入编辑前内容。
6. 修改内容后，将组件状态标记为 dirty。
7. 文本内容允许为空，但为空时编辑态显示占位文案“请输入标题”，预览态不显示占位。

**4.1.4 渲染逻辑**

1. 组件使用矩形容器承载文本。
2. 文本按 horizontalAlign 和 verticalAlign 在组件容器内定位。
3. 如果 overflowHidden = true，文本超出组件区域时裁剪。
4. 如果 overflowHidden = false，文本允许超出显示。
5. 标题组件默认不自动换行，除非样式开启换行。

**4.2 单行文本组件**

**4.2.1 使用场景**

单行文本用于短说明、指标单位、标签说明、状态提示等。

**4.2.2 配置结构**

interface SingleTextStyle extends TitleComponentStyle {

enableScroll: boolean;

scrollSpeed: number;

scrollLoopGapMs: number;

}

默认值：

const defaultSingleTextStyle: SingleTextStyle = {

content: "单行文本",

fontFamily: "Microsoft YaHei",

fontWeight: "normal",

fontSize: 20,

color: "#FFFFFF",

letterSpacing: 0,

lineHeight: 1.2,

horizontalAlign: "left",

verticalAlign: "middle",

textDecoration: "none",

fontStyle: "normal",

enableScroll: false,

scrollSpeed: 40,

scrollLoopGapMs: 1000

};

**4.2.3 滚动逻辑**

开启文字滚动时：

1. 仅当文本实际宽度大于组件宽度时执行滚动。
2. 文本从组件右侧或当前位置开始向左滚动。
3. 滚动到文本完全离开组件区域后，等待 scrollLoopGapMs。
4. 等待结束后重新开始下一轮滚动。
5. scrollSpeed 单位为 px/s。
6. 编辑态默认不自动滚动，避免影响编辑；预览和发布态执行滚动。
7. 如果组件隐藏，滚动暂停。
8. 组件重新显示后，从头开始滚动。

**4.3 多行文本组件**

**4.3.1 使用场景**

多行文本用于大屏说明、公告、段落内容、排名说明、运营提示。

**4.3.2 配置结构**

interface MultiTextStyle extends TitleComponentStyle {

enableScroll: boolean;

scrollDirection: "vertical" | "horizontal";

scrollSpeed: number;

scrollLoopGapMs: number;

wrap: boolean;

}

默认值：

const defaultMultiTextStyle: MultiTextStyle = {

content: "多行文本",

fontFamily: "Microsoft YaHei",

fontWeight: "normal",

fontSize: 18,

color: "#FFFFFF",

letterSpacing: 0,

lineHeight: 1.5,

horizontalAlign: "left",

verticalAlign: "top",

textDecoration: "none",

fontStyle: "normal",

enableScroll: false,

scrollDirection: "vertical",

scrollSpeed: 30,

scrollLoopGapMs: 1000,

wrap: true

};

**4.3.3 多行渲染规则**

1. wrap = true 时，文本根据组件宽度自动换行。
2. wrap = false 时，文本按原始行展示，超出部分根据 overflowHidden 处理。
3. 垂直滚动时，当文本总高度大于组件高度才执行滚动。
4. 横向滚动时，当文本最大行宽大于组件宽度才执行滚动。
5. 编辑态不执行滚动。
6. 预览和发布态执行滚动。

**5. 图形类组件 PRD**

图形类组件包括：

1. 矩形
2. 圆

**5.1 矩形组件**

**5.1.1 使用场景**

矩形用于模块背景、卡片容器、边框装饰、遮罩、色块、分割区域。

**5.1.2 配置结构**

interface RectangleStyle {

fillType: "color" | "image" | "none";

backgroundColor?: string;

backgroundImageUrl?: string;

backgroundImageFit: "cover" | "contain" | "stretch" | "repeat";

borderEnabled: boolean;

borderColor: string;

borderWidth: number;

borderStyle: "solid" | "dashed" | "dotted";

borderRadius: number;

blurEnabled: boolean;

blurType: "background" | "self";

blurValue: number;

boxShadowEnabled: boolean;

boxShadow?: {

x: number;

y: number;

blur: number;

spread: number;

color: string;

};

}

默认值：

const defaultRectangleStyle: RectangleStyle = {

fillType: "color",

backgroundColor: "rgba(255,255,255,0.1)",

backgroundImageFit: "cover",

borderEnabled: false,

borderColor: "#FFFFFF",

borderWidth: 1,

borderStyle: "solid",

borderRadius: 0,

blurEnabled: false,

blurType: "self",

blurValue: 0,

boxShadowEnabled: false

};

**5.1.3 渲染逻辑**

1. fillType = color 时使用背景色。
2. fillType = image 时使用背景图，背景图按 backgroundImageFit 渲染。
3. fillType = none 时无填充，仅展示边框或阴影。
4. borderEnabled = false 时不渲染边框。
5. borderRadius 只对矩形生效。
6. blurEnabled = true 时，根据 blurType 应用模糊：
   * self：组件自身内容模糊。
   * background：组件背后区域背景模糊。
7. overflowHidden = true 时，背景图和内部内容被圆角裁剪。

**5.2 圆组件**

**5.2.1 使用场景**

圆组件用于圆点装饰、状态灯、圆形背景、环状视觉元素的基础形状。

**5.2.2 配置结构**

interface CircleStyle {

fillType: "color" | "image" | "none";

backgroundColor?: string;

backgroundImageUrl?: string;

backgroundImageFit: "cover" | "contain" | "stretch";

borderEnabled: boolean;

borderColor: string;

borderWidth: number;

borderStyle: "solid" | "dashed" | "dotted";

blurEnabled: boolean;

blurValue: number;

}

**5.2.3 渲染逻辑**

1. 圆组件始终渲染为椭圆或圆。
2. 当 width = height 时显示为正圆。
3. 当 width != height 时显示为椭圆。
4. 圆组件不展示圆角配置。
5. 背景图自动裁剪在圆形区域内。
6. 边框沿圆形路径渲染。

**6. 媒体类组件 PRD**

媒体类组件包括：

1. 图片
2. 普通视频
3. 网页
4. 热区
5. 视频流播放器

**6.1 图片组件**

**6.1.1 使用场景**

图片组件用于展示 logo、背景图、业务插图、图标、已设计好的视觉素材。

**6.1.2 配置结构**

interface ImageStyle {

imageUrl?: string;

objectFit: "cover" | "contain" | "fill" | "none";

objectPosition: "left-top" | "left-center" | "left-bottom" | "center" | "right-top" | "right-center" | "right-bottom";

backgroundColor?: string;

emptyPlaceholder: string;

}

**6.1.3 上传逻辑**

1. 用户添加图片组件后，如果未配置图片，画布显示上传占位。
2. 用户点击上传区域，打开文件选择器。
3. 允许上传 png、jpg、jpeg、webp、gif。
4. 上传成功后，后端返回 imageUrl。
5. 前端将 imageUrl 写入组件 style。
6. 上传失败时，组件保持原图，提示失败原因。
7. 删除图片后，组件回到上传占位状态。

**6.1.4 渲染逻辑**

1. objectFit = cover：图片填满组件，超出部分裁剪。
2. objectFit = contain：图片完整展示，可能留白。
3. objectFit = fill：图片拉伸到组件宽高。
4. objectFit = none：按图片原始尺寸渲染。
5. 图片加载失败时，编辑态显示“图片加载失败”，发布态显示空状态或默认占位图。

**6.2 普通视频组件**

**6.2.1 使用场景**

普通视频组件用于播放已上传的视频文件或在线视频地址。

**6.2.2 配置结构**

interface VideoStyle {

videoUrl?: string;

autoplay: boolean;

loop: boolean;

muted: boolean;

controls: boolean;

objectFit: "cover" | "contain" | "fill";

posterUrl?: string;

}

**6.2.3 配置逻辑**

1. 用户可选择已上传的在线视频。
2. 用户也可填写视频 URL。
3. URL 必须为 http 或 https。
4. 如果浏览器安全策略限制自动播放，则自动播放必须配合 muted。
5. 编辑态默认不自动播放，显示视频封面或第一帧。
6. 预览和发布态按配置播放。

**6.2.4 事件**

| **事件** | **触发时机** |
| --- | --- |
| 单击 | 用户点击视频组件 |
| 双击 | 用户双击视频组件 |
| 加载完成 | 视频资源 metadata 加载完成 |
| 播放开始时 | 视频开始播放 |
| 播放结束时 | 视频播放结束，循环播放时每轮结束都触发 |

**6.3 网页组件**

**6.3.1 使用场景**

网页组件用于通过 iframe 嵌入第三方页面、内部业务页面、可视化页面或外部链接内容。

**6.3.2 配置结构**

interface IframeStyle {

url: string;

allowScroll: boolean;

sandboxEnabled: boolean;

sandboxRules: string[];

backgroundColor?: string;

}

**6.3.3 配置逻辑**

1. 用户在样式面板填写 URL。
2. URL 不能为空。
3. URL 必须以 http 或 https 开头。
4. 编辑态如果 URL 为空，显示“请填写网页地址”。
5. iframe 加载失败时，显示“网页加载失败”。
6. 若目标网站禁止 iframe 嵌入，组件显示错误提示。
7. 发布态不允许 iframe 错误影响整个大屏页面。

**6.3.4 安全规则**

1. 私有化环境默认开启 iframe sandbox。
2. 如业务需要访问同源能力，可由管理员配置白名单。
3. 非白名单地址不得开放高危 sandbox 权限。
4. 禁止执行平台未授权的脚本注入。

**6.4 热区组件**

**6.4.1 使用场景**

热区用于在任意区域上覆盖透明点击区域，实现跳转、触发交互、打开链接等效果。

**6.4.2 配置结构**

interface HotspotStyle {

targetType: "url" | "page" | "interaction";

targetUrl?: string;

targetPageId?: string;

openMode: "current" | "newWindow";

showInEditor: boolean;

editorMaskColor: string;

}

默认值：

const defaultHotspotStyle: HotspotStyle = {

targetType: "url",

targetUrl: "",

openMode: "newWindow",

showInEditor: true,

editorMaskColor: "rgba(0, 128, 255, 0.2)"

};

**6.4.3 渲染逻辑**

1. 编辑态显示半透明蒙层，方便用户看到热区位置。
2. 预览和发布态不显示蒙层，但保留点击区域。
3. 用户点击热区时，根据配置执行动作：
   * targetType = url：打开目标 URL。
   * targetType = page：切换到目标大屏页面。
   * targetType = interaction：执行交互面板配置的响应。
4. 如果 URL 为空，预览态点击无动作，并在编辑态提示配置不完整。
5. 热区必须始终位于可点击层级上，如果被其他组件覆盖，则按 zIndex 决定点击命中。

**7. 时间类组件 PRD**

时间类组件包括：

1. 日期时间
2. 日期
3. 时间
4. 星期

**7.1 通用时间组件配置**

interface TimeComponentStyle {

format: string;

timezone: "local" | string;

fontFamily: string;

fontWeight: "normal" | "bold" | number;

fontSize: number;

color: string;

letterSpacing: number;

horizontalAlign: "left" | "center" | "right";

verticalAlign: "top" | "middle" | "bottom";

updateIntervalMs: number;

}

默认规则：

1. 时间组件不需要绑定数据。
2. 时间组件读取浏览器本地时间，除非指定 timezone。
3. 预览和发布态每秒刷新。
4. 编辑态也可以刷新，但不写入历史栈。
5. 时间格式变更后立即重新渲染。

**7.2 日期时间组件**

默认格式：

yyyy-MM-dd HH:mm:ss

示例：

2026-05-25 14:30:01

逻辑：

1. 同时展示日期和时间。
2. 支持修改日期分隔符。
3. 支持是否展示秒。
4. 支持 24 小时制和 12 小时制。

**7.3 日期组件**

默认格式：

yyyy-MM-dd

逻辑：

1. 只展示日期。
2. 支持格式：yyyy-MM-dd、yyyy/MM/dd、MM-dd-yyyy、dd/MM/yyyy。
3. 日期每天跨日后自动刷新。

**7.4 时间组件**

默认格式：

HH:mm:ss

逻辑：

1. 只展示时间。
2. 支持是否展示秒。
3. 支持 24 小时制或 12 小时制。
4. 每秒刷新。

**7.5 星期组件**

默认格式：

星期一

**8. 视频流播放器 PRD**

**8.1 使用场景**

视频流播放器用于监控大屏、安防大屏、园区大屏、设备状态大屏等实时视频场景，支持接入 HLS 和 FLV 类型视频流。

**8.3 视频地址优先级**

视频流地址有两个来源：

| **来源** | **优先级** |
| --- | --- |
| 数据可视化面板中的视频地址字段 | 高 |
| 样式配置面板中手动填写的视频地址 | 低 |

运行逻辑：

如果 dataBinding.videoUrlField 有值，并且查询结果第一行存在有效视频地址

↓

否则

↓

规则：

1. 数据面板的视频地址字段只接受一个维度字段。
2. 如果查询结果有多行，默认取第一行的视频地址。
3. 如果字段值为空，降级使用样式面板视频地址。
4. 如果两个来源均为空，组件显示“请配置视频地址”。

**8.4 支持格式**

| **类型** | **判断方式** |
| --- | --- |
| HLS | URL 包含 .m3u8 或 streamType = hls |
| FLV | URL 包含 .flv 或 streamType = flv |
| auto | 根据 URL 后缀自动识别 |

异常规则：

1. 无法识别格式时，显示“暂不支持该视频流格式”。
2. 播放器初始化失败时，不影响其他组件。
3. 浏览器不支持 FLV 时，显示兼容性提示。

**8.5 断流重连**

配置项：

reconnectEnabled: boolean;

reconnectIntervalSeconds: number;

maxReconnectAttempts?: number;

逻辑：

1. 当播放器触发 error、stalled、network disconnect 等异常时，判断是否开启断流重连。
2. 未开启时，直接显示异常提示。
3. 开启时，等待 reconnectIntervalSeconds 后重新创建播放器实例。
4. 如果配置了 maxReconnectAttempts，达到次数后停止重试。
5. 如果未配置最大次数，持续重试。
6. 每次重试需要先销毁旧播放器实例，避免多连接占用资源。
7. 重连成功后清空错误状态。

**8.6 隐藏卸载**

配置项：

unloadWhenHidden: boolean;

逻辑：

1. 当组件被交互隐藏、页面切换隐藏、容器 Panel 隐藏时：
   * 如果 unloadWhenHidden = true，销毁播放器实例，停止拉流。
   * 如果 unloadWhenHidden = false，播放器实例保持，但暂停渲染。
2. 当组件重新显示时：
   * 如果此前已销毁，则重新创建播放器实例。
   * 如果此前未销毁，则恢复播放。
3. 多点位切换场景建议开启隐藏卸载，避免多个视频流同时占用网络资源。

**10. 重复器 PRD**

**10.1 使用场景**

重复器用于将同一套组件模板按照数据行重复展示，例如：

1. 区域销售卡片列表。
2. 城市指标排名。
3. 设备状态矩阵。
4. 类表格布局。
5. 多个业务对象统一卡片展示。

**10.2 核心逻辑**

重复器不是简单复制组件，而是：

配置一套子项模板

↓

↓

↓

每个重复项使用同一套模板

↓

每个重复项注入当前行数据

↓

通过交互或表达式把行数据写入模板内组件

**10.4 样式配置：重复方向**

| **配置项** | **说明** |
| --- | --- |
| 行 | 子项从左到右排列 |
| 列 | 子项从上到下排列 |
| 行内个数 | 每行或每列展示多少个子项 |
| 超出折行 | 超出每行/每列展示个数后换行或换列 |
| 水平间距 | 子项之间的横向距离 |
| 垂直间距 | 子项之间的纵向距离 |

布局算法：

function getRepeaterItemPosition(index: number, config: RepeaterConfig) {

const lineIndex = Math.floor(index / config.itemsPerLine);

const itemIndexInLine = index % config.itemsPerLine;

if (config.direction === "row") {

return {

x: itemIndexInLine \* (template.width + config.horizontalGap),

y: lineIndex \* (template.height + config.verticalGap)

};

}

return {

x: lineIndex \* (template.width + config.horizontalGap),

y: itemIndexInLine \* (template.height + config.verticalGap)

};

}

规则：

1. itemsPerLine 必须大于等于 1。
2. horizontalGap、verticalGap 必须大于等于 0。
3. wrap = false 时，所有子项沿主方向连续排列，超出容器部分根据 overflowHidden 裁剪。
4. wrap = true 时，超过 itemsPerLine 后换行或换列。

**10.5 分页逻辑**

当重复器子项数量超出可展示区域时，可分页展示。

配置项：

paginationEnabled: boolean;

autoPagePlayEnabled: boolean;

autoPageIntervalSeconds: number;

分页计算：

const itemsPerPage = calculatedVisibleItemCount;

const totalPages = Math.ceil(dataRows.length / itemsPerPage);

规则：

1. paginationEnabled = false 时，不分页，全部子项按布局渲染。
2. paginationEnabled = true 时，只渲染当前页子项。
3. 当前页从 0 开始。
4. 超出数据为空时，显示空状态。
5. autoPagePlayEnabled = true 时，预览和发布态按时间间隔切换页面。
6. 自动轮播仅在预览和发布态生效，编辑态不自动切换。
7. 页面隐藏时自动轮播暂停。
8. 页面重新显示后继续轮播。

**10.6 数据配置**

重复器数据面板字段：

| **字段** | **说明** |
| --- | --- |
| 列 | 首个字段决定重复器重复项数量；添加到列中的所有字段都可在事件中取值 |
| 排序 | 对结果进行升序、降序或自定义排序 |
| 筛选 | 对数据进行过滤 |
| TopN | 展示头部或尾部 N 条数据 |

规则：

1. columns 至少配置 1 个字段。
2. 第一个字段作为重复项主字段。
3. 重复器最终生成的重复项数量等于查询结果行数。
4. 字段可包含维度和指标。
5. 如果查询失败，重复器显示异常状态。
6. 如果查询成功但无数据，重复器显示空状态。
7. 如果字段被删除，重复器进入配置异常状态。

**16. 树状下拉选择器 PRD**

**16.1 使用场景**

树状下拉选择器用于多层级数据逐级选择，例如：

1. 省 - 市 - 区。
2. 大区 - 城市 - 门店。
3. 一级品类 - 二级品类 - 商品。
4. 组织 - 部门 - 小组。

**16.2 数据配置**

interface TreeSelectDataBinding extends ControlDataBinding {

optionFields: FieldMapping[];

}

字段规则：

1. optionFields 可接受多个维度字段。
2. 字段顺序对应树形菜单层级。
3. 第一个字段为第一层级。
4. 第二个字段为第二层级。
5. 以此类推。
6. 至少配置 1 个字段。
7. 不支持指标字段作为树层级字段。

树构建逻辑：

function buildTree(rows: any[], fields: string[]): TreeNode[] {

const root: TreeNode[] = [];

for (const row of rows) {

let currentLevel = root;

fields.forEach((field, level) => {

const value = row[field];

if (value === null || value === undefined || value === "") return;

let node = currentLevel.find(item => item.value === value);

if (!node) {

node = {

label: String(value),

value: String(value),

level: level + 1,

fieldName: field,

children: [],

rawRows: []

};

currentLevel.push(node);

}

node.rawRows.push(row);

currentLevel = node.children;

});

}

return root;

}

**19. 数据更新、排序、筛选、TopN 通用逻辑**

所有支持数据配置的默认组件，包括重复器、下拉、树状下拉、多选下拉、日期选择器、视频流播放器，都遵循统一数据处理链路。

应用全局筛选

应用组件筛选

↓

↓

↓

↓

**19.2 排序**

interface SortConfig {

fieldKey: string;

规则：

1. 排序字段必须来自当前数据源。

4. 自定义排序按 customOrder 顺序排列。

| "="

| "!="

| "in"

| "notIn"

| "contains"

| "notContains"

| ">"

| ">="

| "<"

| "<="

interface TopNConfig {

}

规则：

1. n 必须为正整数。
2. direction = top 时取前 N 项。
3. direction = bottom 时取后 N 项。

5. 如果未配置排序字段，则按查询返回顺序取 TopN。
6. TopN 在筛选之后执行。

**21.1 交互结构**

**21.2 执行规则**

1. 事件触发后，先检查 enabled。
2. 如果事件禁用，则不执行。
3. 如果有条件，则依次计算条件。
4. 所有条件通过后执行 actions。
5. actions 默认按顺序执行。
6. 某个 action 失败时，记录日志，不阻断后续 action，除非 action 配置为强依赖。
7. 设置元素属性时，如果目标组件不存在，跳过并记录错误。
8. 表达式函数需要显式启用 fx 状态，否则按普通字符串处理。
9. 表达式执行异常时，当前 action 失败，不影响整个大屏运行。

**25. 验收标准**

**25.1 默认组件创建与编辑**

1. 用户可以从左侧组件区添加所有默认组件。
2. 双击组件卡片可以在画布中心创建组件。
3. 拖拽组件卡片可以在释放位置创建组件。
4. 创建组件后，画布选中新组件。
5. 图层面板同步新增组件。
6. 组件可拖拽、缩放、锁定、隐藏、复制、删除。
7. 修改组件样式后，画布实时更新。
8. 保存后刷新页面，组件配置不丢失。

**25.2 文本与图形组件**

1. 标题、单行文本、多行文本可以编辑内容。
2. 文本字体、粗细、字号、颜色、字间距、对齐方式生效。
3. 单行文本和多行文本开启滚动后，预览和发布态可以滚动。
4. 矩形支持背景色、背景图、边框、圆角、虚线、模糊。
5. 圆组件支持背景色、背景图、边框、模糊。
6. 超出区块隐藏配置对文本、图片、图形均生效。

**25.3 媒体组件**

1. 图片组件可以上传并展示图片。
2. 普通视频组件可以播放视频 URL。
3. 网页组件可以嵌入合法 URL。
4. 热区编辑态显示蒙层，预览态不显示蒙层但可点击。
5. 视频流播放器支持 HLS、FLV。
6. 视频流播放器数据面板视频地址优先于样式面板视频地址。
7. 开启断流重连后，断流时按重试间隔重新连接。
8. 开启隐藏卸载后，组件隐藏时销毁播放器实例。

**25.4 容器组件**

1. 重复器可以双击进入内部模板编辑。
2. 重复器可以按行或列重复展示子项。
3. 重复器支持行内个数、折行、水平间距、垂直间距。
4. 重复器绑定数据后，按数据行数生成重复项。
5. 重复器每项事件可以抛出当前行数据。
6. 轮播器可以创建多个 Panel。
7. 轮播器预览态可以自动轮播。
8. 轮播器指示点可显示、点击、配置样式。
9. 标签页可以创建多个 Tab。
10. 标签页可以显示或隐藏 Tab 头部。
11. 标签页开启自动轮播后，预览态自动切换内容。

**25.5 控件组件**

1. 下拉选择器可以查询选项并选择单个值。
2. 下拉选择器支持搜索系统提供的选项，不支持用户自由输入。
3. 多选下拉框支持多选、全选、反选、清除。
4. 树状下拉选择器支持多层级字段生成树。
5. 树状下拉选择器选中节点后抛出路径、层级、字段名和子节点。
6. 树状多选下拉框支持多层级多选。
7. 树状多选下拉框支持自动勾选下一级。
8. 日期选择器可以选择日期。
9. 配置可选择日期字段后，非可选日期置灰。
10. 日期变化事件可以抛出 dateString、timestamp、date、month、year。

**25.6 数据与交互**

1. 所有支持数据配置的组件都支持更新方式、数据来源、排序、筛选、TopN。
2. 数据查询失败时，只影响当前组件。
3. 控件选项变化后可以触发交互事件。
4. 交互事件可以设置其他组件属性。
5. 交互事件可以刷新图表数据。
6. 表达式 fx 未启用时，内容按普通字符串处理。
7. 表达式执行失败时，不影响整个大屏运行。
