**数据集创建PRD**

**1. 产品定位**

**1.1 功能目标**

数据集是智能数据洞察系统中承载数据、管理数据、建模分析和可视化消费的基础对象。用户需要先将数据源表、SQL 查询结果、文件数据、LAS 表、主题数据集或多个已有数据集加工为可分析的数据集，后续才能在可视化查询、仪表盘、关联分析、标签分析、人群分析等场景中使用。

本模块需要支持以下核心能力：

1. 创建普通数据集
   用户可以基于已有数据连接、LAS 数据源、表、视图、自定义 SQL 等创建数据集。
2. 创建关联数据集
   用户可以将多个已有数据集按字段进行 Join 关联，形成新的分析数据集。
3. 配置模型结构
   用户可以通过拖拽表、配置 Join、Union、字段选择、字段别名、字段类型等方式构建数据模型。
4. 配置数据筛选
   用户可以在模型配置前或模型配置后对数据进行过滤，减少冗余数据，提高同步和查询性能。
5. 配置字段
   用户可以基于原始字段生成逻辑字段、计算字段、维度指标、排序规则、字段可见性等。
6. 配置同步
   对抽取数据集，用户可以配置同步频率、依赖、监控、性能、高级运行参数，并查看同步状态。
7. 应用主题数据集
   用户可以使用 CDP、数据洞察、GMP 等主题数据集进行可视化探索、群体分析、标签分析和营销融合分析。
8. 应用关联数据集
   用户可以将主题数据集与自定义数据集关联，形成跨系统、跨业务域的融合分析能力。

**2. 用户角色与权限**

**2.1 用户角色**

| **角色** | **说明** | **可执行操作** |
| --- | --- | --- |
| 项目管理员 | 拥有项目管理权限 | 创建、编辑、删除、授权、转移、配置同步、配置权限 |
| 数据生产者 | 负责数据准备和建模 | 创建数据集、配置模型、配置字段、配置同步、创建关联数据集 |
| 分析用户 | 负责看数和分析 | 查看有权限的数据集、发起可视化查询、使用仪表盘 |
| 普通只读用户 | 只能消费已有分析结果 | 查看被授权的数据集、查看仪表盘，不可修改配置 |
| 主题数据集用户 | 拥有 CDP/数据洞察/GMP 相关权限 | 查看主题数据集、使用主题数据集分析、创建关联分析 |

**2.2 权限规则**

**2.2.1 创建普通数据集权限**

用户必须同时满足：

| **条件** | **规则** |
| --- | --- |
| 项目权限 | 用户拥有当前项目的编辑权限 |
| 数据连接权限 | 用户拥有目标数据连接的查看或使用权限 |
| 表权限 | 用户只能看到自己有权限访问的库、表、字段 |
| 数据集目录权限 | 用户对目标文件夹拥有创建权限 |

如果用户没有项目编辑权限：

1. 新建数据集按钮置灰。
2. 鼠标悬浮显示：当前账号暂无项目编辑权限，请联系管理员开通。
3. 如果系统支持权限申请，则显示 申请权限 按钮。
4. 点击后弹出申请权限弹窗，默认申请当前项目的编辑权限。

**2.2.2 创建关联数据集权限**

用户必须满足：

| **条件** | **规则** |
| --- | --- |
| 数据集资源权限 | 用户对参与关联的数据集拥有查看及以上权限 |
| 数据集行列权限 | 关联后的数据查询仍继承原始数据集行列权限 |
| 存储兼容性 | 参与关联的数据集必须满足存储方式兼容规则 |
| 主题数据集权限 | 使用 CDP/数据洞察/GMP 数据集时，必须拥有对应系统的数据权限 |

对于无权限或仅阅览权限的数据集：

1. 不展示在可拖拽列表中，或展示但置灰。
2. 置灰原因显示：当前账号暂无该数据集的查看权限，无法用于关联建模。

**2.2.3 主题数据集权限**

主题数据集展示依赖产品部署和权限：

| **条件** | **展示逻辑** |
| --- | --- |
| 用户无主题数据集权限 | 展示文件夹但数据集置灰，提示无权限 |
| 用户有权限 | 可查看详情、预览、可视化查询 |

主题数据集通常不允许用户编辑基础信息、修改模型、删除、移动、复制或切换资源配置。

**5. 用户主流程**

**5.1 新建普通数据集流程**

进入数据集模块

→ 点击新建

→ 选择新建数据集

→ 选择数据连接或 LAS

→ 进入模型配置页面

→ 拖拽表或自定义 SQL 到画布

→ 选择字段

→ 配置 Join / Union

→ 配置模型配置前筛选

→ 配置模型配置后筛选

→ 配置字段

→ 如果是抽取模式，配置同步设置

→ 预览数据

→ 保存

→ 生成数据集

→ 可视化查询 / 仪表盘 / 关联分析

**5.2 新建关联数据集流程**

进入数据集模块

→ 点击新建

→ 选择新建关联数据集

→ 左侧展示当前用户有权限的数据集

→ 拖入两个或多个数据集

→ 配置关联字段

→ 如果字段格式不一致，可配置字段表达式

→ 如果涉及主题数据集和 ID 字段，可启用 ID-Mapping

→ 配置输出字段

→ 保存

→ 生成关联数据集

→ 进入可视化查询或仪表盘分析

**5.3 应用主题数据集流程**

进入数据集模块

→ 切换到主题数据集

→ 打开 CDP / 数据洞察 / GMP 文件夹

→ 选择主题数据集

→ 查看详情、数据预览、模型信息、血缘、权限

→ 点击可视化查询

→ 生成图表

→ 保存为分析或保存到仪表盘

**5.4 主题数据集与自定义数据集关联分析流程**

准备主题数据集

→ 准备自定义数据集

→ 新建关联数据集

→ 拖入主题数据集和自定义数据集

→ 配置关联字段

→ 必要时启用 ID-Mapping

→ 保存关联数据集

→ 使用关联数据集做可视化查询

→ 生成营销分析、用户行为分析、标签分析、转化分析仪表盘

**8.3.1 交互逻辑**

用户从左侧拖拽表到画布：

1. 前端创建临时 ModelNode。
2. 调用元数据接口获取字段。
3. 默认选中所有字段。
4. 节点显示表名、连接名、字段数量。
5. 节点底部显示操作：字段、筛选、预览、删除。

**8.3.2 默认节点状态**

const defaultModelNode = {

type: "table",

alias: tableName,

selectedFields: allFields,

preFilters: [],

};

**8.3.3 节点别名规则**

1. 默认别名为表名。
2. 同一画布中别名不可重复。
3. 如果重复，系统自动追加序号，例如 order\_1、order\_2。
4. 用户可手动修改别名。
5. 别名只能包含中文、英文、数字、下划线。
6. 长度限制 1 到 64 个字符。

**8.4 字段选择**

**8.4.1 入口**

用户点击表节点上的 字段 按钮，底部或右侧打开字段选择面板。

**8.4.2 字段面板内容**

| **字段** | **说明** |
| --- | --- |
| 勾选框 | 是否导入该字段 |
| 原字段名 | 数据源字段名 |
| 显示名 | 数据集字段展示名 |
| 类型 | string、number、date 等 |
| 是否分区字段 | 分区表展示 |
| 是否主键 | 如果元数据可识别则展示 |

**8.4.3 字段选择规则**

1. 默认全选。
2. 用户可取消勾选字段。
3. 至少保留一个字段。
4. 被 Join 条件引用的字段不可取消，除非先删除 Join 条件。
5. 被筛选条件引用的字段不可取消，除非先删除筛选条件。
6. 被计算字段引用的字段不可取消，除非先删除计算字段。

**8.4.4 校验提示**

| **场景** | **提示** |
| --- | --- |
| 未选择任何字段 | 至少需要选择一个字段。 |
| 取消被 Join 使用的字段 | 该字段已被关联条件使用，请先删除关联条件。 |
| 取消被筛选条件使用的字段 | 该字段已被数据筛选使用，请先删除筛选条件。 |
| 取消被计算字段引用的字段 | 该字段已被计算字段引用，请先删除或修改计算字段。 |

**9. 自定义 SQL 数据集**

**9.1 入口**

在模型配置页面左侧固定展示 自定义 SQL 节点，用户可以将其拖入画布。

**9.2 SQL 编辑区**

拖入自定义 SQL 后，底部显示 SQL 编辑器。

**9.2.1 编辑器功能**

| **功能** | **逻辑** |
| --- | --- |
| 输入 SQL | 支持多行 SQL |
| 插入表查询语句 | 用户点击表名后，可快速插入 SELECT \* FROM table\_name |
| 格式化 SQL | 对 SQL 进行格式化 |
| 保存 SQL | 保存到当前 SQL 节点 |
| 校验 SQL | 调用后端解析 SQL |
| 预览结果 | 执行采样查询 |
| 切换抽取/直连 | 根据连接支持情况选择 |

**9.2.2 SQL 保存逻辑**

点击 保存 SQL：

1. 前端检查 SQL 非空。
2. 后端解析 SQL。
3. 后端返回字段结构。
4. 前端更新当前 SQL 节点的字段列表。
5. 如果 SQL 解析失败，保留原 SQL，不更新字段。

**9.2.3 SQL 校验规则**

| **校验项** | **规则** |
| --- | --- |
| SQL 非空 | 不能为空 |
| SQL 类型 | 只允许查询类 SQL，不允许 DDL、DML |
| 字段别名 | 输出字段名不可重复 |
| 字段数量 | 至少输出一个字段 |
| 直连模式 | 不允许跨数据连接查询 |
| 抽取模式 | 可按系统能力支持跨源加工 |
| 危险语句 | 禁止 drop、delete、update、insert、truncate、alter |

**9.2.4 SQL 节点字段生成逻辑**

后端返回：

type SqlParseResult = {

valid: boolean;

fields: SourceField[];

errorMessage?: string;

};

字段生成规则：

1. SQL 输出列作为节点字段。
2. 如果 SQL 输出列没有别名，则使用原列名。
3. 如果存在重复字段名，保存失败。
4. SQL 字段类型由后端推断。
5. 用户后续可在字段配置中修改显示名、维度指标、格式等。

**10. Join 多表关联**

**10.1 创建 Join**

用户在画布中拖入两个表后：

1. 可以从一个节点拖线到另一个节点。
2. 系统创建 Join 边。
3. 打开 Join 配置弹窗。
4. 用户选择关联方式和关联字段。
5. 点击确定后生成 Join 关系。

**10.2 Join 配置弹窗**

**10.2.1 弹窗结构**

标题：配置关联关系

关联方式：

- Inner Join

- Left Join

- Right Join

- Full Join

关联条件：

左表字段 / 表达式 = 右表字段 / 表达式

高级能力：

- 启用 ID-Mapping 服务

按钮：

取消 / 确定

**10.2.2 Join 类型逻辑**

| **类型** | **逻辑** |
| --- | --- |
| Inner Join | 仅保留两边关联字段匹配成功的数据 |
| Left Join | 保留左表全部数据，右表无匹配时右表字段为空 |
| Right Join | 保留右表全部数据，左表无匹配时左表字段为空 |
| Full Join | 保留左右两边全部数据，无匹配一侧字段为空 |

**10.2.3 Join 条件规则**

1. 至少配置一个 Join 条件。
2. 每个条件必须包含左字段和右字段。
3. 默认操作符为 =。
4. Join 字段类型必须一致。
5. 如果字段类型不一致，允许用户使用表达式转换。
6. 多个 Join 条件之间默认为 AND。
7. 不支持空字段 Join。
8. 不支持聚合表达式 Join。

**10.2.4 字段类型不一致处理**

如果用户选择的左右字段类型不同：

页面提示：

当前关联字段类型不一致，可能导致关联失败。

你可以：

1. 更换字段；

2. 使用字段表达式进行类型转换；

3. 启用 ID-Mapping 服务。

用户点击 使用表达式 后：

type JoinExpression = {

};

示例：

CAST(user\_id AS STRING)

校验通过后，表达式结果作为 Join 字段。

**11. Union 多表合并**

**11.1 创建 Union**

用户在画布中选中多个表后，可以点击 合并 按钮创建 Union 关系。

**11.2 Union 配置面板**

Union 配置面板包含：

| **区域** | **说明** |
| --- | --- |
| 合并方式 | Union All / Union Distinct |
| 输出字段 | 最终数据集字段 |
| 字段映射 | 每张表字段映射到输出字段 |
| 类型校验 | 检查字段类型是否兼容 |
| 缺失字段处理 | 允许设置为空值或表达式 |

**11.3 Union 规则**

1. 至少选择两个表。
2. 每个输出字段必须至少有一个来源字段。
3. 同一个输出字段下，来源字段类型必须兼容。
4. 如果某表没有对应字段，可以设置为 NULL。
5. 如果类型不同，可使用表达式转换。
6. 输出字段名不可重复。
7. Union 后的字段顺序以输出字段列表为准。

**12. 数据筛选**

**12.1 筛选类型**

数据筛选分为两类：

| **类型** | **筛选对象** | **支持模式** | **用途** |
| --- | --- | --- | --- |
| 模型配置前筛选 | Join 或 Union 前的单表数据 | 直连、抽取 | 减少单表数据量，提高建模效率 |
| 模型配置后筛选 | Join 或 Union 后的数据模型 | 抽取 | 缩减最终数据集数据量，提高查询性能 |

**12.2 模型配置前筛选**

**12.2.1 入口**

用户点击表节点，在节点属性区域看到 数据筛选。

**12.2.2 筛选条件结构**

**12.2.3 直连模式规则**

1. 仅支持单表字段筛选。
2. 多个条件之间仅支持 AND。
3. 不支持模型配置后筛选。
4. 不支持复杂跨表表达式筛选。
5. 筛选实时作用于查询 SQL。

**12.2.4 抽取模式规则**

1. 支持分区筛选。
2. 支持非分区字段筛选。
3. 多个条件之间仅支持 AND。
4. 筛选作用于抽取任务。
5. 只有满足筛选条件的数据才会被同步到数据集。

**12.2.5 分区筛选规则**

当表存在分区字段时，展示 分区筛选。

分区筛选字段不可更换，只能使用系统识别出的分区字段。

支持操作符：

| **操作符** | **说明** |
| --- | --- |
| = | 指定单个分区 |
| in | 指定多个分区 |
| 无限制 | 不限制分区 |

分区筛选直接影响同步范围。

**12.2.6 非分区筛选规则**

非分区筛选可选择普通字段。

示例：

user\_id != 11111111

channel = 营销活动

amount > 100

**12.2.7 删除条件**

用户悬浮某个条件时，右侧显示 删除。

点击删除：

1. 删除当前条件。
2. 重新计算筛选表达式。
3. 如果删除后没有条件，则筛选配置为空。
4. 页面状态变为未保存。

**12.3 模型配置后筛选**

**12.3.1 入口**

抽取模式下，完成模型配置后，右上角显示 数据筛选 图标。

点击后打开模型后筛选弹窗。

**12.3.2 支持范围**

1. 仅抽取模式支持。
2. 筛选对象是 Join 或 Union 后的最终模型。
3. 支持模型输出字段。
4. 支持非聚合表达式结果筛选。
5. 不支持直连数据集。

**12.3.3 配置逻辑**

用户添加条件：

字段 操作符 值

多个条件默认 AND。

保存后：

1. 写入 DatasetModel.modelFilter。
2. 同步任务执行时，在最终模型结果上追加过滤条件。
3. 数据预览也需要应用该筛选条件。

**13.4 数据源字段与数据集字段**

**13.4.1 数据源字段**

数据源字段是实际从数据表中读取或导入的物理字段。

特点：

1. 来源于数据库表、SQL 输出或主题数据集。
2. 一般不可修改原字段名。
3. 删除字段会影响模型输出。
4. 不能直接覆盖数据源结构。

**13.4.2 数据集字段**

数据集字段是基于数据源字段加工后的逻辑字段。

特点：

1. 可以修改显示名。
2. 可以设置维度或指标。
3. 可以增加计算字段。
4. 可以配置格式、排序、可见性。
5. 是可视化查询实际使用的字段。

**13.5 添加计算字段**

**13.5.1 入口**

点击 添加字段。

打开弹窗：

字段名称

字段显示名

字段类型

字段表达式

字段说明

维度/指标

保存 / 取消

**13.5.2 表达式规则**

计算字段表达式可引用已有字段。

示例：

price \* quantity

CASE WHEN amount > 1000 THEN '高价值' ELSE '普通' END

**13.5.3 校验规则**

| **校验项** | **规则** |
| --- | --- |
| 字段名称 | 必填，唯一 |
| 显示名 | 必填，允许中文 |
| 表达式 | 必填 |
| 引用字段 | 必须存在 |
| 输出类型 | 必须可推断或用户指定 |
| 聚合表达式 | 数据集字段层默认不允许使用聚合表达式，除非系统明确支持 |
| 循环依赖 | 禁止计算字段互相循环引用 |

**13.5.4 保存逻辑**

点击保存：

1. 前端校验必填项。
2. 后端解析表达式。
3. 后端校验字段引用。
4. 后端推断字段类型。
5. 保存字段。
6. 字段加入字段列表。
7. 页面状态变为未发布或未保存。
8. 用户点击整体保存后才真正生效。

**13.6 修改维度指标**

用户可以将字段设置为：

| **类型** | **使用场景** |
| --- | --- |
| 维度 | 分类、分组、枚举、文本、时间 |
| 指标 | 数值、金额、次数、数量 |
| 时间 | 日期、时间戳 |
| ID | 用户 ID、设备 ID、订单 ID |

**13.6.1 自动识别规则**

| **字段类型** | **默认语义** |
| --- | --- |
| string | 维度 |
| date/datetime | 时间 |
| number/integer/decimal | 指标 |
| boolean | 维度 |
| 字段名包含 id | ID |
| 字段名包含 time/date | 时间 |

**13.6.2 指标默认聚合**

| **字段类型** | **默认聚合** |
| --- | --- |
| number | sum |
| integer | sum |
| decimal | sum |
| id | count\_distinct |
| string | count |
| date | none |

**13.7 字段排序**

字段排序支持两种模式：

1. 数据源顺序
   按数据源字段原始顺序展示。
2. 先维度后指标
   字段列表先展示维度，再展示指标，维度和指标内部保持当前排序。

用户切换排序方式后：

1. 前端重新排序字段列表。
2. 需要点击保存才持久化。
3. 如果用户手动拖拽排序，则排序模式变为 自定义排序。

**13.8 字段批量操作**

支持批量：

| **操作** | **逻辑** |
| --- | --- |
| 批量隐藏 | 选中字段在可视化查询中不可见 |
| 批量显示 | 恢复字段可见 |
| 批量设置为维度 | 字段语义改为维度 |
| 批量设置为指标 | 字段语义改为指标 |
| 批量删除计算字段 | 仅计算字段可批量删除 |
| 批量修改格式 | 同类型字段可批量设置格式 |

批量操作限制：

1. 原始字段不能批量删除。
2. 被引用字段不能隐藏或删除，除非允许仅隐藏展示但保留计算引用。
3. 不同字段类型不能批量设置同一格式。

如果选择定时同步：

1. 用户必须配置频率和时间。
2. 系统生成调度任务。
3. 到达时间后触发同步。

3. 时间点按升序展示。
4. 至少保留一个时间点。
5. 超过系统限制数量时提示。

**14.4 依赖配置**

**14.4.1 功能目标**

依赖配置用于确保当前数据集在上游数据准备完成后再同步。

典型逻辑：

到达当前数据集同步时间

→ 检查上游依赖任务状态

→ 全部就绪

→ 执行当前同步任务

→ 任一未就绪

→ 等待或跳过

**14.4.2 配置结构**

type DependencyConfig = {

enabled: boolean;

mode: "manual" | "system\_recommended";

dependencies: DependencyItem[];

waitPolicy: {

maxWaitHours: number;

checkIntervalMinutes: number;

onTimeout: "fail" | "skip";

};

};

type DependencyItem = {

id: string;

dependencyType: "dataset" | "partition\_sensor" | "external\_task";

upstreamDatasetId?: string;

upstreamTaskId?: string;

businessDateExpression?: string;

statusCheckRule: "success" | "partition\_ready";

};

**14.4.3 系统推荐依赖**

对于 LAS 分区表：

1. 用户在模型配置中选择了带分区的表。
2. 用户配置了分区筛选。
3. 系统自动识别分区字段。
4. 在同步设置的依赖配置中展示推荐依赖。
5. 用户可以一键启用。

系统推荐依赖运行逻辑：

调度任务被唤醒

→ Sensor 每 5 分钟检测一次分区是否生成

→ 分区存在

→ 当前同步任务启动

→ 超过最大等待时间

→ Sensor 失败

→ 当前同步任务失败或跳过

默认建议：

waitPolicy = {

maxWaitHours: 50,

checkIntervalMinutes: 5,

onTimeout: "fail"

};

**14.4.4 创建后限制**

依赖配置属于强调度配置，部分场景仅支持创建时配置。

如果数据集创建后不允许修改依赖配置：

1. 页面展示只读。
2. 编辑按钮不展示。
3. 提示：依赖配置仅支持在数据集创建时设置，创建完成后不可修改。

**17.7 关联数据集权限继承**

关联数据集 X 由数据集 A 和数据集 B 生成。

查询规则：

1. 用户在可视化查询中查询 X，需要拥有 X 的资源权限。
2. 实际可见行列仍受 A、B 原始行列权限控制。
3. 如果用户没有 A 的某些列权限，则 X 中对应列不可见。
4. 如果用户没有 B 的某些行权限，则 Join 后相关数据也不可见。
5. 仪表盘查看 X 生成的图表时，用户需要仪表盘权限，同时仍需要 A、B 的行列权限。

**23. 校验规则汇总**

**23.1 数据集名称**

| **规则** | **说明** |
| --- | --- |
| 必填 | 不能为空 |
| 长度 | 1 到 64 个字符 |
| 唯一 | 当前项目内唯一 |
| 特殊字符 | 不允许只包含空格，不允许控制字符 |

**23.2 模型节点**

| **规则** | **说明** |
| --- | --- |
| 至少一个节点 | 模型不能为空 |
| 节点别名唯一 | 同一模型内不可重复 |
| 字段至少一个 | 每个输出节点至少保留一个字段 |
| 权限有效 | 保存时重新检查权限 |

**23.3 Join**

| **规则** | **说明** |
| --- | --- |
| 至少一个条件 | 每条 Join 边必须配置条件 |
| 字段类型兼容 | 不兼容需表达式转换 |
| 不允许空字段 | 两边字段都必填 |
| 多条件 AND | 默认且关系 |

**23.4 Union**

| **规则** | **说明** |
| --- | --- |
| 至少两个节点 | 单表不能 Union |
| 输出字段唯一 | 输出字段名不可重复 |
| 映射类型兼容 | 不兼容需转换 |
| 缺失字段可置 NULL | 但需用户确认 |

**23.5 筛选**

| **规则** | **说明** |
| --- | --- |
| 字段必选 | 每个条件必须选择字段 |
| 操作符必选 | 每个条件必须选择操作符 |
| 值按操作符校验 | in 需要数组，between 需要起止值 |
| 分区字段不可更换 | 分区筛选字段固定 |
| 直连不支持模型后筛选 | 入口隐藏 |

**23.6 字段配置**

| **规则** | **说明** |
| --- | --- |
| 字段名唯一 | 数据集内唯一 |
| 表达式合法 | 后端解析 |
| 禁止循环依赖 | 计算字段不能互相循环 |
| 被引用字段不可删除 | 需先解除引用 |

**23.7 同步配置**

| **规则** | **说明** |
| --- | --- |
| 抽取数据集必须配置 | 直连不展示 |
| 定时同步必须有时间 | 手动同步除外 |
| 依赖任务必须可访问 | 否则不可保存 |
| 运行参数必须白名单 | 非白名单参数拒绝 |
| 性能设置保存后不可修改 | 页面需提示 |

**24. 异常与边界场景**

**24.1 数据源结构变化**

如果数据源字段被删除：

1. 数据集详情页显示异常状态。
2. 模型信息中标记缺失字段。
3. 可视化查询中引用该字段的图表报错。
4. 用户编辑数据集时，缺失字段标红。
5. 用户必须删除或替换字段后才能保存。

如果字段类型变化：

1. 系统标记字段类型不一致。
2. Join、筛选、计算字段可能失效。
3. 预览时提示具体错误。
4. 保存前必须重新确认字段类型。

**24.2 权限变化**

如果用户创建后失去数据源权限：

1. 数据集仍存在。
2. 当前用户不能编辑模型。
3. 预览或同步可能失败。
4. 页面提示：当前账号已失去部分数据源权限，请联系管理员。

**24.3 同步失败**

同步失败后：

1. 数据集状态显示 同步失败。
2. 同步状态页展示失败原因。
3. 提供 查看日志 和 重跑。
4. 如果失败与参数相关，展示建议调整运行参数。
5. 如果失败与依赖相关，展示上游依赖未就绪信息。

**24.4 主题数据集不可编辑**

用户打开主题数据集时：

1. 编辑按钮隐藏。
2. 删除、移动、复制隐藏。
3. 仅保留查看、预览、可视化查询。
4. 如果用户尝试通过接口修改，后端返回 403。

**24.5 大数据量关联**

当主题数据集或增长营销产品数据集作为右表参与关联时，如果数据量过大：

1. 保存前进行数据量预估。
2. 超过阈值时提示：当前右表数据量较大，可能导致查询缓慢或失败，建议增加筛选条件。
3. 允许用户继续保存，但需要二次确认。
4. 如果系统强限制，则禁止保存。

**25. 验收标准**

**25.1 新建普通数据集**

1. 用户可从已有数据连接创建数据集。
2. 用户只能看到有权限的数据连接和表。
3. 用户可拖拽表到画布。
4. 用户可选择字段。
5. 用户可配置 Join 和 Union。
6. 用户可配置自定义 SQL。
7. 用户可配置模型配置前筛选。
8. 抽取数据集可配置模型配置后筛选。
9. 用户可预览数据。
10. 保存后生成数据集，并能在数据集列表中看到。

**25.2 字段配置**

1. 用户可查看所有输出字段。
2. 用户可新增计算字段。
3. 表达式错误时不能保存。
4. 字段名重复时不能保存。
5. 用户可修改字段显示名。
6. 用户可切换维度和指标。
7. 用户可批量隐藏、显示字段。
8. 可视化查询中只展示可见字段。

**25.3 同步设置**

1. 直连数据集不展示同步设置。
2. 抽取数据集展示同步设置。
3. 用户可配置手动同步和定时同步。
4. 用户可配置依赖。
5. 用户可配置监控。
6. 用户可配置运行参数。
7. 保存后可触发同步。
8. 同步状态可查看任务历史、日志和结果。
9. 同步失败后可重跑。

**25.4 关联数据集**

1. 用户可创建关联数据集。
2. 左侧只展示有查看权限的数据集。
3. 存储方式不兼容时不可关联。
4. 用户可配置 Join 字段。
5. 字段类型不一致时可使用表达式处理。
6. 满足条件时可启用 ID-Mapping。
7. 保存后生成新的关联数据集。
8. 关联数据集可用于可视化查询。
9. 行列权限按原始数据集继承生效。

**25.5 主题数据集**

1. 已部署且有权限的主题数据集可展示。
2. CDP 群体数据集可导入。
3. CDP 标签数据集可作为字段分析。
4. 数据洞察 主题数据集可直接用于可视化查询。
5. 主题数据集不可编辑、删除、移动、复制。
6. 主题数据集可与自定义数据集创建关联数据集。
7. 无权限用户不能查看敏感字段或数据。

**25.6 可视化应用**

1. 数据集详情页可进入可视化查询。
2. 字段按字段配置展示。
3. 用户可基于普通数据集、关联数据集、主题数据集创建图表。
4. 图表可保存为分析。
5. 图表可保存到仪表盘。
6. 数据集字段变化后，相关图表能识别异常并提示用户修复。
